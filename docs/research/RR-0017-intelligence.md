# RR-0017 — Разведка, промышленный шпионаж, контрразведка и дезинформация

> Пометки: **[Факт]** — подтверждено источником; **[Предп.]** — предположение; **[Предл.]** — предложение. Предложения не утверждены. В силе: #19, #28, #68, #203, #208, #222, #223, #256, #259, #260. Заменяет запланированную «Разведку» волны 3 (CONCEPT_EXPANSION_ANALYSIS). Политические системы — RR-0015.

## Вопрос исследования
Как дать игроку и ИИ разведку (текущее положение дел, промышленный шпионаж, контрразведка, дезинформация) по #259/#260 так, чтобы она была ресурсом решений с неопределённостью, не отменяла НИОКР, не давала микроменеджмента и сохраняла детерминизм L1/L2?

## Краткий вывод
1. [Предл.] Одно новое состояние: разреженный запас `Net[o,t]` — сеть наблюдателя `o` в стране `t` (размер `N`, возраст `A`, `exposure`-счётчик не нужен). `eff = N·maturity(A)`.
2. [Предл.] Рост: `growth = sat(fund + aff)·(1 − k·ci_eff)` — контрразведка режет и платный, и идейный рост (#259: идеология даёт рост без денег).
3. [Факт, #260] Раскрытие — ежемесячная вероятность от активности и `ci_eff`; RNG из потока по ключу сети в слое событий (P05), L1/L2 сохранены. Итог — событие «скандал» (#256): сеть потеряна, `support` падает; санкции и рост `T` делает торговля/мир, INT в `T` не пишет (#222 не меняется).
4. [Факт, #260] В v1: наблюдение, контрразведка, рост сети, разведка ИИ теми же рычагами (ИИ видит диапазоны, A34c), промышленный шпионаж, дезинформация. Надёжность — в процентах.
5. [Предл.] Выходы: (a) `intel_conf` по слою 3 — на узел/ребро; (b) `steal` в KNW: `min(cap, own + max(licence, steal))`, без культуры и оснастки; (c) `dis` — искажает наблюдение. Слой 3 существует без E3 и N14 (#203, RR-0008): v1 зависит от режимов данных графа и `aff`.
6. [Факт, #260] Бюджет — седьмая доля `security` (сети + контрразведка); `ci_eff = sat(ci_budget/GDP)`.
7. [Предл.] Милестоун КНР/Франции (#255/#257) даёт `Alignment`, `Regime`, `support`; N14 (скрытие/обнаружение) остаётся FUTURE и для v1 не нужен.

### 2. Модель [Предл.]
Месячный тик. **Хранение:** разреженное, только активные `Net[o,t]`. Масштаб: 65 стран (≈4,2 тыс. направленных пар) и до 200 акторов (≈40 тыс.); активных, по [Предп.], 5–20% ⇒ ≤ 8 тыс. записей; обновление O(активных), ≪ 0,1 мс [Предп.] — проверить в Lab.

**Переменные, единицы, пределы** (все — фикс. точка, L2):
| Переменная | Единица | Пределы / замечание |
|---|---|---|
| `N` | доля ёмкости цели | [0,1] |
| `A` | месяцы | ≥0, `maturity` насыщается при `A_mat` ≈ 60–120 [Предп.] |
| `maturity(A)` | — | `m0 + (1−m0)·min(1,A/A_mat)`, `m0 = 0,1–0,2` (калибровка) |
| `fund` | `sat(spend_net/GDP_t_ref)` | [0,1], из доли `security` бюджета `o` |
| `aff` | — | [0,1]: `opp_share_t(ideology_o) × legit_patron_o × openness_t`; группы населения — позже, через тот же интерфейс. Читает `Regime`/`Alignment` (RR-0015) |
| `ci_eff[t]` | — | `sat(ci_budget/GDP_t)`, [0,1]; `Regime.coercion` добавляет, но снижает `legitimacy` (интерфейс к RR-0015) |
| `k` | — | (0,1], калибровка |
| `p_expose` | 1/мес | [0, p_max], p_max ≈ 0,15 [Предп.] |
| `dis[o,t]` | — | [0,1] |
| `bias` | доля | ±b, b ≈ 0,25 [Предп.] |
| `intel_conf` | — | [0,1]; игроку — в процентах |

**Рост:** `dN = r·(1−N)·sat(fund + aff)·(1 − k·ci_eff) − d·N`. Критерий (Lab): при `ci_eff = 1` равновесный `N*` и скорость роста падают ≥ 50% и для чисто платной (`aff=0`), и для чисто идейной (`fund=0`) сети; при `ci_eff = 0` — полная скорость. Деньги покупают размер, не возраст.

**Бюджет.** Седьмая доля `security` (#260): сети (`spend_net`) и `ci_budget` делят одну долю — это реальный выбор «шпионить или защищаться».

**Выходы:**
- **a) Наблюдение.** Классификация — **на узел/ребро**, не один скаляр (RR-0008 §4): у закрытого ребра есть `reveal`; `visible(observer, actor, node, layer)` (I08) для слоя 3 = `intel_conf[o,t,node] ≥ порога`, где `intel_conf = conf(clean sources)·sens(node)` (источники и порча — ниже); `sens` — трудность узла (RESTRICTED < CLOSED). Слои 1–2 видны без разведки; слой 3 существует по данным графа (#203, RR-0008), без E3/N14. Оценка — диапазон `[x(1−w), x(1+w)]` со смещением `bias`, `w = 1 − intel_conf`. ИИ получает тот же диапазон (A34c), не истину.
- **Источники и достоверность (#261).** `sources = clamp(floor(S_max·N), 0, S_max)`, `S_max = 6` [Предп.] — целое число независимых источников (растёт с размером сети). Качество одного источника `q = maturity(A)`. Достоверность чистого наблюдения `conf = 1 − (1−q)^s` (источники независимы), в UI — `round(100·conf)%` и число источников: «3 независимых источника, достоверность ~70%» (при `q = 0,33`, `s = 3`). Слова STATE_WORDS — подпись по порогам. Ограничение `intel_conf ≤ conf` в формуле выше заменяет `eff`: `intel_conf[o,t,node] = conf(clean)·sens(node)`.
- **Порча источников.** Дезинформация (и обращённая сеть) портит `c = round(φ·s)` источников, `φ = dis·κ`. Если чистых источников `s−c ≥ 2`, перекрёстная проверка находит расхождение: порченые отбрасываются, `bias = 0`, `conf` считается по чистым, игрок видит «расхождение источников». Если `s−c < 2` — перекрёстной проверки нет, `bias_eff = b·c/s`, `conf` не снижается (ложная уверенность — цена малой сети). Целые числа, без RNG.
- **b) Промышленный шпионаж.** Канал `steal[o,t,node]` в KNW. **Цель (#261):** сеть хранит `dir[o,t]` — сектор или кластер, выбранный владельцем (ручка игрока и ИИ; смена направления — раз в N мес. и сбрасывает 50% `A` как переориентация [Предп.]). Скорость кражи идёт на узлы `dir`; на остальные — утечка `leak = 0,1` от скорости [Предп.] (почти ноль, но не нуль: «случайно попавшиеся» документы). Новое знание узла: `K_new = min(cap, own + max(licence, steal))` (лицензия и кража не складываются; побеждает лучший канал). Условия: (1) у `o` есть **все** прямые предшественники узла (иначе не усваивается); (2) скорость ≤ `ε·eff·sector_cap(o, сектор узла)` — масштаб по ёмкости сектора наблюдателя; ε ≈ 0,2–0,3 [Предп.]; (3) не обходит `k_diff` (трудность диффузии узла остаётся множителем), `access` и экспортный контроль, если узел не доступен по `allowed` — шпионаж идёт мимо лицензии, но **не** мимо `allowed` по физической осуществимости (проверка гейта сохраняется, где применима); (4) знание без культуры и оснастки — ловушка культуры (A43.8) действует; (5) цена — деньги и риск раскрытия, растущий с `activity`. Лицензионный `support`-платёж здесь не применяется (отдельное правило RR-0014/RR-0012 не опирается на источник — убрано).
- **c) Дезинформация, два пути (#261).** **(а) Отдельная операция** `dis[o,t]` — бюджет в долях `security`: портит долю `φ = dis·κ` источников цели (см. выше), `bias` оценок ИИ в пределах ±b. **(б) Обращение обнаруженной сети.** Когда месячный бросок обнаружения (`intel.expose`, #260) сработал против сети `o` в `t`, у `t` два варианта: *разоблачить* (событие `scandal`, ниже) или *обратить*: `Net.mode = turned`. Обращённая сеть продолжает работать: все её источники у `o` портятся (`φ = 1` для вклада этой сети), шпионаж по ней идёт с `taint`, `o` по-прежнему платит. Теория: операции Double-Cross 1940-х, Farewell — [Факт, не перепроверен для Double-Cross]; Farewell — источники выше. **Правило ИИ (детерминированное)**: обращать, если `value_turn = eff ≥ порога` и у `o` менее 2 других независимых источников в `t` (обращение трудно проверить) и у `t` есть бюджет `dis > 0`, иначе разоблачать; игрок выбирает сам. Риск для `t`: обращённая сеть раскрывается владельцем как обращённая, если у `o` есть ≥ 2 чистых источника в той же цели — расхождение находится автоматически (см. «Порча источников»); при `s−c < 2` — ежемесячная вероятность `p_detect_turn = 0,05` [Предп.] (поток `intel.turn` по ключу `(o,t)`, слой событий). Раскрытие обращения → `scandal` в обратную сторону: сеть `o` теряется, `t` получает `support` и `o` — потерю. Истинное состояние мира не меняется. **`taint`** (заражение краденого узла, Farewell) — FUTURE и только как **операция дезинформации**, зависящая от `ci_eff` и `exposure` цели: детерминированный штраф надёжности первых серий ≤ 0,3, снимаемый испытаниями.

**Контрразведка и раскрытие.** `p_expose = clamp(a·activity·eff·f(ci_eff), 0, p_max)`; `activity` = steal + dis (наблюдение пассивно, малый вклад). Бросок раз в месяц на сеть из потока `intel.expose` по ключу `(o, t)` (счётчик-RNG, ключи сущностей, реестр P05 RR-0011; не месячный хэш). При успехе у цели выбор «разоблачить / обратить» (см. 2c); при разоблачении — событие `scandal(o,t)` (#256): потеря частичная, но тяжёлая: `N ·= f_N`, `A ·= f_A`, `f_N = 0,25`, `f_A = 0,2` [Предп.] (уцелевшие сохраняют сниженную зрелость, `maturity` падает к `m0`), `support_o −= s`. Обоснование [Факт, не перепроверен]: Гузенко (Оттава, 1945) вскрыл канадскую сеть, но не всю советскую; после Фукса (1950) цепочка Голд–Грингласс–Розенберги была вскрыта, часть связей уцелела; Кембриджская пятёрка пережила бегство Берджесса и Маклина (1951) частично (Филби — до 1963). Историческая доля потерь по ним — оценка, не расчёт: калибровать в Lab; торговля/мир по событию вводит санкции и `T↑` (WLD пишет, INT нет, #222). Игроку показывается «риск раскрытия» полосой, не числом. **Ложный след** (FUTURE): скандал приписывается `c ≠ o`, зависит от `attr_conf` цели.

**Писатель `support`.** Раскрытие даёт запись в `support` одной строкой merge в фиксированном порядке (по образцу A33d/D23, колонка K02) [Предл.]; нужна новая строка карты A-INT-support (ниже).

**Детерминизм.** RNG — только в слое событий (#28: в слоях способности и изделия нет); `steal`, `dis`, `taint` детерминированы. Поток `intel.expose` заносится в P05.

**Надёжность как процент и STATE_WORDS (#68).** [Предл.] Решением #260 в v1 разведка есть, значит снимается условие #68 «уверенность не показывается до разведки». Игрок видит `intel_conf` **в процентах** (например «≈ 62%»), слова-шкала STATE_WORDS («достоверно ≥ 80%, вероятно 50–80, по слухам 20–50, нет данных < 20») остаются подписью и порогами. Изменить STATE_WORDS: ссылка на «0–1» → проценты, слово — вспомогательное. Правка в зоне game-designer/Orchestrator (OPEN).

### 3. Ценность и режимы отказа
Выбор: платить за сеть или ждать идеологической базы (медленно, зависит от `Regime`, раскола СССР–КНР, #256); рискованная кража против роста `p_expose`; доля `security` между сетями и `ci_budget`; дезинформация против ИИ-соперника. Ручек ≤ 3 на пару: бюджет сети, классы целей (не отдельные узлы), `dis` (#19).
- **Слишком сильна:** Lab «R&D + espionage» против «R&D» (при равном общем бюджете): у `R&D + espionage` время до серии по краденому узлу ≥ 70% пути собственного НИОКР, а выигрыш по `K` и культуре = 0 [Предп., порог калибруется].
- **Невидима:** у каждой строки наблюдения `why` («нет данных: сеть молода»); ни одно скрытое значение не показано точным.
- **Микроменеджмент:** агентов и миссий по одной нет.

**Lab-тесты** (≥ 50 сидов, 95% ДИ по среднему; проходит, если нижняя граница ДИ выполняет критерий):
| Тест | Метрика | Правило |
|---|---|---|
| T1 рост | `N*` и скорость при `ci_eff` 0 и 1, `fund` и `aff` по отдельности | падение ≥ 50% в обоих режимах |
| T2 «шпионить до порога» | кража на `p_expose` чуть ниже порога | сеть всё равно теряется с частотой ≥ ожидаемой от `p_expose` (±ДИ); нет «безопасного» уровня активности |
| T3 бесплатные `aff`-сети во многих целях | число целей `n` при `fund = 0`, `aff` высок | суммарный эффект на цель убывает; суммарная доля `security` на ci целей растёт; нет доминирования «aff везде» |
| T4 цель с `ci = 0` | `N*`, время до эффективной сети | `N*` растёт, но `p_expose` остаётся > 0 при активности; сеть не мгновенна (`maturity`) |
