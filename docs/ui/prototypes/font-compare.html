7. Чек-листы

Я не могу открыть страницу в браузере из своей среды: рендер не проверен. Поля ☐ заполняет владелец при просмотре. «Предварительно» — ожидания из описаний шрифтов, не наблюдения. [Предп.]

OpenGost Type B (OFL-1.1)

  • Покрытие кириллицы: все 33 буквы, Ёё, № « » — предварительно: ГОСТ-шрифт, кириллица основная; проверить Ё, №, кавычки, ± ° ≈ ≤ ≥ −
  • Латиница D/P/S/O и цифры 0 / O, 1 / l / I различимы (раздел 4)
  • Наклон: Type B по ГОСТ 2.304 — курсив 75°; приемлем ли наклон для всего UI-заголовочного набора, включая кнопки? проверить на странице
  • Кернинг/пары: заметные дыры в «ТРД», «АТ», «Ку», «ЛУ», «1:50», «№ 17»; межстрочные пропуски
  • Читаемость 14 px (100%) и 18 px (125%): засоры в «ш/щ/ы/ё», тонкость штриха
  • Ширина 24 знаков в кнопке: укладывается ли «ЩЩЩ…», «WWW…» (раздел 2)
  • Стрелки/значки ▲ ■ ● ✕ ⤢ → подставляются другим шрифтом и выглядят чужеродно?
  • Встраивание: файл в fonts/, лицензия OFL приложена, имя Reserved Font Name соблюдено проверить в OFL.txt рядом с файлом

Jura (SIL OFL, Google Fonts)

  • Покрытие кириллицы: Google Fonts публикует подмножества cyrillic и cyrillic-ext предварительно; проверить Ё, №, « », ± ° ≈ ≤ ≥ −
  • Латиница D/P/S/O и цифры 0 / O, 1 / l / I различимы (раздел 4)
  • Гарнитура геометрическая, без наклона: «чертёжность» ощущается без ГОСТ-курсива? Достаточно ли похожа на техническое письмо?
  • Кернинг/пары: «ТРД», «АТ», «Ку», «1:50», «№ 17»; не слипаются ли «rn», «ы»
  • Читаемость 14 px: тонкий штрих на светлом (бумага) и светлое на синем; вес 400 против 500
  • Ширина 24 знаков в кнопке: укладывается ли «ЩЩЩ…», «WWW…» (раздел 2)
  • Стрелки/значки ▲ ■ ● ✕ ⤢ → подставляются другим шрифтом и выглядят чужеродно?
  • Встраивание в Godot: нужен TTF (загрузить с Google Fonts / GitHub, OFL.txt приложить); веб-подключение на этой странице не годится для игры

8. Как получить файл OpenGost Type B

[Факт] Файл получен: релиз v0.4.0, https://codeberg.org/nadevko/opengostfonts/releases/download/v0.4.0/OpenGostFonts-0.4.0.zip (2026-11-03), OpenGostTypeB-Regular.ttf и LICENSE (SIL OFL 1.1, Reserved Font Name «OpenGost Type B»). На опубликованной странице файл лежит в fonts/ вместе с fonts/OFL.txt; в репозиторий не добавлен.

Прежняя заметка: репозиторий https://codeberg.org/nadevko/opengostfonts (проверено 2026-11-03): готовых шрифтов в дереве нет (src, scripts, GNUmakefile, LICENSE), в README указано, что собранные шрифты появляются в dist/, пример цели — make dist/OpenGostTypeA-Regular.ttf. Тип B по аналогии: make dist/OpenGostTypeB-Regular.ttf [Предп.]. Release-ассеты и текст лицензии со страницы получить не удалось; бинарные файлы моими инструментами не скачиваются.

Шаги. 1) Склонировать репозиторий, выполнить make dist/OpenGostTypeB-Regular.ttf (нужны зависимости из README), либо взять готовый файл из вкладки Releases, либо из пакета дистрибутива (openSUSE, ALT Linux — по именам из drafting-kit, названия пакетов не проверены [Предп.]). 2) Положить файл в docs/ui/prototypes/fonts/OpenGostTypeB-Regular.ttf, рядом — текст лицензии (OFL.txt) и убедиться, что в нём OFL-1.1. 3) Перезагрузить страницу: баннер вверху покажет «встроен». Если путь иной, имя семейства OGB в @font-face тоже подхватит установленный локально «OpenGost Type B».

Выбор шрифта, лицензия и добавление файла в репозиторий — решение владельца (ADR-0009: OFL требует одобрения).
