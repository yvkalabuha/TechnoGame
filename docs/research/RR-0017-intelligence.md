## Краткий вывод
1. [Предл.] Основное состояние — разреженный запас `Net[o,t]` (размер `N`, возраст `A`, `dir`, `mode`). Единая ёмкость сети: `eff = N·maturity(A)`. Достоверность `conf` — только производная для показа игроку и ширины диапазона; в механику (кража, `hazard`, обращение) входит одна `eff`.
2. [Предл.] Рост: `growth = sat(fund + aff)·(1 − k·ci_eff)`; в v1 без RR-0021 `aff = 0`, модель проверяется на `fund`.
3. [Предл.] Цель `t` — активный контролирующий актор (#349/#350). Правила раскола, поглощения и передачи контроля — §2.
4. [Предл.] Бюджет — национальный: ≤3 приоритетные цели на актора (как #214), остальные пары — автоматический «фон» детерминированным правилом.
5. [Предл.] Раскрытие по ADR-0021: INT пишет `hazard[o,t]`, `StochasticEventSystem` бросает, INT применяет последствия (`N`, `A`) в merge D−1. Событие не пишет `support` и `T`; реакция политики и санкции — за владельцами (RR-0021, AI/TRD).
6. [Предл.] `steal` реализуется школой инженерии вора (#322): знание сокращает путь, но не копирует изделие.
7. [Предл. / вопрос владельцу] Этапность v1 (Q17), исторические разоблачения как детерминированные события (Q18/Q30) — не решаются здесь.

### 2. Модель [Предл.]
**Каденция (ADR-0019 r3).** Тик — сутки. Годовые ставки (`r`, `d`, расходы) режутся по дням (#345): `x_day = x_year/365` в фикс. точке, остаток накапливается. Бросок раскрытия — раз в месяц, в день `D(o,t) = hash(o,t) mod 30` (разнесение, как у ИИ #344); бросает `StochasticEventSystem`, ключ счётчик-RNG `(seed, tick=day, stream=intel.expose, (o,t))`, не месячный хэш. Решения ИИ (`dir`, приоритеты, разоблачить/обратить) — в недельном слоте ИИ (#344). Результат события применяется в merge D−1 (#347): `N`, `A`, `mode`.

**Хранение.** Разреженно, канонический порядок обхода — по `(o,t)` по возрастанию (для хэша сохранения, ADR-0013, L2). Масштаб: ≤200 акторов-наблюдателей × 65 целей = 13 тыс. направленных пар; активных 5–20% [Предп.] = 0,65–2,6 тыс.; обновление O(активных) в сутки. Строка INT в бюджет тика RR-0011 §6 — предложение: ≤ 2% тика [Предп.], измерить в Lab (T7). Новые акторы — предаллоцированные строки с флагом `active` (ADR-0020 r3).

**Цель и жизненный цикл (#349/#350).** `t` — только активный контролирующий актор региона; страны без правительства, зоны и сектора (Берлин) сами не цели. `GDP_t` — выпуск регионов под контролем `t` (одно определение для `fund` и `ci_eff`).
- *Раскол* (`create_polity`, FRG/GDR 1949): сеть наблюдателя `o` на `t` делится `Apportion` по долям контролируемой экономики регионов; `A` сохраняется, `N` пересчитывается на ёмкость новой цели.
- *Поглощение* `t_b → t_a`: `N = (N_a·C_a + N_b·C_b)/(C_a + C_b)`, `A` — тем же взвешиванием, `C` — `GDP` контролируемых регионов; если `o` — сам `t_a`, сеть `t_b` исчезает.
- *Передача контроля* регионов (`transfer_controller`): доля сети по `Apportion` уходит к новому контролёру, `A` сохраняется.
- *Цель неактивна* (нет контролёра): `Net` замораживается, рост и бросок отключены; возобновляется при активации.
- *`o` неактивен или поглощён*: записи удаляются; ИИ-сети не наследуются автоматически.
Изменения применяются в merge D−1, как события ADR-0020.

**Переменные** (фикс. точка, L2):
| Переменная | Единица | Определение / пределы |
|---|---|---|
| `N` | доля ёмкости цели | [0,1] |
| `A` | сутки | ≥0; насыщение `A_mat` ≈ 60–120 мес. [Предп.] |
| `maturity(A)` | — | `m0 + (1−m0)·min(1, A/A_mat)`, `m0` = 0,1–0,2 |
| `eff` | — | `N·maturity(A)`; **единственная** мера мощи сети |
| `fund` | — | `sat(spend_net/GDP_t)`, [0,1] |
| `aff` | — | [0,1]; **0 до RR-0021**. После: `opp_share_t·legit_patron_o·openness_t` по снимку POL, лаг 1 сутки |
| `ci_eff[t]` | — | `sat(ci_budget/GDP_t)`, [0,1] |
| `r`, `d` | 1/год | рост 0,4–0,8, убыль 0,05–0,15 [Предп., калибровка] |
| `k` | — | (0,1] |
| `act_*` | доли бюджета | `act_steal`, `act_dis` — доли разведбюджета `o` (безразмерные, [0,1]); `act_obs = 0,1` — фоновая активность наблюдения |
| `hazard[o,t]` | 1/мес | `clamp(a0·eff·(act_obs + act_steal + act_dis)·(1 + g·ci_eff), 0, p_max)`; `a0`, `g` [Предп.], `p_max` ≈ 0,15 |
| `φ` | — | `min(1, dis·κ)` (κ ≤ 1 не гарантирован, поэтому зажим) |
| `leak` | — | 0,1 [Предп.] |

Наблюдение даёт ненулевой `hazard` (через `act_obs`): «безопасного» режима нет, но он низок. `dis` — доля разведбюджета, одна размерность с `act_steal`; единицы `steal` — тоже доля бюджета.

**Рост:** `dN = r·(1−N)·sat(fund + aff)·(1 − k·ci_eff) − d·N` (годовые ставки, нарезка по дням). Критерий: при `ci_eff = 1` равновесный `N*` и скорость падают ≥ 50% для режима `aff` (после RR-0021) и для чисто платной сети (`aff = 0`); при `ci_eff = 0` — полная скорость.

**Бюджет.** [Факт, #260] Седьмая доля `security`; [Предл.] она делится внутри на `spend_net` (сети и `dis`) и `ci_budget`. Конфликт с A10/E1 (шесть долей, нет `security`) — вынесен в OPEN. Ручки игрока: доля `security`; на нём — **≤3 приоритетные цели** и доля `dis`. Остальные пары получают «фон» — детерминированное правило по угрозе (`T`, блок, соседство) и интересу (торговая и научная связь), минимальный `fund`, без своих ручек ИИ/игрока. Число ручек игрока ограничено (≤3 цели + 2–3 национальных), а не растёт с числом пар (#19). INT←ECO: чтение `GDP`, долей бюджета — новая строка карты (OPEN).

**Выходы:**
- **a) Наблюдение (слой 3).** Классификация — на узел/ребро (RR-0008 §4): `visible(observer, actor, node, layer)` (I08) = `intel_conf[o,t,node] ≥ порога`, `intel_conf = conf·sens(node)`; `sens` — трудность узла (RESTRICTED 1,0; CLOSED 0,6 [Предп.]); порог 0,3 [Предп.]. Слои 1–2 видны без разведки. Оценка — диапазон `[x(1−w), x(1+w)]` со смещением `bias`, `w = max(w_min, 1 − intel_conf)`, `w_min = 0,1` [Предп.] (точное значение не показывается никогда). ИИ получает тот же диапазон (A34c); новых классов отказа в таксономии G09 не вводится: ИИ видит диапазоны, причина (`why`) — только в UI. `comm` (RR-0019) на видимость слоя 3 **не умножается** (двойной учёт, D01): видимость определяют только `intel_conf` и `reveal`.
- **Источники и достоверность (#261).** `s = clamp(floor(S_max·N), 0, S_max)`, `S_max = 6` [Предп.]; `q = maturity(A)`; `conf = 1 − (1−q)^s`; в UI — «3 независимых источника, достоверность ~70%». При `s = 0` `why`: «нет данных: сеть слишком мала» (не «молода»). Слова STATE_WORDS — подпись по порогам.
- **Порча источников (операция `dis` цели против `o`).** `c = floor(φ·s + ½)` в целочисленной фикс. точке: `c = (2·φ_fx·s + ONE) / (2·ONE)`, зажим `[0, s]`. Если `s − c ≥ 2` — рассинхрон находится: порченые отбрасываются, `bias = 0`, `conf` по чистым; игрок видит «расхождение источников» [Предл., игровая абстракция: порченые определяются детерминированным правилом по индексу источника, не оракулом]. Если `s − c < 2` — `bias_eff = b·c/s`, `conf` не снижается («ложная уверенность — цена малой сети»). Без RNG. Направление: `dis[t→o]` — операция цели `t` против сети `o`; `dis[o→t]` — собственная операция `o` против ИИ цели; обозначения различаются.
- **b) Промышленный шпионаж (после M2, Q17).** Канал `steal[o,t,node]` — ещё один канал ускорения знания узла; он не копирует изделие. Цель — `dir[o,t]`, по умолчанию кластеры приоритета из #214; ручная смена — только чтобы отклониться (раз в N мес., сброс 50% `A` [Предп.]). На узлы вне `dir` — `leak = 0,1` скорости. Скорость `ε·eff·sector_cap(o, сектор)`, ε ≈ 0,2–0,3 [Предп.]. Условия: все прямые предшественники узла у `o` есть; трудность диффузии `k_diff` остаётся множителем; экспортный контроль (RR-0014) обходится, лицензия и кража не складываются (побеждает лучший канал, `max`); ссылка на `allowed` как на гейт убрана (это политический гейт товаров, RR-0014 T1). **Реализация (#322):** краденое знание реализуется инженерной школой вора, а не школой жертвы; изделие — другое (Ту-144), знание без культуры и оснастки (ловушка A43.8). Точная привязка к `prog`/`known` (RR-0008) и к каналу `access` (RR-0014 §4): OPEN; непрерывные `own`/`cap` не вводятся, пока не привязаны.
- **c) Дезинформация (после M3).** (а) Операция `dis` портит долю `φ` источников. (б) Обращение раскрытой сети: у цели при срабатывании броска два варианта — разоблачить или обратить (`Net.mode = turned`). Обращённая сеть: вклад в `conf` — порченый (`φ = 1`), шпионаж с `taint`, `o` продолжает платить. Один `Net` на пару — «другие независимые источники» не учитываются; правило ИИ упрощено: обращать, если `eff ≥ порога` и у цели `dis > 0`, иначе разоблачать. Раскрытие обращения — `p_detect_turn = 0,05/мес` [Предп.], поток `intel.turn`, ключ `(o,t)`, тот же механизм ADR-0021. `taint` — FUTURE, зависит от `ci_eff` цели (счётчика `exposure` нет), штраф надёжности первых серий ≤ 0,3, снимается испытаниями.

**Раскрытие и скандал (ADR-0021).** INT пишет `hazard[o,t]`; `StochasticEventSystem` бросает по ключу выше и порождает `scandal(o,t)`. Применяет **INT** (владелец `Net`) в merge D−1: `N ·= f_N`, `A ·= f_A`, `f_N = 0,25`, `f_A = 0,2` [Предп.]; зрелость падает по формуле `maturity` (не обязательно до `m0`). Событие **не пишет `support`**: политическая реакция (потеря/приобретение `support`, `legitimacy`) — правило владельца POL по флагу `scandal_fired` в снимке, предлагается в RR-0021; санкции и рост `T` — AI/TRD и WLD по своим законам (#222: INT в `T` не пишет). Историческое обоснование потерь — [Предп.] (Гузенко, Фукс, Берджесс–Маклин не перепроверены), калибровать в Lab. Игроку — «риск раскрытия» полосой.

**Детерминизм.** RNG — только в `StochasticEventSystem` (ключи `(seed, day, stream, (o,t))`, поток в P05); `steal`, `dis`, `taint`, рост детерминированы. Новые сущности меняют формат сохранения/хэш: ADR-0013, golden — событие erratum.

**Округление.** Все доли — Fx фикс. точка; `floor` для `s` (целое), `round-half-up` целочисленно для `c`; нарезка годовых ставок по дням с накоплением остатка (без потерь в сумме за год); `(1−q)^s` — целочисленное возведение (s ≤ 6); без `e^x`.

**Скрытность и STATE_WORDS (#68).** [Предл.] По #260 разведка есть в v1, условие #68 снимается; игроку — проценты `intel_conf`, слова — подпись. Правка STATE_WORDS — за game-designer/Orchestrator.

### 3. Ценность и режимы отказа
Выбор: платить за сеть или ждать идеологической базы (после RR-0021); рискованная кража против `hazard`; доля `security` между сетями и `ci_budget`; дезинформация против ИИ. Ручки — бюджет, ≤3 цели, `dis`.
- **Слишком сильна:** гипотеза (HYP, не критерий приёмки): «R&D + шпионаж» против «R&D» при равном бюджете даёт время до серии по краденому узлу ≥ ~70% пути собственного НИОКР, выигрыш по `K` и культуре = 0. Порог не имеет расчётного источника [Предп.]; проверяется в Lab, калибровка — отдельная HYP.
- **Невидима:** у каждой строки наблюдения `why`; точных скрытых значений нет.
- **Микроменеджмент:** агентов и миссий нет; пары вне приоритета — автоматом.

**Lab-тесты.** T1, T4 — детерминированные кривые по параметрам (сиды не нужны). T2, T3, T6 — ≥50 сидов, 95% ДИ по среднему, нижняя граница ДИ выполняет критерий.
