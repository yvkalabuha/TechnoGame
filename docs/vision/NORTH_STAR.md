# Главная идея (north star) — коротко для каждого старта и после сжатия контекста

- Игра: симулятор цивилизации 1945–2100, наука и технологии в центре; игрок — государство: темы исследований выбирает прямо, через институты (один институт — одна тема, очередь, ускорение за деньги, #561); остальное — бюджет, производство, лицензии, разведка, политика. Цель партии — военное превосходство («воздушная мощь», #565), затем давление на других (`docs/vision/PROJECT_VISION.md`).
- Главный урок партии 2026-11-24 (#470): у игрока должны быть настоящие решения с видимой ценой до клика; всё непонятное — словами, без кодов и номеров.
- Принципы: детерминизм L1/L2 (ADR-0002), данные только PD/CC0/CC BY (ADR-0009), нет фальшивых механик, история — правдоподобная, по источникам.
- Владелец решает направление (D1), Orchestrator — обратимые детали (D2, ORCH_DECISIONS.md). Вопросы — разом в точке остановки (/autopilot, #529).
- Сейчас: волна рычагов 1 (одна сборка для партии владельца, #474, #497) и М1 параллельно (#504, ADR-0027…0029). Источник правды о ходе работ — `CURRENT_STATE.md`, `development/PLAN.md`, последний handoff и `development/handoff/auto-checkpoint.md`.
- Процесс: запуск игры только с разрешения (client_permit), тесты пачками, агенты по свободным слотам (`tools/development/capacity.py`).
