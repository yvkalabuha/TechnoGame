### 1.2. Модель песочницы [Предл., только для замера]
- Копия `src` ветки (= `main` 2e146b9 + слияние TASK-0171 f40cdaa) в `lab/results/sandbox-0185` (не коммитится), правка — `lab/patches/TASK-0185-slots.sandbox.diff`; переключатели — переменные окружения `SLOT_*`. Без `SLOT=1` песочница — сборка ветки (проверяется пилотом: тот же `golden_hash`).
- **Прогресс только у узла со слотом** (S1): `Δprog = scale · mult / T_n`; остальные узлы фронтира — 0, прогресс сохраняется. Слот — построенный институт (стоящий в 1945 г. или исторический кандидат, построенный ИИ по нынешнему правилу §7) или виртуальный (серия потолка). Разовые программы выключены (иначе прогресс без слота).
- **Время узла**: `T_n = TB · c_тип · (1 + GK·gen)` мес., `c_тип` — нынешний `CostByType` (FND 1, PRN 1,5, ENG 3, CMP 1,5, PRC 2, APP 1); вариант «как цена»: `(1+GK·gen)` заменяется `CostGenMultiplier[gen]` (1; 1; 1,6; 2,5; 4; 6,4; 10,2). Скидки знаний, диффузия, кража, `informs`, цена опережения действуют только на цену.
- **Деньги**: ставка слота `C_eff / T_n` в месяц; `B = S · (1 − 0,008 · виртуальных)` (`S` = нынешний бюджет науки с `BudgetFactor` реальных институтов; виртуальный институт — 2 уровня × 0,4 % содержания); `Σ ставок ≤ B` — все слоты на полной скорости, иначе все × `B/Σ`. Неизрасходованное не тратится (печать).
- **Выбор узлов (ИИ)**: класс 0 — цели правила PATH (#559, `PriorityGoals`); класс 1 — начатые узлы (`prog > 0`, по убыванию); класс 2 — фронтир по `Priority × J`. Слот простаивает только при пустом фронтире.
- **Назначение и скорость** (`SLOT_DIR`): D0 — институт с наибольшим уровнем в дисциплине узла, `mult = 1 + bonus·уровень` (нынешнее правило #493, bonus 0,05); D1 (доп. Н) — у узла 2 направления (дисциплина + второе: самая частая другая дисциплина его прямых требований, иначе по типу: ENG→prop, APP→aero, PRC→metal, CMP→mech, FND/PRN→chem), `mult = 1 + bonus·Σ уровней института в направлениях узла` (ускоряет только пересечение), ИИ назначает как D0; D2 — как D1, но ИИ назначает институт с наибольшим пересечением и в классе 2 ранжирует узлы по `вес·(1 + bonus·лучшее пересечение)`. Потолок скорости ×2,5 (#568).
- Не моделируется: фокус, очередь (#567), `research_speed`, стройка новых типовых институтов ИИ (виртуальные слоты её заменяют).

### 1.4. Метрики и правила решения (до данных)
- **M1 первая машина** (`gen_times.t_first_unit`, любой актор и по странам; медиана по seeds, ненаступившее = +∞). Широкие полосы #566 (окна C4 ±10 лет): G2 ≤ 1962-12, G3 1943-12…1971-12, G4 1956-12…1985-12; разброс p90 − p10 первого G4 любой страны ≤ 15 лет; G4 наступает до 2030 в ≥ 9/10 seeds.
- **M2 простой слотов** = 1 − занятые/все слото-месяцы, 1945–1990 и 1991–2030; «простой при непустом свободном фронтире» должен быть 0 (инвариант песочницы).
- **M3 ширина фронта** = узлов фронтира на слот, 1950/1960/1975/1990/2010, медиана по seeds.
- **M4 исчерпание дерева**: год, когда фронтир страны впервые меньше числа слотов, и год, когда известны все 99 узлов (или фронтир пуст).
- **M5 деньги**: доля месяцев с недостачей (`scale < 1`), неизрасходованная доля `S`.
- **Выбор `T*`**: среди 7 вариантов при слотах hist — проходящие M1 (все три полосы, разброс, G4 до 2030); из них — с наименьшей суммой |медиана первого G2/G3/G4 любой страны − середина окна C4| (1949,9; 1957,9; 1971,4); при равенстве — меньший TB. Если не проходит ни один — ближайший, с пометкой «полосы не пройдены».
- **Старт по истории подтверждён**, если при `T*` и hist: ширина фронта ≥ 1,5 × n0 у каждой страны в 1945–1960 (медиана годовых средних), простой ≤ 5 % слото-месяцев 1945–1990, порядок «USA или SUN первыми к G4» в ≥ 7/10 seeds.
- **Потолок подтверждён**, если при `T*` и ceil: простой ≤ 5 % в 1945–1990 у каждой страны, недостача денег ≤ 25 % месяцев 1945–1990 (медиана), фронт на слот ≥ 1 до 1990; иначе — «высок» (простой/недостача) или «низок» (ширина ≥ 3 на слот и деньги остаются > 20 %). Сверка `b`: `b_sim` = `S` страны / `S` USA в 1946–1950 → `round(4 + 8·√b_sim)` против принятых 12/9/8/7/6.
- **Направления**: печать — средний множитель, доля слото-месяцев без пересечения, сдвиг медиан G3/G4 против D0; «заметно», если |сдвиг| ≥ 2 года; D2 нужен ИИ, если D2 раньше D1 на ≥ 2 года по G3 или G4.
