## Вопрос
Какая цель прохода 2 A39 снимает замок «оснастка × культура» с наименьшими побочными эффектами? [Факт, прогон диагностики] Сейчас (V0) проход 2 доводит `M` ровно до `H`, а C-B при `M < H` даёт предел `TOOLING`. После износа `M = H − ε` держится постоянно: у USA/GBR 49/54 `TOOLING` стоит в 94% месяцев, а `E > 0` бывает в 6%. Результат — вход gate (critic + advocate, #129). Выбор делает владелец, до его решения `TOOLING_TARGET` = V0.

## Начальные условия и параметры

- **Плечи** (проход 2 A39, остальное без изменений; числа — литералы манифеста, объявлены до прогона; `h_lo`, `h_hi`, `m_lead` — произвольные «З»):

|---|---|---|---|---|
| V0 | источник `M` (`M < H`) | `min(H, M_cap)` | — | контроль |
| V1 | источник `M` | `min(H + ρ_max, M_cap)` | `ρ_max` = 0,021 | кандидат |

- **V4 — это контрфакт A диагностики** с участием `M ≤ H`. Его значение без R-H-MS известно из данных (первое `fielded` USA на мес. 73), поэтому V4 не слепой вариант.
- **Прогоны:** 7 плеч × seeds 1…20 = 140 (main) плюс 3 факторные ячейки × seeds 1…10 × 7 плеч = 210. Всего 350 прогонов по 384 мес. Seeds во всех плечах одни и те же.
- **Детерминизм:** V0 на seeds 1…5 воспроизводит golden-хеш D2. V4 на seed 1 даёт один хеш при threads 1 и 4.

## Метрики
Точные определения — в спеке §11 T6e r1. Пул ячеек общий для всех плеч одного seed: это объединение пулов V0 и VINF. Агрегация: сначала отношение сумм по пулу для пары (seed, актор), затем медиана по seeds; USA и GBR считаются отдельно. CI — парный bootstrap по seeds (2000 повторов). `E_useful` не используется: после предела `TOOLING` он равен 0.
- **M1. Замок и деньги:** доля месяцев пула с `Σ E_p > 0`; смены `EFFORT ↔ TOOLING`; доля месяцев с `TOOLING`; рост `ΔH`, стоимость `C` прохода 2, цена роста `c = C/ΔH`; неизрасходованный остаток.
- **M2. Выпуск:** по окнам 48 мес., баланс `r_w = out_USA/out_GBR`.
- **M3. Освоение и вооружение:** первый месяц `mastered` (tier ≥ 4), первый месяц `G ≥ g`, `G_front`, `maxG`.
- **M4. Якоря:** `d_k` для C1 и C2 по §8.2 п.3. C3 — проверка согласованности. C4 только печатается. Это не калибровка.

## Критерии и правило выбора (объявлены до прогона)
Кандидат V ∈ {V1, V2, V3, V4} **годен**, если выполнены все пять условий:
- **K1.** `ΔH(V)/ΔH(VINF)` ≥ 0,75 у USA и у GBR, в main и в каждой факторной ячейке.
- **K2.** `c(V) ≤ c(VINF)`, то есть X = 1: вариант, который за единицу роста платит больше, чем держать оснастку на потолке, доминируется эталоном.
- **K3.** `d_k(V) ≤ d_k(V0)` для C1 и C2.
- **K4.** Медиана `r_w(V)/r_w(V0)` лежит в [0,67; 1,5] в каждом окне, где у обоих плеч выпуск > 0.
- **K5.** p50 первого `mastered` для пар (актор, PRC tier ≥ 4, не освоен на t0) не позже, чем у V0.

«На грани» — CI 95% пересекает порог. Годность по порогам v0.13 (0,9 и 0,02) печатается отдельно. Вариант, годный только после переобъявления порогов, помечается «на грани по переобъявлению».

**Выбор.**
- Из годных берётся вариант с наименьшей ценой роста `c`.
- Если разница ≤ 5%, берётся вариант с меньшим `S` = новые литералы + смена условия участия + поправка контракта. Значения: V1 = 0, V2 = 2, V3 = 2, V4 = 2.
- При равном `S` — вариант с меньшим числом новых литералов, затем с меньшим номером.
- Если годных нет, остаётся V0, и отчёт идёт владельцу. Новые числа — только новым EXP на seeds 21…40.
