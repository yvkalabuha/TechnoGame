# Sketch brief: tech map stage 2 (owner decision #582)

Reference: attached frame = current knowledge map (1920x1080), science strategy game 1945-2100. Owner rejected the blueprint style.
Owner wants:
- Volume and depth: "dive into an ocean of technologies". The map is a 3D space the player flies through with the mouse (drag to orbit/pan, wheel to fly in), no -/+ buttons. Nodes are objects in depth; near ones large and detailed, far ones small and faded; years as depth layers or rings receding into the distance; direction sectors as coloured currents/regions.
- Institutes strip at the bottom: smaller cards, ALL the same size, each with an emblem (simple badge), skills (directions) as small icons with level digits, status by colour AND symbol (free / busy / queue), no amber fill (owner dislikes the colour).
- More graphics, fewer words; tooltips on hover (show one tooltip open in the sketch).
- Keep: node card (price in dollars, time, directions), path to goal highlighted, queue of 5.
- Text in Russian, legible at 100 %, 16:9.
Make 3 variants: (A) deep-ocean dark with luminous nodes; (B) light paper-like atmosphere with depth fog; (C) constellation/star-map feel.
