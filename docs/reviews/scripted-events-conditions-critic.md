# Gate scripted-events-conditions rev 2 — critic (2026-11-18)

5 high, 7 medium, 4 low. Most serious: failed-`sufficient` rules contradict #341; the document needs columns ADR-0020 lacks; one `group` field carries two meanings; the Taiwan core example cannot fire at t0.

- **HIGH §3 "N true, S failed → skip at once", YAML `on_fail.sufficient: skip`.** In M1, S is built from transient atoms (`controls_all`); #341 defers any transient failure, so the same atom defers in N and skips in S. Fix: classify failures by atom monotonicity only; transient S failure defers; remove `defer_on_sufficient`.
- **HIGH §1 `absorbed`/`dissolved`, §4.** Relies on `polities.alive`, `was_alive`, `dissolved`; ADR-0020 (ACCEPTED) has only `actors.active`, `events.status`, `effective_tick`, and a joint polity is not an actor (p. 18). Fix: derive atoms from existing columns, no save change: `was_alive(P)` = active at t0 or the creating event `fired`; `dissolved(J)` = the `dissolve_joint` event for J `fired`. New columns would be an ADR-0020 amendment (owner).
- **HIGH §2, §5 `group`.** One field = S5 ablation group (`germany_korea`) and atomic K9 group (`partition_1947`, `austria_1955_withdrawal`); India/Pakistan not expressible; S5 names differ from HYP-0005 (`germany_korea_taiwan_condominia`, `south_asia`, …). Fix: `ablation_group` (enum of the 5 HYP-0005 groups) and `atomic_group`.
- **HIGH §3 group atomicity undefined:** position in the daily pass (smallest member key?), window across classes (6 vs 12), one member permanent and another transient, `alt` per group or member, same status and `effective_tick` for all. Fix: the group is one decision; N/S = AND over members; window = minimum; `alt` group-level only; test: break one member, none fires.
- **HIGH §2 Taiwan C19.** Start "owner JPN, controller ROC" and N `controls(ROC, taiwan)` contradict RR-0020 C19 (controller JPN→ROC on 1945-10-25) and #338 (owner and controller ROC from 10-25). At t0 = 1945-10-01 N is false → `deferred`; the "all fired" golden fails. Fix: N = `owns(JPN)` ∧ `controls(JPN)` ∧ `exists(ROC)`; effect sets owner and controller to ROC.
- MED §2, §5: #339 requires the from-side still owns/controls; GDR C05 and FRG C03 do not check `owns(DEU, set)`; validator check 4 is static only (mods, ablation, partial ownership). Fix: generate from-side atoms from `effects.from`; partial foreign ownership at runtime → skip with reason.
- MED §2 Oder–Neisse: E_ODER_1970 has three outcomes (transfer / confirmed / skip) — does not fit one N with an unconditional effect; `excludes` (ADR-0019 p. 18) would drop 1970 when 1950 fires, so #343's `confirmed` record is never written. Fix: C07b_TRANSFER (`excludes` against C07) and C07b_CONFIRM (`no_effect`, N `fired(C07)` ∧ `owns(POL)`); Kaliningrad needs its own event (Moscow Treaty 1970 / 1972-06-03) independent of C07.
- MED §5 kinds: no kind sets `actors.active = 0`, so `absorbed(SAAR)` after C02b never holds; one `kind` per record cannot cover India (create + owner + controller) or Austria (controller + dissolve). Fix: add `absorb_polity`; kind = list of effects.
- MED §1, §5: status atoms on an event with a larger key read yesterday's status — order-dependent. Fix: the validator requires every event referenced in a condition to have a smaller key.
- MED §3 `soft_after`: does waiting for a deferred predecessor consume the dependent's window; when does the dependent skip? Fix: window starts at the predecessor's resolution; test.
- MED §4, §5, HYP-0005 hidden degrees of freedom: `nominal_date` among signed/in force/handover; `after` vs `soft_after`; `cross_group`; existence of `alt` (changes S5 via cascades, e.g. Saar alt when C09 is ablated); window class per event. Fix: `nominal_date` = RR-0020 "Rek." date only; window class from a flag (add `decolonisation`; no `defer_months`); every base `alt` needs a source; freeze the event pack `data_hash` in the HYP-0005 pre-registration before the first `full` run.
- MED §5 validator: a forbidden-names list was rejected in ADR-0021 (misses indirect paths); taint check (ADR-0021 p. 16a) and `base|branch` row class missing. Fix: each atom declares the columns it reads; check against taint rules; add `branch` to the schema.
- LOW §1: the [Предп.] "exact before/after merge — systems-architect" is settled by ADR-0019 p. 16–17; reference it.
- LOW §3: window `max(nominal, effective(pred)+lag)` adds `lag` vs ADR-0019 p. 18 — state it is a refinement; name the column `effective_tick` (ADR-0020).
- LOW §4: S5 needs `affected_polities` (from/to) in the journal for actor creation/absorption; a `disabled` predecessor cascades as `skipped` and inflates S5's skip share — separate reason/status for ablation cascades.
- LOW §5: state that `events/*.yaml` and `sets.yaml` enter `scenario_hash`, and `territories.yaml` `DataHash` (ADR-0020).

Missing tests: group atomicity; save/load mid-deferral and between D−1 and D; `AddMonths` clamping (31 Jan); the 36-month cap; a cascade across `cross_group` under ablation; why_not per reason_code; seed independence of the event journal (#329).
Open: `was_alive`/`dissolved` derived (preferred) or ADR-0020 amendment (owner); who freezes the event pack for the HYP-0005 pre-registration.
