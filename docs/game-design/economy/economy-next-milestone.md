# Минимальная экономика следующего milestone

> Всё в документе — **[Предл.]**, кроме строк с пометкой [Факт] (источник и дата доступа 2026-11-04) или [Предп.]. Ничего не утверждено; контракт слоёв (`docs/architecture/LAYER_CONTRACT.md` v2.4 r7) и решения владельца главнее. Код — только после M0 (#164). ## Краткий вывод
- [Факт: спека среза §3.4, контракт §4.0] Сейчас экономика среза — **бюджет актора**: `budget_a(t) = budget_a(t−1)·(1 + g_a/12)` экзогенно, пять статей, притоки извне (`LicenceFlow`, `sale_income`), содержание парка. Слой способности денег не имеет; кадры следуют за `budget_index`; материал один (сплав).
- [Предл.] Минимум для следующего milestone — не «моделировать экономику», а **замкнуть три петли**, которых нет: (1) деньги → промышленность → ВВП → деньги; (2) образование и население → кадры → способность; (3) материалы и торговля → выпуск, с эмбарго как рычагом.
- [Предл.] Модель — **новый слой `Core.Economy`** на уровне страны (ключ `actor`), а не расширение `Core.Industry` (ключ `site`). Он заменяет только то, что срез задаёт экзогенно: `budget_a(t)`, `pool_base`, поставку сплава, внешний рынок. Режим `EXOGENOUS` включает старое поведение побитово — это и абляция слоя, и регрессионная гарантия для M0.
- [Предл.] Абстрактным остаётся всё, что не нужно решениям игрока: нет таблиц «затраты–выпуск», валют и инфляции, цен по заводам, потоков между site, ордербуков. ВВП — **один скаляр на страну** (постоянные цены 1945); стратегические отрасли описаны процессами `PRC`, остальная экономика — агрегат.
- [Предл.] Рост ВВП = исторический базовый путь (Maddison/PWT) **+ отклонение от возможностей** (индекс способности, шоки эмбарго и войны). История сохраняется, а развилки игрока получают экономическую цену.
- [Предл.] Этапы: **E0** документы и данные (сейчас) → **E1** макроядро и бюджет → **E2** материалы и национальный баланс → **E3** торговля и экспортный контроль → **E4** регионы и уязвимость (с картой и HYP-0003). После каждого — gate (§6).
- [Предл.] Главные риски: распухание модели, дрейф результатов M0 (HYP-0002) из-за эндогенного бюджета, калибровка без якорей до 1950 г., доминирующие стратегии «автаркия» и «копить запасы». Вопросы владельцу (5) — §8.

## 2. Минимальная экономика: что внутри

### 2.1 ВВП и рост (E1)
- **Состояние на страну:** `Y_a` (реальный ВВП, `Fx6`), `pop_a`. `CI_a` (индекс способности) — производная, не состояние. ВВП один скаляр, **без секторов**.
- Динамика (месяц; годовые ставки делятся на 12): `g_a(t) = g_base_a(t) + β·(CI_a(t) − CI_ref_a(t)) − g_shock_a(t)`, `Y_a(t) = Y_a(t−1)·(1 + g_a(t)/12)`.
  - `g_base_a(t)` — исторический путь из данных (Maddison/PWT; после 2022 — сценарные пути в данных мода);
  - `CI_a` — средний `capability_tier(site, cluster)` по кластерам (веса из данных) относительно лидера мира; `CI_ref_a(t)` — значение в **базовом прогоне без вмешательств** (таблица из Lab, часть данных, попадает в `data_hash`);
  - `g_shock` — потери от эмбарго (E3), войны, дефицита CMP (E2); приходят событиями из потока событий (ADR-0004). В самом слое RNG нет (#28).
- Основание [Факт: RR-0006 ист. 15]: сложность производства страны предсказывает будущий рост (Hidalgo–Hausmann 2009). Вес `β` и форма — [Предп.], калибруется в Lab.
- Схождение отстающих (advantage of backwardness, Gerschenkron 1962 [Предп., по памяти]) выражено **данными** `g_base`, а не вторым механизмом, иначе двойной счёт с `k_catch`.
- Арифметика: рациональные выражения, при необходимости `PowFrac` (ADR-0012, ADR-0003 R1–R3); `exp`, `double` нет.

### 2.2 Формирование бюджета (E1)
- `budget_a(t) = τ_a·s_prog_a·Y_a(t)`: `τ_a` — доля государства, `s_prog_a` — доля на программы (НИОКР, оснастка, наладка, закупки, QP, образование). Оба — данные сценария по эпохам [Предп.].
- Регрессия: `EXOGENOUS` — старая траектория бит в бит; `COUPLED` при `β = 0` и `g_shock = 0` — те же значения до округления (проверка в Lab).
- Рычаги игрока: доли статей (есть) + `edu`; `τ`, `s_prog` в первой версии не рычаги (вопрос 4).
- Положительная связь «деньги → культура → ВВП → деньги» ограничена `E_full`, `sat`, `Hcap`; в бюджет каналов контракта §8.2 добавляется «канал денег».

### 2.3 Труд (E1)
- 4 пула на site (`unskilled`, `skilled`, `engineer`, `scientist`; в M0 два). На страну: `pop_a`, доля трудоспособных, выпускники по ступеням.
- Поток: статья `edu` → выпускники с лагом 5–15 лет → пулы; смертность, пенсия. Миграция и «утечка мозгов» — FUTURE (RR-0015).
- Спрос — как сейчас: `reserve_workforce(site, cat, n, requester_id)` (контракт §4.6, без изменений); дефицит уже бьёт по `act`, `w`.
- Отличие от среза: численность пулов **не масштабируется бюджетом**, поэтому малая страна с большим бюджетом не получит инженеров мгновенно (асимметрия #24).

### 2.4 Ресурсы, материалы, цепочки (E2)
- 10 природных категорий (RR-0006 §4.9): мощность добычи — данные страны, без истощения; ценность месторождения нулевая, пока процесс-потребитель не известен. Материалы — только выходы `PRC`; нефть не подменяет пластик.
- Национальный баланс по CMP: `supply = Σ выход + импорт + выдача из запаса`, `demand = Σ вход + экспорт + пополнение`; делёж дефицита целыми единицами в порядке `(country_id, cmp_id, consumer_id)`; граф «вход → выход» ацикличен, циклы рвёт пометка `lagged` (RR-0010 §5(a), §6).
- Запас `stock[country, cmp]`: цель в месяцах потребления, стоимость хранения в бюджете, запас не учит.
- Концентрация `share_site` пока вырождена (один site); осмысленна в E4.
- Открыто для systems-architect: проход по графу CMP за месяц или лаг месяц на звено (RR-0010, OPEN 1).

### 2.5 Торговля и экспортный контроль (E3)
- Мировой рынок — **цена по CMP как функция мирового баланса** (`price = p0·(1 + k·дефицит)`), без ордербука. Сделка допустима, если `allowed(from, to, item)` и хватает мощности перевозки и денег импортёра.
- Предмет торговли: CMP, **компоненты** (изделие без проекта игрока; граница RR-0010 §6), лицензии (`take_licence` уже есть). Готовые системы и знание — вне E3 (RR-0015).
- Инструменты: `embargo`, пошлина как коэффициент цены, лицензия на экспорт. Санкции = набор эмбарго + `g_shock`; **политика санкций — вторая волна по роли**, в E3 только механика.
- Платёжный баланс — один агрегат на страну (экспорт − импорт в постоянных ценах); отрицательный режет `s_prog`. Курсов и долга нет.
- Инварианты: `Σ экспорт = Σ импорт` по item; `stock ≥ 0`; импорт не растит `culture_H` (RR-0006 §4.14); #62 — импорт не даёт лидерства.
- Внешний рынок парка (#142) в E3 — частный случай торговли «изделие → страна-покупатель с бюджетом»; до E3 остаётся как в срезе.

### 2.6 Что остаётся абстрактным
Валюты и курсы, инфляция, налоги по видам, цены по заводам и отраслям, домохозяйства и потребление (кроме доли `τ`), финансовый сектор, логистика (один коэффициент цены), потоки между site, энергия (один баланс по RR-0006 §4.8, не раньше E2).

## 3. Стык с контрактом слоёв
**Новый слой, не расширение.** Причины: ключ `actor` против `site`; нужна абляция-заглушка (`EXOGENOUS`/`COUPLED`, как слой по контракту §1); у экономики нет RNG (#28) — шоки приходят событиями.

| Слой | Читает из снимка | Пишет (своё) |
|---|---|---|
| **Economy** (новый, ключ `actor`, месяц) | `capability_tier`, `world_lead`, `proc_v`/`proc_yield` (стоимость выпуска), `granted` кадров, флаги эмбарго | `Y_a`, `pop_a`, выпускники, `stock[country,cmp]`, цены CMP; колонки `budget_a`, `pool_base`, `cmp_supply` для соседей |
| Industry | + `budget_a` (как сейчас через `IIndustryInputs`), `pool_base`, `material_availability` | без изменений |
| Knowledge | без изменений | без изменений |
| Products | `ProcurementBudget`, `B_in`, `material_availability`, цена импортного компонента | без изменений |
| Бюджет/ИИ | `budget_a`; доля `edu`; решения о запасах и торговле | команды |

Новые функции (чистые функции снимка): `BudgetBase(actor, t)`, `PoolBase(site, cat, t)`, `MaterialSupply(country, cmp, t)`, `ImportAvail(country, cmp, t)`, `WorldPrice(cmp, t)`. Существующие `material_availability`, `line_capacity`, `reserve_workforce`, `report_output` **не меняют интерфейса**, меняется источник данных.

Фаза тика (ADR-0006): Economy — месячный compute по снимку t−1; `budget_a`, `pool_base`, `cmp_supply` видны слоям с t+1 (лаг, как у `proc_E`). Порядок merge — `(country_id, cmp_id, consumer_id)`.

Правки контракта (уровень **gate**, версия v2.5): строка слоя в §1; запасы в таблицу §3; канал денег в §8.2; доля `edu` в `set_budget_shares` и формат сохранения (ADR-0013 п. 7, `save_format_version` растёт один раз); §10 «вне среза». §4.1–4.4 и §6 не затрагиваются.

## 7. Инварианты (post-проверка каждого тика)
`Y ≥ 0`; расходы ≤ `budget_a`; сохранение каждого CMP `Σ выпуск + импорт = Σ вход + экспорт + Δзапас` точно; `stock ≥ 0`; сумма кадров ≤ трудоспособного населения; в `Core.Economy` нет обращений к RNG (тест, как для Industry); L1/L2.

## 8. Вопросы владельцу (≤ 5)
1. **Масштаб.** ВВП одним числом на страну + стратегические отрасли процессами (рекомендация) или многоотраслевая экономика (дороже, текущим решениям не нужна)?
2. **Рост ВВП.** Исторический базовый путь + отклонение от возможностей и шоков (рекомендация, сохраняет «историю») или полностью эндогенный рост (честнее для альтернативной истории, труднее калибровать)?
