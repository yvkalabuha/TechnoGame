## Гипотеза «открытая гонка» (HYP-NEW; по шаблону `development/templates/hypothesis.md`; разделы «альтернативы» и «риски» — на gate 3.1)

### Формулировка
> На мире с экономикой E1, тремя слоями и стартом 1945-10-01, возмущённым по seed в пределах неопределённости источников (#329), исход гонки за 30 лет **не предрешён и не случаен**: лидер 1975 года не определяется лидером 1945, но и не меняется как попало; причины смен читаются.

Это свойство **распределения исходов по seeds**, а не желание, чтобы победил кто-то заданный. Реальные траектории не входят в метрику (RISK-0011).

### Объект гонки
- **Участники `G(t)`:** акторы, существующие в момент `t` и имеющие ≥ 5 регионов в `t`. Государства, возникшие по событиям (Индия, Индонезия, ФРГ), входят с момента создания; правило входа фиксируется до прогонов. «Великие державы» — 8 акторов с наибольшим промышленным выпуском на `t0`; список печатается в манифесте.
- **Позиция и лидер (#330):** ранги по двум осям — (A) доля мирового промышленного выпуска E1, (B) `tech_lead` (#44). Сумма рангов; ничья — по среднему рангу за последние 12 месяцев, затем по рангу B, затем по id актора. Отдельно печатается лидер только по `tech_lead`.
- **Гистерезис:** лидер сменился, только если претендент удерживал первую позицию ≥ 12 месяцев подряд; момент смены — начало этого окна. Так «мерцание» сумм рангов не создаёт смен и не провалит P3 артефактом.
- Горизонт: `t0` = 1945-10, `t1` = +360 мес. Точка +240 мес. — диагностика.

### Метрики (определены до прогонов; у каждой есть CI и правило провала)
| Код | Определение | CI | Провал |
|---|---|---|---|
| **P1 `chg30`** | доля seeds, где за 30 лет была **любая** смена лидера (с гистерезисом, #357); `L(t1) ≠ L(t0)` печатается справочно | Wilson 95% | весь CI вне полосы провала P1 |
| **P2 `Neff_c`** | `1 / Σ p_i²` по лидерам `t1` **среди seeds со сменой** лидера | bootstrap по seeds | весь CI вне полосы провала P2; при < 30 seeds с конечной сменой P2 не оценивается и в правило `refutes` не входит (#356) |
| **P2τ `mob5`** | средняя нормированная дистанция Кендалла между порядком топ-5 на `t0` и `t1` (0 — тот же порядок, 1 — обратный) | bootstrap по seeds | вне полосы провала; полоса фиксируется на gate 3.1 |
| **P3 `flip`** | доля seeds с > 3 сменами лидера за 30 лет (с гистерезисом) | Wilson 95% | нижняя граница CI > порога провала P3 |
| **S1 `abl`** | парный дизайн (общие случайные числа по seed): McNemar по `chg30` и разность log-odds, `full` против `off` слоя | CI разности | вторичная, порога нет |
| **S2 `why`** | доля смен лидера с названной причиной из `why_not` в окне 36 мес. | Wilson | диагностика; критерий — контрфактическая проверка K8 |
| **S3 `dom`** | тестовый актор `a*` (3-й по рангу на `t0`) получает пресет бюджета (промышленность / наука / баланс / импорт знаний), остальные — базовый ИИ; доминирует пресет, у которого шанс быть лидером `t1` выше остальных на ≥ 0,15 при непересекающихся CI | парный по seeds | если в HYP на gate 3.1 определение не принято — S3 снимается |
| **S4 `scr`** | все метрики на прогоне без сценарных событий | как у основной | диагностика, порога нет (см. правило ниже) |
| **S5 `evt`** | доля смен лидера в течение 12 мес. после события, затрагивающего лидера или претендента; абляция по 5 группам событий | Wilson | диагностика |
| **S6 `non-gp`** | доля seeds, где лидер `t1` не из великих держав | Wilson | печать; порог ошибки задаёт gate 3.1 (защита от «широкого Neff за счёт малых стран», #24) |

**Полосы [Факт #323; точные значения, включая полосы провала и «на грани», фиксируются на gate 3.1]:** P1 — проход при точечной оценке в [0,20; 0,50]; P2 — при `Neff_c` ∈ [1,6; 4,0]; P3 — при `flip` ≤ 0,10. Полосы провала — [Предл.]: P1 вне [0,15; 0,55], P2 вне [1,3; 5,0], P3 CI > 0,15.
**Почему P2 считается по сменам:** при почти постоянном лидере `t0` (если #329 не развела старт) `Neff ≤ 1/(1−chg30)²` — при `chg30` = 0,20 это ≤ 1,56 < 1,6, то есть P1 и P2 были бы одним событием (критик, п. 1). `Neff_c` и `mob5` измеряют разнообразие, а не частоту смены.

**Правило исхода (предрегистрируется):**
- `supports` — проходят P1, P2 (по `Neff_c`; `mob5` дополняет), P3;
- `refutes` — провал P1 (любая сторона), или провал P3, или (P2 оценён и провален) (#356); `mob5` — только диагностика;
- на шаге 600 seeds решение принимается по точке, без `inconclusive` для P1/P2; серая зона — оговорка в отчёте (#359). Ничья в сумме рангов решается технологическим рангом, затем id (#358).
- `inconclusive` остаётся только для P3/S-метрик вне правил. `invalid` — нарушена воспроизводимость или пре-регистрация.
- **Правило S4:** если основной прогон проходит, а прогон без событий вне полосы, исход фиксируется как `supports only with scripts` отдельной записью в отчёте: исход `supports`, но вывод об открытости экономикой не подтверждён. Если без событий проходит, а с событиями нет — записывается как «скрипты ломают гонку».

### Защита от ошибок HYP-0002
1. **Старт (#329):** значения старта возмущаются по seed в пределах неопределённости каждой оценки; точка — эталон.
2. **Пилот пола** (пункт 3.2a): на калибровочных seeds 22001–22100 (исключены из основной серии, фиксируются в манифесте), сразу после первой рабочей E1a. Печатает: распределение `L(t0)`, разброс стартовых позиций, долю seeds с одним и тем же лидером в `t1`. Если ≥ 90% seeds имеют одного лидера `t1`, допустима **одна** коррекция старта, и только внутри документированной неопределённости источников (#329); коррекция вне интервала — решение владельца. Допуск и предел записываются в HYP заранее.
3. **Seeds [сверить с манифестами]:** основная 20001–21000 (последовательный план: 300, затем расширение до 600 по заранее записанному правилу — если CI P1 или P2 пересекает границу полосы), калибровка 22001–22100, детерминизм 23001–23060. Старые 1–1000 и 10001–10100 не используются.
4. Калибровка — только по микроякорям (население и пашня региона, угольная мощность; CC0/CC BY); исторические лидеры — не якоря. После выбора формы `chg30` на калибровочных seeds не печатается, кроме пилота 3.2a (RISK-0021).
5. ИИ заморожен до калибровки. Повторный EXP — один, после промаха (#332, #43). Отступления пишутся в `meta.deviations` до чтения результата.

Прежняя оценка 50–70 ч была ошибкой. Реальный расчёт — **матрица «серия × N × время одного прогона в один поток в дневном режиме»**: серии — main, без событий, `E1b off`, `H/M off`, 5 групп событий, 4 пресета S3, det (≈ 14); N = 300, затем 600.
