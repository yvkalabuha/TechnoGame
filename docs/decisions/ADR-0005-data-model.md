# ADR-0005 — Модель данных ядра: таблицы struct-of-arrays

## Контекст
В grand strategy мало типов сущностей и много связей. RR-0002.

## Решение (предложение)
- Каждый тип сущности — таблица: по массиву на поле, плотные целые индексы.
- Связи — индексные таблицы и обратные индексы; графы — массивы смежности.
- В данных и сохранениях — стабильные строковые ID; при загрузке они отображаются в плотные индексы.
- ECS-фреймворк не используется.

## Рассмотренные альтернативы
ECS (Arch, DefaultEcs, Friflo): сильнее для множества однородных сущностей; проигрывает на связях и читаемости.

## Проверка
Архитектурный тест: состояние мира только в `Singularity.Kernel` таблицах.
