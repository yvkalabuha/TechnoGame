# Политическая карта: привычная атласная раскраска стран (v0.1, [Предл.])

Заказ владельца 2026-11-25: «раскрасить страны по стандартизированной политической карте, так привычнее». Расширяет `task-0138-country-palette.md` (12 тонов, валидатор §2.2 и правило штриховки остаются). Документ без кода и без кадров: на кадрах не проверялось [не проверено].

## 1. Решение (коротко)
1. **Индексы Natural Earth MAPCOLOR как источник цвета не берём.** [Факт] В репозитории поля нет (поиск `mapcolor` по репо: 0 файлов); конвейер карты и `polities.yaml` несут только `ne_adm0` (код ADM0_A3). [Факт] По ответу команды Natural Earth числа 7/8/9/13 только делят страны на группы без соседей одной группы, смысла у числа нет ([форум NE](https://www.naturalearthdata.com/forums/topic/what-does-mapcolor-mean-in-ne_10m_admin_0_countries/), 2026-11-25). [Факт] Они посчитаны для границ сегодняшнего мира: СССР, Югославии, Чехословакии, РК-КНР и колоний 1945 там нет, соседства другие. Они не дают «привычности» (Британия там не розовая), только непересечение; а его даёт наша жадная раскраска по графу 1945.
2. **Привычность задаёт таблица традиций по коду державы (§2)**, остальные государства раскрашивает существующий жадный алгоритм `CountryPalette.Assign`. Основа традиции: британские владения розовым ([Manchester Historian](https://manchesterhistorian.com/2013/painting-the-world-pink/): красный светлили до розового ради чёрных подписей), синий для Франции, красно-розовый для СССР, жёлтый для Китая. Остальные привычки (Япония и Нидерланды оранжевые, Германия серая и т.д.) [Предп.]: общеизвестная школьная и атласная практика, надёжного открытого источника не нашёл, владелец вправе заменить.
3. **Колония = тон метрополии**, заливка светлее на 18 % (смесь с белым) + штриховка 45° из 0138 §4.
4. Палитра 12 тонов `tint.1..12` остаётся как есть (hex в 0138 §2): она уже в атласных семействах, прошла ΔE и CVD. Меняется только таблица `Fixed`.

Прочие владельцы (Латинская Америка, Ближний Восток, Балканы, малые государства, `TANGIER`, `TIB`...) получают тон жадно, как в 0138 §3.4, только с учётом закреплённых выше. Совместные администрации (`kind: joint`) берут тон первого из `members` (как сейчас). Для закреплённых пар соседей проверено ΔE2000 (скрипт сессии): SUN/ROC 20,0; 2/4 29,7; USA/GBR-доминионы по таблице не запрещены (1/2 не измерено [не проверено]). Запрещённые пары `Forbidden` не нарушены ни одним закреплённым соседством (FRA-BEL 4/11, DEU-NLD 12/8, ESP-PRT 9/6, ITA-FRA 10/4).
Правила: (а) закреплённая держава не уступает тон соседу, если соседу есть свободный; (б) если закреплённые тоны двух соседей из таблицы окажутся запрещённой парой, побеждает та, у которой больше регионов, вторая берёт ближайший по ΔE свободный (разовая правка таблицы, не динамика); (в) стоит тест: ни одна пара соседей по графу 1945 не запрещена, детерминизм (одни и те же вход и выход).

## 3. Колонии, мандаты, протектораты, аренда
- Заливка = `mix(tint.N, #FFFFFF, 0.18)`, штриховка 45° линией `tint.N.line` (0138 §4). Измерено: ΔE2000 к метрополии 2,4-3,4 (одно семейство, различие несёт штриховка), L* 84-91. L* tint.5 и tint.8 при смеси выходит к 90-91: для заливок колоний верхняя граница §2.2(а) расширяется до 91 [Предл.].
- ΔE колониальной заливки к `sea` ≥ 8,3 и к `land-none` ≥ 7,7 для tint.1-11 (§2.2 г ≥ 6 выполнено); у tint.12 смесь даёт 5,6 к `land-none` (не проходит), но колоний у DEU в 1945 нет: правило «колония не берёт tint.12, берёт tint.12 без смеси».
- Примеры 1945: Британская Индия, Бирма, Африка GBR розовые со штриховкой; Индокитай, Сирия (мандат), Мадагаскар голубые; Индонезия персиковая; Конго пурпурное; Ангола бирюзовая; США: Филиппины зелёные.
- Доминион (CAN/AUS/NZL/ZAF) от британской колонии отличают: нет штриховки, толстая граница державы (0138 §3a), подпись. [Предл., спорно] Если на кадрах Канада «читается как колония», запасной вариант: доминионам tint.7 и пояснение в легенде «Содружество»; цену решает владелец.
- Италия, Япония, Германия: колонии и оккупированные земли в 1945 уже под чужим контролем: заливка владельца, штриховка −45° цветом контролёра (0138 §4), правило колонии не применяется.

## 4. Читаемость
- **Подписи без плашек (TASK-0163).** Тушь `#1D1E20` на любом тоне при свете 0,70: контраст 6,9-9,0:1 (худший tint.12 6,9; tint.3 7,3) — ≥ 4,5:1 (C5) и без плашки [Факт: расчёт, модель света из 0138, формулу шейдера сверить с developer]. Проблема не заливка, а штриховка под буквами: под подписью штриховка гаснет в полосе подписи (маска по bbox текста +4 px, не плашка), либо 2 px «ореол» цветом базового тона (alpha 0,9). Подпись колоний не ставится на заливку (мелкий курсив только по порогу площади 0138 §5).
- **Серый кадр (A5).** Тоны в L* 79-89 различимы слабо: опора на второй канал (толстая граница владельцев, штриховка, подписи), как в 0138 §6; привычность цвета на серый кадр не влияет. Критерий приёмки тот же: границы держав, колонии, оккупация различимы без цвета.
- **CVD.** Новые закрепления не создают пар из `Forbidden`; слабые CVD-пары 0138 остаются в запретном списке соседств.
