Новые сквозные правила [Предл.]:
1. **Штриховка = «владение без власти».** Оккупированная земля (держим, но не своё) и разрыв «знаем, но не делаем» (знание есть, производства нет) рисуются одним приёмом. Это одно понятие на карте, на ленте и на планисфере.
2. **Второй канал у каждого отклонения**: форма знака (■ авария, ▲ внимание, ● справка) и слово на ярлыке. Цвет только ускоряет поиск.
3. **Цвет у причины.** Следствие (например, падение выпуска) не окрашивается, а получает ссылку на причину. Так нет двойной тревоги (практика ISA-101: тревога по корню).
4. **Слово на экране, число в подсказке** (#33). Закреплённая выноска (СКМ) — это подсказка, поэтому числа в ней разрешены [Предп.: толкование #33 — нужно подтверждение, OPEN].

## 3. Главное противоречие: цветная карта и «цвет = отклонение»
Рисунок 0 в `directions-v2.html` показывает один фрагмент карты тремя механизмами.

| | A · бюджет насыщенности | B · передача канала | C · резерв тонов |
|---|---|---|---|
| Государства | Светлота L* 82–90, низкая насыщенность, тон любой | Эмаль средней светлоты; в «обстановке» — только кайма 8 px и цветной квадрат у имени | 8 насыщенных тонов вне сектора 345°–65° |
| Отклонения | Насыщенные: авария, внимание; всегда ярлык с обводкой тушью | Яркие на тёмном; в «политике» — только знаки | Красный, оранжевый, янтарный — только у них |
| Команда игрока | Ультрамарин (третья насыщенная краска) | Голубой `info` | Тушь, двойная линия |
| Одновременно? | Да | Нет: два режима | Да |
| Цена | Пастель хуже различима на мелких государствах | Переключение; политика и обстановка не видны вместе | Державам нельзя дать «красный» или «жёлтый» |
| Проверяемость | Правило на L* и насыщенность в валидаторе палитры | Правило режима в коде | Правило на тон в валидаторе палитры |

[Предп.] Насыщенность — самая «селективная» визуальная переменная на фоне ненасыщенных тонов (Bertin, `UI_REFERENCE_LIBRARY.md` §1). Поэтому механизм A работает предвнимательно, а не после чтения легенды. Это стоит проверить на прототипе P2 (§14).

## 4. Три направления
### A. «Надпечатка» (`overprint`) — рекомендуется
| Поле | Содержание |
|---|---|
| Ключевая идея | Мир напечатан спокойными плашками: светлые тинты, тушь, штриховка. Всё, что требует решения, **впечатано поверх** тремя насыщенными «красками». Так печатают оперативные карты: основа готовится заранее, обстановка — надпечаткой |
| Структура | Карта — основа во весь экран. Анализ — «вклейка» справа (30–50% ширины), карта не закрывается. Технологии и конструктор — полноэкранные вклейки. Поля вокруг карты — служебная зона: сверху сигнальное поле (6 мест), снизу кальки и легенда |
| Подпись | Ярлык надпечатки (плашка с текстом) + выноска от места на карте к строке-причине |
| Карта | Пастельные тинты, тушь для границ, штриховка оккупации, плавная отмывка не обязательна. Своя держава обведена внутренней линией тушью |
| Мнемосхема | Тушью на листе. Потоки шириной по объёму, план — контуром, дефицит — жёлтой штриховкой между планом и фактом. Ветка брака. Рычаги у звена с ценой и сроком |
| Паспорт | Основная надпись: крупная литера стадии (Э/О/С/М), обозначение, КБ, интервал эффективности P10–P90, узкое звено, соперник, строка «жизненный путь»; рядом схема изделия по слотам |
| Типографика | Literata (карта, заголовки), Golos Text (интерфейс), PT Mono (числа, id) |
| Плотность | Высокая во вклейке, средняя на карте |
| Сильное | Цвет государств и тревоги сосуществуют без режимов; ближе всего к «атласу» и «мнемощиту» одновременно; самая дешёвая реализация |
| Слабое | Светлая основа утомляет в долгих сессиях; пастель плохо различается на микрогосударствах (нужен режим каймы для мелких) |
| Стоимость · риск | M · риск «ретро-атласа» — запрет текстур бумаги, пятен, сепии |

### B. «Диспетчерская карта» (`control`)
| Поле | Содержание |
|---|---|
| Ключевая идея | Государство — диспетчерская, карта — её главный мнемощит. Матово-тёмный плотный пульт и постоянное табло сигналов |
| Структура | Жёсткие плитки: табло 2×10 сверху, перечень отклонений слева, карта в центре, мнемосхема и шильдик справа, самописцы снизу. Плитку можно развернуть, но не переставить |
| Карта | Два режима. «Политика»: эмаль государств, отклонения только знаками. «Обстановка»: суша серая, кайма и имя, цвет — у отклонений. Режим меняется сам при включении кальки обстановки |
| Мнемосхема | HMI: аппараты с тегами `[ТИП-№]`, серые трубы, шкалы с уставкой, маленький самописец в каждом аппарате |
| Паспорт | Шильдик: моноширинные поля, интервалы, **матрица слотов × альтернатив** (выбрано / доступно / неизвестно / узкое звено), лампы сигналов изделия |
| Типографика | Fira Sans Extra Condensed, IBM Plex Mono |
| Сильное | Лучшая видимость отклонений; прямо продолжает понравившееся во II |
| Слабое | Политика и обстановка не видны вместе; теги с числами **нарушают #33**; шильдик слабо передаёт характер изделия; плитки — L по стоимости |
| Стоимость · риск | L · риск «тёмной админки» высокий |

### C. «Хроника» (`chronicle`)
| Поле | Содержание |
|---|---|
| Ключевая идея | Игра — о разрыве во времени: «узнали» → «научились делать» → «выпускаем». Позвоночник интерфейса — **хронолента** под картой. «Сейчас» стоит на месте, слева прошлое, справа прогноз |
| Структура | Слева рельс систем, сверху карта (55%), снизу лента (40%). Строки ленты — закреплённые объекты: изделия, процессы, знания, политика. Справа паспорт-биография. Табло прикреплено к линии «сейчас» |
| Карта | Насыщенные «школьные» тона без тёплого сектора; белые границы; штриховка оккупации — та же, что на ленте |
| Мнемосхема | **Критический путь**: длина полосы = `eta_months` (контракт §6), узкое место — самая длинная полоса, видны запасы времени и то, как рычаг сдвигает путь и какое звено станет следующим узким местом |
| Паспорт | Штамп + биография изделия рядом с биографией изделия соперника; уверенность разведки — плотность полосы |
| Типографика | Source Serif 4, Source Sans 3, Source Code Pro |
| Сильное | Лучше всех передаёт суть игры; отвечает на «когда?»; самая цветная карта |
| Слабое | Лента постоянно занимает 40% высоты; державам запрещены тёплые тона; политика выражена слабее производства |
| Стоимость · риск | M–L · риск «офисного Ганта» |

## 5. Сравнение
| Критерий | A Надпечатка | B Диспетчерская | C Хроника |
|---|---|---|---|
| Карта + «цвет = отклонение» | одновременно | попеременно | одновременно, с запретом тонов |
| Видимость карты | всегда, 70% ширины | плитка ≈ 40% | всегда, 55% высоты |
| Узкие места | высокая | лучшая | высокая + «когда» |

| Риск шаблонности | низкий | высокий | средний |
| Стоимость в Godot | M | L | M–L |

Анти-шаблонная проверка (бриф §5) для главного экрана A: (1) не похоже на ИИ-дашборд — нет карточек, свечения, тёмных панелей; (2) идентичность — ярлык надпечатки, выноска, литера; (3) раскладка следует из задачи «где → почему → что сделать»; (5) иерархия: сигнал → место → причина → рычаг; (9) декоративных элементов нет. Открытые пункты: (4) повторяемость компонентов вклейки проверить на втором экране (производство); (10) нужна внешняя оценка.

## 6. Рекомендация
[Предл.] **A «Надпечатка»**. Причины:
1. Только в A цветная карта и «цвет = отклонение» действуют **одновременно**, без переключения и без запрета тонов.
2. Все понравившиеся элементы входят в A как родные: атласная карта, штриховка, мнемосхема тушью, штамп, планисфера, хронотаблица (вторым видом).
3. Самый низкий риск шаблонности и самая низкая стоимость.

Заимствования, которые не ломают A: из B — «цвет у причины» и квитирование сигналов ПКМ; из C — критический путь как вкладка «когда?» у мнемосхемы и прогноз всегда интервалом.

| Аспект | Решение [Предл.] |
|---|---|
| Радиус | Слой: FND 112 → PRN 172 → ENG 236 → CMP 300 → PRC 372 → APP 444 (px при 1080p). Кольцо PRC шире остальных и отделено **двойной линией — рубеж «знание ≠ производство»** |
| Угол | 9 макросекторов RR-0008 §2 → клинья дисциплин → **поколения G0–G4 по часовой стрелке внутри клина**. «Новое» всегда лежит по часовой от «старого», а граница знания видна как фронт |
| Фокус + контекст | Секторы, где у игрока цель или выбор, развёрнуты («рыбий глаз»: в эскизе S5–S8 занимают 270°). Остальные сжаты в клетки «сектор × слой» с заливкой = доля известного |
| Рёбра | `requires` идут по **каналам** между кольцами: радиально до канала, по дуге, радиально к узлу. Общие участки сливаются в связки (идея hierarchical edge bundling, Holten 2006, в полярной ортогональной форме). Смена поколений в одном кольце — скобка внутри кольца. Дальние межсекторные связи — хорды, изогнутые к центру. `informs` и `synergy` — только при наведении |
| Состояние узла | Форма = тип: ○ знание (FND/PRN/ENG/CMP), □ процесс (PRC), ◇ изделие (APP). Заливка = состояние: точка — неизвестно; контур — знание есть; сектор внутри — изучается (доля); сплошная — производим или освоено; штриховка — **знаем, но не можем**; пунктирный ◇ — знаем о чужом изделии. Метки: ▲ наружу — соперник впереди; кольцо — ключевой узел (★) |
| Цвет | Только три: ультрамарин — маршрут цели; красный — узкое место; жёлтый — «с трудом» или дефицит. Остальное — тушь и серое |
| Рубеж PRC | На внешнем крае кольца — дуги кластеров (MET/CHEM/MECH/AERO) со **словом способности site**: «уверенно» (серая), «с трудом» (жёлтая), «не можем» (красная) |
| Режим цели | Двойной клик по изделию. Маршрут — синие связки к недостающим узлам. **Производственный контур** — пунктирные кольца вокруг PRC из `prc_set` выбранного варианта. Узкое место выведено выноской в панель: шкала «есть / нужно», `yield_if_fixed`, `eta_months`, рычаг с ценой и недоступные рычаги с причиной. Панель повторяет порядок `why_not` (контракт §6) |
| Время | Часы в центре: стрелка — «сейчас», дуги — окна поколений. Ctrl+перетаскивание стрелки показывает граф на дату — свой или соперника (по данным разведки). Год **не кодируется цветом**: цвет занят отклонениями |
| Подписи (LOD) | На уровне узлов подписаны ключевые узлы, узлы маршрута и выбранный; остальные — при наведении. Подпись всегда горизонтальна, с ореолом |
| Уровни детализации | (1) Круг секторов, ~2000 узлов: клетки «сектор × слой», дуги разрыва на рубеже PRC, метки соперника на ободе. (2) Клин, ~300 узлов: засечки (тёмные — известные), семейства — дуги. (3) Узлы: всё выше. Переход — колесом, по смыслу (RR-0008 §10) |
| Второй вид | **Хронотаблица**: те же узлы, строки в порядке секторов планисферы, время по горизонтали. Открытие — засечка; знание — контур; разрыв — штриховка; освоение — сплошная; прогноз — интервал P10–P90; соперник — ◆ с буквой. Третий вид для экспертов — матрица DSM (RR-0003) |

Расхождение с RR-0008 §2 [Предл.]: там «год виден по цвету и фильтру, а не по геометрии». Предлагаю: по геометрии — только порядок поколений внутри клина (без оси времени), по фильтру — часы. Цвет для года не используется. Это вопрос раскладки, а не модели, но его стоит согласовать (OPEN).

Производительность [Предп.]: 2000 узлов и ~6000 рёбер на уровне секторов не рисуются — там 54 клетки. На уровне клина рисуются ≤ 300 узлов и рёбра только видимого клина. Каналы позволяют кэшировать дуги как общие сегменты. В Godot это `CanvasItem._Draw` с `draw_arc` / `draw_polyline` и MultiMesh для глифов. Оценку должен подтвердить systems-architect (OPEN).

## 8. Ввод: мышь прежде всего (#38)
Грамматика [Предл.]: **кнопка — что сделать; модификатор — в каком измерении расширить**. `Shift` = «больше» (больше объектов, крупнее шаг). `Ctrl` = «время» (темп, история, прогноз).

| Жест | Без модификатора | Shift — больше | Ctrl — время |
|---|---|---|---|
| ЛКМ клик | выбрать, нажать | добавить в набор или убрать; по рычагу — применить ко всему набору со сводной ценой до подтверждения | история объекта (строка хронотаблицы) |
| ЛКМ двойной | паспорт; по изделию на планисфере — режим цели | сравнить с предыдущим выбранным | — |
| ЛКМ перетаскивание | сдвиг холста; «скраб» числа | рамка выбора; «скраб» ×10 | по шкале времени или часам — просмотр прошлого и прогноза |
| Колесо | масштаб под курсором; над числом ±1 | перебор множества: следующий объект того же типа, следующий узел маршрута, следующая строка | **темп игры** в любом месте экрана |
| ПКМ | выноска-меню у курсора; повторно — закрыть | то же для набора | — |
| СКМ | закрепить выноску или подсказку (до 3) | снять все | — |
| Кнопки 4/5 | назад/вперёд по связанным экранам | — | — |

Пути одной мышью [Предл.]: темп — колесо или клик по часам; пакет — кнопка «ко всем выбранным» в полосе выбора; история — вкладка «биография» паспорта; закрепление — значок булавки. Клавиатура — удобство: пробел — пауза, 1–5 — темп, F1–F8 — системы, Esc — закрыть. Опасные пакетные действия подтверждаются в выноске со сводкой. Удержание кнопки как подтверждение не используется.
Дополнения направлений — в `directions-v2.html` (по разделу на направление).
Риск [Предп.]: в браузерах `Ctrl`+колесо означает масштаб. В клиенте Godot конфликта нет, но при первом использовании нужна одноразовая подсказка.

## 16. Вопросы владельцу
1. **Какое направление раунда 2 взять за основу?** Варианты: (а) A «Надпечатка» — светлая атласная карта, тревоги и команды впечатаны насыщенным цветом поверх, анализ во вклейке справа; (б) B «Диспетчерская карта» — тёмный плотный пульт, карта переключается «политика ↔ обстановка»; (в) C «Хроника» — под картой постоянная лента времени, тёплые тона только у тревог; (г) своё сочетание. **Рекомендую (а)** с заимствованиями из B («цвет у причины») и C (критический путь как вкладка «когда?»). Эскизы — `docs/ui/prototypes/directions-v2.html`.
2. **Как назначать цвета государствам на карте?** Варианты: (а) у каждой страны постоянный цвет из палитры, заданный в данных сценария; валидатор следит, чтобы соседи различались; новым странам цвет подбирается автоматически; (б) карта перекрашивается автоматически по правилу «соседи разного цвета» при каждой смене границ — у стран нет постоянного цвета; (в) цвет выбирает игрок. **Рекомендую (а)**: страну узнают по цвету всю партию, а авто-подбор нужен только для новых государств.
3. **Утвердить ли грамматику ввода «Shift = больше, Ctrl = время»?** Ctrl+колесо — темп игры, Shift+клик — добавить в набор или применить к набору, Ctrl+клик — история объекта, колесо — масштаб под курсором. Варианты: (а) да, как в §8; (б) привычная схема программ: Ctrl+клик — добавить в выбор, Ctrl+колесо — масштаб, темп — только кнопками и клавишами; (в) смешанная: (а), но Ctrl+клик — добавить в выбор. **Рекомендую (а)**: она связная, и колесо с модификаторами становится главным ускорением, как требует #38.
4. **Что делать с лишним местом на 2560×1440?** Варианты: (а) по умолчанию масштаб 125%: та же раскладка крупнее, остаток ширины отдаётся карте; (б) 100%: больше информации на экране, но мельче текст; (в) только ручной выбор при первом запуске. **Рекомендую (а)** с настройкой 100–150%.
