## 2. Механизм ловушки
1. Культура C-B (контракт §4.1, временное правило, RISK-0016) растёт от выпуска `v_p`; без выпуска `H` медленно дрейфует вниз (FRA AERO qc −0,0008/мес.).
2. `g_d = G(c − req)` = 0 при `c ≤ req − 1` (`IndustryMath.Yield`), `yield = Π g_d·ramp` = 0 → `production_profile.Admitted = false`.
3. F17 (#138): серия ИИ стартует только при `admitted`; без старта нет `v_p`; без `v_p` `H` не растёт. Состояние поглощающее; выход только через `Effort` (рост от денег разработки процесса, `eta` > 800 мес. у 48) или будущие каналы T6d (лицензия, программа качества — не реализованы).
4. До F17 (печать TASK-0026, `d1-output-diagnosis.md` §4) FRA запускал серию в 15/20 seeds, выпуск был 0, линию снимала ветка С. F17 лишь перенёс провал из С в О.
