Три лучшие точки фазы А: p23 (2,0; 0,12; 0,9; `L` 0,730), p20 (2,0; 0,08; 0,9; 0,802), p18 (2,0; 0,08; 0,6; 0,884).

**Фаза Б (`κ` ∈ {0; 0,25; 0,75; 1} в этих трёх точках, p45–p56):** лучшее — p46 (ранг 1, `κ` 0,25), `L` 0,751; оно хуже p23. `κ` сдвигает G3 и G4 (у ранга 1 при `κ` 0 → 1 доля G4 падает 0,79 → 0,10, G3 растёт 0,32 → 0,57). **Долю G2 `κ` не меняет** (0,09 / 0,07 / 0,06 во всех четырёх `κ`).

**Выбор по правилу:** p23, `L` = 0,730 = d_C3² 0 + d_G2² 0,82² + d_G3² 0,02² + d_G4² 0,24². **Не заморожено.**

**Почему G2 недостижим** [Факт: `node_times`, `gen_times` точек p00, p23, p42]. APP G2 (узел 59) у USA известен в p50 на месяце 139 (k 1) → 84 (k 2) → 56 (k 3, `h_max` 0,16); проект G2 от `Requirement` до первой машины — 36 мес. Первый G2 в строю: p50 1961 → 1956 → 1954, самый ранний за 100 seeds — 1951. Окно 1947–52 требует APP G2 к месяцу ≈ 40–50 больше чем в половине seeds. Тогда APP G4 (узел 61; у USA 233 → 166 → 116) приходит к ≈ 1955 и G4 выходит из окна 1967–75 раньше времени. Промежуток «знание G2 → знание G4» в модели — 6–8 лет, окна требуют ≈ 15–20. Это **относительный** сдвиг поколений при общем k, и `κ` (только сроки проектов G3/G4) его не устраняет. По §8.2 п.4а(5) это структурная находка: она идёт к Orchestrator, а не в новые делители.

**Прочее:** `DESIGN_CAPACITY` = 0 во всех 57 точках (`design_commands_without_design_all_slots_used` = 0, слотов не больше 5 из 12). Отказов по иным кодам — 0–3 на 100 прогонов, печать.
