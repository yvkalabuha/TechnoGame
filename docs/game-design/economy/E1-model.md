## Краткий вывод
- **[Решение владельца #171–#172 → v0.3] Производительность — не путь TFP.** `A_a`, `g_f`, `κ`, `ι`, `β`, `A_min`, `θ_*` удалены; выпуск региона = мощность × загрузка × `f_E` × `f_L` × `Π_rk`, где `Π_rk` — явная функция технологии кластера (Knowledge), способности `min(H,M)` (Industry, те же величины среза) и образованности `h`, с убывающей отдачей (п. 15). Условная конвергенция (#165) получается сама и служит проверкой по Maddison, не множителем. П. 2.2 и 2.3 ниже — **SUPERSEDED** (оставлены как история); в силе п. 14 с поправками п. 15.
- Слой `Core.Economy`, ключ `actor`, шаг месяц (демография и выпуск образования — раз в год, в декабре). Состояние на страну: `Y`, `pop[21]` (5-летние когорты), `edu_pipe`, 4 страновых пула труда, `h` (индекс образования), `s_prog`, `s_edu`. **Капитала нет**: приведённая форма, роль накопления играет доля инвестиций `s_inv` (п. 2.2).
- Рост: `g = g_f + A·κ·gap + ι·(s_inv − s_inv0) + clamp(β·w_slice·ΔCIs, ±ε_cap) − g_shock − pen`. Подушевой темп; `Y` растёт на `g` и на рост населения. Ряды Maddison/PWT — не в рантайме.
- Бюджет: `budget = τ·s_prog·Y`; коридор `[s_lo, s_hi](era, regime)`, штраф вне коридора с потолком. Слои получают `budget_a`, `pool_base` как раньше.
- Числа: `Fx6` (`int64`, единица `Y` — млн $ 1945), все произведения через `Int128`, одно округление на уравнение. `PowFracFx` — единственная нелинейность (кривые демографии, п. 4).
- Режимы: `EXOGENOUS` (колонки Economy вне хеша, M0 бит в бит) и `COUPLED`; регрессионный пакет `g_base ≡ g_a` (п. 7).
- Параметров ~45; «З» (заданы владельцем/контрактом) 7, калибруются 25, данные 13 (п. 11). Данные: лицензии UN WPP, COW, Barro–Lee, USGS, SSP не закрыты (п. 12).
- Gate E1: смена лидера 30–40% (#24, #27), out-of-sample, golden 1945–2100, абляции (п. 10).

## 2. Макроядро (месяц, снимок t → значения t+1) — **SUPERSEDED v0.3 (#172)** в части роста
> Причина: рост через `A_a·κ·gap` и `g_f` — абстрактный путь TFP; владелец (#172) требует, чтобы производительность давали технологии, оснастка и образованность. Замена — п. 15. Остаются в силе: `y_f` как **диагностика** (п. 2.1), пенальти «пушки/масло» `pen` (п. 15.5), предохранители `g_cap`/`g_min` как инварианты на `Y(t)/Y(t−12)`. Текст ниже — история v0.1–v0.2.
### 2.1 Фронтир и разрыв
- `y_f(t) = max_a y_a(t)` по акторам с `pop ≥ pop_min` (микрогосударства не считаются фронтиром). Берётся из снимка: порядок обхода не влияет.
- `gap_a = max(0, (y_f − y_a) / y_f)` — рациональное, без `ln`.

### 2.2 Темп роста (годовая ставка, затем /12)
```
A_a   = A_min + (1 − A_min)·clamp01( θ_h·h_a + θ_c·CIs_a )          # поглощающая способность
cap_a = clamp( β·w_slice·(CIs_a − CIs0_a), −ε_cap, +ε_cap )          # вклад слоя способности
s_inv_a = s_inv0(era,regime) − ρ·max(0, s_prog − s_hi)               # вытеснение инвестиций сверх коридора
pen_a = min( pen_cap, λ·dist(s_prog, [s_lo, s_hi]) )                 # dist = max(0, s_lo−s)+max(0, s−s_hi)
g_a   = g_f + A_a·κ·gap_a + ι·(s_inv_a − s_inv0) + cap_a − g_shock_a − pen_a
g_a   = clamp(g_a, g_min, g_cap)                                     # общий предохранитель
```
- `w_slice = min(w_slice_max, n_slice_clusters / n_clusters_total)` ([Предп.] `w_slice_max = 0,15`). Срез управляет ВВП страны не больше чем на `ε_cap` ([Предп.] 0,005/год).
- `CIs_a = Σ_k ω_k · tier_k(a) / tier_k(world_lead)` по кластерам среза (веса `ω_k` — данные); берётся из `capability_tier`, `world_lead` снимка t.
- Двойной учёт «пушек»: `ρ` (через `s_inv`) и `λ` (через `pen`) бьют по одному и тому же избытку; **суммарный** эффект избытка ≤ `pen_cap + ι·ρ·(s_prog−s_hi)max`, проверяется в Lab (п. 10, E1-L6); в базе [Предл.] `ρ = 0`, `λ` несёт весь штраф, `ρ` — только абляция.
- Темп фронтира в единственной стране-лидере: `gap = 0`, `g = g_f + ι(…) + cap`: лидер не тормозит ниже `g_f`, но и не разгоняется выше `g_f + ε_cap + ι·Δs`.
- Основание формы: условная конвергенция Barro–Sala-i-Martin; Cohen–Levinthal (поглощающая способность); Hidalgo–Hausmann 2009 (сложность предсказывает рост) — [Факт/по памяти; источники в `economy-next-milestone.md`, ист. 4, часть не перепроверялась]. Численные значения `κ ≈ 2%/год`, `g_f ≈ 1,5–2%/год` — [Предп.].

### 2.3 Обновление `Y`
```
pop_total' = pop_total(t+1)                         # из демографии (п. 4); в месяцы кроме декабря = pop_total(t)
Y(t+1) = Y(t) · (1 + g_a/12) · pop_total' / pop_total(t)
```
Реализация: `Y' = MulDiv(Y, (1e6 + g/12), 1e6)` с `Int128`, затем `MulDiv(Y', pop', pop)`; **два округления** (round half to even — [Предл.], привести к правилу Fx6 в `.claude/rules/csharp-core.md`, не проверялось). Рост населения входит только в декабре: так подушевой `y` не ломается ступенькой, потому что `Y` растёт на `pop'/pop` в тот же шаг.

## 3. Бюджет
```
budget_a(t+1) = MulDiv( MulDiv(τ_a(era,regime), s_prog_a, 1e6), Y(t+1), 1e6 )
```
- `τ` — данные (доля государства в ВВП); `s_prog` — рычаг игрока/ИИ (#165); `Σ shares статей = 1` по валидатору `set_budget_shares` (контракт §4.0): **шесть** статей вместо пяти; `edu` — доля, а не отдельный бюджет. ИИ играет по тем же правилам (одинаковый `pen`).
- Рост `s_prog` ограничен скоростью `ds_max` ([Предп.] 2 п.п./год): нельзя сбросить экономику одним шагом.
- В Industry уходит `budget_a` с лагом +1 тик (как `proc_E`); `s_edu` делит бюджет только между `edu` и остальными пятью статьями.
- Положительная связь «деньги → культура → ВВП → деньги» режется `ε_cap`, `E_full`, `sat`, `Hcap` (контракт §8.2); в M0 `E_full` — константа 1945: для рабочих цен 1945 это сохраняется (контракт §13 — не решается здесь).

## 4. Демография (раз в год, шаг декабря; 5-летние когорты)
```
out_c   = pop_c / 5                      # доля когорты, переходящая в следующую за год
pop_c'  = pop_c − out_c − μ_c·pop_c + out_{c−1}     (c ≥ 1)
pop_0'  = births − μ_0·pop_0 − out_0
births  = tfr_a · F_share · Σ_{c=3..9} pop_c / 35     # 35 = ширина фертильного окна, лет
```
Фертильные когорты — 15–49 (c=3..9); `F_share` = 0,5 [Предп.] (пол не разделён). Нормировка проверяется калибровкой: TFR 5–6 должен давать рост 2–3%/год (WPP).
- Транзиция: `tfr_a = tfr_lo + (tfr_hi − tfr_lo)·PowFracFx(1 − min(1, y_a/y_tr), q_tfr)`, `y_tr` — подушевой порог транзиции (данные). `μ_c = μ_min_c + (μ_max_c − μ_min_c)·PowFracFx(1 − min(1, y_a/y_mort), q_mort)`. Показатели `q_tfr`, `q_mort` — целые в 1/1024 (ADR-0012), кеш на актора на год (≤ 2 вызова × 200 акторов раз в год).
- Годовой шаг для мирных потерь; **войны и катастрофы — события потока** (`pop_loss` по когортам, пропорционально), не часть кривой.
- Миграция: нет (FUTURE, RR-0015). Закрытая популяция; инвариант `Σ pop' = Σ pop + births − deaths` точно (остаток округления — в когорту 0, правило фиксируется).
- Данные 1945: UN WPP — с 1950; 1945 = обратная экстраполяция [Предп.], с пометкой на каждую страну (СССР, Германия, Япония — ручная оценка по G-E0).

## 5. Труд и образование
Годовой шаг (декабрь), после демографии.
```
L           = Σ_{c=3..12} pop_c            # 15–64
enrol_sec   = min( cap_sec·cohort_sec,  enrol0_sec(era,regime)·cohort_sec + edu_sec_budget / c_sec )
enrol_ter, enrol_sci — аналогично (c_ter, c_sci — стоимость места, в постоянных ценах 1945)
edu_X_budget = s_edu · budget_a · w_X          # делит доля `edu` по ступеням (w_X — данные/решение ИИ)
```
- Базовое обучение `enrol0` **бесплатно** (данные эпохи): иначе бедная страна без `edu` не имеет школ. Рычаг `s_edu` добавляет места сверх базы, с потолком `cap_*` (доля когорты). Если бюджета не хватает на место — берётся floor(budget/c): целые единицы, остаток в `rem_edu` (не теряется, переходит на следующий год).
- Выпуск: ступень `X` учится `dur_X` лет; выпускники кладутся в `edu_pipe[X][dur_X]`, раз в год `edu_pipe[X][k]` сдвигается; по `k=0` выпускники входят в `N[cat]`. Лаг 5–15 лет: `sec→skilled` ~4–6, `ter→engineer` ~8–10, `sci→scientist` ~12–15 [Предп.].
- Потери выбытием: `N'[cat] = N[cat] − N[cat]·(ret_cat + μ_L) + inflow[cat]`; `ret_cat` — оборот 1/годы карьеры (данные), `μ_L` — смертность 15–64 из п. 4.
- `unskilled = L·emp_rate − Σ N[skilled…scientist]`, не ниже 0 (`emp_rate` — данные эпохи/режима); `Σ N ≤ L` — инвариант.
- `h = Σ_{cat≠unskilled} N / L` ([0,1]); `A_a` использует `h`.
- **Малая страна с большим бюджетом не получает инженеров мгновенно** (#24): `inflow` ограничен `cohort·cap` и лагом; численность пулов **не масштабируется бюджетом** (в отличие от M0).
- Спрос: `reserve_workforce(site, cat, n, requester_id)` без изменений; страновой пул → site через `share_site`.
- Миграция/«утечка мозгов» — вне E1.

## 6. Фиксированная точка и детерминизм
- Базовый тип `Fx6` (`int64`, масштаб 10⁶; ADR-0003: `*`, `/` — в `Int128`). Все `MulDiv(a, b, c) = round_half_even( a·b / c )` в `Int128`.
- **Запас:** `Y_max` в сырых единицах = `Y[млн $]·10⁶`. США 1945 ≈ 1,6·10⁶ млн $ [Предп., Maddison, проверить] → 1,6·10¹² сырых. При `g_cap = 6%/год` 190 лет: ×~10⁵ → ~10¹⁷ < `int64.Max = 9,2·10¹⁸`, запас ~50×. Инвариант: `Y_raw · H_Y < Fx6.Max`, `H_Y = 8` — тест на «макс. рост 190 лет» и на «`g_cap` тик за тиком» (проверка числа — в Lab, не гарантирована).
- Промежуточные `Y·(1e6+g/12)` до 10²⁴ → только `Int128`; `int64` умножения запрещены (арх. тест).
- Порядок округления: один round_half_even на `MulDiv`; сложение без округления; `clamp` после. `g/12` — целочисленное деление Fx6 с round_half_even, остаток **не** переносится (дрейф ≤ 0,5 ulp/мес. на страну, проверяется golden).
- `PowFracFx(Fx6 x, int q10)` — ADR-0012/0003 R2; `x ∈ [0,1]` в обеих кривых, `q10 ∈ [128, 2048]`. Других `pow/exp/ln/double` нет.
- RNG нет (#28): шоки — события потока; порядок merge по `country_id` по возрастанию; обход когорт и ступеней — по индексу.
- **Golden:** хеш `Y`, `pop_total`, `h`, `budget_a` по годам 1945–2100 на 3 сценариях (база, `g_cap`, `s_prog` ломаная).
- Кросс-платформа L1/L2 (ARM64 — ADR-0003, TASK-0009 открыт: Economy не использует FMA-зависимых выражений; `a*b+c` в `Int128` целочисленные).

## 7. Режимы связи и порядок в тике
**Порядок (ADR-0006).** Economy — месячный compute по снимку t (читает: `capability_tier`, `world_lead`, события, `granted` кадров, флаги эмбарго E1.5); в снимке t+1 видны `budget_a`, `pool_base`, `Y`, `h`. Вычисления акторов независимы (читают только снимок), merge по `country_id`. Годовой шаг — в тике декабря; календарь (`month_index % 12`) — данные тика, не состояние.
- **EXOGENOUS (по умолчанию):** `budget_a(t) = budget_a(t−1)·(1 + g_a/12)` (сценарий), `pool_base` — как в M0; колонки Economy (`Y`, `pop`, `N`, `h`, …) не пишутся и не входят в хеш мира; 4 пула вырождены в 2 пула M0 (`skilled+engineer`, `unskilled`). **M0 хеш бит в бит** — стоп-критерий при любом изменении.
- **COUPLED:** полная модель п. 2–5; печатается абляция «пулы как в M0» (RISK-0018, FRA не лечатся скрытно).
- **Регрессия `g_base ≡ g_a`** (пакет данных): `g_f = g_a`, `κ=ι=β=λ=ρ=0`, `g_shock=0`, демография выключена (`pop` const, `births=deaths=0`), `s_prog` и `τ` const; **бюджет в пакете считается рекуррентно** тем же порядком операций, что и M0 (`budget·(1+g/12)`), иначе `τ·s·Y` даст другое округление; тогда бит в бит. Вариант без рекуррентности — допуск `|Δbudget| ≤ ε_reg` на 30 лет; **любое расхождение статистики HYP-0002 — провал.** Допуск — [Предп.], определяется замером.
- Без пакета регрессия `COUPLED ≡ EXOGENOUS` не заявляется.

## 8. Инварианты тика (post-check)
`Y ≥ 0`; `Y_raw·H_Y < Fx6.Max`; `|cap_a| ≤ ε_cap`; `g ∈ [g_min, g_cap]`; `s_prog ∈ [0,1]`, `Σ shares = 1`; расходы ≤ `budget_a`; `Σ N ≤ L`, `N ≥ 0`, `pop ≥ 0`; сохранение людей; `y_f` монотонен только в сценарии без шоков; в `Core.Economy` нет RNG (тест как для Industry); в `EXOGENOUS` слой не пишет в хеш; L1/L2.

### 14.1 Состояние региона `r` (ключ `region_id`, страна `a(r)`)
| Переменная | Тип | Смысл |

### 14.2 Энергия, диспетчеризация (месяц)
```
D_r  = Σ_k e_k · K_rk · u_r                      # потребность (u_r — загрузка, ≤1)
loc_r = min(D_r, Gav_r)                           # 1) своя энергия
R_r  = D_r − loc_r ;  S = Σ_r (Gav_r − loc_r)·(1−loss) # 2) остаток пула
imp_r = выдача из S в порядке (prio_k, region_id), не больше R_r   # целые единицы
σ_r  = (loc_r + imp_r) / D_r                      # доля покрытия
p_e,r = (loc_r·p_loc,r + imp_r·p_loc,avg·(1+m_{d(r)})) / (loc_r+imp_r)
```
`d(r)` — число шагов в графе до ближайшего региона-донора (из графа ADR-0011, целое, предрассчитано); `m_d = m_1·d` (линейно, ≤ `m_max`). Инварианты: `Σ(loc+imp) ≤ E_nat`; `σ ∈ [0,1]`; все остатки округляются в пользу экономии (floor), порядок обхода — по индексам.
Цена энергии `p_loc,r = Σ_t share_t·c_fuel,t(region)` (данные; тепло — цена топлива, гидро ≈ 0 переменных).

### 14.3 Выпуск, деньги, рост
```
f_E,rk = e_floor_k + (1 − e_floor_k)·σ_r            # e_floor_k: 0 (жёсткая потребность) … 0.5 (гибкая)
a_r    = min(1, (N_r,свободно + commute_c·N_соседей,свободно) / need_r)
f_L,r  = a_r^η   (вариант B)   |   запрет строительства при need > доступно (вариант A)
V_rk   = φ_k · A_a · K_rk · u · f_E,rk · f_L,r  − c_en,rk         # c_en = e_k·p_e,r·... учитывается в φ_k·(1 − energy_cost_share)
Y_a    = Σ_{r,k} V_rk + Y_rest,a
Y_rest,a(t+1) = Y_rest,a(t)·(1 + g_rest)·pop'/pop , g_rest = g_f + A_a·κ_rest·gap  # без построек
```
Рекомендуется вариант B с порогом: `build_ok ⟺ a_r(после ввода) ≥ a_min`, ниже — штраф. `η ∈ [1,2]` — калибруется (>1: штраф сильнее при малой доле штата).
**Рост по частям:** `g_A = A_a·κ·gap + clamp(β·w_slice·ΔCIs, ±ε_cap) − g_shock − pen`; `A_a' = A_a·(1 + g_A/12)`; `I = s_inv·Y`; `K' = K + ΔK_done − δ_K·K`, `G' = G + ΔG_done − δ_G·G`. `Y` теперь — выход (не состояние), `g_cap` — инвариант на `Y(t)/Y(t−12)`. `ι` удалён из формулы (двойной счёт); `ρ/λ` (пушки/масло) действуют через `s_inv` и `pen` без изменений. Положительная петля `Y → I → K → Y` режется: `δ`, `rise(K_r/pop_r)`, труд, `g_cap`, `ε_cap` — абляции: `ι≡0`, `δ` высок, `rise = 0`.

**v0.3 поправка (#172):** в формуле `V_rk` множитель `A_a` заменяется на `Π_rk` (п. 15); строки `Y_rest` и «Рост по частям» (`g_A`, `A_a'`) **SUPERSEDED** — `A_a` и его динамики нет; `Y_rest` — п. 15.4. ### 15.2 Функция
```
Π_rk = clamp( Π_min_k + (Π_max_k − Π_min_k) · τ_ak^α · c_rk^γ · h_r^ε , ·)       # α+γ+ε ≤ 1,  α,γ,ε ∈ (0,1): убывающая отдача, PowFracFx
e_rk,eff = e_k · (1 − ζ·τ_ak)                                                    # энергоёмкость падает с технологией (выпуск на единицу энергии растёт)
V_rk = K_rk · u · f_E · f_L · Π_rk          # K измерена в млн $ 1945 при Π = 1; цену энергии платит себестоимость, п. 14.2
|ΔΠ_rk|/Π_rk ≤ ε_Π за год  (общий предохранитель вместо ε_cap·w_slice)
```
- Выпуск на работника и на единицу энергии: `V/N_eff = (K/N_eff)·Π…` и `V/e = Π/e_eff` — обе растут по `τ, c, h` и имеют потолок `Π_max_k` (насыщение).
- Нехватка квалификации (`h` мал) снижает `Π` гладко; нехватка людей вообще — `f_L` (п. 14.3, #171). Это разные каналы: `f_L` — **сколько** людей, `h` — **какие**.
- ~~Кластеры вне среза: `c_rk = c_0`~~ — **SUPERSEDED v0.4 (#173):** для **всех** промышленных кластеров есть слой `H, M` — «лёгкий слой» п. 15.9; `c_rk` берётся из него (или из среза там, где владелец срез). Вес среза в стране ограничен долей `K` его кластеров, а не `w_slice_max`.

### 15.3 Откуда берётся рост `τ` и сближение
- Для кластеров среза `τ` = Knowledge, слой его не пишет Economy (открытие, исследование, лицензия, `X½`, диффузия — как в срезе). Для остальных — грубый индекс `τ_ak`, правило: `dτ = (r_own_k + δ_τ·gap_τ,k·Abs_a)·dt`, `gap_τ,k = τ_lead,k − τ_ak`, `Abs_a = Abs_min + (1−Abs_min)·h_a^{ε_a}`; `r_own` — внутреннее открытие (мало, зависит от доли `scientist`), `δ_τ` — скорость заимствования **с отставанием** (чем дальше от лидера, тем быстрее). Тот же закон заимствования, что `world_lead`/`X½` в срезе — [Предп., сверить со спекой среза §3.x; если срез использует иное, общий закон берёт срез].
- Сближение возникает из трёх причин, ни одна не множитель: (1) заимствование пропорционально отставанию; (2) убывающая отдача `Π`, `rise(K/pop)` — у бедных стройка дешевле на единицу эффекта; (3) условие `Abs_a` и `c`: без образованности и оснастки заимствованное не работает — «условность» конвергенции. Лидер растёт только со скоростью собственных открытий `r_own`, `c`, `h` — потолок `Π_max`.
- **Проверка (не вход):** Lab считает β-конвергенцию по симуляции, `Δln y = a + b·ln y₀ + d·h`, ожидается `b < 0`, значение — коридор эмпирики (≈ −1…−3%/год, Barro–Sala-i-Martin 1992; [по памяти, не перепроверялось]) и траектории Maddison 1945–2020 для стран V.

### 15.4 Сельское хозяйство и услуги (`Y_rest`), минимум
```
τ̄_a (состояние, EMA):  τ̄' = τ̄ + (1/T_rest)·(Σ_k w_k τ_ak − τ̄)             # T_rest 20–30 лет: механизация, удобрения, электричество приходят из промышленности с задержкой
y_rest,r = y_rest_min + (y_rest_max − y_rest_min) · τ̄_a^{α_r} · h_r^{ε_r}      # $ 1945/чел., PowFracFx
Y_rest,a = Σ_r pop_r · y_rest,r · (1 − pen_a)                                  # без стройки; (1 − pen): «пушки/масло» бьёт потребление
```
Одно состояние на страну (`τ̄`) и 5 параметров (`y_rest_min/max, α_r, ε_r, T_rest`). Образованность — главный быстрый драйвер, технологический индекс — медленный. Пока `Y_rest` не имеет мощности и стройки (#171).

### 15.5 Бюджет и «пушки/масло»
Рост `Y` больше не задаётся ставкой, поэтому штраф `pen` действует: (а) через `s_inv` (меньше мощности), (б) множителем `(1−pen)` на `Y_rest`. `ι` и `ρ` как отдельные ставки удалены; `ρ` — доля вытеснения `s_inv`, `λ`, `pen_cap` остаются. `g_cap`/`g_min` — инварианты на `Y(t)/Y(t−12)`.

### 15.6 Связь с способностью среза и защита от двойного учёта
- **Экономика читает способность** (`τ, H, M, mastered, yield` из снимка t, лаг +1 тик); **способность тратит деньги экономики** (`budget_a = τ_g·s_prog·Y`, лаг +1). Замкнутая петля «способность → `Π` → `Y` → бюджет → оснастка/образование → способность» режется: насыщением `Π_max`, убывающей отдачей, `ε_Π`, `E_full/sat/Hcap` среза, лагом, инвариантом `Y ≤ …`.
- Правила: (1) `H, M, yield, mastered` пишет **только** Industry/Knowledge; Economy их не дублирует и не хранит; (2) `Π(t0)` вычисляется из `τ, c, h` t0, а `K_rk(1945)` калибруется так, чтобы `Σ V = Y_1945`; GDP на душу не вводится вторым входом (R-W: он уже в `culture_H`); (3) образование входит в `Π` через `h`, в `Hcap` v1 = 0 (F-SC3). Если позже `Hcap` получит рост с образованием, `h` в `Π` заменяется на разность `h − h_in_Hcap` или `Π` читает `min(H,Hcap)` — решение на gate, не молча; (4) режим `EXOGENOUS`: `Π ≡ 1`, `f_E=f_L=1`, колонки вне хеша — M0 бит в бит.

### 15.8 Критерии Lab (замена/добавление)
- E1-L3 (прежде) смена технологического лидера среди великих за 30 лет — **30–40%** (#24) на регионной модели, повтор E1-L12; теперь лидерство — по `τ` и `c`, а не по `A`.

- E1-L17: `Y_rest` без образования/технологии не растёт сверх `y_rest_min` на 30 лет.

### 15.9 Лёгкий слой культуры и оснастки для всех кластеров (v0.4, решение #173) [Предл.]
**Идея.** Те же величины, что в срезе (`culture_H`, `tooling_M`, `Hcap`), но **одна пара на ячейку `(r,k)` без деталей процессов и измерений**: `H_rk` — это `culture_H[precision]` (в срезе `purity = H−0,2`, `qc = H−0,3` — смещения), `M_rk` — `tooling_M[precision]`. Агрегат по процессам ячейки — максимум (как правило R-H-MS среза). `c_rk = min(H_rk, M_rk)/Hcap_ref_k ∈ [0,1]`.

**Кто владеет значением (нет двойного счёта).** Таблица владения `owner(r,k)` — данные сценария:
| Ячейка | Владелец `H, M` | Что делает Economy |
|---|---|---|
| `(r0, k)`, `k ∈ кластеры среза` (авиация и др.), site среза | **срез** (Industry, детальные процессы) | читает `c_rk` из снимка: `max` по `mastered` процессам `min(H,M)` для precision; своих `H,M` не пишет |
| любая другая ячейка | **лёгкий слой** (Economy) | считает `H, M` ниже |
| регион ≠ `r0` страны среза, кластер среза | лёгкий слой, **потолок** `H_rk ≤ H_slice(r0,k)` (опыт внутри страны не превышает лучший завод) и старт `H_rk(t0) = H_slice(t0)·ratio_reg` | как выше |
Правило: каждое `(r,k)` читается из ровно одного источника; тест — хеш владения. `EXOGENOUS`: слой выключен, `c ≡ 1`.

**Рост культуры (упрощённый C-B, месяц).** Деньги наладки ячейки `E_rk = D_light · V_rk / Σ V` (пропорционально выпуску; `D_light` — часть статьи «наладка» `D`, п. ниже); потолок выпуска `c_p = SmoothStep01(min(1, u_rk / u_cap))` (загрузка вместо `ṽ/v_cap` среза). 
```
ΔH⁺ = min( Hcap_rk − H_rk,  r_cap_L · c_p · SatE(E_rk / E_ref_k) )        # SatE: насыщение, PowFracFx
ΔH⁻ = r_decay_L · (H_rk − H_floor_rk) · max(0, 1 − u_rk/u_keep)             # забывание при простое; H_floor = φ_floor·Hcap
H' = H + ΔH⁺ − ΔH⁻ ;  Hcap_rk = H(t0) + hc_k  (рост с образованием v1 = 0, как в срезе F-SC3)
```
Импорт `H` не повышает (RR-0006 §4.14); заимствование — только через `τ` (п. 15.3), `H` растёт лишь от собственных денег наладки и выпуска.
**Оснастка.** `M* = min(H + m_lead, M_cap)` (цель V5 среза), инвестиция из `D_light` долей `s_M`: `ΔM⁺ = min(M* − M, ρ_max_L·InvShare)`, износ `ΔM⁻ = δ_M·max(0, M − M*)`; `M ≥ 0`, `M ≤ M_cap`. `c` ограничен слабейшим из `H` и `M`: деньги на наладку без оснастки (и наоборот) повышают `c` лишь до `min`.

**Деньги.** Статья `D` делится по выпуску: `D_slice = D·f_slice`, `D_light = D·(1 − f_slice)`, `f_slice = ΣV(кластеры среза)/ΣV`; `D_slice` идёт в существующую процедуру среза (A37/A39) как прежний `D`. [Предл., требует сверки systems-architect/game-designer: в M0-бюджете `D` целиком срезовый; доля `f_slice` в COUPLED — меняет поток; в `EXOGENOUS` не действует.] Инвариант `D_slice + D_light = D` точно (остаток — в `D_light` в порядке индексов).

**Согласование со срезом (должно сводиться).** Для кластера среза в отдельной ячейке лёгкое правило, запущенное параллельно на агрегате, обязано воспроизводить траекторию `H, M` среза: калибровка `r_cap_L, r_decay_L, ρ_max_L` на сценариях среза (seeds, **не** «увиденные» 41–60), допуск `|H_light − H_slice| ≤ ε_H` на 30 лет [Предп., 0,15 шкалы H] — проверка, значение для расчёта берётся из владельца (срез). Если расхождение > допуска — правится лёгкое правило, а не срез (срез главнее: M0).
**Старт 1945.** `H_ak(t0) = H_ref_t·(y_a/y_ref)^q_H` по классу сложности `t ∈ {1,2,3}` (3 класса, не 12), якорь — 21 ячейка среза (R-W/R-H-MS); `H_rk = H_ak·ratio_r`, `ratio_r = (h_r/h_a)^{ε_r0}`; `M(t0) = H + 0,2` (как A20). Ручных чисел: `H_ref_t` (3), `q_H`, `hc_k` по классу (3).

**Параметры.** З: структура (`c = min(H,M)`, `M(t0)=H+0,2`, `D_slice+D_light=D`, 3 класса сложности, потолок по лучшему заводу страны). Калибруются (К, ~10): `r_cap_L, E_ref_k(по классу), u_cap, u_keep, r_decay_L, φ_floor, ρ_max_L, δ_M, m_lead, q_H, ε_r0`. Данные (Д, ~8): `H_ref_t`(3), `hc_t`(3), `M_cap_t`(3 → общие с срезом `Hcap`-правилом), `ratio_r`. Итого по документу: **≈ 92** (было ≈ 78; `c_0` удалён) [Предп.], фиксируется «по классу сложности».
**Размер и такт.** Ячеек `(r,k)` ≈ 200 регионов × ~6 активных кластеров ≈ 1200–1500 (разрежено); состояние `H, M` = 2 `Fx6`/ячейка, ~20 операций/ячейку/мес ⇒ ≈ 3·10⁴ операций, **+0,05–0,1 мс** [Предп.]; E1 в целом ≈ 0,25–0,3 мс (прежний E1-L13 «< 0,2 мс» → **< 0,35 мс**). Формат сохранения: +2 колонки на ячейку в тот же `save_format_version` bump. Объём E1 растёт (деньги наладки, оснастка, владение) → E1 вероятнее делить на E1a/E1b: лёгкий слой в E1b рядом с образованием [Предл.].
**Lab.** E1-L18 «сводимость»: лёгкое правило на агрегате среза ≈ H/M среза (`ε_H`). E1-L19 тест владения (каждая ячейка читается из одного источника; `D_slice + D_light = D`; сдвиг `H` на δ → ΔY ≤ (∂Π/∂c)·δ·K, ср. L16). E1-L20 границы `H ≤ Hcap`, `M ≤ M_cap`, `H ≥ H_floor`, импорт не растит `H`. E1-L21 абляции `LIGHT_OFF` (`c ≡ c_0`) / `LIGHT_NO_TOOLING` (`M ≡ ∞`) / `LIGHT_NO_DECAY`: сравнить смену лидера (30–40%) и β-конвергенцию. E1-L22: прогон без слоя vs с слоем на M0-сценарии — статистика HYP-0002 не меняется при `EXOGENOUS`.
**Риск:** «ещё один слой» — распухание и дубль с срезом (RISK-0016 правило C-B временное: лёгкий слой наследует его слабости и обязан заменяться вместе с ним — единая функция роста вызывается обоими слоями, [Предл.] параметры общие там, где срез их задаёт).
