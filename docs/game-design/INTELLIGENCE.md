## 3. Контрразведка, раскрытие, дезинформация (по RR-0017 §2)
- **Контрразведка:** `ci_eff = sat(ci_budget/GDP_t)` ∈ [0,1]. Рост чужой сети: `× (1 − k·ci_eff)`, `hazard`: `× (1 + g·ci_eff)`; критерий: при `ci_eff = 1` равновесный `N*` и скорость падают ≥ 50 %. Игроку — два уровня «обычная / усиленная». Видимое: «поймано сетей: N», «успешные кражи у вас (оценка): мало / много».
- **Трение секретности:** [Предп., дизайн, не из RR-0017] усиленная контрразведка относительно траектории ИИ даёт `e_intel` ≥ −0,02 по дисциплинам обменивающихся институтов; исторической основы нет, проверяется в Lab (I-3). Уровень «обычная» = траектория ИИ, вклад 0.
- **Раскрытие (ADR-0021):** `hazard[o,t] = clamp(a0·eff·(act_obs + act_steal + act_dis)·(1 + g·ci_eff), 0, p_max)`, `p_max` ≈ 0,15/мес; наблюдение (`act_obs` = 0,1) тоже рискованно, безопасного режима нет. Потери: `N ·= 0,25`, `A ·= 0,2` в merge D−1 (применяет INT); событие `support` и `T` не пишет.
- **Дезинформация `dis` (исправлено против rev 1).** Это порча источников *наблюдения*: `φ = min(1, dis·κ)`, `c = floor(φ·s + ½)` из `s = floor(S_max·N)` источников (`S_max` = 6). Если `s − c ≥ 2`, порченые отбрасываются («расхождение источников»), иначе `bias_eff = b·c/s` — «ложная уверенность — цена малой сети». Направления: `dis[t→o]` — цель портит сети наблюдателя; `dis[o→t]` — собственная операция против ИИ цели. **Прямого эффекта на скорость исследований нет**; rev 1 приписывал «ложный след −3 % скорости вору» — этого в RR-0017 нет, убрано. Косвенно: ИИ/игрок решает по искажённой оценке.
- **Обращённые сети** (`mode = turned`, `taint`): `turned` — в v1 по #364, `p_detect_turn` = 0,05/мес, поток `intel.turn`; `taint` — FUTURE (RR-0017). Для игрока в срезе — только событие «обратить / разоблачить» у ИИ, без ручки.
- **Показ уверенности:** `conf = 1 − (1−q)^s`, `q = maturity(A)`; `intel_conf = conf·sens(node)`; видимость слоя 3 при `intel_conf ≥ 0,3` [Предп.]. `comm` (RR-0019) на видимость не умножается.
- Доминирующей стратегии быть не должно: T2 RR-0017 (кража у порога `hazard` теряет сеть с ожидаемой частотой).

## 6. Бюджет: `security` без седьмой доли
- [Факт, E1-model:73, RR-0011 A10] `set_budget_shares` — шесть долей; RR-0017 (§2 «Бюджет») называет `security` седьмой долей и выносит конфликт в OPEN. RR-0021 (46) ожидает ось `security` в решениях.
- [Предл.] Разрешение: `security` не седьмая доля, а **подстатья существующей государственной статьи** (оборона/безопасность; название и состав — economy-analyst, мной не проверено). Отдельных ручек «разведка» и «контрразведка» игрок не получает: `ci` задаётся тем же уровнем. A10/E1, формат сохранения и валидатор `Σ shares = 1` не меняются; INT←ECO читает `GDP_t` и значение подстатьи (одна новая стрелка).

- Диапазон: 1–3 % ВВП [Предп.]; один бюджет на три потребителя (D-new-2): сумма не удваивается.

## 8. Детерминизм и идентификаторы
- RNG только в `StochasticEventSystem`: ключ `(seed, day, stream, (o,t))`, потоки `intel.expose`, `intel.turn` (RR-0017); бросок раз в месяц в день `D(o,t) = hash(o,t) mod 30`. Рост сетей, `steal`, `dis`, `maturity`, `conf` — фикс. точка без RNG, без `e^x`, `floor`/round-half-up целочисленно.
