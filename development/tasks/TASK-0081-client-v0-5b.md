# TASK-0081 — Client v0.5b: main menu, settings, new game, palette C with alert validator, time icons

## Цель
Клиент v0.5b по спецификации `docs/ui/CLIENT_V05B_SPEC.md` и макету `docs/ui/prototypes/client-v05b.html`.

## Описание
1. Главное меню: Новая игра, Загрузка (неактивна до кода сохранений ADR-0013), Настройки, Выход.
2. «Новая игра»: выбор державы игрока (заменяет флаг `--power`).
3. Настройки: Видео, Звук, Общие (язык переезжает сюда). DLSS — серый пункт «требует плагин» (предложение ui-art-director, может быть изменено владельцем).
4. Иконки времени: пауза, медленнее, быстрее.
5. Палитра C (токены §17), скругления, `warn` #D9860F с ореолом, контуром и знаком ▲ (#326).
6. Валидатор контраста тревог по алгоритму спецификации (ΔE2000 и оттенки серого, включая затенённую сушу); запуск в `--shots`, результат в лог; провал не блокирует сборку, а печатается.
7. Пункты v0.5b из `docs/ui/reviews/task-0077-visual.md`: легенда цветов и глифов, центр камеры с учётом правой панели, отклик панели на клик по другой стране.

Не менять Core, Session, Kernel.

На глобусе (`Overlay`): ореол `sheet` 3 px, контур тушью 1 px, знак; плашка появляется по настоящему сигналу державы игрока (СПЛАВ, ЛИЦЕНЗИЯ, ОТКАЗ, СБОЙ). В `--shots` добавлены демо-плашки на тинтах (только для снимков, помечено в логе).

Esc в игре открывает меню (время на паузе), «В главное меню» перезагружает сцену. Настройки: Видео, Звук, Общие, `user://settings.cfg`, «Применить / Отмена / Сбросить», диалог отката через 15 с для разрешения, режима окна и апскейла, масштаб UI 100–150% шаг 12,5, DLSS серый с причиной, Alert не ниже 20% (штриховка).

- **Пункты ревью v0.5a для v0.5b.** Легенда дерева (кнопка и клавиша L, Esc закрывает; цвета из токенов, коды FND…APP); уровень «узлы» подписывает фронтир именами; центр камеры по свободной области слева от панели (`PlanisphereMath.CameraForShift`: ошибка 0,0–0,1 px при сдвиге 270 px); тег выбранной чужой державы (тинт, название, «ЧУЖАЯ ДЕРЖАВА · только просмотр», кнопка «К своей державе», Esc).
- **Валидатор** `ContrastValidator.cs` (без Godot): sRGB→Lab, ΔE2000, ΔL* по оттенкам серого, CVD (Machado), затенение суши и моря из шейдера (день, терминатор, ночь, ночь с оттенком, блик), ореол, попарные тинты ≥ 8 при каждом затенении, хрома OKLCH. Запускается в `--shots`, печатает PASS/FAIL по каждой паре в `run-log.txt`; провал не прерывает сборку.

**Результат валидатора на палитре C** (103 из 107 пар PASS; ΔE2000 вручную не подгонялись):
- FAIL `warn` на `land-none` (затенённая): ΔE 25,6, ΔL 12,5 (< 15); ореол ↔ фон 6,1 < 8, поэтому ореол не спасает.
- FAIL хрома `warn` 0,150 и `command` 0,162 при пороге ≥ 0,17 (порог из спецификации [Предп.]); FAIL хрома `tint.3` 0,135 при пороге ≤ 0,13.
- Все пары `alarm`, `command` на тинтах, море, интерфейсе — PASS; `warn` на `tint.1/5/7` — PASS по ореолу (прямая ΔE 14,4 / 17,4 / 20,1: прямой контакт не проходит, ореол обязателен); попарные тинты при ночном и терминаторном затенении — все PASS (минимум 8,4 у `tint.1` и `tint.7`).
- Для сравнения палитра v0.2: 97 из 107; FAIL `warn` на море и ничьей земле (ореол слаб), пять пар тинтов при ночном затенении (ΔE 3,6–7,6). Приёмка спецификации «на v0.2 PASS» этим не выполняется; юнит-тест проверяет v0.2 только на интерфейсе и тинтах.
- Вердикт по спецификации §7: палитра C «условно» (обязателен ореол `warn`); три FAIL порога хромы и `warn` на `land-none` требуют решения (см. ниже).

**Не сделано / отклонения от спецификации:**
- Загрузка и Сохранение неактивны (нужен код ADR-0013); «Продолжить» в заглавном меню неактивно (нет сохранений); таблица сохранений §3 не делалась.
- Превью державы в «Новой игре»: поворот фонового глобуса, отдельного мини-глобуса в карточке нет.
- Пауза по аварии (§5г) и настройка «пауза при аварии», «анимации», канал «Эффекты» (нет шины) помечены «макет»: у них нет потребителя.
- Легенда: пять дисциплин текущего дерева, не шесть (электроники в дереве нет).
- Диапазон ступеней времени: три (день, неделя, месяц), как в симуляции, а не пять.
- Ширина вкладок и прочих листов проверена на 1600×900 при 100% и 150%; 1280×720 и 1920×1080 не снимались.
- Жадная раскраска карты использует только тинты 1–5 (тинты 6–8 на глобусе не встречаются), поэтому демо-плашка «на тинте 7» стоит на тинте 5; тинты 6–8 валидатор проверяет как токены, на снимке их нет.
- «Кромка выбранного пункта цветом домена» в главном меню: кромка слева у пунктов цвета росписи, у выбранного — тушь; цвет линии домена в выделении не применён.
