## 2. Правило (формула)
Обозначения: `L` — класс изделия (`ProductsLayout`), `APP(g)` — узел поколения g, `K(a, n)` — узел n известен актору a (снимок).
1. **Следующее поколение** g* — наименьшее g, которое актор ещё не может собрать: `APP(g)` неизвестен **или** в каком-то слоте нет доступной (`DesignRules.Available`: требования и процессы известны) альтернативы, подходящей g: двигатель с `eng_gen ≥ max(1, g − 1)` (#70: `gen = min(g_p, eng_gen + 1)`), планер с `rank ≥ platform_min_rank(g)`, прочие слоты — с `max_eng_gen` под этот двигатель.
2. **Затравка пути** `S(g)` = `APP(g)` + для каждого слота без подходящей доступной альтернативы — требования (`requires_nodes`, у группы any_of — все члены) и процессы (`prc_set`) подходящей альтернативы наименьшего ранга. Так в путь попадают нужные процессы, а не только узлы знания.
3. **Путь** `P(g)` = неизвестное замыкание `S(g)` по `requires` (тот же обход, что `KnowledgeSystem.BuildGroups`: из неудовлетворённой группы — все неизвестные члены). Ярус 1 = `P(g*)`, ярус 2 = `P(g* + 1)` (узлы, ещё не попавшие в ярус 1).
4. **Выбор цели свободного слота** (заменяет `PickForFreeSlots` rev 4 §7): кандидаты — узлы фронта, не занятые другим слотом; правило `PATH` (предлагаемое) — только ярус 1, среди них — наибольший `PolicyRules.Priority` (как сейчас), при равенстве — порядок `_g.Order`; если узлов фронта на пути нет — слот **без цели** (деньги идут обычной долей). Институт для цели — как сейчас (наибольший уровень в области, при равенстве — меньший слот); удержание цели и перевод раз в 12 мес. не меняются.
5. Замерены также: `PATH2` (ярус 1, затем ярус 2, иначе без цели), `PATH_FILL` (ярус 1, 2, затем самый весомый вне пути), `MIX1` (не больше 1 слота на пути, остальные — самый весомый вне пути, каждый откатывается на другой список).

## 3. Почему правдоподобно
- [Предп.] Государственные НИИ 1945–1970 работали по программам изделий: ЦАГИ/ЦИАМ — под конкретные МиГ и двигатели, NACA — под требования ВВС (стреловидное крыло, правило площадей), RAE — под заказ министерства снабжения. «Самый тяжёлый узел науки» как цель — артефакт веса `Priority`, а не политика.
- [Предп.] Процессы в пути (литьё лопаток, механообработка крыльчатки) — исторически узкое место (у СССР двигатель G1 — копия Nene, но серийная технология отставала); правило их видит, весовое — нет.
- Правило читает только снимок знания и данные класса изделия: оно детерминировано, не смотрит на соперников и на исторические годы (нет «подгонки под историю»).

## 4. Чем отличается от игрока
- Игрок ставит цель куда угодно (в т. ч. на науку «впрок»), ИИ — только на путь своего ближайшего поколения; советник (#479, `Propose`) предлагает игроку цель по тому же правилу — игрок видит «что сделал бы ИИ».
- ИИ не оставляет слот «на будущее» и не держит цель ради опыта института; при пустом пути слот без цели. Игрок может обогнать ИИ, заранее ставя цели на g* + 1 или на науку, которая откроет несколько поколений, — это и есть его преимущество в планировании (правила денег, κ и бонус те же, #496).
