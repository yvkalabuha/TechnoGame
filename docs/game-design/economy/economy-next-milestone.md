## 2. Минимальная экономика: что внутри

### 2.1 ВВП и рост (E1)
- **Состояние на страну:** `Y_a` (реальный ВВП, `Fx6`; **единица — млн $ 1945**), `pop_a`; `y_a = Y_a/pop_a`. `CI_a` — производная. ВВП один скаляр, **без секторов**.
- **Правило условной конвергенции** [Предл., по Barro–Sala-i-Martin; Solow с фронтиром]. Месяц; годовые ставки /12:
  - `gap_a = max(0, (y_f − y_a)/y_f)` (рациональное, без `ln`); `y_f` — подушевой ВВП фронтира = лучшая страна в снимке (не ряд из данных);
  - `g_a = g_f + A_a·κ·gap_a + ι·(s_inv_a − s_inv_0) + clamp(β·(CI_a − CI_0), ±ε_cap) − g_shock_a − pen_prog_a`;
  - `g_f` — темп фронтира: параметр сценария (константа по эпохам, [Предп.] ~1,5–2%/год), не историческая серия;
  - `A_a ∈ [0,1]` — поглощающая способность: функция `CI_a`, доли образованных (`edu`-поток, E1) — Cohen–Levinthal [Предп., по памяти]; `κ` — скорость схождения ([Предп.] ~2%/год по эмпирике условной конвергенции, проверить источник на E0);
  - `s_inv_a` — доля инвестиций в `Y` (часть `s_prog`, т. е. решение игрока); `s_inv_0` — нейтральное значение эры;
  - `CI_a` — средний `capability_tier` по кластерам (веса из данных) относительно лидера; **вес среза в CI ≤ `w_slice_max`** ([Предп.] 0,15): 3–4 кластера не должны управлять ВВП страны;
  - **предел петли CI → Y:** `|clamp(...)| ≤ ε_cap` = [Предп.] 0,5 п.п./год на страну; инвариант тика;
  - `g_shock` — эмбарго (E3), война, дефицит CMP (E2) — события из потока (ADR-0004); RNG в слое нет (#28). Шоки 1973/1990-х **не зашиты**: они сценарные события мода, а не базовый путь.
- Основание [Факт: RR-0006 ист. 15]: сложность производства страны предсказывает будущий рост (Hidalgo–Hausmann 2009). `β`, `κ`, `ι`, `ε_cap` — [Предп.], калибруются в Lab.
- **Maddison/PWT — только калибровка:** подбор `κ`, `g_f`, `ι` на одном диапазоне сидов/стран и **out-of-sample проверка на отдельном диапазоне сидов и отдельном наборе стран** (калибровка и проверка не пересекаются; иначе тавтология, п. 1 «Разногласий»). Ряды не входят в `data_hash` рантайма; в репозитории — только таблица якорей для Lab.
- **Контрфактический сценарий** (обязательный EXP): «страна X не инвестирует в `CI`/`edu`» против базового; проверка, что выход разумен (отставание накапливается, но |эффект| ≤ `ε_cap`), и что без вмешательств игрока история не «ломается» (Y в коридоре ±40% якоря на 30 лет [Предп.]).
- Арифметика: рациональные выражения, `PowFrac` при необходимости (ADR-0012, ADR-0003 R1–R3); `exp`, `double` нет. **Инвариант запаса `Fx6`:** `Y_max(2100)·headroom < Fx6.Max` при `g ≤ g_cap`; тест на сценарии «макс. рост 190 лет»; **golden длинного ряда** (1945–2100, хеш `Y` по годам) против накопления округления.

### 2.2 Формирование бюджета (E1)
- `budget_a(t) = τ_a·s_prog_a·Y_a(t)`: `τ_a` — доля государства (**данные** по эпохе/режиму), `s_prog_a` — доля на программы (НИОКР, оснастка, наладка, закупки, QP, образование) — **рычаг игрока/ИИ** (решение владельца #165).
- **Коридор:** `[s_lo(era, regime), s_hi(era, regime)]` — данные (напр. СССР 1950 vs. нейтральная малая страна; источники — военные расходы COW/SIPRI-подобные, [Предп.] лицензии проверяются на G-E0). Внутри коридора штрафа нет; вне — `pen_prog_a = λ·dist(s_prog, коридор)` в годовом росте (меньше потребления/инвестиций → ниже рост; «пушки или масло»), с потолком `pen_cap`. Рост `s_prog` сверх коридора также съедает `s_inv` (альтернативная стоимость).
- ИИ выбирает `s_prog` по тем же правилам (нет бесплатного разгона у ИИ); штраф симметричен для игрока и ИИ.
- **Регрессионный пакет** `g_base ≡ g_a`: отдельный пакет данных, где `g_a(t)` = экзогенный путь среза (константа по месяцам); тогда `COUPLED` при `β = 0`, `κ = 0`, `ι = 0`, `pen = 0`, `g_shock = 0` воспроизводит `EXOGENOUS` (M0) бит в бит или с оговорённым допуском округления; без пакета регрессия не заявляется. `EXOGENOUS` — старая траектория бит в бит.
- Рычаги игрока: доли статей (есть), `edu`, `s_prog` (в коридоре); `τ` — данные.
- Положительная связь «деньги → культура → ВВП → деньги» ограничена `E_full`, `sat`, `Hcap`; в бюджет каналов контракта §8.2 добавляется «канал денег».

### 2.3 Труд (E1)
- 4 пула на site (`unskilled`, `skilled`, `engineer`, `scientist`; в M0 два). На страну: `pop_a`, доля трудоспособных, выпускники по ступеням.
- Поток: статья `edu` → выпускники с лагом 5–15 лет → пулы; смертность, пенсия. Миграция и «утечка мозгов» — FUTURE (RR-0015).
- Спрос — как сейчас: `reserve_workforce(site, cat, n, requester_id)` (контракт §4.6, без изменений); дефицит уже бьёт по `act`, `w`.
- Отличие от среза: численность пулов **не масштабируется бюджетом**, поэтому малая страна с большим бюджетом не получит инженеров мгновенно (асимметрия #24).
- **Объём E1 — по решению владельца (#165): макроядро + 4 пула + демография + образование.** Два следствия:
  - **Уровень gate+research** (DF-001 §6): доля `edu` и пулы/демография меняют формат сохранения (ADR-0013 п. 7, `save_format_version` растёт один раз) и валидатор `set_budget_shares`; нужны ADR, research по демографии/образованию и миграция сохранений.
  - **Как E1 не мешает открытым пунктам M0** (RISK-0018 малый пул, пул FRA, вердикт HYP-0002): (a) E1 стартует **после** вердикта M0; (b) режим по умолчанию `EXOGENOUS`, 4 пула в нём вырождаются в 2 пула среза (`skilled+engineer`, `unskilled`) с тем же `pool_base`; (c) `COUPLED` — отдельный прогон с отдельной абляцией «пулы как в M0» (не лечит скрытно RISK-0018/FRA); (d) значения пулов FRA и параметры M0 не правятся в E1; (e) любое изменение статистики M0 при `EXOGENOUS` — стоп-критерий.
- Два сектора (Льюис, п. 10) — отложено; доля аграрной занятости как источник `unskilled` — вопрос после E1.

### 2.7 Экспортный контроль на существующих предметах, этап E1.5 (решение #165)
- Без торговли и CMP (E2–E3): `export_control(from, to, item)` над **уже существующими** предметами среза — лицензия (`take_licence`), компонент, сплав. Режимы данных: `OPEN`, `LICENSE_REQUIRED`, `DENIED` по блоку и эре.
- Историческая рамка [Факт, по памяти — проверить на E0]: CoCom, 1949 (западный блок против СССР/ВД); эффект на срез: отказ лицензии/компонента → `why_not` корень «контроль экспорта», а не «нет денег».
- Цена: страна под контролем теряет канал `LicenceFlow`/`sale_income` и получает `g_shock` малого размера (не больше `ε_cap`). Эмбарго бьёт и экспортёра (потеря `sale_income`).
- Не делает: цен CMP, платёжного баланса, санкционной политики (вторая волна).
- Gate E1.5: контрфактуры «блок с контролем / без» в Lab; не даёт серебряной пули (замещение через собственную культуру C-B остаётся).

### 2.4 Ресурсы, материалы, цепочки (E2)
- 10 природных категорий (RR-0006 §4.9): мощность добычи — данные страны, без истощения; ценность месторождения нулевая, пока процесс-потребитель не известен. Материалы — только выходы `PRC`; нефть не подменяет пластик.
- Национальный баланс по CMP: `supply = Σ выход + импорт + выдача из запаса`, `demand = Σ вход + экспорт + пополнение`; делёж дефицита целыми единицами в порядке `(country_id, cmp_id, consumer_id)`; граф «вход → выход» ацикличен, циклы рвёт пометка `lagged` (RR-0010 §5(a), §6).
- Запас `stock[country, cmp]`: цель в месяцах потребления, стоимость хранения в бюджете, запас не учит.
- Концентрация `share_site` пока вырождена (один site); осмысленна в E4.
- Открыто для systems-architect: проход по графу CMP за месяц или лаг месяц на звено (RR-0010, OPEN 1).

### 2.5 Торговля и экспортный контроль (E3)
- Мировой рынок — **цена по CMP как функция мирового баланса** (`price = p0·(1 + k·дефицит)`), без ордербука. Сделка допустима, если `allowed(from, to, item)` и хватает мощности перевозки и денег импортёра.
- Предмет торговли: CMP, **компоненты** (изделие без проекта игрока; граница RR-0010 §6), лицензии (`take_licence` уже есть). Готовые системы и знание — вне E3 (RR-0015).
- Инструменты: `embargo`, пошлина как коэффициент цены, лицензия на экспорт. Санкции = набор эмбарго + `g_shock`; **политика санкций — вторая волна по роли**, в E3 только механика.
- Платёжный баланс — один агрегат на страну (экспорт − импорт в постоянных ценах); отрицательный режет `s_prog`. Курсов и долга нет.
- Инварианты: `Σ экспорт = Σ импорт` по item; `stock ≥ 0`; импорт не растит `culture_H` (RR-0006 §4.14); #62 — импорт не даёт лидерства.
- Внешний рынок парка (#142) в E3 — частный случай торговли «изделие → страна-покупатель с бюджетом»; до E3 остаётся как в срезе.

### 2.6 Что остаётся абстрактным
Валюты и курсы, инфляция, налоги по видам, цены по заводам и отраслям, домохозяйства и потребление (кроме доли `τ`), финансовый сектор, логистика (один коэффициент цены), потоки между site, энергия (один баланс по RR-0006 §4.8, не раньше E2).

### 2.8 Региональная модель (v0.3, по замыслу владельца #170)
Формулы и порядок тика — `E1-model.md` п. 14. Здесь — суть, стык со срезом, карта, данные. Всё [Предл.], кроме #170.

**2.8.1 Модель.** Регион `r` (устойчивый ID, принадлежит стране; группа провинций ADR-0011). Состояние региона: `pop_r` (доля страны, когорты — на уровне страны), `N_r[cat]` (труд по 4 категориям), `K_r[k]` (мощность промышленности по кластеру `k`, единица — выпуск в млн $ 1945/год при полной загрузке), `G_r[type]` (генерация по типам), `queue_r` (очередь строительства). Страна: `E_nat = Σ_r G_r` — национальный объём энергии.
- **Энергия:** потребность `D_r = Σ_k e_k·K_rk·u`. Диспетчеризация детерминированная: (1) своя энергия региона по цене `p_loc`; (2) недостающее берётся из остатка национального пула по цене `p_loc·(1 + m_dist)`, `m_dist` — наценка по числу шагов в графе регионов (целое); (3) очередность при дефиците — приоритет кластера (рычаг), затем `region_id`; `Σ использовано ≤ E_nat·(1 − потери)` — инвариант.
- **Себестоимость:** `c_rk = c_mat,k + e_k·p_e,r + c_lab`; цена энергии региона входит в стоимость выпуска (видна в UI и в `why_not`).
- **Дефицит энергии → объём:** `f_E = σ_r` (доля покрытой потребности), выпуск `K·u·f_E·f_L`; для кластеров с жёсткой потребностью (металлургия, химия) пол `f_E ≥ f_floor` не вводится — линейно; для остальных можно смягчать (данные `e_elast_k`).
- **Труд: два варианта.** (A) **жёсткий запрет**: строить мощность можно, только если после ввода `need_r ≤ N_r,свободно + приток из соседей`. Плюсы: нет пустых заводов, читаемо; минусы: бинарность, «стена» для малых и разрушенных регионов (Германия/Япония 1945), игрок обходит дроблением стройки. (B) **штраф**: стройка разрешена, `f_L = a_r^η`, `a_r = min(1, N_r,доступно / need_r)`; плюсы: гладкая функция, нет стен; минусы: можно строить «пустое» (потеря денег, это цена решения). **Рекомендация [Предл.]: B с мягким порогом** — штраф по умолчанию, а ниже `a_min` (≈ 0,3, данные) постройка запрещена; ингредиент — рабочие соседних регионов считаются с коэффициентом `commute_c` (≈ 0,5). Так нет ни пустых «призрачных» заводов, ни стен.
- **Деньги:** `Y_a = Σ_r Σ_k V_rk + Y_rest,a`; `V_rk = φ_k·A_a·K_rk·u·f_E·f_L` — добавленная стоимость, `A_a` — множитель производительности (TFP) страны. `Y_rest` — не-промышленная часть (сельское хозяйство, услуги): доля `ψ_a` от `pop`-взвешенного ВВП по данным, растёт с `A_a` и населением, **не строится** (вопрос 2).

**2.8.2 Как это сочетается с условной конвергенцией (#165).** [Предл.] Конвергенция остаётся, но управляет только `A_a`: `g_A = A_a·κ·gap + clamp(β·w_slice·ΔCIs, ±ε_cap) − g_shock − pen` (прежний `g_f` — темп фронтира для `A`; член `ι·(s_inv − s_inv0)` из v0.2 **удаляется**: инвестиции теперь действуют через построенную мощность, иначе двойной счёт). Рост мощности — из `I = s_inv·Y`, расходуемых на стройку, минус износ `δ·K`. Следствие: догоняние = дешёвая стройка (мало мощности на душу) + перенос технологий; потолок — труд региона, энергия, убывающая отдача (`cost_build` растёт с `K_r/pop_r`). Предохранители E1 (`g_cap`, `ε_cap`, `w_slice_max`) сохраняются; `g_cap` теперь ограничивает рост `Y` итоговый. Альтернатива (оставить скалярный `Y`, регионы — только распределение) отвергается: теряется весь смысл #170 (деньги зависят от промышленности).

**2.8.3 Стройка.** Объект — промышленная мощность `(r,k)` или генерация `(r,type)`.
| Параметр | Промышленность | Энергетика |
|---|---|---|
| стоимость | `c_K,k·ΔK·(1+rise(K_r/pop_r))` | `c_G,type·ΔG` |
| срок | 24–60 мес. [Предп.] | тепло 24–36, гидро 48–72 [Предп.] |
| труд | строительный: unskilled+skilled региона на время стройки | то же |
| энергия | после ввода `e_k` на единицу | топливо — ресурс страны (уголь, нефть из 10 категорий); гидро ограничено потенциалом региона (данные) |
Стройка не мгновенна, очередь `queue_r` с датой ввода (детерминированно, без RNG #28), ресурсы списываются помесячно. Новые типы энергии (атом и др.) — через знание (Knowledge), как изделия.
**Рычаги игрока/ИИ:** `s_inv` (в коридоре, #165); раздел инвестиций «энергия/промышленность/регион»; приоритет диспетчеризации (кого отключать первым); тарифы энергии (субсидия) — FUTURE. ИИ — эвристика «запас энергии ≥ m, строить, где `a_r ≥ a_min`», те же правила, что у игрока.

**2.8.4 Стык со срезом.** [Предп., требует сверки со спекой среза] Site Industry = **региональный завод** `(r, cluster)`: ключ `site` уже есть; один site на страну в срезе = один регион-носитель (регион `r0`). Слой способности (`culture_H`, оснастка) остаётся **на site** — а значит региональный, в соответствии с принципом «умение ≠ мощность»; `f_E`, `f_L` входят множителями в `line_capacity` / `act` (интерфейс не меняется, меняется источник). Пулы труда §2.3: страновой `N[cat]` делится на `N_r` по `share_r` (данные + динамика по росту населения, миграция — FUTURE); `share_site` из E1 становится частным случаем. Сплав: в E2 — национальный CMP; доставка в регион — через `m_dist`-подобную наценку (E3/E4), в E1 сплав считается доступным в регионе среза. Режим `EXOGENOUS`: страна из одного региона, `f_E = f_L = 1`, колонки регионов вне хеша → M0 бит в бит.

**2.8.5 Устойчивость [Предл.].** Риски: разгон «деньги → стройка → деньги» (ограничен `δ`, трудом, `rise`, `g_cap`); доминирующая стратегия «строить энергию везде первой» (энергия без потребителя даёт 0 и стоит денег, амортизация); «все приоритеты — военные» (рационирование бьёт гражданский `Y`, цена); накопление излишков генерации. Инварианты: `Σ использовано ≤ E_nat`; `K,G ≥ 0`; деньги, списанные на стройку = Σ взносов очереди; `Σ N_r ≤ N`. Lab-эксперименты: (i) шок энергии −30% на 12 мес.: `ΔY` в коридоре и затухает; (ii) контрфактур «без строек»: `Y` не растёт сверх `A`; (iii) абляции `NO_DISPATCH_MARKUP`, `LABOUR_A/B`; (iv) смена лидера 30–40% (#24) на регионной модели — повторно; (v) малая страна не догоняет (E1-L8).

**2.8.6 Агрегация и стоимость тика.** ~150–250 регионов × ~12 кластеров × ~10 операций + диспетчер O(R log R) ≈ 3·10⁴/тик, < 0,2 мс [Предп.]; хранение: `Fx6`, детерминированный порядок `(country_id, region_id, cluster_id)`.

**2.8.7 Карта (ADR-0011, PROPOSED).** ADR-0011 сейчас — «для M0 нужен только граф», масштаб открыт. Для регионов нужно: стабильные ID регионов, площадь, граф соседства и **шаги/расстояние** (для `m_dist`), принадлежность стране, флаг береговой линии (E3). Гранулярность: **регион ≈ группа провинций**, 5–15 на великую державу, 1–4 на малую, итого ~150–250; провинции (сотни/тысячи) в экономику не нужны. **Влияние на этапы:** «регионы» уходят из E4 в **E1** (первичные регионы, энергия, мощность, труд); E4 сужается до уязвимости/захвата/перелива и транспортного ограничения. E1 тяжелее → остаётся gate+research, **ADR-0011 должен быть доработан и принят до E1** (число регионов, ID, формат в сохранении, ADR-0013). Идёт новый ADR при смене формата.

**2.8.8 Данные (#168: CC BY/PD/CC0 + ручные оценки с источником; 1945, #130).** Регионы 1945: границы — Natural Earth (PD) [Факт по ADR-0011]. (a) Население регионов: Maddison — только страна; регионы — ручные оценки по переписям (США 1940, СССР 1939, Германия 1939, Япония 1940 — первичные источники, часто PD; не проверено); возможный кандидат — HYDE 3.x (сетка населения, CC BY 4.0?) [Предп., лицензию и охват не проверял — проверить на G-E0]. (b) Энергия 1945: по странам — отраслевая статистика (Mitchell, Etemad–Luciani, USGS/Bureau of Mines — лицензии не проверены); для генерации по регионам — ручная оценка по крупным объектам (ГЭС, ТЭС) на 1945 год с источником; Global Power Plant Database (CC BY 4.0) содержит текущие станции с годом ввода — только как вспомогательное, [Предп., проверить]. Потери войны (Германия, Япония, СССР-запад) — факт на t0, входит в старт (#130). Ничего из этого не подтверждено как набор с лицензией и покрытием 1945; все региональные числа — ручная оценка.

Что **не** меняется: контракт слоёв §4.1–4.4, §6; содержание парка и закупки; правило культуры C-B.
