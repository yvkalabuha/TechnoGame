## 5. Изделие по поколению: правила
- **R-HF.** T_h[g] = (историческая цена без GFE в $ 1950)·0,8 / `c_h`; `h_floor[g]` = 0,25·T_h, округлённое до 10 ч; `h_first[g]` = 4·`h_floor[g]` (отношение §8.1). Часы от `M$` не зависят.
- **R-MF.** `materials_floor[g]` = ⌊доля GFE · цена в $ 1950 / `M$`⌋. Покупное не учится, множителя 0,8 нет.
- **R-PS (принято #78).** Процессная часть изделия = `⌊proc_scale[g]·Σ base_cost_p⌋` по `prc_set` изделия. `proc_scale[g] = 0,75·T_raw[g] / Σ base_cost_p(prc_set превосходящего g)`, где `T_raw[g]` = обучаемая цель в raw (T_h·`c_h`/80 $). Множитель относится к изделию поколения g, а не к процессу (`base_cost_p` общий для всех изделий). Одинаков у всех акторов. Причина: у G3 и G4 общий `prc_set` планера, и без R-PS G4 получает 0,49 цены (F-PI5). Вариант «остаток в `materials_floor`» отклонён решением #78.
- **R-AK.** `alloy_kg[g]` = масса двигателя × доля жаропрочного сплава × коэффициент отхода (5 у всех поколений, est). Один двигатель на изделие.
- **R-DS (принято #78).** `W = W0·complexity·design_scale[g]/(1 + bureau_exp/E_B)`; `design_scale[g]` = (DAPCA `H_E`[g]/`H_E`[G1]) / (`complexity`[g]/`complexity`[G1]) (§7). Одинаков у всех акторов. Это калибровка по эмпирической регрессии, а не по исходу.

- **Предложение R-BS [Предл.] → simulation-engineer (F-PI8):** запрос КБ `bureau_req[g] = ⌊500·√design_scale[g]⌋` = 500 / 526 / 674 / 883 инж. Тогда T (exp = g−1) = 23 / 23 / 31 / 35 мес., что близко к историческим 29 / 18–43 / 31–43. Показатель ½ — предположение: численность КБ 1945–75 в источниках не найдена. Следствие: SWE (`engineer_base` 480) не может полностью укомплектовать КБ G3–G4 и проектирует дольше. Это нейтральное правило, а не подгонка под исход.
- Окна C4 (spec §9: G4 в строю 1967–75): при exp = 0 и фиксированных 500 инж. G4 требует ≈ 122 мес. проекта + испытания, то есть > 12 лет. Это риск для окна, если APP G4 появляется позже ≈ 1958. С R-BS — ≈ 70 мес. при exp = 0.

**14.3. [Предл.] R-PS2m — монотонная огибающая, точные эталоны.**
