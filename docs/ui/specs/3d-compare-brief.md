# Сравнение 3D: одна модель через Claude и через Gemini (#539)

Задача обоим исполнителям одна и та же. Исполнитель строит модель в живом Blender через Blender MCP (execute_blender_code).

## Объект
Оригинальный реактивный истребитель 4-го поколения игры (слоты `eng_g4` + `af_mach2` + `ab_on`, `mods/core/product_classes.yaml`). Не копия реального самолёта: без узнаваемых силуэтов конкретных машин.

- Два турбовентиляторных двигателя рядом в хвосте, два круглых сопла с форсажем.
- Боковые прямоугольные воздухозаборники по бокам фюзеляжа за кабиной.
- Крыло для 2 Махов: трапециевидное, стреловидность передней кромки около 40–45°, высокоплан или среднеплан, корневые наплывы.
- Два киля, слегка развалены наружу. Цельноповоротный горизонтальный стабилизатор.
- Одноместная кабина, каплевидный фонарь. Острый нос с радиолокационным обтекателем.
- Размеры: длина около 19 м, размах около 13 м, высота около 5,5 м.

## Правила сцены
- Метры. Нос по оси +X, размах по Y, верх по +Z. Центр модели около начала координат, низ на z = 0 (шасси не нужно).
- Все объекты модели — в одной коллекции с именем исполнителя (`Claude_G4` или `Gemini_G4`), в отдельной сцене с тем же именем. Чужие сцены и коллекции не трогать.
- Только собственная геометрия: без импорта и генерации чужих моделей.
- Материалы: окраска обязательна (процедурные текстуры: камуфляж, линии панелей, металлические сопла, тонированный фонарь). Освещение и камеры не нужны — рендер делает общий скрипт.
- Бюджет: не больше 60 вызовов execute_blender_code. Проверяйте себя через look.

## Оценка
Общий скрипт рендерит обе модели одинаково: вид сверху, сбоку, спереди и 3/4 в стиле чертежа игры. Судит ui-art-director вслепую (модели подписаны «A» и «B»).
Критерии: силуэт читается как истребитель 4-го поколения с двумя двигателями; чистота геометрии (без дыр и пересечений); пропорции; соответствие брифу; число вызовов и время.
