# Иконки областей (решение #352; структура — `docs/game-design/UI_INFORMATION_ARCHITECTURE.md`)

Свои рисунки, ничего не трассировано; лицензия проекта. [Факт] 20 файлов: 10 знаков x 2 размера. Сетка 24 du, поле 2 du, рабочая зона 20x20; линия `#1D1E20` (`ink`), без заливки, miter, butt, углы 45°/90° и окружности.
Размеры: `*-24.svg` — штрих 1,5 px; `*-48.svg` — тот же рисунок (viewBox 24), штрих 1,25 ед. = 2,5 px при 48 px (оптическая поправка: прямое удвоение дало бы 3 px и тяжёлый знак). Цвет области и состояния задаёт контейнер кнопки, не файл.

| Файл | Область | Горячая клавиша | Образ |
|---|---|---|---|
| science | Наука | T | граф зависимостей (три узла) |
| production | Производство (+ресурсы) | E | цех с трубой |
| finance | Финансы и торговля | F | фасад с колоннами |
| forces | Силы (армия + снабжение) | M | щит с двумя шевронами |
| intel | Разведка | I | глаз с визирными засечками |
| politics | Политика (внутренняя + дипломатия) | G | амфитеатр зала и флаг |
| projects | Проекты и люди | J | ракета (нацпроект); люди — в картинке области |
| map | Карта (постоянная сцена) | Esc | глобус с сеткой |
| journal | Журнал сигналов (не область) | ` | лист с записями |
| lock | Состояние «заперто» | — | замок (накладывается на кнопку) |

Если владелец выберет 9 областей (вместо слияний): `forces` остаётся армией, логистике нужен 11-й знак (сходящиеся рельсы), политике — отдельная дипломатия; знаки дорисовать по этим правилам.
