# Моды (ADR-0010)

- Каждый мод — каталог с `mod.yaml` (id, версия semver, зависимости `{id, min, below?}`, `files` в порядке загрузки). Базовая игра — мод `core`.
- Схемы файлов — `schemas/*.schema.json` (JSON Schema 2020-12); проверка в CI — `tests/Singularity.Core.Tests/Data/SchemaTests.cs`. Загрузчик — `src/Singularity.Core/Data/ModLoader.cs`.
- Данные — строгий YAML: без якорей, тегов и неявных типов. Текст, похожий на число или на bool YAML 1.1 (`yes`, `no`, `on`, `off`, `y`, `n`), пишется в кавычках — и в значениях, и в ключах. Это касается и id мода: мод с id `no` или `y` записывается как `id: "no"`.
- Файлы данных — только с расширением `.yaml`; файл `*.yml` или `.yaml`, не перечисленный в `files`, — ошибка загрузки.
- Операции над объектами по ID: `define`, `override`, `patch` (поля верхнего уровня заменяются целиком), `delete`. Менять чужой объект можно, только если мод зависит (транзитивно) от каждого мода, который уже менял этот ID.
- Правило v0: удалённый ID остаётся удалённым — повторный `define` или `override` того же ID запрещён. Чтобы заменить объект, используйте `override` вместо `delete` + `define`.
