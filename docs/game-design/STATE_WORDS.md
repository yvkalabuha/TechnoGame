## 0. Общие правила
| Правило | Содержание |
|---|---|
| R1 Пересчёт | Слово пересчитывается раз в тик (месяц) по снимку, а не каждый кадр |
| R2 Гистерезис «тревога сразу, отбой с запасом» | Слово ухудшается **точно на механическом пороге**. Улучшается, только когда значение ≥ порог + `h`. `h = 0,03` для величин в [0, 1], `h = 5%` от порога для отношений. Поэтому хорошее слово никогда не противоречит `why_not` и `mastered`, а отставание плохого слова не превышает `h` |
| R3 Состояние гистерезиса | Только UI, в состояние симуляции и сохранение не входит. После загрузки слово берётся прямо по порогам, без памяти |
| R4 Подсказка | Точное число, порог следующего слова, тренд за 6 мес.; для способности ещё `have / need` и источник `H|M|ramp` (контракт §4.2, A5–A6) |
| R5 Цвет у причины (#54) | Красный (■) — только корневое звено: первое звено `why_not` текущей цели или `bottleneck`. Жёлтый (▲) — плохое слово, которое не является первым звеном. Следствия (изделие, линия, готовность) пишутся тушью со ссылкой «← причина». Насыщенного цвета у слова без причины нет |
| R6 Второй канал | Каждое тревожное слово сопровождается формой знака (■/▲), см. UI §2 |

## 1. Способность `CAP`: `g_d` по измерению, `yield_p` процесса, кластер site
| Слово | Условие | Цвет (R5) |
|---|---|---|
| свободно | ≥ 0,9 (для `g_d`: `gap ≥ 0`, g = 1) | тушь |
| уверенно | [0,7; 0,9) | тушь |
| с трудом | [0,3; 0,7) — ниже порога CAPABILITY в `why_not`, `world_lead`, `mastered` | ▲ жёлтый |
| на грани | (0; 0,3) — допущено, но выпуск не питает `K_ind` (§4.3) | ▲ жёлтый |
| не можем | = 0 (`gap < −1` или `p ∉ known_processes`) | ■ красный, если это корень; иначе ▲ |

- `gap = min(culture_H, tooling_M) − r_d`. Для справки: `g = 0,7` при `gap ≈ −0,16`, `g = 0,3` при `gap ≈ −0,45`.
- **Кластер site (дуга на кольце PRC):** слово = `CAP(min yield_p)` по процессам кластера из `prc_set` текущей цели. Если цели нет — по процессам, которые site ведёт (`proc_v > 0`). Если нет и их, дуга серая, без слова.
- **Профиль изделия (`production_profile`):** слово = `CAP(yield узкого процесса)`. Цена — отдельно (§3).
- «не можем» без гистерезиса: `admitted` — двоичный факт симуляции.

## 8. Уверенность разведки
В срезе величины-источника нет: соперник виден полностью. Слово «достоверно» на каждом экране было бы фальшивой механикой. Поэтому в срезе слово не показывается. Шкала-заготовка для будущей `intel_conf ∈ [0, 1]` (RR-0015): «достоверно» ≥ 0,8 · «вероятно» [0,5; 0,8) · «по слухам» [0,2; 0,5) · «нет данных» < 0,2. Это слова неопределённости, а не тревоги: цвета нет, только плотность полосы (UI §5).

## 9. Метка альтернативы «заменитель» и причина `ENGINE_GEN_LIMIT` (v0.3)
Основания: DECISIONS_LOG #131, #136; `docs/simulation/slice-jet-aviation.md` v0.14 §1.4 «Поля альтернатив v0.14»; `docs/game-design/rank0-steel-g1-review.md` §1, §3. Это **метка** (двоичный факт данных), не шкала: гистерезис (R2) не нужен.

**Определение.** «заменитель» — подпись альтернативы с `substitute: true` (сейчас одна: `hot_steel_g0`, ранг 0). Это не ступень лестницы рангов, а обходной вариант: работает с ограничениями и уступает «настоящей» альтернативе слота.

**Когда показывается.**
- Рядом с названием альтернативы везде, где она видна: выбор в `compose_design`, паспорт проекта, состав в `derive`, строка `why_not`, список вариантов в подсказке слота.
- Для проекта — подпись у слота, где выбран заменитель («горячая часть: сталь, заменитель»). Слово не показывается у альтернатив без `substitute` и не зависит от того, что выбрал ИИ или игрок.
- Цвет: тушь. Метка сама не тревога (R5): красный/жёлтый получает только корневая причина (`ENGINE_GEN_LIMIT`, `ECONOMY` и т. д.).

**Подсказка (шаблон из полей данных).**
> «заменитель: {name} — без {alloy_node_name}, только для двигателя G{max_eng_gen}; содержание ×{upkeep_mult}; для G{max_eng_gen+1}+ нужен {lever_node_name} (узел {lever_node})».

Для `hot_steel_g0` (подстановка полей `alloy_free: true`, `max_eng_gen: 1`, `upkeep_mult: 2,5`, `requires_nodes` не-`substitute` альтернативы с наименьшим рангом: 30): «сталь без сплава, только для двигателя G1, содержание ×2,5, для G2+ нужен сплав 30». Фрагменты показываются только для заданных полей: нет `max_eng_gen` — нет «только для двигателя»; `upkeep_mult` = 1 — «содержание» не пишется; `alloy_free: false` — «без сплава» не пишется. Числа берутся из данных мода, а не из текста подсказки. В подсказку же добавляются (R4): `perf_mult` (0,90), цена штуки и содержание рядом с эталоном не-`substitute` альтернативы, если она известна.

**Отношение к `simplified_variant`.** Разные слова и разные факты, не смешивать.
| | «заменитель» | «упрощённая» (`simplified_variant`) |
|---|---|---|
| Что это | альтернатива слота класса изделия с `substitute: true` | вариант изделия/производной с меньшей сложностью, выбранный как упрощение |
| Источник | данные альтернативы (`substitute`) | флаг варианта (`simplified_variant`) |
| Ограничения | `max_eng_gen`, `upkeep_mult`, `alloy_free` | нет межслотового предела |
| Подпись в UI | «заменитель» | «упрощённая» |
Слово «упрощённая» к стали не применять, «ранг 0» игроку не показывать (`slice-jet-aviation.md` §1.4, UI). Если у одного проекта есть обе метки, они пишутся раздельно.

**Новая причина `why_not`: `ENGINE_GEN_LIMIT`** (слой «изделие»; не `ALLOY_DEFICIT`: иначе игрок ищет поставки сплава, а не знание).
- Условие (спец §1.4): в слоте есть альтернатива, недоступная **только** из-за `max_eng_gen` при наибольшем известном двигателе, и в `avail` слота нет не-`substitute` альтернативы.
- Формулировка в строке `why_not`: **«сталь допустима только с двигателем G1»** + уточнение «двигатель G{eng_gen} (известен), предел заменителя G{max_eng_gen}».
- Рычаг: **«изучить 30»** (при неизвестном 30; затем «изучить 33» — узлы `requires_nodes` не-`substitute` альтернативы с наименьшим рангом, которые ещё не известны). Кнопка рычага ведёт на узел в графе знаний.
- Цвет (R5): ■ красный, если это первое звено `why_not` цели; иначе ▲. Пока не выполнено условие причины, слово не показывается.
- Поля в подсказке: слот, `eng_gen` наибольшего известного двигателя, `max_eng_gen`.
- Различение причин для игрока: `ALLOY_DEFICIT` — «сплава мало» (рычаг: поставки), `ENGINE_GEN_LIMIT` — «сплава нет, а двигатель новее G1» (рычаг: знание). Для альтернативы `alloy_free` звено `ALLOY_DEFICIT` не выдаётся.
- [Предл.] Предупреждение заранее: при выборе в `compose_design` двигателя G2+ в составе со сталью строка «сталь недоступна: нужен узел 30» видна до применения (отказ `SLOT_UNAVAILABLE`, журнал «max_eng_gen»), чтобы «ловушка заменителя» была видна, а не обнаруживалась по провалу.
