# MS-M0 — Headless-прототип симуляции и Simulation Lab

## Цель
Проверяемое ядро без графики: несколько государств, упрощённые наука и экономика, Simulation Lab с массовыми запусками и регрессиями. Решение владельца (DECISIONS_LOG #3).

## Критерии завершения (черновик — утверждается вместе со списком задач)
- [x] Kernel: тик, детерминированный RNG, fixed-point, хеш состояния; тесты L1/L2 в CI (PHASE E).
- [ ] Core: вертикальный срез «реактивная авиация» (знание → способность → изделие) по контракту слоёв (DECISIONS_LOG #25).
- [x] Lab: прогон по манифесту, batch и Monte Carlo, метрики, golden-hash (PHASE E).
- [x] Хотя бы одна гипотеза проверена экспериментом с полями воспроизводимости (EXP-0001 → HYP-0001 REJECTED).
- [ ] Совместная гипотеза среза с абляциями слоёв; ориентир смены лидера среди великих держав 30–40% за 30 лет (#24).
- [ ] Бенчмарк тика зафиксирован.

## Задачи
Формируются после PHASE E (пилот) и PHASE F (фундаментальная модель).

## Зависимости
PHASE E, PHASE F; ADR-0003…0008 до ACCEPTED.
