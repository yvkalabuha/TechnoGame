**Сделано** по `docs/ui/specs/task-0136-clarity-depth.md`:

- Легенда 560×330 du: Кольца / Состояния узла / Дисциплины / Линии; знаки рисует та же функция `DrawMark`, что и узлы карты (1:1 по построению); коды FND/PRN… убраны.
