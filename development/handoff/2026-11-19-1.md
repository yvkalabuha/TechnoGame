## Уроки сессии
- Кадры на подставных данных не доказывают работу в игре: панель «Наука» была пуста в партии, а на кадрах выглядела верно. Правило добавлено в `.claude/rules/ui.md`.
- Прибор не должен выводить значение симуляции из чужого представления; если значения нет в данных сессии — добавить поле или убрать прибор.
- Десять кругов Codex на одной клиентской задаче: каждый круг исправлений приносил новые замечания. Признаки, что пора менять подход, а не чинить дальше: решение держит состояние там, где можно без него; клиент угадывает то, чего нет в данных.
- Отчёт агента о проверке может быть неточным: проверку эталонов базовой сборки Orchestrator повторил сам (оба раза результат подтвердился, детали отчёта — нет).
- Агент доставляет только один итоговый отчёт за запуск; при повторных поручениях состояние ветки смотреть напрямую (`git log`, журнал прогона кадров).
- `land.py` не видел отклонённые замечания из-за имени файла — исправлено; предел размера для Codex разделён на запрос (1 МБ) и открываемые файлы (4 МБ).
- Не больше двух сборок одновременно: правило соблюдалось, сбоев по нагрузке не было.
