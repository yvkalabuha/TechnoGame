# ADR-0002 — Уровни детерминизма

> ACCEPTED: текст не меняется. Изменение — новый ADR с `supersedes`.

## Контекст
Simulation Lab сравнивает прогоны и версии. Возможный будущий lockstep-multiplayer требует одинаковых результатов на разных машинах. RR-0002.

## Решение
- **L1** (обязателен с M0): тот же бинарник, та же машина, тот же seed и вход → побитово одинаковое состояние.
- **L2** (обязателен с M0): результат не зависит от числа потоков.
- **L3** (отложен): одинаковый результат на Windows, Linux, macOS. Правила ADR-0003, 0004, 0007 вводятся сразу, чтобы L3 оставался достижимым.

## Рассмотренные альтернативы
- L3 с M0: дороже и медленнее в разработке без текущей потребности.
- Только L1: L2 нужен для регрессий Lab при разном числе ядер.

## Последствия
Хеш состояния по таблицам считается каждый тик (или по расписанию) и сравнивается в тестах.

## Проверка
Тесты test-engineer: два прогона подряд; прогон с 1 и N потоками; сравнение хешей. CI на ubuntu.
