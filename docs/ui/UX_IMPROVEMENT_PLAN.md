## 2. Идеи: ценность для неспециалиста и цена
Цена: **S** — до 2 дней клиента, **M** — 3–7 дней, **L** — больше; «Core» — требует данных от ядра (только через Session, не Core по product-review §4).

|---|---|---|---|
| ★ Полоса «Что дальше» (одна строка под верхней полосой: 1 главное действие + «почему») | высокая: снимает G2 | S (клиент) | Правила на данных снимка: нет закреплённой цели исследований → «Выберите цель в Науке»; доли бюджета не менялись → «Распределите бюджет»; иначе — ближайшее событие/отставание. Закрывается, не мигает |
| ★ Подсказки по месту (контекстные, не туториал на 20 экранов) | высокая для первых 2 минут | S–M | 5–7 карточек-выносок «первый раз здесь» (`Callout` §7.3), показываются один раз, повтор из «?» в рейке; пропуск `Esc` |
| ★ Обычные слова вместо терминов | высокая | S (словарь ключей) | Для каждого модельного термина — строка локализации «для игрока» + короткое пояснение; таблица соответствий в STATE_WORDS (владелец game-designer) |

| Глоссарий по наведению и по клику | средняя | S | Слово с пунктирным подчёркиванием (штрихпунктир = «определение», один знак §4.2); текст постоянно доступен и с клавиатуры (A6), не только по наведению |

## 3. Стиль внутри палитры C и бумаги
- **Упростить.** (а) Шкалы-приборы: оставить функциональные (скорость, колбы, штангенциркуль без нониуса), остальное — на столе слабым слоем (UI_INSTRUMENTS §10). (б) Текстура бумаги на панелях с длинным текстом (Авторы, журнал): [Факт] на снимке «Авторы» штрихи волокон проходят по строкам — для плотного текста множитель текстуры снизить, чтобы серый `ink-3` держал ≥ 4,5:1 (A3). (в) Не более одного акцентного цвета-«пятна» на экран, кроме тревог.
- **Где декор вредит.** Мелкая графика прибора (A2); тон «светящихся» сегментов E2; штриховки, не читаемые при 100%; заголовки на фоне глобуса: подпись над окном не должна спорить с плашкой окна (C5).
- **Шкала и отступы.** [Предл.] Данные и действия ≥ 13 du, вторичные ≥ 12 du (A1), метаданные не светлее `ink-3`. Ряды URL/моноширинные строки — `type.s` с переносом по символу, а не обрезка. Интервал между блоками записи ≥ 12 du, между целями нажатия ≥ 4 du (A10). Главная кнопка ≥ 32 du высотой.
- **Состояния (ok / внимание / заблокировано), без добавления цветов.**
  | Состояние | Форма | Слово | Цвет (палитра C) | Критерий |
  |---|---|---|---|---|
  | ok | залитый круг ● | «норма» | `moss` линия | A5, A11: форма + слово |
  | внимание | треугольник ▲ + штриховая рамка 45° | «внимание» | `warn` (ink на плашке, §2.5) | A4, A5 |
  | блокировано | ■ или перечёркнутый круг + нижняя линия штрихпунктир | «нельзя: <причина>» | `ink-3` (приглушённо), не цвет | C4, A5 |
  Тревога `alarm` остаётся для корня проблемы (§1.2) и всегда со знаком и словом. На синьке второй канал обязателен (§2.4). Серый снимок читается без цвета.
- **Фокус и движение.** Рамка фокуса 2 px, 3:1 к обоим фонам (A7); все анимации (стрелка, выноски) выключаются «Меньше движения» (A8).
