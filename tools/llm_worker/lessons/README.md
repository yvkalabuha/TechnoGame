# Уроки llm_worker

Пополняет только Pilot (Claude), после проверки удачного цикла доработки (EXTERNAL_LLM_STRATEGY §6).
Не для дообучения модели.

Формат: один файл `*.md` на урок. Первая строка — `applies_to: A1, B1` (типы задач); остальное
уходит в пакет контекста задач этих типов: типичная ошибка, рабочая формулировка замечания, шаблон.
Этот файл (`README.md`) в пакет не попадает: у него нет строки `applies_to:`.
