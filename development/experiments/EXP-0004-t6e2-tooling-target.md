# EXP-0004 — Цель оснастки A39, повтор после F17b: V0, V1, V3, V4 против VINF (T6e2)

- **О11. Печать раздельного `ΔD`** («p `eligible` в судимом плече / нет»): `D_in` — `D`, посчитанный по `E* ∩ E(плечо)`; `D_out = D − D_in`. Это разложение (максимум по процессам ячейки неаддитивен), не критерий.
- **О12. M5 (F17b).** Сосуществование — непрерывный отрезок снимков с двумя линиями в С и одной и той же парой (`W`, `N`); смена кандидата — конец эпизода и начало нового. Причина конца по решениям compute последнего месяца: `W` закрыт и `y_min(N) ≥ y_prod` → `YPROD`; `N` закрыт при запуске в том же месяце → `REPLACE`; закрыт с `idle_c ≥ T_ab` (60) → `A40C_N` / `A40C_W`; отрезок до мес. 383 → горизонт (цензура); иначе «прочее». «Доля `left`, взятая `N`» не экспонирована Core — печатается доля `rate·unit_cost` `N` в сумме двух линий (прокси). Класс L-C «деньги сосуществования» — срабатывание ветки С на `N` во время сосуществования без культурной причины (О T6c2/L-C); прочие некультурные срабатывания ветки С — L-C0 (должно быть 0). L-O0 — ветка О класса «дефекты» = 0.
- **О13. Диагностика ревьюера** (`y_min(N)` = `Π g_d · ramp`): разложение — у процесса, дающего минимум по `prc_set(N)` в снимке t (`ProcessYield.G`, `Ramp` Core); печать по эпизодам GBR и SUN (main, все плечи) и помесячно — первый эпизод GBR и SUN в V0 и VINF.
- **О12a (уточнение после первого расчёта печати M5, не критерий).** Закрытие, решённое в compute t, применяется в шаге t+1, поэтому снимок t+1 ещё показывает две линии. Первый расчёт брал решения последнего снимка эпизода и дал всем концам «прочее»; исправлено: причина — по решению в одном из двух последних снимков, длительность — до месяца решения включительно.
