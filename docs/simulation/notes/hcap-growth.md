## 4. Правило (к реализации)
- **Формула** (для каждого актора `a`, site `s` (A27: site = актор), любого измерения `d`):
  - `n = max(0, m − m_on)` — месяцев после начала, `m` — номер месяца мира (0 = 1945-09).
  - `g_raw = min(ΔHmax.Raw, k.Raw · n / 12)` — целое деление `long` с отбрасыванием (оба множителя ≥ 0); `k.Raw ≤ 10⁶`, `n ≤ 1024` → переполнения нет.
  - `Hcap(s, d, m) = Hcap0_a + Fx6.FromRaw(g_raw)`.
- **`m_on`**: календарь 1978-01, переводится в номер месяца при сборке мира через `TickCalendar` сценария; для `scenario_1945` это 388 (1945-09 + 388 мес.; ср. «388 месяцев = 1945-09…1977-12», `m-play-horizon-2030.md`). [Предп.] номер месяца, передаваемый в `IIndustryInputs`, — тот же счётчик; проверяет тест §7 п. 1.
- **Параметры** — Core `IndustryParams`: `HcapGrowthPerYear` (Fx6, ≥ 0), `HcapGrowthMax` (Fx6, ≥ 0), `HcapGrowthOnset` (год-месяц). Сначала умолчание 0/0 (рост выключен — ни один эталон не меняется), после зонда — выбранные значения (одна перезапись в поезде 2). Lab-ключи манифеста `HCAP_K`, `HCAP_MAX`, `HCAP_ONSET` и `SliceRunConfig.HcapGrowth*` (nullable, как `CostMultG5`), колонки `run.k.hcap_*` — только при явном значении (образец TASK-0131). Отрицательные значения — `ArgumentException`.
- **Чего не делать:** не трогать `scenario_1945.yaml` (старт заморожен, `slice-jet-aviation.md` §1.1, «изменение старта — только новым EXP»); не разводить `k` по странам (нейтральное правило, как #52; асимметрия #24 остаётся за счёт разрыва 1945: SUN пересекает 5,5 на 0,8/k лет позже USA).
- **Побочный эффект на `H_floor`** [Факт по формуле]: пол растёт на `0,6·ΔHcap` (до +0,6…+0,9). Он только тормозит спад простаивающих ячеек и согласуется с #30 («нижний порог зависит от образования»); поднять `H` он не может (`dMinus = δ_H·max0(H − max(maint, H_floor))`).
- **Что видит игрок** [Предл.]: подсказка ячейки культуры «потолок кадров» уже есть как `limiter = Saturation`; после правки текст подсказки может назвать год, когда потолок превысит требование процесса (предсказуемо: функция месяца). UI — отдельной задачей, не в этом поезде.
