# P-8: срок цели с приоритетом против срока без него — оценка game-designer

> game-designer, 2026-11-25. Вход: `docs/simulation/institutes-p7-measurement.md` (ветка task-0173-lab-p7, серия 440 прогонов, seeds 1–20), `research-institutes-priorities.md` rev 4 §4–§5, P-8. Это оценка, не утверждение: статусы не меняю.

## Краткий вывод
- [Факт, замер] На снимке приоритетная цель никогда не медленнее (6,7 млн цель-месяцев, 0 нарушений). По сроку цель открывается позже, чем без приоритета, в 13,0–18,1 % случаев (позже 12 мес.: 8,5–10,9 %); у института без уровня в области 15,4–22,7 %. Медиана сдвига: раньше на 7–28 мес.
- [Предл.] Правило денег (κ_eff, §5) **не менять**. Принять как свойство «приоритет — ставка, а не гарантия», но убрать из интерфейса обещание «будет раньше» и показать честный диапазон. Это D2.
- [Предл.] Ключевые узлы §2 замера подтверждены с двумя оговорками (ниже). D2.

## 1. Приемлемо ли для игрока
- [Предл.] **Да, при условии честного показа.** NORTH_STAR требует решения с видимой ценой. Цена у приоритета видна и объявлена: остальной фронт получает меньше денег (пример §5: −21 % при K = 3, −37,5 % при K = 6). Задержка других узлов, в том числе предпосылок других целей, — прямое следствие этой цены, а не скрытый дефект.
- [Предл.] **Недопустимо** только одно: если предпросмотр срока показывает «цель раньше на N мес.» как обещание. В 13–18 % случаев оно ложно, в 8–11 % — на год и более. Это и есть «фальшивая механика»: число в интерфейсе, которое игрок читает как гарантию.
- [Предп.] Часть «позже» — не следствие правила, а расхождение траекторий: приоритет меняет фронт, жребий узлов-случаев и лицензии (так пишет сам замер). Без контроля шума нельзя сказать, сколько из 13–18 % реальная цена, а сколько — бабочка. Это надо измерить до решения о правке правила.
- [Факт, §4.4 дизайна] Предпосылки цели **во фронте уже входят в группу** и получают деньги первыми. Поэтому вариант «включить предпосылки цели в группу» уже есть в правиле и данную проблему не объясняет. [Предп.] Замедляются предпосылки, не вошедшие в группу: общие с другими целями игрока, узлы вне фронта на момент назначения, узел «уже занят другой группой». Причина не разложена замером.

## 2. Наименьшая правка (по возрастанию стоимости)
1. [Предл.] **Предпросмотр без обещаний.** В карточке назначения: «срок с приоритетом: диапазон» и «без приоритета: дата», рядом цена («остальной фронт медленнее на ~N %»). Не «+N мес. раньше», а «вероятно раньше (в ~85 % случаев)», когда проценты известны из Lab; пока не откалиброваны — только качественно. Цена: клиент, ~1 день, без ядра. Логика: этот вариант совместим с лимитом «не прогноз, а оценка».
2. [Предл.] **Подсказка советника для института без уровня:** «бонуса института нет, остальная наука замедлится, срок может не улучшиться» (там «позже» 15–23 %). Не запрет: решение #488 «назначить можно любой институт» сохраняется.
3. [Предл.] **Замер-контроль (simulation-engineer, ≤ 1 день):** (а) шумовой пол: два прогона без целей, один с бесполезной целью на узле вне фронта, тот же seed; доля «позже» в ней = шум; (б) разложить «позже» по причине: предпосылка своей группы / узел чужой цели / не цель-путь. Только после этого решать о правке правила.
4. [Предл., только если (3б) покажет, что виновны предпосылки своей цели] поднять κ_eff для узлов пути цели или поднять ρ; это уже меняет баланс и числа §5 — отдельная проверка P-3/P-6.
- Не предлагаю: «не давать цель институту без уровня, если у страны есть свободный с уровнем» (вариант из замера). Это отменяет решение владельца #488 и ломает «непрофильный институт растит опыт» (§3).
