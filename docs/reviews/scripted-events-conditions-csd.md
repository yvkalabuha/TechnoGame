# Scripted event preconditions — civilization-systems-designer input (2026-11-18)

Artifact: `docs/game-design/scripted-events-conditions.md`. Answers to the [CSD] points. The vocabulary is enough for M1 and extends to M2 and branches without a format change.

1. **absorbed.** Accept with two fixes. (a) Drop "no pending successor event": the atom must depend on world state only, otherwise the result depends on the event queue and in-day order. Strictly: absorbed(P) = was_alive ∧ ¬alive ∧ no provinces and territories; `was_alive` lives in the polities table and enters the hash. (b) DEU (government:false) is not absorbed by the creation of the FRG/GDR: it holds Oder–Neisse until 1950/1970 and Berlin, so absorbed(DEU) cannot be in N. For joint polities (ALLIED_*) add a separate atom `dissolved(J)`: they have no own territories, so absorbed would fire at the start.
2. **Proxies for S.** In M1 only a structural "feasibility of the cause" (actor alive and holds the set). For M2 not one `metric(war_exhaustion)` but typed pressures: `metropole_capacity`, `consent_to_hold(metropole, set)`, `external_guarantor(P, Q)`. Decolonisation: S = consent_to_hold < k. Algeria: S = war fallback. In M1 S is trivial; write S fields only for the core (~15–20 rows), the rest from the `kind` template.
3. **Chains.** (a) GDR (C05): remove N `fired(C03)` — the cause is the zone split, not the FRG event. Need `soft_after` (order without cascade skip), N = controls(SUN, east_zone) ∧ polity_free(GDR); otherwise ablating C03 silently kills the GDR and spoils S4/S5. (b) Oder–Neisse: §2 scheme accepted, but the 1970 fallback must also check owns(DEU, set), otherwise "confirmed" cannot tell no-effect from failure. (c) C09: keep fired(C03); Allied rights in Berlin stay a separate no_effect record. (d) Saar: [Факт] RR-0020 has C02 (1947) but not the accession of 1957-01-01 (Saar Treaty 1956-10-27, referendum 1955-10-23). Need C02b transfer_owner SAAR→FRG, soft_after C09, N = exists(SAAR), S = exists(FRG); if skipped(C09) → alt saar_stays_protectorate. (e) Austria: C26 → C27/C28 with lag 90 is right. Controller change to AUT and dissolved(ALLIED_VIENNA) as one group effect (K9), otherwise a day "AUT controls, ALLIED_VIENNA alive" exists.
4. **Trait for schools (#322).** Do not include `trait(P, id)` — it risks turning a school into a country flag, which #322 forbids. Add `has_institution(P, kind, min_capacity)` and `has_figure(P, tag)` + `fired(E)`, as in #322 ("resource, institution, personality, event"). A school is a derived metric of institutions (school_H after EXP-0002, #192). `metric(school_*)` only in #299 branches, not the base. Reserve `trait`, not in M1/M2.
5. **"Table, not a game".** The vocabulary is not the problem; the player has no influence on S. M2 needs levers (support or pressure through institutions and budgets) — a game-designer decision, not M1.

Disagreements with game-designer: (1) absorbed — GD with "pending successor", CSD world state only + dissolved; (2) GDR — GD hard N fired(C03), CSD soft_after; (3) trait — GD atom extension, CSD has_institution/has_figure; (4) Saar C02b — agreed, needs research-scientist.
