## 1. Игровой цикл

### 1.1 Цикл игрока [Предл.]
| Шаг | Действие | Что видит игрок до клика |
|---|---|---|
| 1 | Институт свободен (старт партии, очередь пуста): мягкая пауза «Институт X свободен», не чаще раза в год на страну (по #485); на старте — один общий вопрос | 3 кандидата советника с причиной; открыта карта |
| 2 | Выбрать узел → карточка (§3) → «Исследовать в институте ▾» | цена, срок, поток денег, бонус института, что даст, занятость |
| 3 | По желанию **Фокус** 0/1/2 | цена и срок при каждом уровне рядом |
| 4 | Положить до 5 узлов в очередь (вручную или «Разложить путь») | порядок, предпосылки, оценка срока |
| 5 | Узел готов → карточка «что получили» (эффект числами) → следующий из очереди; пустая очередь → шаг 1 | запись «до → после» через 6/12 мес. |
| 6 | Раз в год (итог года): построить институт, сдвинуть долю науки | «Науке хватает на 85 %: узлы идут на 85 % скорости» |

Решений в год [Расчёт из записки]: ≈ N_институтов / T̄; для USA ≈ 1,5–3, плюс стройка и фокус; в пределах 5–8 осмысленных решений в год (M_PLAY_LOOP §3.2). Очередь делает паузу редкой: пауза только при пустой очереди.

### 1.2 Деньги и время [Предл.]
- У узла: **цена** `C` (нынешний `c_eff` со скидками диффузии, знаний, `informs`, кражи, множителем опережения эпохи), **время** `T_n` (новое), **направление** (aero, prop, metal, chem, mech) и **военная ценность** (§3.2).
- Ставка слота при полной скорости: `r = C / T_eff` в месяц. Деньги: `B = S_наука − содержание − стройка`. Если `Σ r ≤ B`, все слоты идут на полной скорости; иначе каждый слот умножается на `u = B / Σ r` (одинаково, без зависимости от порядка слотов).
- Прогресс за месяц: `Δprog = min(1/T_eff, m_slot / C) · m_inst · f_focus · R`, где `m_inst = 1 + 0,05·Lx (+ руководитель, #493)`, `Lx` — среднее уровней института по направлениям узла (§2a.2), `R` — суммарная добавка `research_speed` (§6). Общий множитель ограничен потолком ×2,5 (#568).
- **Излишек** (Σ r < B): уходит в резерв (утечка 10 %, #475), в верхней полосе строка «Науке не на что тратиться: свободных институтов 2» — сигнал «постройте институт или сдвиньте долю». [Предл.; изменение экономики: согласовать с economy-analyst.]
- **Нехватка**: строка «Науке хватает на N %» рядом с полосой науки; запрет начать узел без подтверждения, если после него `u < 60 %` [ЗАГЛУШКА].
- **Прогресс принадлежит узлу, не институту**: при снятии узла прогресс сохраняется, продолжить может любой институт. Потому перестановка не наказывается потерей; ограничение «не чаще раза в 12 мес. на слот» (#485) заменено ограничением на **активный узел**, см. §4.2 [Предл.].
- `T_n` и `T_eff`: [Предл.] `T_n = TimeByType · TimeGen`, растёт с поколением **медленнее цены**; знания ускоряют срок ослабленно (`T_eff = T_n / (1 + 0,5·K/K_ref)`). **[ЗАГЛУШКА]** — масштаб `T_n` даёт TASK-0185.

## 2. Слот, институт, стройка

### 2.1 Институт как слот [Факт, #561]
Слот = построенный работающий институт. Бонус (`+5 %/уровень`) даёт только **пересечение направлений** узла и института (#571, §2a); узел без общих направлений идёт на базовой скорости, без штрафа (#488; Q9). Узлы без института: прогресс 0, прогресс не теряется. Лицензия — единственный путь к знанию без слота.

### 2.2 Старт и потолок [Факт, #564; формулы — Предл./ЗАГЛУШКА]
| Страна | Старт | Потолок `Cmax` [ЗАГЛУШКА] | Кандидаты в данных |
|---|---|---|---|
| USA | 6 | 12 | DARPA 1958 |
| SUN | 6 | 9 | НИИ-88 1946 |
| SWE | 4 | 6 | — |
| GBR | 3 | 8 | RRE 1953 |
| FRA | 3 | 7 | ONERA 1946, CNES 1961 |
Потолок: `C(t) = min(Cmax_c; n0 + 1 + ⌊(год−1945)/10⌋; ⌊0,25·S/u_ср⌋; кадры)`. Четыре причины серой кнопки, каждая называется словом: «потолок страны», «ещё рано», «содержание больше 25 % науки», «нет кадров». TASK-0185 проверяет: ширина фронта ≥ 1,5 × число институтов в 1945–60; точность `Cmax`.

### 2.3 Стройка [Предл., правила rev 4 §8 в силе]
Цена `1,5 % науки в год за уровень`, срок `2 + 0,5·Σ` лет, окно −10 лет от исторической даты, содержание `0,4 % S в год на уровень` (#494). В карточке стройки: «даст +1 параллельный узел; прибавит поток ≈ N/мес.; сейчас науке хватает на 85 %». Принцип для игрока: **институт без денег бесполезен, деньги без институтов не тратятся**; оба условия видны в одной строке «Наука».

## 2a. Направления узла и института (#571) [Факт, #571; формулы — Предл.]

### 2a.1 Модель данных
- **Узел**: список `dirs[2..4]` из пяти направлений (aero, prop, metal, chem, mech). Сегодня у узла одна дисциплина — нужен данные-шаг research-scientist: добавить 1–3 дополнительных направления, с источником (нужны области знания, в которых узел реально лежит). Первое в списке — основное.
- **Институт**: карта `dirLevel[d] → уровень` для 2–4 направлений. Сегодня институт имеет одну область и один уровень (`institutes.yaml`): миграция — старая область становится первым направлением с нынешним уровнем, остальные направления добавляются в данных по истории (например, ЦАГИ — aero + mech) [Предп., данные не проверены].
- Пересечение `X = dirs(node) ∩ dirs(institute)`.

### 2a.2 Скорость по пересечению [Предл.]
Бонус института к узлу `m_inst = 1 + 0,05 · Lx`, где `Lx = (Σ_{d ∈ dirs(node)} dirLevel[d]) / |dirs(node)|`, а `dirLevel[d] = 0`, если направления нет у института. То есть **среднее по направлениям узла, непересекающиеся считаются нулём**.
Почему не «лучший общий уровень»: лучший общий уровень не отличает узел из 4 направлений, где институт покрывает одно, от узла из 2, где покрыты оба; игрок выбирал бы по одному сильному направлению и игнорировал остальное. Почему не «среднее по общим»: награждало бы узкое пересечение (одно общее направление = полный бонус). Среднее по узлу даёт ясную строку: «пересечение 2 из 3, уровни 4 и 3 → бонус +11,7 %». Альтернатива для Lab: максимум общих (проще читается, но грубее) — сравнить в пилоте на «ширину выбора» (сколько институтов дают заметно разный бонус на один узел; цель ≥ 2 различимых).
Верхняя граница не растёт: `Lx ≤ Lmax` института, поэтому прежний максимум `m_inst` (≈ 1,32 с руководителем) сохраняется.

### 2a.3 Узел без общих направлений [Предл.; интерпретация владельца, подтвердить — Q9]
Институт **может** взять узел при `X = ∅` на базовой скорости (`m_inst = 1`, без штрафа, #488). Это сохраняет «узел без института не движется, но любой институт его двинет» и не запирает малую страну. Цена такого выбора — упущенный бонус, он виден на карточке («без бонуса: направления не совпадают»). Нужен ли штраф <1 — не вводим [Предл.], проверить в пилоте по простою слотов.

### 2a.4 Рост уровней направлений [Предл.; числа ЗАГЛУШКА]
- Уровень растёт **опытом по направлению**: месяцы работы института над узлами, где это направление есть (вес 1/|dirs| узла за месяц). Порог следующего уровня `E_L = E0 · L^1,5` [ЗАГЛУШКА]; потолок `Lmax` на направление по данным.
- Рост не платный, только временем и выбором: чем чаще институт берёт узлы своего профиля, тем он сильнее в нём — это делает смысл «специализация против широты» (часть решения игрока).
- Уровень не падает при простое; в простое опыт не копится.

### 2a.5 Откуда берутся направления у построенного института [Предл.]
- Исторические кандидаты (`institutes.yaml`): направления и уровни из данных.
- Типовой проект: игрок выбирает **2–4 направления** при закладке (старт — уровень 1 по каждому); цена и содержание растут с числом направлений и суммой уровней (rev 4 §8, `Σ` уровней уже в цене); «всеядный» институт на 4 направления дорог и слаб по уровню. Добавить направление позже — вопрос Q10.

### 2a.6 Проверка по потолку ×2,5 (#568) [Расчёт]
Институт ≤ 1 + 0,05·Lmax (с руководителем ≈ 1,32), фокус ≤ 1,5 (уровень 2 [ЗАГЛУШКА]), `R` ≤ 1,25 (потолок +25 % в записке; [Предл.] сохранить). Произведение: 1,32 · 1,5 · 1,25 ≈ **2,48** ≤ 2,5. Потолок почти не режет: он остаётся страховкой на случай роста `Lmax`, фокуса или `R` из данных. Если Lab покажет, что `Lmax` или фокус можно поднять, потолок станет рабочим ограничением; тогда карточка показывает «потолок достигнут». Направленческое пересечение **уменьшает** средний множитель (`Lx` ≤ `Lmax`), так что #571 к потолку риска не добавляет.

### 3.2 Военная ценность [Предл.]
Три степени, считаются из данных, **без нового источника чисел**: «прямо усиливает» (узел меняет `perf` или открывает поколение изделия), «готовит производство» (процессы), «основа» (открывает цепочку). Метка **не сортирует** список само по себе, чтобы не было одного «правильного» выбора; вердикт-строка («Хороший выбор для ЦАГИ: быстрый путь к поколению 2») формируется правилом из тех же данных.

### 3.3 Причины «нельзя» [Предл.]
`no_slot` (нет свободного института), `not_frontier` (нужно сначала X), `taken` (узел уже в очереди/слоте у другого института), `queue_full` («очередь полна (5)»), `underfunded` (после начала `u < 60 %`), `cap_reached`, `already_known`. Каждая — слово и число, не код.

## 4. Очередь, путь к цели, замена

### 4.1 Очередь [Факт, #567; детали — Предл.]
- Институт: 1 активный + до **5** в очереди. Узел — не более чем в одной очереди; в чужой он помечен «уже у ЦИАМ, ещё 14 мес.».
- Узел завершён → следующий из очереди **в тот же месяц**, если предпосылки выполнены; нет — пропуск с записью в журнале, берётся следующий; очередь пуста → пауза «Институт свободен».
- Очередь **не резервирует деньги и цену**: платится поток активного узла; цена/срок очереди — «оценка при старте».
- Узел, открытый другим путём (лицензия, кража, соседний институт), уходит из очереди с записью; деньги не теряются.
- Очередь и план входят в сохранение.
- Состояние очереди — таблица мира (смена `SchemaVersion`: в пакете изменений, меняющих эталоны).

### 4.2 Замена активного узла [Предл., вопрос Q4]
Прогресс сохраняется у узла. Ограничение: после замены активного узла следующую замену на том же слоте можно сделать через **6 мес.** [ЗАГЛУШКА], чтобы не было «дёрганья» ради фокуса; перестановка и удаление очереди свободны; **фокус** при смене узла сбрасывается на 0 (дорогой режим не должен «переезжать» молча).

### 4.3 Путь к цели (#562) [Факт, #562; детали — Предл.]
Игрок выбирает целевой узел или изделие; игра **только показывает**: все непройденные узлы пути, цена и срок по каждому, **итоговый срок с учётом параллельности** (жадное расписание по вашим институтам, диапазон), «узкое место» (узел без профильного института; длинный последовательный отрезок). Кнопка «Разложить по институтам» **предлагает** расстановку (с учётом бонусов областей, предпосылок, лимита 5); игрок подтверждает или правит; **автоматического выбора без подтверждения нет**. Расчёт — чтение Session, состояние не меняет.

## 5. Фокус (платное ускорение)

### 5.1 Правила [Предл.; все числа — ЗАГЛУШКА для Lab]
- Название на экране: **«Фокус»**? В M_PLAY_LOOP §6 слово «Фокус освоения» занято производством, поэтому в интерфейсе **«Ускорение узла»**; в коде и этом документе `focus`. Решение по слову — ui-art-director.
- Уровни 0/1/2: скорость `s = 1 + 0,25·f` [ЗАГЛУШКА], ставка `s^1,6`, полная цена узла `s^0,6` (выпуклость: ускорять все узлы сразу невыгодно, один-два нужных разумно). Уровень 2 = прежний «деньги первым» κ = 1,5 (#487).
- Оплата из потока науки **или из резерва** (выбор игрока); деньги не возвращаются.
- Смена уровня — раз в 6 мес. на институт [ЗАГЛУШКА]. Недостача денег снижает **все** узлы, включая ускоренные.
- Фокус не может сократить срок ниже `0,5 · T_eff` (срок нельзя купить деньгами сверх предела).
- Инвариант «приоритетный узел не медленнее неприоритетного» (P-8) выполняется автоматически: фокус — только добавка.

### 5.2 Слияние с `FundProgramme` [Предл., D2 для Orchestrator]
`FundProgramme` (разовая докупка прогресса из резерва) и платный фокус делают одно: платят деньги за скорость узла. Два рычага = дублирование и вопрос «чем отличаются» (ровно путаница из партии 24.11). Предлагаю **одну** команду `BuyFocus(instituteId, level, fromReserve)`; `FundProgramme` убрать из клиента и ядра в режиме слотов (код остаётся для `LEGACY`/`Shares`, затем — в техдолг). Экономия ≈ 1,5 дня и один рычаг. **Помечено как D2 Orchestrator; владелец вправе вето.** Если владелец хочет сохранить «разовое вливание» — оставить его только на узле со слотом и ограничить `0,5·T_eff` (вариант из записки simulation-engineer).

## 6. research_speed [Факт, #562, #568; детали — Предл.]
- Новый тип эффекта узла: `{kind: research_speed, dirs: [..] | all, bonus: 0,06}`; без ссылки на данные в игроке не показывается. В 99 узлах среза таких нет (вычисления, ЭВМ — вне среза): механика сегодня пуста, пока research-scientist не добавит узлы; **игроку не обещаем до появления данных**.
- `R(c,d) = 1 + Σ bonus_i` по узлам страны `c` для направления `d`: **складывается**, не умножается. Итоговая скорость узла (институт × фокус × R) **не выше ×2,5** (#568): при превышении — ограничение сверху; игрок видит «потолок скорости достигнут».
- Тормоза «убегающего лидера» [Расчёт]: поток денег пропорционален скорости (быстрее — больше в месяц при той же цене → `u` падает без роста доли науки); цена опережения эпохи; диффузия и кража удешевляют догоняющему; лицензии.
- Окупаемость показывается числом («окупится через ≈ 9 лет при вашем потоке»), чтобы выбор «ЭВМ или военный узел» был решением, а не обязаловкой. `bonus ≤ 0,08` на узел [ЗАГЛУШКА].

## 7. Цель: воздушная мощь [Факт, #565; детали — Предл.]
Индекс `MPI` = Σ парк × готовность × качество (диагностика `FV_fleet`, `FLEET_RETIREMENT.md` §11; [Предп.] проверить, что реализована в Session). Отрыв `R = MPI_игрока / max MPI_соперника`: паритет ≥ 1,0; превосходство ≥ 1,5; господство ≥ 2,0 — **держится 5 лет**. Честное имя на экране — «воздушная мощь» (армии и флота в срезе нет). Чужие значения — диапазон по правилу #68/#367. Победа и «золото» — M_PLAY_LOOP, обновить отдельной правкой (замена цели #422 по #569). «Давление» — не здесь. Узлы, у которых «прямая военная ценность», питают `MPI` через поколение изделия; в карточке показывается связь «узел → что это даёт мощи».

## 8. Правила ИИ [Предл., по записке simulation-engineer]
0. **Пересечение (#571)**: при равном весе ИИ предпочитает узел с большим `Lx` для своего свободного института, а институт — для выбранного узла; узел без пересечения берёт только если нет кандидатов с `Lx > 0` на пути. Стройка: ИИ выбирает направления нового института из тех, где у него больше всего кандидатов во фронте.
1. **Выбор узла для свободного слота (PATH, #559)**: ступень 1 (нужен для следующего поколения изделия) → ступень 2 (поколение g*+1) → любой узел фронта по весу `Priority` (военный уклон профиля) → простой только при пустом фронте. Самый весомый узел идёт в институт с наибольшим уровнем в его области.
2. **Запасные ступени**: слот не должен простаивать при непустом фронте (метрика §10).
3. **Очередь**: ИИ **не использует** очередь — выбирает при освобождении слота; очередь — удобство интерфейса, не преимущество, правила равны (#549).
4. **Устойчивость**: ИИ не снимает слот с начатого узла, пока тот на пути или прогресс > 0,5.
5. **Фокус**: уровень 1 на узел ступени 1 с наибольшим остатком срока, если соперник впереди по `G` и запас денег после ставок ≥ 10 % `B`; уровень 2 — только при угрозе (позже, с военным слоем). Снимает при недостаче денег.
6. **Стройка**: исторические кандидаты около даты (остаётся) + общее правило: все слоты заняты ≥ 12 мес., кандидатов ступеней 1–2 больше слотов, содержание после стройки ≤ 15 % науки, число институтов ниже потолка.
7. **Покупка лицензий** (M2, #553) остаётся; цена решения выросла: слот занят → лицензия закрывает изделие.
