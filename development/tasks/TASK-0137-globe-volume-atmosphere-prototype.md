# TASK-0137 — Объём и атмосфера глобуса: прототип трёх вариантов

## Цель
Владелец: глобус плоский, нужен объём и атмосфера на границе (#442). Выбор — по кадрам прототипа (#426).

## Описание
По `docs/ui/VISUAL_DIRECTION_V06.md` §2 и `docs/ui/GLOBE_DIRECTION.md`. Переключатель варианта в клиенте (настройка или ключ запуска), один свет сверху слева, привязанный к камере (A8):
- **А** — Lambert-wrap, мягкий терминатор, отмывка рельефа, тонкий ободок 1,5–2 du;
- **А+** — то же и выраженная атмосфера снаружи диска (Френель, голубая дымка шириной ≈ 3–5 % радиуса за краем, тёплый оттенок у терминатора), тинты стран внутри диска не меняются;
- **В** — физическая атмосфера (рэлей) по §2 «В».
Кадры для каждого варианта: Европа днём, терминатор, ночная сторона, серый кадр; 1920x1080 при 100 %; время кадра на текущей машине. Страница для владельца с кадрами рядом.

## Критерии приёмки
- [ ] Три варианта переключаются без пересборки; по умолчанию — текущий вид, пока владелец не выберет.
- [ ] Кадры и серые кадры; проверка C5/A4/A5/A8 арт-директором; второе мнение Gemini.
- [ ] Время кадра записано; ревьюер APPROVE.

## Результат
**Сделано.** Три варианта глобуса (А, А+, В) и прежний вид (current). Свет один, сверху слева, привязан к камере (A8); заливка стран умножается на light в [0,70; 1,05], терминатор ≈ 25°. Атмосфера — отдельная оболочка снаружи диска (`shaders/globe_atmosphere.gdshader`); В заходит внутрь диска не больше 4 % радиуса с плавным затуханием. Процедурно, без текстур и сторонних данных (ADR-0009 не затронут).

**Решение владельца от 2026-11-24 (запись в журнале решений делает Оркестратор): по умолчанию вариант В.** Выбор — настройка «Вид глобуса» (Общие; Прежний / Матовый / Матовый + дымка / Атмосфера; `general/globe_look` в `user://settings.cfg`, ключи `set.globelook`, `set.gl.*` RU/EN), с живым просмотром и откатом по «Отмена». Ключ запуска `--globe-look current|a|aplus|b` перекрывает настройку на один запуск; F6 переключает по кругу только в режиме отладки (F3).

**Не сделано:** отмывка рельефа в А — в проекте нет карты высот; шум дал бы выдуманную географию. Нужен Natural Earth shaded relief (PD) и GEBCO отдельной задачей. Проверки арт-директора (C5/A4/A5/A8), Gemini и ревью ещё не было.
