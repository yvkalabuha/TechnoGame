# EXP-0001 — Пилот: траектории государств с разным сочетанием науки, инженерии и производства

> Модель: `docs/simulation/toy-science-industry-model.md` (дальше «модель», §N). Критерии и архетипы взяты из HYP-0001.

## Вопрос
Дают ли три раздельные мощности (модель A: K → A → T, P, N) разнообразные и объяснимые траектории 1910–1950 без доминирующего архетипа? Разнообразие должно быть заметно выше, чем у контроля B с единым уровнем τ, при двух уровнях шума.
Гипотезу подтверждает выполнение критериев 1–6 HYP-0001 для модели A при обоих уровнях шума. Провал критерия 1 или 6 её опровергает (в текущем виде). Провал критериев 3–5 означает, что модель нужно дорабатывать.

## Начальные условия и параметры
Шесть стран, по одной на архетип. Уровни: низкий l = 0,6, средний m = 1,0, высокий h = 1,6. В каждом seed уровни S, E, Pl, Nl умножаются на U(0,85; 1,15) (RNG system = SETUP). Значит, диапазон для l — 0,51–0,69, для m — 0,85–1,15, для h — 1,36–1,84.

## Метрики
Таблица `yearly.csv`, строка на (run, year, country): K, A, T, P, R, E, N, Y_year, Power, rank, B, eng_binding_months, bottleneck1, bottleneck2.
Таблица `milestones.csv`: (run, country, j, q_j, m_K, m_A, m_T). Файл `run.json`: параметры, seed, threads, хеши.
**Итоговая мощь** Power_y — сумма месячного выпуска Y за год y. Y = z·(1+T/T_ref)^γ·P^β·N^(1−β)·шок, то есть объём производства с учётом технического уровня парка. Ранжирование идёт по Power_1950.

## Метод вычисления критериев HYP-0001 (скрипт `lab/analysis/exp0001.py`, Python stdlib)
Каждый критерий считается отдельно для каждой пары (model, ν).
1. **Нет доминирования:** win_share(a) — доля seeds, где a занимает топ-1 по Power_1950. top2_share(a) — то же для топ-2. Проход: max win_share ≤ 0,40 и min top2_share ≥ 0,05. 95% доверительный интервал считается по Уилсону.
2. **Рейтинг меняется:** leader_changes — число смен argmax Power_y за 1910–1950. Проход: медиана ≥ 1 и доля seeds с leader_1950 ≠ leader_1910 ≥ 0,30.
3. **Лаг:** лаг вехи = m_T − m_K, с цензурой (модель, §6). Сравниваются медиана лага A1 и медиана объединённых остальных архетипов. Проход: отношение ≥ 1,5, интервал — bootstrap по seeds (1000 повторов, seed бутстрапа фиксирован).
4. **Догоняние A1:** доля seeds, где A1 входит в топ-2, должна быть в [0,10; 0,40]. Для этих seeds и для остальных сравниваются признаки: множители начальных уровней, E_1930/E_1910, B, eng_binding_months, ν-шоки. В отчёт идут признаки с наибольшим KS-D.
5. **Объяснимость:** берутся все страна-годы с отставанием (Power < 0,8·лидер, год ≥ 1915). Проход: доля случаев, где два главных фактора дают ≥ 0,7 разрыва, должна быть ≥ 0,80. Распределение этой доли и частоты ярлыков приводятся по архетипам.
6. **Контроль:** разнообразие D = энтропия Шеннона распределения win_share, нормированная на ln 6, и медиана leader_changes. Проход: D_B ≤ 0,7·D_A и median_changes_B < median_changes_A [Предл.].
Сверх критериев в отчёт идут квантили p5/p50/p95 Power_1950 по архетипам, крайние seeds (min и max для каждого архетипа) и разброс Power_1950 внутри архетипа против разброса между архетипами («шум вместо системы»).
Внешние пакеты не нужны: 800 × 41 × 6 ≈ 200 тыс. строк; KS и bootstrap укладываются в ~30 строк stdlib. polars/duckdb (ADR-0008) для пилота не требуются.

**Принято Orchestrator (технические, в рамках ADR):**
1. Pre-registration: манифест, пороги и правило решения фиксируются до официального прогона (`manifest_hash` в frontmatter). Любое изменение — новый EXP. Итог формулируется с указанием области параметров.
2. Правило прохода критериев 1 и 4: по точечной оценке; если Wilson CI пересекает порог — флаг «на грани». Для п.4 порог: ≥1 признак с KS-D ≥ 0,3 при p < 0,01.
3. Смена лидера — с гистерезисом: новый лидер держится ≥2 лет или опережает на >5%.
4. Критерий 3: левая цензура — вехи, пройденные при t=0, исключаются; доля цензуры указывается.
5. Критерий 5: ярлыки узких мест считает только анализ (Python); из Core и `yearly.csv` убираются. Добавляется ярлык NOISE; отрицательные компоненты обнуляются; доля — от полного ln-разрыва.
6. RNG: цепочка `mix(mix(mix(seed ^ c1) ^ tick) ^ …)` с константой на поле; для SETUP n = 0..3; эталонные векторы в тестах Kernel.
7. StateHash: заголовок (schema_version, tick, n_countries) + зарегистрированные колонки в порядке объявления, int64/int32 little-endian, SHA-256 от current после swap. Отдельно — хеш `yearly.csv`.
8. Kernel получает минимальные `LongColumn`/`Table` с регистрацией колонок и раннер фаз compute/merge/post; Core использует их (ADR-0005).
9. Разрешённый список `System.Math` в Kernel/Core: Sqrt, Floor, Abs, Min, Max, BigMul. Остальное запрещено тестом.
10. Инвариант T': допуск ±1 raw; явно указать, какие значения из снимка t, какие из t+1.
11. Отклонение от ADR-0008 для пилота: JSON-манифест + CSV вместо TOML + Parquet (без NuGet). ADR-0008 пересматривается до ACCEPTED.
12. Альтернатива D (трансфер технологий) — отложена; триггер: «догоняющий архетип не входит в топ-2 при выровненных суммах».
