## 6. Клавиатура и фокус
- Порядок Tab: шапка → вкладки (стрелки) → поиск → чипы → «Сбросить» → «Легенда» → карта (стрелки по соседним узлам, Enter выбрать, Esc снять) → кнопки масштаба → «Построить институт» → пейджер → карточки полосы (←/→, Enter открывает очередь) → инспектор сверху вниз → «Закрыть (Esc)». Alt+↑/↓ порядок очереди. Пробел — пауза везде. Перетаскивание только как дополнение.
- Кольцо фокуса: 3 du, цвет ink #1D1E20, снаружи элемента с зазором 2 du цвета бумаги; кольцо лежит на фоне панели, не на заливке кнопки (на command #2347A8 ink даёт ≈ 2:1, внутри кольцо не годится). На узлах карты: ink 3 du на бумажном ореоле 2 du. Синий для фокуса не использовать (command = намерение игрока и маршрут).
- Состояния любого элемента: обычный; hover #E8E4D8; фокус (кольцо); нажат (инверсия ink/paper); выключен (рамка пунктиром, текст ink-2, причина словом рядом); для выбранного см. §3.
- Контраст (расчёт, [Предп.]): ink на paper ≈ 14:1; ink-2 ≈ 6:1; ink-3 ≈ 5:1 (только ≥ 12 du, не для данных); ink на warn ≈ 7:1. Проверить на кадре клиента.
- Reduced motion: состояние читается без анимации; песочные часы статичны.
