# HYP-0001 — Научное лидерство не даёт автоматического промышленного превосходства

> Пример из мастер-промта (там — «EXP-0001»). Кандидат для пробного цикла PHASE E.

## Гипотеза
Если разделить научный потенциал, инженерные возможности и производственные мощности, то государства с разными их сочетаниями пойдут по разным траекториям, и ни одно сочетание не получит автоматического превосходства.

## Причина появления
Государство может иметь сильную фундаментальную науку, но не уметь создавать передовую технику. Модель «наука = сила» делает игру линейной.

## Предполагаемое решение
Три отдельных потенциала: наука (открытия), инженерия (перевод открытий в применимые решения), производство (масштабирование). Каждый зависит от своих ресурсов.

## Способ проверки
Эксперимент в Simulation Lab: несколько государств с разными сочетаниями науки, кадров, промышленности и ресурсов; Monte Carlo по seeds.

## Критерии успеха
Разные стартовые условия дают разные результаты развития. Ни одно сочетание не доминирует во всех seeds. Оценка — по распределениям, не только по средним.
