# ADR-0026 — Картинки, созданные ИИ, как неподвижные иллюстрации

> Поправка к ADR-0009 (лицензии внешних данных) по решению владельца #445. ADR-0009 не меняется: он касается внешних данных и ассетов; здесь — изображения, созданные моделями ИИ по заданию проекта.

## Краткий вывод
- [Факт: #445] Картинки ИИ разрешены в игре только как неподвижные иллюстрации: схемы узлов, изделия, заставки, текстуры бумаги и стола.
- Условия: (1) каждую картинку отбирает и одобряет ui-art-director; (2) в `mods/core/ATTRIBUTION.md` записаны модель, дата и описание-задание (prompt); (3) приборы и всё, что показывает данные, рисуются кодом.
- В «Авторах» указывается, что часть иллюстраций создана ИИ.

## Контекст
- [Факт] ADR-0009 разрешает внешние данные и ассеты только под PD, CC0, CC BY; про изображения ИИ в нём ничего нет. `.claude/rules/ui.md` требовал собственной процедурной отрисовки.
- [Факт] Генерация картинок через Gemini API на бесплатном ключе недоступна (квота 0, 2026-11-24); возможна ручная генерация владельцем по подписке или платный уровень.
- [Предп.] Во многих юрисдикциях изображение ИИ без творческого вклада человека не охраняется авторским правом; провайдер (Google) не претендует на созданное. Риск: случайное воспроизведение чужой работы; невидимая метка SynthID в изображениях Google.

## Решение
1. Допустимо: неподвижные изображения, не несущие данных игры.
2. Недопустимо: приборы, шкалы, карты, значки состояний — то, что меняется с данными или должно проходить критерии §12 по точной геометрии.
3. Отбор: ui-art-director проверяет стиль (`docs/ui/VISUAL_DIRECTION_V06.md`), отсутствие узнаваемых чужих работ, логотипов и текста; одобрение записывается в обзоре задачи.
4. Учёт: строка в `mods/core/ATTRIBUTION.md` — файл, модель, дата, prompt, кто одобрил.
5. Деньги: платная генерация — только с отдельного решения владельца о лимите (ADR-0015).

## Последствия
- Быстрые иллюстрации без ручной отрисовки; цена — ручной отбор и учёт.
- Правило `.claude/rules/ui.md` дополнено (#445).
