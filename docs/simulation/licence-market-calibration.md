## 6. Предложение для developer (Core; не менял, только песочница)
### 6.1. Прыжок поколения
`src/Singularity.Core/Policy/PolicyProfile.cs`, класс `PolicyParams`: новый `public int AiMaxGenJump { get; init; } = 1;` (проверка в `Validate`: ≥ 0; 0 = без предела). `PolicySystem.Market.cs`, `ComputeMarketBuy`: цикл
`for (int gen = Math.Min(_marketGens, _ev.EngineGen(s, t)); gen > gBuyer; gen--)` →
`int top = _p.AiMaxGenJump > 0 ? Math.Min(_marketGens, gBuyer + _p.AiMaxGenJump) : _marketGens;`
`for (int gen = Math.Min(top, _ev.EngineGen(s, t)); gen > gBuyer; gen--)`. Игрока не касается.
### 6.2. ИИ покупает у своего блока и друзей
Там же, после проверки круга продавца: `if (_p.AiBuyFromFriendsOnly && !_p.Alliances.InCircle(_p.MarketActorIds[s], _p.MarketActorIds[row], year, SaleCircle.Friends)) continue;`; `PolicyParams.AiBuyFromFriendsOnly = true`. Круг продавца-ИИ по умолчанию (`All`) не трогаем, поэтому игрок по-прежнему может купить у любого ИИ (кроме закрытых каталогов). Проект (разд. 2.6 «противникам не продаёт»), O-056, O-068 («данные о противниках — позже»): блок + друзья — ближайшее к «союзники», что есть в данных.
### 6.3. Порог цены ИИ
`PolicyParams.AiPriceK`: `F(1_500_000)` → `F(1_200_000)` (меняет O-062 «k = 1,5»; в O-062 оговорено «Lab может уточнить числа»). Смысл: ИИ не покупает у продавца-«качества» (m = 1,3), только игрок.
### 6.4. Предел 64 каталогов
`PolicySystem.Market.cs`: удалить проверку `rows > MaxWorldPriceActors` в `AddMarketColumns` и константу; `WorldPrice` — сумма и счётчик в том же порядке без `stackalloc`: `sum += o.Price; count++;` → `(count < _p.ThinMarketSellers || count == 0 ? null : sum / Fx6.FromInt(count), count)` (то же, что `LicenceRules.WorldAverage`: сумма тем же порядком, одно деление — результат побитно тот же). После этого `ProcessBench.Config` может включать рынок (бенч остаётся на замороженной сборке до решения по серии #355).
