# Лицензии и покрытие 1945 внешних наборов данных для экономики (E0, критерий G-E0)

Дата проверки: 2026-11-04 (все «дата доступа» ниже). Автор: research-scientist. Критерий G-E0: (i) лицензия из ADR-0009 (PD, CC0, CC BY); (ii) покрытие 1945 по каждой стране. Решения по трактовке ADR не принимаются — см. «Вопросы владельцу».

## Краткий вывод
- [Факт] Два набора имеют подтверждённую на странице правообладателя лицензию CC BY 4.0: Maddison Project Database 2023 и PWT 11.0. Оба проходят критерий (i).
- [Факт] PWT начинается в 1950 → критерий (ii) на 1945 не проходит ни для одной страны. Годится только как калибровка от 1950.
- [Предп.] Maddison: на 1945 покрытие по USA/GBR/FRA/SWE ожидается годовым (длинные ряды), по СССР — только оценки; файл Dataverse в этой сессии не открывался → покрытие 1945 **не подтверждено**, нужна проверка по самому файлу (DOI 10.34894/INZBF2).
- [Факт] COW NMC v7: страница не содержит лицензии/условий использования (только просьба цитировать; вопросы лицензии — к хостам, UNT). По ADR-0009 без явной лицензии использовать нельзя → блокер до письменного ответа.
- [Факт] UN WPP 2024: на страницах UN, доступных проверке, лицензия не найдена; CC BY 3.0 IGO заявлена только вторичными источниками (OWID, R-пакет). Данные с 1950 → 1945 не покрыт. Лицензия **не подтверждена у правообладателя**.
- [Факт] Barro–Lee: лицензии нет, сайт «all rights reserved» (©2021); 1950–2010, шаг 5 лет → не проходит ни (i), ни (ii).
- [Факт] SSP (IIASA): лицензия на странице не воспроизведена; в её тексте есть запрет воспроизведения «существенной части» данных → вероятно несовместимо; базовый год и 1945 не покрыты (проекции от современного года).
- [Факт] USGS DS140: только США; с 1900 по многим товарам; явного заявления о PD на странице набора не найдено (проверить политику USGS).
- Вывод: для 1945 нет ни одного набора, прошедшего G-E0 полностью. Ручные оценки с источниками (как `sun-start-data.md`) остаются основным путём.

## Альтернативы для населения и образования 1945 [Предл.]
- Maddison также содержит население (`pop`), та же CC BY 4.0 — первый кандидат для населения 1945 (после проверки файла).
- Переписи и статистические ежегодники: статус PD зависит от страны и срока (правительственные работы США — PD; Великобритания — Crown copyright/OGL, срок 50 лет у публикаций, 1945 истёк [Предп., проверить]; статистика Лиги Наций/ООН — авторское право ООН/ЛН, на PD не опираться без проверки). Статус для SUN/FRA/SWE не проверялся.
- Образование 1945: Barro–Lee недоступен; варианты — переписи (США 1940, Швеция), ручная оценка по грамотности/школьному охвату с источником.
- Военные расходы 1945 (замена COW): ручные оценки из PD-публикаций (напр. правительственные отчёты США) или бюджет-таблицы с явной лицензией.

## Не проверено
- Файл Maddison (годовые значения 1945, ряд СССР/России, преемственность границ).
- Лицензионный текст UN на странице `population.un.org` (портал вернул мало содержимого; страницу «Terms of use»/«Copyright» не удалось открыть).
- Полный текст лицензии SSP (получены лишь два предложения).
- Политика USGS по PD (страница 404).
- Ответ UNT по COW.

## Вопросы владельцу
1. Допускается ли CC BY 3.0 IGO (UN WPP) как «CC BY» в ADR-0009, и допустимо ли опираться на вторичные источники при отсутствии лицензии на странице?
2. Допускаются ли данные «просьба цитировать, лицензии нет» (COW) до получения письменного разрешения, или запрос к UNT обязателен до G-E0?
3. Принять ли для 1945 ручные оценки с источником как основной путь (по `sun-start-data.md`), а наборы 1950+ (PWT, WPP) — только калибровка вперёд?
4. Статус PD для государственных статистических публикаций (США — §105; другие страны) — принимать ли по юрисдикции источника?
