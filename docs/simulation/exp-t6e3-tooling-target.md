## Метрики
Определения `E*`, `δ`, `D`, `ΔD`, `R`, `C`, `π`, `π̂`, M1–M5 — T6e2 r1 и О4–О13 EXP-0004. `E*` — объединение по V0 и VINF той же конфигурации и seed. Судятся USA и GBR; SUN, FRA, SWE — печать.

**Новые печати (не критерии):**
- **P-dec — разложение `D`:** «культура» `Σ max(0, r_d − H)` + «оснастка ниже культуры» `Σ (min(H, r_d) − min(H, M, r_d))` по тем же (ячейка, месяц, процесс-максимум), по плечам и державам.
- **P-part — участие:** ячейко-месяцы с `M ≤ H ∧ M < r_d` хотя бы у одного p из `E*`, и доля из них, участвующих в проходе 2 плеча; для V5 ожидается 1 по построению (кроме `M_dec ≥ M_cap`) — проверка реализации.
- **P-g — `D` с весом `1 − g_d`:** `δ_g(c, d, t) = max_{(p, d) ∈ E*} (1 − g(min(H, M) − r_d(p)))`, `g` — контракт §4.2 (`(1 + x)²` при −1 ≤ x < 0; 0 при x < −1; 1 при x ≥ 0); `D_g`, `ΔD_g`, `R_g` — как `D`, `ΔD`, `R`. Только печать: смена метрики K1 на `D_g` возможна лишь новым EXP, объявленным до прогона.
- **P-pool — пул:** доля месяцев, когда проход 2 исчерпал пул (`pool_left` = 0); ячейки, получившие меньше `need` из-за исчерпания, по кластерам (порядок водопада — MET, CHEM, MECH, AERO); `T_a` и неизрасходованный остаток против V4.
- **P-A40 — охрана:** число месяцев, где ветка О сняла бы проект без охраны, а `L(d, t)` = true, и чем кончился проект (запуск, позднее снятие).

## Критерии и правило выбора (объявлены до прогона)
Дословно T6e2 r1 «Критерии и правило выбора»; кандидаты — {V4, V5}.
- **V-0** по державе; не выполнено у обеих — inconclusive, A39 остаётся V0.
- **K1** `R ≥ 0,75` (main, точечно; факторные — провал только при верхней границе CI < 0,75, ячейка судится при нижней границе CI `ΣΔD(VINF)` > 0); **K2** `π̂ ≤ 1`; **K4** медиана `b_w` ∈ [0,67; 1,5] в окнах с выпуском USA и GBR > 0 в VINF у ≥ 10 из 20 seeds; **K5** `R5 ≥ 0,75` (не судится и не блокирует при `T(V0) − T(VINF) ≤ 0`).
- **Выбор:** из годных — наименьшее среднее `π̂` USA/GBR; разница ≤ 5% → меньший `S` → меньше новых литералов → меньший номер (V4 и V5 равны по `S` и литералам ⇒ ничья решается в пользу V4). Годных нет — A39 остаётся V0, `outcome` = refutes, отчёт владельцу; новых чисел этот EXP не вводит.

## Ожидания на бумаге (до прогона)
[Предп.; основание — определения плеч, а не подбор; не критерий]
- V5 доливает все ячейки, которые V4 пропускает по условию «узкое», поэтому часть «оснастка ниже культуры» в P-dec у V5 должна быть заметно меньше, чем у V4; остаток — месяц `M ≤ H` на цикл износа (условие по снимку, как у V4) и ячейки, оставшиеся без денег пула.
- Цена: V5 берёт из пула больше V4, `T_a` (учебная серия) меньше; возможны исчерпание пула и недолив AERO (последний в порядке водопада). Если это случится, K1 V5 может провалиться не по условию участия, а по деньгам — P-pool это покажет.
- Культура: другие деньги учебной серии могут сдвинуть часть «культура» и K4; направление заранее не известно.
