> Пометки: **[Факт]** — подтверждено источником; **[Предп.]** — предположение (в т.ч. знание «по памяти», не проверенное в этой сессии); **[Предл.]** — предложение, не решение. ## Вопрос исследования
Как представить государство набором институтов со своими интересами, так чтобы (а) режим, преемственность и устойчивость считались детерминированно от состояния, (б) политика ограничивала бюджет и решения ИИ в E1, (в) игрок управлял условиями, а не процессами (#19), и (г) в M1 не появилось порогов по политике (#340)?

## Краткий вывод
1. [Предл.] Режим — **данные**, не код: набор из ≤5 слотов-институтов (`executive`, `party_or_legislature`, `security`, `bureaucracy_industry`, `society`) с весом `w_i` (Σ=1), вектором интересов `pref_i` над осями бюджета E1 и флагом `veto`. Типы режимов — пресеты (монархия, однопартийное, военное, парламентское, колониальное управление, оккупация, ...) плюс переходные «переходы» между ними.
2. [Предл.] Три состояния на политию в Fx6: `legit` (согласие общества), `elite` (удовлетворённость коалиции), `strain` (внешнее и военное давление). Устойчивость `stab = min`-подобная свёртка с гистерезисом; все обновления ежемесячные, без RNG.
3. [Предл.] Преемственность: правило режима (срок / возраст-здоровье из RR-0012 / решение коалиции) + слот из ≤3 кандидатов; выбор — `argmax` взвешенной поддержки институтов, ничья по id. Смена режима при `stab < θ_low` — детерминированный переход в пресет-преемник из данных.
4. [Предл.] Политика **фильтрует**, а не заменяет решение ИИ E1: кандидат бюджета ИИ (еженедельно, со сдвигом по дням, #344) сводится к равнодействующей `Σ w_i·pref_i`, затем вето-институты ограничивают шаг. Непринятое попадает в `why_not` как звено «институт X против».
5. [Предл.] Рычаги игрока косвенны и дороги: структура бюджета, финансирование/ступень института (#192), назначение руководителя из ≤3 (#207), реформа как национальный проект, внешние рычаги (помощь, блок). Прямого «сменить режим» нет.
6. [Факт, #361] **M1:** только статическое поле `regime_id` в данных, политической динамики нет (ни `pref`/`λ` в бюджете ИИ, ни `legit/elite/strain`); `PolityState` остаётся `support`. **M2+:** `legit/elite/strain`, вето, преемственность, `consent_to_hold`, `metropole_capacity`.
7. [Факт, #362] ИИ-страна может сменить режим эндогенно по `stab`. Игрок меняет свой режим только реформой — национальным проектом; потерять власть переворотом он не может, game-over по смене режима нет.
8. [Факт, #363] Внутренняя `legit` и внешняя `support_world` — две отдельные величины.
9. [Факт] Данные V-Dem под CC BY-SA 4.0 — несовместимы с ADR-0009 (только PD/CC0/CC BY) для копирования в игру; использовать как справку для калибровки, пресеты писать вручную.

### 2. Теоретическая база (идеи, не данные)
[Предп., по памяти, не проверено в сессии] (a) теория селектората: удержание власти зависит от размера выигрышной коалиции и её лояльности (Bueno de Mesquita et al., *The Logic of Political Survival*, 2003); (b) вето-игроки: число и разброс позиций институтов, чьё согласие нужно, определяют возможность изменить статус-кво (Tsebelis, *Veto Players*, 2002); (c) типология автократий — личная / военная / партийная — различается способом ухода и устойчивостью (Geddes). Игровая абстракция берёт отсюда только три числа: размер коалиции (через `w_i`), число вето (флаги), лояльность (`elite`). Исторические якоря [Предп.]: смена руководства СССР 1953 и 1964 решением узкой элиты; монархия/диктатура и передача власти в Испании 1975; давление внутри блока на Британию и Францию в 1956 (см. RR-0016). Каждый якорь нужно подтвердить источником до записи в данные (§6).

### 3. Модель режима (идентификаторы)
```
RegimePreset { id, slots[5]: { inst, w, pref[axes], veto, tol }, succession_rule,
               term_ticks | age_rule, theta_low, theta_high, successor_regime }
PolityPolitics { regime_id, legit, elite, strain, leader_id, last_change_tick }   // Fx6
```
- `axes` = оси решений E1: доли `security / science / investment / consumption / institutions` (согласовать с economy-analyst), плюс внешние (`aid`, `trade_open`) в M2+.
- Режим меняет только **весы и вето**, не формулы экономики (граница с economy-analyst). `occupation` и `joint` — пресеты, где `executive` = контролёр, `society` слабо весит, вето у контролёра.
- Слоты, отсутствующие в режиме (нет легислатуры), имеют `w=0`. Малое число слотов (5) — граница читаемости: экран «кто хочет чего» помещается в одну панель.

### 4. Устойчивость и преемственность (детерминированно)
- [Предл.] Ежемесячно:
  - `legit ← legit + k_l·(consumption_gap_clamped − war_cost_load) − decay`, где `consumption_gap` = доля потребления против «ожидаемой» (память сглаживания EMA, не RNG);
  - `elite ← elite + k_e·Σ w_i·(budget_share_i − expected_i)`;
  - `strain ← f(война RR-0016, блокада/дефицит RR-0019, скандал RR-0017)`.
  - `stab = min(legit, elite) − strain·k_s`.
- Гистерезис: переход при `stab < θ_low`, возврат режима невозможен до `stab > θ_high` — иначе дребезг (инвариант как в HYP-метриках S1–S6).
- Преемственность: триггер — срок, возраст/здоровье личности (RR-0012; появление и уход людей — **слой событий, единственный источник случайности**, #28), либо `stab < θ_low`. Кандидаты ≤3 (из данных и сгенерированных); победитель — `argmax Σ w_i·fit_i(candidate)`, ничья по возрастанию id. Игрок в своей полии выбирает из тех же ≤3 только если правило режима даёт ему слот (напр. назначение в авторитарном режиме); иначе наблюдает.
- **Асимметрия ИИ/игрок (#362).** Эндогенная смена по `stab < θ_low` действует только для ИИ-стран. Для полии игрока `stab` и `θ_low` дают лишь издержки (падение `elite`, замедление проектов, `why_not` «институт X против»), но `regime_id` игрока по `stab` не меняется, переворота и поражения нет. Режим игрока меняет только его проект-реформа (§6 п. 4). Инвариант для Lab: ни при каких входах `stab` полития игрока не теряет управление и не вызывает game-over.
- Смена режима (ИИ): `regime_id ← successor_regime`, `legit/elite` частично сбрасываются к значениям пресета (данные), `last_change_tick` блокирует новую смену на N месяцев. Без RNG: одинаковое состояние даёт одинаковый исход (L1/L2).
- [Предп.] Метрика «режим ухода» в датасетах — калибровка по частоте смен режима на 1945–2025 (диапазон), не точечная подгонка.

### 5. Как политика ограничивает бюджет и ИИ E1
- [Предл.] Порядок на день решения страны `c` (#344): 1) ИИ формирует кандидат `x*` по своей логике (цели, `Inclination` #202, `why_not`); 2) `x_pol = Σ w_i·pref_i`; 3) `x = x* + clip(x_pol − x*, ±step)` — доля политического смещения `λ(regime)`; 4) для каждого `veto`-института: если `|x_axis − pref_i| > tol_i`, ось подтягивается к границе допуска; 5) если вето несовместимы (пустое множество) — остаётся прошлый бюджет, а звено `why_not` «вето: институты A и B». Всё — Fx6, фиксированный порядок оси и слота, чистая функция состояния → детерминизм без RNG.
- Цена: `O(slots·axes)` на страну на решение (≈25 операций); при ~200 полиях и еженедельных решениях — пренебрежимо (≪ 1 мс в день) [Предп., замерить Lab-микротестом до принятия].
- Автократия не «лучше» демократии по определению: пресеты различаются обменом — узкая коалиция даёт быстрый поворот бюджета (малый `tol`, мало вето), но высокий риск смены при `elite`↓; широкая — медленный поворот (много вето), но устойчивость. Тест на отсутствие доминирующего режима: H-POL-1 (§7).
- Объединённая полития (#312): `Apportion` бюджета уже есть (ADR-0020 п. 11); политика совместной полии — вето у каждого члена по сумме долей `econ_shares`, иначе равные.

### 6. Рычаги игрока (смысл, а не таблица)
Идея: каждый рычаг двигает **одну из трёх переменных** и имеет цену в другой, так что «поднять `stab`» не бесплатно.
1. **Структура бюджета** (прямая власть над условием): потребление → `legit`↑, инвестиции/наука ↓ (отложенная цена); безопасность → `elite` у силового слота↑ и `strain`↓, но вес силового слота растёт (парадокс «защита от переворота»).
2. **Институты как проекты** (#192): повышение ступени института `tier_up` растёт его вес `w_i`; цена — срок и деньги, эффект медленный. Исследовательский институт с весом — лобби науки (читается в RR-0012).
3. **Руководитель** (#207): назначение из ≤3 меняет `fit_i` и направление; цена `support`.
4. **Реформа режима** — национальный проект с этапами (RR-0012): временное падение `elite` на время перехода, срыв при `stab < θ` — детерминированный (#28), а не кубик. Срыв реформы откладывает или откатывает проект, но не отнимает власть у игрока (#362).
5. **Внешние** (M2+): помощь/блок меняют `strain` и `S_bloc`; `consent_to_hold` колонии зависит от `legit` колонии и `metropole_capacity` метрополии (войны, бюджет, #322 школа не нужна).
[Предл.] Анти-микроменеджмент: игрок не выбирает министров и не раздаёт посты; интерфейс — одна панель «институты и их интересы» с `why_not` для отклонённого бюджета и прогнозом «что сдвинется через N месяцев» (читаемость причин).

### 7. M1 и M2+
- **M1 (#361, не блокирует, #340):** только статическое поле `regime_id` в данных полии (из `polities.yaml`, `scenario_hash`); без `pref`/`λ` в бюджете ИИ, без `legit/elite/strain` и вето; `PolityState` остаётся `support`. Сценарные события (#328) берут только структурные условия. Цена в тике — ноль. Стык: `controller ≠ owner` (#313), `joint` (#312) не ломаются.
- **M1.5/M2:** три переменные, вето-фильтр, преемственность, смена режима; атомы условий `regime_is`, `stab_below`, `consent_to_hold` — новая версия реестра атомов (scripted-events §6). Выход — событие слоя событий «смена власти» (RNG только там).
- **M3+:** переворот как следствие `strain` от войны (RR-0016), внешнее вмешательство (RR-0017), многоуровневые полити (федерации, блоки), UN-вето из RR-0016.

### 8. Эксперименты Simulation Lab (предложение simulation-engineer)
- H-POL-1: ни один пресет не доминирует по доле «лидер гонки» по 300+ seeds с одинаковым стартом (доля победителя ≤ порога, согласовать с game-designer).
- Инварианты: детерминизм L1/L2; `Σ shares = 1`; ничья всегда по id; `stab` без дребезга (число смен режима ≤ k за 10 лет при постоянных входах); вето-тупик не блокирует бюджет (остаётся прошлый); абляция «политика off» даёт M0/E1 бит в бит.
- Распределение смен режима 1945–2100 в диапазоне исторической частоты (калибровка диапазоном).
