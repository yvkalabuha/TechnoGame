# ARCHITECTURE

> Объединяет TECHNICAL_DESIGN_DOCUMENT и ARCHITECTURE (DF-001 §5.5). Источник решений — ADR в `docs/decisions/`; этот документ — карта, а не копия.
> Статус: ядро ещё не реализовано. Решения со статусом PROPOSED могут измениться.

## Обзор

```
Singularity.Lab (CLI, эксперименты)      Godot-клиент (после M0)
            \                              /
             └──────► Singularity.Core ◄──┘     доменные системы
                            │
                     Singularity.Kernel         тик, RNG, fixed-point, таблицы, хеши
                            │
                        mods/core/              данные базовой игры (мод)
```

| Слой | Ответственность | Решения |
|---|---|---|
| Kernel | Конвейер тика, детерминированный RNG, fixed-point, таблицы struct-of-arrays, хеш состояния | ADR-0003 … 0007 (PROPOSED) |
| Core | Доменные системы (наука, экономика, ...), namespaces по доменам | появятся в PHASE F |
| Lab | Прогоны по манифесту, метрики, регрессии | ADR-0008 (PROPOSED) |
| Данные | Мод `core`, схемы, загрузчик | ADR-0009 (ACCEPTED), ADR-0010 (PROPOSED) |
| Карта | Векторные полигоны → граф провинций | ADR-0011 (PROPOSED) |

## Утверждено
- **ADR-0001** — C# / .NET 10 ядро без движка; Godot 4 .NET после M0.
- **ADR-0002** — детерминизм L1 + L2 с M0; L3 позже.
- **ADR-0009** — лицензии данных: PD, CC0, CC BY.

## Тик (ADR-0006, PROPOSED)
1 тик = 1 день; системы с частотами день / неделя / месяц / год. Фазы: команды → compute (параллельно, чтение прошлого состояния) → merge (детерминированный порядок) → post (инварианты, метрики, хеш).
