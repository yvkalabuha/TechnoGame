# RR-0023 — Start data 1945 by region: estimates with uncertainty ranges

> Пометки: **[Факт]** — подтверждено источником; **[Предп.]** — предположение; **[Предл.]** — предложение.

## Вопрос исследования
Как получить для t0 = 1945-10-01 значения E1 по регионам и акторам, у каждого — источник и диапазон (для возмущения по seed, #329), если из разрешённых наборов (#168: Maddison 2023, PWT 11.0) 1945 покрыт только частично, а регионального разреза нет ни у одного. Пункты MS-M1 2.1–2.4, риск «ручные оценки 150–250 регионов».

## Краткий вывод
- [Факт] Maddison 2023 (через зеркало OWID) даёт ВВП на душу 1945 для USA, GBR, FRA, DEU, JPN, но **не даёт** SUN (пропуск 1941–45) и CHN (пропуск 1939–49). PWT начинается в 1950 — только калибровка вперёд.
- [Факт] Ни один разрешённый набор не содержит региональных данных, энергии, промышленной мощности по кластерам, образования: всё это — ручные оценки (#168).
- [Предл.] Метод: Y страны (Maddison/ручная) × доля региона по прокси (население, город, промышленные центры) — у каждой величины диапазон; приоритет A (великие державы, спорные регионы, зоны по #350) → B → C (крупные ячейки).
- [Предл.] Возмущение: общий множитель страны (диапазон Y) × независимые коррелированные сдвиги долей (Дирихле) с сохранением Σ долей = 1; точка истории остаётся эталоном.
- [Факт] Проверка 2026-11-18: pc 1945 для USA, GBR, FRA, DEU, JPN совпал с OWID-API; Dataverse (DOI 10.34894/INZBF2) подтверждён как источник файлов и лицензия CC BY 4.0. Сам xlsx прочитать не удалось (бинарный, нет разбора) — значения и население (= ВВП / pc) взяты из OWID CSV, построенного на Maddison 2023.
- [Факт] DEU: 1943 = 9 389, 1944 = 9 698, **1945 = 7 195**, 1946 = 3 534, 1947 = 3 883 — 1945 это точка спада военного пика, не послевоенный уровень. Примечаний Maddison к этому году на странице релиза нет (причину в статье/Source sheet не проверяли) [Предп.]: военное производство.
- [Факт] CHN 1945 в зеркале — это значения 1950 (GDP Original Year = 1950; pop ≈ 546,8 млн = население 1950), не оценка 1945. Население из таблицы §3 (465) заменено/помечено.
- Таблица §3: Y_1945 в трлн $ (2011 int., Maddison через OWID): USA 2,31; GBR 0,553; FRA 0,163; DEU 0,482 (военный пик); JPN 0,280; CHN 0,437 (=1950); SUN не проверен (ряда в OWID нет; RUS 0,337 = значение 1950).
- Лицензии: Maddison — CC BY 4.0 (подтверждено на RUG и Dataverse 2026-11-18); OWID — CC BY для собственных данных, сторонние данные по условиям провайдера; остальные источники §4 — не проверены.
- Нужно решение владельца по 4 вопросам (§Открытые).

### 2. Метод
**2.1 Итоги страны.** (а) Maddison 2023: `GDPpc_1945 × pop_1945`, где ряд есть; (б) где ряда нет (SUN, CHN) — интерполяция ряда по соседним годам Maddison + поправка военного года [Предп.] с диапазоном, вилка шире; (в) первичная статистика (переписи, бюджеты) там, где Maddison слаб (DEU, FRA). PWT 11.0 — только калибровка 1950 вперёд (проверка траектории Lab E1-L4, не вход 1945). Деньги — постоянные цены (#168): единица `u$` = международный доллар 2011 по Maddison, без пересчёта [Предл., см. вопрос 4].

**2.2 Доли регионов.** `Y_r = Y_a · (w_pop · sh_pop_r + w_urb · sh_urb_r + w_ind · sh_ind_r)` с весами по типу региона; промышленность `V_rk` — через долю промышленных центров (известные: Рур, Ленинград/Москва/Урал, Детройт–Питтсбург, Мидлендс, Кансай/Кантō, Маньчжурия) [Предп.]. Для каждой доли — интервал `[lo, hi]`: перепись — ±5%; оценка по городам — ±15%; промышленный центр по экспертным оценкам — ±30%; регион без источника — ±50%.

**2.3 Возмущение (#329).** На seed: (1) `Y_a` — тянется один раз на страну из треугольного/логнормального распределения на `[lo, hi]` с модой в точке истории; (2) доли регионов — Дирихле вокруг точки с дисперсией из интервала, нормировка Σ = 1 (сохранение суммы — инвариант); (3) общие множители на кластер, чтобы не нарушить `ΣV = Y`. Все тянутся из RNG мира с фиксированным потоком (L1/L2). Свойства для теста: сумма регионов = страна; перестановка региона не меняет остальных; точка = эталон при нулевом разбросе.

**2.4 Приоритет и объём.** [Предп.] Порядок: A — USA, SUN, GBR, DEU (зоны), JPN, CHN (по #350: Маньчжурия, Тайвань, Корея, зоны) и все регионы с событиями владения (#350); B — FRA, ITA, POL, регионы, вовлечённые в гонку; C — остальные. Грубо: A ≈ 60–90 регионов с индивидуальными долями, B ≈ 50, C ≈ 50–100 крупных ячеек. Это ≈ 1/3 от полного объёма ручной работы.

**2.5 Регионы без источника (крупные ячейки).** Правило [Предл.]: ячейка наследует страновое среднее на душу и страновую структуру кластеров (`ratio_r = 1`, `sh^N_r` = страновое); долю `sh_r` берёт по площади/населению соседей; диапазон — ±50% (потолок), промышленность — только при подтверждённом центре, иначе `K_rk = 0` кроме сельского `Y_rest`. Помечается флагом `cell_class=C` в данных, чтобы Lab мог исключать из метрик.

**2.6 Текущая карта.** `mods/core/map/regions.yaml` ([Факт], прочитан 2026-11-18) — ~70 европейских регионов, иногда по одной провинции страны (напр. `france_ain`, `france_gers`, `france_marne`, `russia_perm`); это сгенерированная от `spec/regions` карта в современных границах, не 150–250 регионов и не с линиями событий (#350). Для данных нужен слой «регион → доля страны» поверх; регион 1945 по границам 1945 и линиям зон. Для зон Германии и Австрии — отдельный набор долей (не доли современных земель).

## Риски
- Широкие диапазоны DEU/SUN/CHN → гонка чувствительна к старту; метрика «доля дисперсии исхода от старта» нужна в EXP.
- Maddison интерполирует военные годы: возможен артефакт на t0 (DEU).
- Регионов с источником мало; доля класса C высока → ошибка уходит в «пол» экономики.
- Лицензии национальных статистик не проверены.

## Открытые вопросы
1. Единица денег: оставить международный доллар 2011 (Maddison) как `u$` или пересчитать в «доллар 1945» (тогда нужен дефлятор, источник которого нужно выбрать)?
2. DEU и SUN: брать для t0 военную точку (Maddison 1945) или послевоенную (1946), если файл подтвердит разрыв? Влияет на начальный вес стран.
3. Допустимы ли для региональных долей данные из книг (с цитатой, без копирования таблиц) — граница «факт vs авторское право»?
4. Объём: принять ли A/B/C (§2.4) как план, с классом C крупными ячейками, ради срока M1?
