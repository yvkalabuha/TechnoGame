## 2. Дерево знаний, 1920x1080 при 100 % (1 du = 1 px)
### 2.1 Раскладка
- [Факт] Сейчас: планисфера x 0–1144, инспектор x 1152–1912 (760 du), штамп снизу справа. Оставляем: панели те же, меняется содержимое.
- Инспектор сверху вниз (всё в ScrollContainer, A12): шапка 28 du (система · «Дерево знаний», плашка статуса справа 28×104 du) → ряд «№7 · Знание · …» 22 du → заголовок узла 30 du serif (одна-две строки) → подстрока «Силовые установки · Историческая дата: 1960» → окно картинки 736×200 du → «Параметры узла» (4 строки по 32 du) → «Зависимости и открытия» (по строке на узел, 32 du, плашки «Известно/Доступно/Закрыто») → «Почему не» (аккордеон, 32 du) → «Фокус освоения» + кнопка 36 du → блок причины. Высота ≈ 880 du: влезает без скролла на 1080, скролл включается на 125–150 % (A9).
- Планисфера: ничего не добавляем поверх колец; легенда внизу слева ≈ 560×330 du по 0136 §2.2.
### 2.2 Планисфера (цвет «Атласа»). Критерии: C2, C5, A4, A5, A11
- Сектор = система (3 цвета: бирюза, роза, серо-синий — уже есть). Заливка — **декор** (C5: контраст к бумаге ≤ 1,6:1, под подписи не заходит). Значит несёт смысл штриховка: [Предл.] второй канал по системам, угол 45° / 135° / крест (закрывает находку design-pass-2 №19, A5). Штрих 1 du, тон `ink.X.text` α 0,35.
- Подпись дуги системы вдоль сектора, 13 du caps `ink.X.text` ≥ 4,5:1 (A3), на плашке `sheet` α 0,92 (как 0136 §2.3). В Фолио подписаны **дисциплины**; в Атласе нет подписей. [Предл.] подписываем системы (на секторе их три) — 3 подписи, не 12.
- Римские номера колец I–V слева: 13 du `ink-2`; расшифровка в легенде: «кольцо = слой: I знание … V изделие» (C6). [Факт] кольца и их шесть уровней уже в легенде 0136 §2.2: сверить, что номера кольцо ↔ уровень совпадают (developer).
- Узлы: форма и состояние строго по 0136 §2.1. Не меняем.
- Выноски соседей (№16, №27): подпись-плашка `sheet` непрозрачная, 13 du, штрих 1 du; показывать **только** узлы «открывает дальше» и «зависит от» выбранного (≤ 6). Это DEBT-0085.
### 2.3 Карточка узла (Фолио). Критерии: C1, C2, C3, C4, C6, A1, A3, A5, A6, A10
- Плашка статуса: слово + значок формы (○ △ ● как в узлах), не только цвет (A5). Известно / Можно открыть / Закрыто / Освоен.
- Таблицы: колонки «название | значение», зебра `sheet` / `sheet` +4 % L*, граница 1 du `rule`, текст 14 du, заголовок раздела 13 du caps. Единицы в значениях (C3).
- Строка зависимости — **цель нажатия** (24×24 du минимум, строка 32 du): Enter/клик выбирает узел (то же, что нажатие на планисфере). Фокус 2 px (A7).
- Причина (C4): блок под кнопкой, `sheet` -6 % L*, текст 13 du, слева знак «!»-квадрат 14 du (как 0136 §2.1). Тексты — 0136 §2.4, без «API», «макет», «тик».
- Кнопка «Отдать приказ: фокус»: 36 du; enabled = заливка `command` (0136 §2.9); disabled = штриховка + замок + причина под ней.
### 2.4 Центральный циферблат. Критерии: C3, C5, C7
[Факт] сейчас часы-циферблат без подписи; 0132 просит подписать. Компас/секундомер эскизов — тоже стрелочный прибор без значения. [Предл.] сделать **розетку-ориентир** (неподвижная, без стрелки, контраст ≤ 1,6:1) и подписать «центр: корни знания»; стрелку убрать. Стрелка, показывающая цель, возможна только вместе с числом «шагов до цели: N» (C3) и запасным видом (C7); пока не берём.
### 2.5 Картинка узла: откуда (решение владельца, ADR-0026 + #445)
| Вариант | Что это | Плюс | Минус |
|---|---|---|---|
| **A. Код-схема** [Предл., по умолчанию] | рисуется `_Draw`: шаблон по классу узла (кольцо 1–6) с осями-`Label` и подписью «Схема (пример)» (0136 §2.7) | честно (данных у узла нет), 0 лицензионных вопросов, работает для всех узлов | одинаковые схемы у многих узлов; не «гравюра» как в Фолио |
| **B. ИИ-иллюстрация** | статичный разрез/деталь в стиле гравюры, 1 файл на узел, подписи (T, s, Q) наносятся `Label` поверх, не в картинку | та самая «книжность» Фолио | объём: нужен список узлов [Предп.: узлов в слайсе ≈ 70+, проверить по данным]; каждая картинка проходит мою приёмку, модель/дата/промпт в файл атрибуции (#445); картинка не показывает данные |
| **C. Смесь** [Предл. рекомендую] | A для всех; B только для узлов цепочки реактивного истребителя (≈ 10–15, число уточнит game-designer), по мере готовности | видно улучшение там, где игрок играет; нет дыр | два вида окна: рамка одна, внутри либо схема, либо иллюстрация |
Правило: нет файла иллюстрации → схема A. Картинка-подделка данных (кривая «T–s» с реальными цифрами) запрещена: цифр на ней нет.
