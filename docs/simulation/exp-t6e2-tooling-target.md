# EXP-NNNN — T6e2: цель прохода 2 A39 на сборке F17b

> Текст пункта для `development/experiments/` (создаёт Orchestrator командой `/new`, номер и `related` проставляет он). Нормативные правила модели — спека `docs/simulation/slice-jet-aviation.md` v0.20 (§3.5 A39, A41 «F17b»; §11 T6e — определения плеч и VINF). Решения: #129, #156, #160. ## Краткий вывод
- Вопрос тот же, что в EXP-0003: какая цель прохода 2 снимает замок «оснастка × культура» дешевле всех. Сборка — после F17b: рабочая линия закрывается только при `y_prod` новой серии, поэтому главная причина падения культуры USA в EXP-0003 (потеря выпуска) должна уйти.
- Плечи: **V0, V1, V3, V4, VINF**; V2 и V3b не прогоняются. Числа вариантов — прежние (не подбираются после EXP-0003).
- Рост культуры `ΔH` заменён **дефицитом способности** `D` — суммой недостачи `min(H, M)` до `r_d` по ячейкам и месяцам. `D ≥ 0` всегда, поэтому доля «улучшения против эталона» определена при любом знаке изменения культуры.
- Критерии: K1 (≥ 0,75 улучшения VINF), K2 (цена не выше VINF), **K4 против VINF**, K5 (освоение, ограниченное среднее время). K3 (якоря) — печать. Условие пригодности V-0 — по каждой державе отдельно (решение Orchestrator): держава, где VINF не улучшает `D` против V0, исключается из критериев; у обеих — исход inconclusive.
- **Сказано прямо:** K1 и K2 почти не различают V3 и V4 (оба держат `M ≥ H`, как VINF); вероятнее всего, исход решит правило ничьей (разница цен ≤ 5% → `S` → новые литералы → номер), то есть V3 при годности обоих (ревью critic до прогона).

(2) С опорой на EXP-0003 (**да**): V2 снял замок частично, провалил K1 в факторных ячейках и неустойчив между ними. ## Метрики
Судятся USA и GBR (там, где замок наблюдался); SUN, FRA, SWE — печать. Все суммы — в `Fx6` raw, анализ — в рациональных/`decimal` без округления до отношения.

**Определения.**
- **Релевантные процессы месяца** `E*(a, s, t)` — пары (p, d): p — PRC кластера c, `r_d(p) > 0`, p `eligible` на `home(a)` (известен ∧ (`proc_v > 0` ∨ `planned`), О5 EXP-0003) **в месяце t** в V0 **или** в VINF seed s. Набор общий для всех плеч seed (парность) и не зависит от судимого варианта; процесс, брошенный в обоих эталонах, с этого месяца не считается.
- **Способность ячейки** `c(c, d, t, arm) = min(H, M)` на `home(a)` по снимку месяца t (контракт §4.2: измерение не ограничивает `yield` (`g_d` = 1) тогда и только тогда, когда `min(H, M) ≥ r_d`).
- **Дефицит ячейки-месяца** `δ(c, d, t, arm) = max_{(p, d) ∈ E*(a, s, t), cluster(p) = c} max(0, r_d(p) − c(c, d, t, arm))`; пусто → 0.
- **Соизмеримость измерений** [Факт: контракт §4.2 — `g_d = g(min(H, M) − r_d)`, одна функция `g(x) = (1 + x)²` при −1 ≤ x < 0 для всех измерений; `mods/core/nodes.yaml` — `r_d` всех трёх измерений на одной шкале tier, 2,5…5]. Влияние на `yield` задаёт абсолютная недостача `r_d − c`, а не относительная, поэтому сумма по `precision`/`purity`/`quality_control` без нормировки корректна; нормировка `1 − c/r_d` дала бы низким `r_d` больший вес без основания в модели. Печать: тот же `D` с весом `1 − g_d` (дефицит в единицах `yield`).
- **Дефицит актора** `D(a, s, arm) = Σ_{t=0}^{383} Σ_{(c, d)} δ` (единица — «культура·месяц»).
- **Улучшение** `ΔD(a, s, V) = D(a, s, V0) − D(a, s, V)`.
- **Доля достижимого улучшения** `R(a, V) = Σ_s ΔD(a, s, V) / Σ_s ΔD(a, s, VINF)` по seeds набора (main или одна факторная ячейка). Определена, если знаменатель > 0.
- **Стоимость** `C(a, s, arm) = Σ_t Σ_{все ячейки a} invest прохода 2` (VINF — `invest_notional`); `ΔC(a, s, V) = C(V) − C(V0)`.
- **Цена улучшения** `π(a, V) = Σ_s ΔC / Σ_s ΔD` (определена при `Σ_s ΔD > 0`; при `Σ_s ΔC ≤ 0` — 0); **относительная** `π̂(a, V) = π(a, V) / π(a, VINF)`.

**Почему так** [Предл.]: (1) `δ ≥ 0`, поэтому `D ≥ 0` и знак `ΔD` значит одно — «лучше/хуже V0»; отношение сумм по seeds не взрывается на seed с малым знаменателем. (2) `min(H, M)` против `r_d` — ровно то, что влияет на `yield`; замок V0 даёт и `M < H`, и недорост `H` — оба видны. Рост выше `r_d` на выпуск не влияет и не считается. (3) Набор `E*` задают V0 и VINF, а не судимое плечо: вариант не может уменьшить дефицит, потеряв процесс. Печать: `ΔD` раздельно по (p, месяц), где p `eligible` в судимом плече, и где нет. (4) Цена — приростная к V0: V0 тоже платит за проход 2.

**Метрики печати** (p10/p50/p90, min/max, крайние seeds поимённо; по seed и в сумме):
- **M1 — замок и деньги:** доля месяцев пула с `Σ E_p > 0`; смены `EFFORT ↔ TOOLING` на 100 мес.; доля месяцев `TOOLING` (определения О6, О7 EXP-0003); `D`, `ΔD`, `R`, `C`, `π`; неизрасходованный остаток. **Прежний `ΔH` пула EXP-0003** — для сравнимости, не для суждения.
- **M2 — выпуск** по окнам 48 мес. (w = 0…7), по актору; `r_w = out_USA / out_GBR`.
- **M3 — освоение и вооружение:** первый `mastered` (tier ≥ 4), первый `G(a) ≥ g`, `G_front`, `maxG` — функции Core.
- **M4 — якоря** C1, C2 (`d_k` по §8.2 п.3, О8, О9 EXP-0003), C4 — печать; не калибровка (RISK-0011).
- **M5 — F17b:** число и длительность сосуществований линий, причина конца, `y_min(N)`, класс L-C «деньги сосуществования» (spec A41 «F17b», «Печать»).
- **M6 — диагностика `ADMIT`:** `ΔD(VINF)` и доля seeds с `ΔD(VINF) ≤ 0` при `YPROD` и `ADMIT`; `ΔH` USA в обоих режимах.

## Критерии и правило выбора (объявлены до прогона)
**V-0 — пригодность, по державе (решение Orchestrator).** Для a ∈ {USA, GBR}: `Σ_s ΔD(a, s, VINF) > 0` и нижняя граница CI > 0 в main. Держава, где V-0 не выполнено, в отчёте называется и **исключается из K1, K2, K4, K5** (K4 — отношение USA/GBR — тогда не судится); если V-0 не выполнено у обеих — `outcome` = inconclusive, A39 остаётся V0, отчёт владельцу. Печатается доля seeds с `ΔD(VINF) ≤ 0`.

Кандидат V ∈ {V1, V3, V4} **годен**, если выполнены все условия:
- **K1 — улучшение.** Main: `R(a, V) ≥ 0,75` у каждой державы, прошедшей V-0. Факторные ячейки (10 seeds; расширения до 20 нет — выбрано, чтобы не добавлять 150 прогонов): ячейка судится для державы, только если нижняя граница CI `Σ ΔD(VINF)` > 0 (как V-0); в судимой ячейке K1 **провален, только если верхняя граница CI `R` < 0,75** (10 seeds слабее main, поэтому провал требует уверенности). Несудимые ячейки печатаются с пометкой. Порог — T6e r1: «три четверти того, что дал бы мир без предела `TOOLING`»; задан относительно эталона, а не ожиданий вариантов.
- **K2 — цена.** `π̂(a, V) ≤ 1` у каждой державы, прошедшей V-0, в main (X = 1, T6e r1): вариант, который за единицу улучшения платит больше, чем держать оснастку на потолке, доминирован эталоном.
- **K4 — баланс против эталона (#160).** Seeds окна w — те, где выпуск USA и GBR > 0 **в VINF** (условие только на эталон, чтобы не отбирать «выживших» варианта). `b_w(s) = r_w(V) / r_w(VINF)`; в варианте `out_USA = 0` → `b_w = 0`, `out_GBR = 0` → `+∞`, оба 0 → `+∞` (вне интервала, консервативно) — все остаются в медиане. Окно судится, если таких seeds ≥ 10 из 20 (большинство; опора на EXP-0003 — «Уроки»). Условие: медиана `b_w` ∈ [0,67; 1,5] в каждом судимом окне. Границы — v0.13, симметричны в логарифме (1/1,5 = 0,667). Смысл: вариант не должен сдвигать баланс великих держав против мира без замка; против V0 это мерило бы само снятие замка (урок A2). Печать рядом с K4: несудимые окна; `out_a(V)/out_a(VINF)` по актору; **эффект свободного бюджета VINF** — деньги прохода 2, которые вариант берёт из пула (`rest_a`, `B_cap`), а VINF оставляет, и куда они ушли у VINF (учебная серия `T_a`, неизрасходованный остаток) по окнам: часть расхождения с VINF — следствие условных денег эталона, а не правила оснастки.
- **K5 — освоение.** Пары (s, a, p): все 5 акторов, PRC tier ≥ 4, не освоен на t0, первый `mastered` в VINF есть (≤ 383) — набор задаёт эталон. `T(arm) = Σ_пары min(t_mastered, 384)` (ограниченное среднее время, цензура 384 входит честно). `R5(V) = (T(V0) − T(V)) / (T(V0) − T(VINF))` ≥ 0,75 в main (все акторы; пары державы, не прошедшей V-0, исключаются). Если `T(V0) − T(VINF) ≤ 0` — K5 не судится (эталон не ускоряет освоение). Порог — тот же принцип «три четверти достижимого», что в K1.
- **K3 — якоря — печать, не критерий.** Основание: (1) EXP — не калибровка (RISK-0011); (2) [Факт: EXP-0003 M4] C2 на этой сборке не определён (`d` = 1 во всех плечах), C1 «зрелая» вне коридора во всех плечах — критерий, который не может различить варианты, ничего не проверяет. Если C1 «освоение» уйдёт из коридора у варианта, но не у VINF, это пишется в «Ошибки и аномалии» и выносится на gate.

**Выбор.**
1. Из годных — наименьшая `(π̂(USA, V) + π̂(GBR, V)) / 2` (main; если одна держава исключена по V-0 — `π̂` другой). Относительная цена безразмерна, поэтому среднее USA и GBR не зависит от масштаба бюджетов.
2. Если у двух годных разница ≤ 5% (относительно меньшей) — меньший `S`; при равном `S` — меньше новых литералов, затем меньший номер.
3. Годных нет (при выполненном V-0) — A39 остаётся V0, `outcome` = refutes для всех кандидатов, отчёт владельцу. Новые числа вариантов — только новым EXP на seeds 41…60.
