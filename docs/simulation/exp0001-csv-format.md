# Формат входных CSV для анализа EXP-0001 (`lab/analysis/exp0001.py`)

> Связано: EXP-0001, HYP-0001 rev 2 («Критерии успеха»), модель `toy-science-industry-model.md` §6, TASK-0002/0003.

## Краткий вывод
- [Предл.] Генератор (прототип `lab/proto/` или C# Lab) пишет в один каталог 4 файла: `runs.csv`, `yearly.csv`, `countries.csv`, `milestones.csv`. UTF-8, разделитель `,`, первая строка — заголовок, порядок строк и лишние колонки не важны.
- Числа — десятичные с точкой (`long` fixed-point выводится как raw/10^6). Пустое поле — «не достигнуто» (только `m_K`, `m_A`, `m_T`).
- Ярлыков узких мест в CSV нет: их считает только анализ (EXP-0001 «Ревью» п.5).
- Запуск: `python3 lab/analysis/exp0001.py DIR [--config thresholds.json] [--out report.md]`; `--dump-config` печатает все пороги по умолчанию. Конфиг перекрывает только указанные ключи, неизвестный ключ — ошибка.

## Правила расчёта, которые задаёт скрипт
- Группа = (series, model, ν, β, γ); каждый критерий считается в каждой группе. Ранги — по Power с разбором ничьих по индексу страны.
- п.2: смена лидера засчитывается, если новый argmax держится `hysteresis_years` лет подряд или опережает прежнего лидера на > `hysteresis_margin`. Итоговый лидер для доли «leader_1950 ≠ leader_1910» — сырой argmax 1950 (`final_leader: raw`).
- п.3: вехи с m_K = 0 или m_T = 0 — левая цензура, исключаются; пустой m_T — правая, лаг = 492 − m_K; m_T < m_K — импорт, исключается. Доля левой цензуры — отдельно для A1 и остальных, без неоткрытых вех в знаменателе; флаг «на грани», если любая > 30%. Bootstrap — по прогонам группы.
- п.4: признаки A1 — `mult_*`, E_1930/E_1910, B_1950, сумма `eng_binding_months`, среднее `shock`; KS двухвыборочный, p асимптотический.
- п.5: NOISE = max(0, ln-разрыв − сумма компонент со знаком); затем отрицательные компоненты обнуляются; доля двух главных — от полного ln-разрыва (обрезается до 1). Случай объяснён, если доля двух главных ≥ `top2_share_explained` и NOISE < `noise_unexplained_share`·разрыв (0,3; DECISIONS_LOG #17, заменяет прежнее «NOISE в двух главных — необъяснён»). Y_year = 0 обрабатывается через safe_ln (eps 1e-12). CI доли — кластерный bootstrap по seeds.
- п.6: контроль ищется в той же группе (series, ν, β, γ), иначе в `main` с тем же ν. Нет контроля — N/A.
- Решение: точка сетки проходит, если проходят все п.1–7 (N/A = не прошёл). Итог по ν: `incomplete` (нет main/сетки или любой критерий N/A из-за отсутствия данных, например нет контроля B/C), `refutes` (п.1 или 6 провален в main или проходит < 5 точек), `supports` (main проходит и ≥ 5 точек), `inconclusive` (большинство или main — только с «на грани»), иначе `rework`. Общий `supports` — только при обоих ν. Триггер D печатается флагом.
