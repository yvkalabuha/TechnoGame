# EXP-0003 — Цель оснастки A39: варианты V0–V4 против эталона VINF (T6e)

## Вопрос

Дизайн, критерии K1–K5, правило выбора — `docs/simulation/exp-t6e-tooling-target.md` и спека v0.19 r1 §11 «EXP T6e» (объявлены до прогона, ревью critic учтено). Выбор варианта — владелец.

## Начальные условия и параметры
Сборка после TASK-0029 (b203293): данные R-H-MS′, переключатель `TOOLING_TARGET` ∈ {V0, V1, V2, V3, V3b, V4, VINF}; seeds 1…20 main + 3 факторные ячейки × seeds 1…10; 350 прогонов по 384 мес.

## Метрики

Замена: процессы с `cell(p)` = ячейка (`d*(p) = d`), `eligible`, `r_d − H > 0`; метка месяца — `TOOLING`, если у кого-то из них `limiter = TOOLING`, иначе `EFFORT`, если есть `EFFORT`, иначе «прочее». Смены `EFFORT ↔ TOOLING` — переходы между соседними месяцами, оба в пуле, на 100 месяцев пула.
- **О7. M1(а):** `Σ E_p > 0` по процессам с `d*(p) = d` (`d*` — снимок месяца t, `E` — `proc_E` после шага t).

Статистики C1 — суммарное `Δln unit_cost` за удвоение накопленного выпуска линии (ключ линии — актор, слот, поколение; `Q1` — выпуск первого месяца, удвоение k — первый месяц с накопленным ≥ 2^k·Q1): (а) освоение — по линии max по удвоениям 1–3, медиана по линиям, коридор [0; ln(1/0,6) = 0,511]; (б) зрелая линия — удвоения, в месяц начала которых min `yield` по `prc_set` ≥ 0,9, медиана, коридор [ln(1/0,85) = 0,163; ln(1/0,7) = 0,357]; пусто → `d` = 1.
