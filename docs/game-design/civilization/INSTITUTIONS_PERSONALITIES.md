## 3. Как институты меняют скорость и направление (косвенное управление)

[Предл.] Механика в три шага, без микроменеджмента:

1. **Деньги → усилия.** Доля бюджета `Research` (уже в срезе) делится по институтам страны пропорционально «приоритету» (`обычный = 1`, `приоритет = 1,5`, `сокращён = 0,5` [Предл.]). Институт превращает деньги в усилия только до потолка `tier` (выпуклая отдача: сверх потолка деньги не ускоряют). Следствие: «залить деньгами» не работает, нужна ступень — это время и проект.
2. **Усилия → узлы знаний.** Скорость узла дисциплины `d`: `v(a, node) = v_base(a, node) · m_total(a, d, t)`, где `m_total` — множитель, ограниченный коридором ±15 % (раздел 6). `m_total = m_tier · m_spec(d) · m_leader`, затем клип в коридор.
3. **Направление.** `spec` не меняет суммарную скорость страны, а перераспределяет её: совпавшие дисциплины идут быстрее (до +15 %), остальные медленнее (до −10 %) [Предл.]. Игрок не «ускоряет науку», а выбирает, чем страна сильна. Это то, что делает выбор профиля интересным.

[Предл.] Различие с производством: освоение производства (Hcap #438, «Обучение персонала: процесс X») — отдельный слой. Институты влияют на **знания и проектирование**, не на кривую освоения производства. Это исключает двойной счёт с `production-mastery.md`; проверка — инвариант в разделе 9.

## 6. Влияние на скорость исследований (#460)

### 6.1 Постановка

[Предл.] Скорость исследований страны `a` в год `t` = базовая скорость (уже откалиброванная по историческим годам открытий) × `m_dev(a,t)`. Два принципа:

1. **Нейтральность к истории.** Исторический ход (реальные руководители, ступени из данных сценария) даёт `m ≈ 1` по определению: калибровка годов открытий уже включает эту «историю институтов». Институты вносят **отклонение** `m_dev` только от решений игрока и от ветвления (`branched`). Тогда текущая калибровка годов открытий не ломается: при `m_dev = 1` результат не меняется бит-в-бит (инвариант раздела 9).
2. **Узкий коридор.** Любые источники вместе (`tier`, `spec`, руководитель) дают не больше ±15 % от траектории [Предл., D15 RR-0012]. Шире — доминирующая стратегия «купить науку» и поломка калибровки #24 (смены лидера 30–40 % за 30 лет).

Только для сгенерированных свободно; для реальных — только при документированном событии (Paperclip 1945 и последующие, перевозка специалистов в СССР 1946: [Предп.], даты проверить, RR-0013). - **Защита.** Контрразведка (RR-0017) снижает рост чужой сети; институт читает `ci_eff` страны как данные, собственной шкалы не заводит.
- [Предл.] Хуки в срезе **не реализуются**: в срезе поле `visibility` и `defect` отсутствуют, они описаны, чтобы схема данных не пришлось ломать (и чтобы одно из двух — `Personality.country` не константа).

## 8. Минимальная версия для среза реактивной авиации (самое малое, что интересно)

[Предл.] Интересно, когда у игрока есть выбор с видимым отложенным результатом и с ценой. Минимум:

1. **Институтов 2 на страну** (10 всего): «НИИ» (исследовательский, влияет на скорость знаний) и «КБ» (проектный, ёмкость 1, #229; влияет на `D0` через `bureau_exp`). Ступени 1–3, старт — из данных (GBR и FRA чуть ниже USA и SUN; не равны).
2. **Профиль НИИ из 3 пресетов:** «планер / двигатель / материалы». Это даёт прямой выбор для сюжета «ТРД есть, сплава нет» (FRA) и «сплав есть, а двигатель догонять» (GBR).
3. **Один `tier_up` за партию на страну**: цена и срок видны, ждать годы. Ступень 3 недостижима раньше ~1960 [Предл.], чтобы в начале не выиграть деньгами.
4. **Руководители:** по 1 на институт (10 слотов); пул — ≈ 3–5 личностей на актора (реальные, где данные есть, иначе сгенерированные); вакансии бывают ≈ 3–6 раз за партию на игрока. Кандидаты ≤ 3, не доминирующие.
5. **События личностей:** уход на пенсию, смерть, вакансия. Без `defect`.
6. **Не входит:** конкурс КБ (#215), слияния, `school_H`, `support`, накладные расходы, отпочкование, личности 2-го эшелона, `build_complex`.

[Предл.] Почему это достаточно: решений ≈ 12–20 за партию, каждое объяснимо одной причиной по `why_not`, итог партии получает 4-ю причину «институты» рядом с тремя из M-play §6.

## 9. Что нужно от Core (списком, не код)

Поля и системы; названия [Предл.], имена согласует systems-architect. Ничего из этого не реализуется до вердикта M-play (#459).

**Поля данных**

- Сценарий: `research_speed_mult[actor]` и `research_speed_ramp[actor]` (подставная величина 6.4, можно добавить раньше остального).

**Системы**

## 10. Числа [Предл.] и как их проверять в Lab

| Параметр | Значение | Проверка |
|---|---|---|
| Коридор скорости | ±15 % всех источников | R-1…R-5 (6.5) |
| Бонус/штраф `spec` | +15 % / −10 % | суммарная скорость страны не растёт от профиля (≤ +2 %), проверка «профиль не бесплатен» |
| Приоритет института | 1,5 / 1,0 / 0,5 | H-INST-2: «всё в один» ≤ N средних + X % |
| `T_on` вход руководителя | 6–12 мес. | потери ≥ бонус нового лидера (RR-0012 §5b) |
| Пенсия | 65–72 лет | распределение лет службы, доля вакансий 3–6 за партию (диапазон решений) |
| Цена и срок `tier_up` | выпуклая, годы | H-PROJ-1: «все ступени подряд» не лучше «по потребности» |
| Коридор смен лидера | 30–40 % за 30 лет (#24) | с институтами и без: разность внутри ДИ (H-PERS-1a) |

Инварианты: `m_dev = 1` → результат бит-в-бит как без институтов; `Σspec = 1`; суммарная скорость узла ≤ коридор; не меняет мастерство производства (`Hcap`); один человек — один слот; кандидаты — антицепь; нет отрицательного звена `why_not` на `real = true`; одинаковый seed — одинаковый результат (L1/L2).

## 11. Что показывает UI (один экран словами)

[Предл.] Экран «Институты страны». Открывается по клавише и по автопаузе (вакансия, ступень готова). Один взгляд — один ответ: «где моя наука сильна и что мешает».

- **Слева** список из 2 карточек на институт страны: название, тип, ступень (3 точки, закрашены), профиль (3 пресета, подсвечен текущий), руководитель (портрет или значок, имя, три слова черт: «администратор», «осторожный», «двигатели»), статус одним словом («идёт», «простой», «вакансия»).
- **В центре** выбранный институт: полоса «скорость исследований: ×1,06 (+6 %)» с разбивкой на 3 строки «ступень / профиль / руководитель» (не больше трёх звеньев), ниже «что делает сейчас» (узел или проект, срок) и «почему не быстрее» (`why_not`: «потолок ступени», «руководитель вне профиля»).
- **Справа** рычаги: «профиль» (3 кнопки с ценой смены), «повысить ступень» (цена, срок, что даст), «руководитель» (при нажатии три карточки кандидатов с ценой и провалом на вхождение; ни у кого не доминирующий набор).
- **Внизу** лента «до → после» последних решений (через 6 и 12 месяцев) и сравнение со страной-лидером одной строкой («у лидера ×1,10»).
- Правила: все названия слов вместо чисел там, где возможно (STATE_WORDS); числа вторым планом; для реальных людей нет негативных текстов; цена показывается до решения; отказ всегда с причиной.
