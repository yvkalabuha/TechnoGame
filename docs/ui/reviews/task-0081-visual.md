**ПРИНЯТО С УСЛОВИЯМИ (не блокирую).** Палитра C, плашки тревог, иконки времени, легенда, камера и тег чужой державы выполнены и читаются. Четыре правки в v0.5b (ниже, раздел «Сейчас»), остальное в v0.5c.

## Оценка по пунктам
- **Палитра C [Факт: снимки].** Бумага/тушь/тинты C держатся; атлас стал спокойнее v0.2, ночное затенение тинтов различимо (пары ≥ 8,4). Лайм `tint.3` самый громкий на карте (Ангола) — решение ниже его приглушает. Двухступенчатого моря нет (`sea.deep` не нарисован, в отчёте указано): допустимо, но токен в валидаторе проверяется зря — [Предл.] либо нарисовать, либо убрать из контекстов.
- **Меню / Новая игра / Настройки.** Структура верна: список, поиск, карточка с цифрами сценария, сид, «Начать» тушью; кромка пунктов цвета росписи даёт ритм. Настройки: вкладки, сегменты, DLSS серый с причиной, подпись об апскейле только на глобусе — честно. Замечания: (1) под диалогами нет затемнения, панель державы и сигнальное поле просвечивают и обрезаются краем окна (в `settings_video.png` строка «ЧУЖАЯ ДЕРЖАВА» перечёркнута краем диалога) — шум; (2) `main_menu.png` снят поверх работающей игры (дата, панель СССР): холодный старт должен показывать чистый глобус без HUD, иначе заглавный экран не проверен; (3) «Продолжить/Загрузить/Сохранить» неактивные — подписи причин приемлемы.
- **Иконки времени.** Три кнопки с общими вертикалями, заливка паузы, штриховка на краю ступени, три засечки + слово темпа: читается без цвета. Принято. Ступеней три вместо пяти — следствие симуляции, не дефект.
- **Плашки тревог #326.** ▲ СПЛАВ с ореолом `sheet`, контуром тушью и тёмным текстом читается и на дне, и на ночной стороне (`alert_tint5_night.png`). Принято. Замечание: плашка без хвостика/привязки к границе — на плотной карте непонятно, чья она; для v0.5c вывести её на центроид с выноской.
- **Легенда.** Цвета из токенов, коды FND…APP, Esc закрывает. Замечания: перекрывает нижне-левую часть диска планисферы (узлы и ось «Металлы» под ней); четыре типа FND/PRN/ENG/CMP нарисованы одинаковым кругом — отличаются только текстом, т.е. глиф не несёт информации (форма — только у PRC и APP). Пять дисциплин вместо шести — честно, электроники в данных нет.
- **Камера.** Ошибка центра 0,0–0,1 px при сдвиге 270 px, зум неизменен; Франция встала в середину свободной области. Принято на 1600×900; 1280 и 1920 не сняты.
- **Тег чужой державы.** Образец тинта, название, «ЧУЖАЯ ДЕРЖАВА · только просмотр», кнопка «К своей державе» — работает. Слабее, чем нужно: подпись `ink-3` мелкая, весь блок на `hover`. [Предл. v0.5c] цветная кромка в тинт державы на левой стороне панели.

## Решения по валидатору
Принцип: порог откалибровать, если он [Предп.] из спеки и снимки показывают читаемость; токен менять, если нарушается правило дизайн-системы (§17.2.3).

1. **`warn` на затенённой `land-none`** (ΔL 12,5 < 15; ореол 6,1 < 8) — **калибровать порог.** Прямой контакт ΔE 25,6 ≥ 20, CVD 21,4 ≥ 14; провал только по ΔL. Край плашки держит обводка тушью, а не заливка; `tint.5` при ΔL 9 на снимке читается. Новый порог `warn` ΔL* **≥ 12**. Ореол, совпадающий с фоном (`land-none` — бумага), не провал, если прямой контакт проходит. Токен `warn #D9860F` не менять: тёмнее — уходит в коричневый и теряет сигнальность (#326 уже согласован).
2. **Хрома плашек** (`warn` 0,150, `command` 0,162 < 0,17) — **калибровать порог.** 0,17 из спеки [Предп.], без обоснования; оранжевый L* ≈ 63 и синий L* ≈ 34 физически не дают 0,17 без неона. Новые пороги OKLCH C: `alarm` **≥ 0,17**, `command` **≥ 0,15**, `warn` **≥ 0,145** (запас на округление). Токены `command #2347A8`, `warn #D9860F` без изменений.
3. **`tint.3` хрома 0,135 > 0,13** — **менять токен.** Правило §17.2.3 осознанное (декор-заливки спокойные), лайм самый громкий. `B8E07C` → **`BBDE86`** (смесь 12% с серым равной яркости; ожидаемая хрома ≈ 0,12). Запас по парам огромный (минимум tint.3 vs tint.5 — 16,7 при пороге 8; alarm на tint.3 ΔE 58,7), риска для других проверок нет. [Предп.] значение посчитано вручную: разработчик прогоняет валидатор; если C > 0,13 — снижать, пока не пройдёт, шаг 2% к серому.
