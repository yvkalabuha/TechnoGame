## 3. Бонус института и опыт
[Предл., #493]
- Узел цели `r` области `d` закреплён за институтом `i`: `m_inst = 1 + 0,05·c(i,d) + e_lead`, `c ∈ 0..4`, `e_lead ∈ [−0,04; +0,04]` (#461, IP2 6.2). Диапазон `m`: **0,96…1,24**. Узлы вне приоритета и узлы пути цели (кроме самой цели): `m = 1` (критика adv. п. 7: игрок видит одно число; бонус только на целевой узел).
- Нормировки `c_ref` **нет**: калибровка годов открытий #457/#458 пересчитывается один раз по прогону с институтами (#493, #496; Lab-пилот P-1).
- **Потолки (#462).** ±15 % относится к множителю руководителя в IP2; бонус института +20 % — отдельный канал, как и рывок денег ×1,5. Максимальная скорость приоритетного узла против неприоритетного: 1,5 × 1,24 = **1,86**. Предел по годам Y = 3 (IP2 6.3) ограничивает **только `m`**; влияние рывка денег проверяется P-3/P-6 (критика п. 8).
- **Опыт и рост (v0).** Опыт `exp(i,d)` растёт на 1 за каждый завершённый **целевой** узел области `d` у института (в том числе непрофильного, #488). Пороги пропорциональны числу узлов области `N_d` (критика п. 6): уровень L при `exp ≥ ceil(q_L·N_d)`, `q = 0,08; 0,20; 0,35; 0,50` для L = 1..4. Узлов: aero 3/8/13/19, prop 3/6/10/14, metal 2/3/6/8, chem 2/3/5/7, mech 1/2/3/3 [Предп.]. Стартовый `exp` = порог текущего уровня. **Забывания и проекта «углубить область» в v0 нет** (критика п. 9, advocate п. 6; частично сужает #192, возвращается после Lab).
- Узел непрофильного института без бонуса даёт больше, чем у неприоритетного (рывок остаётся), поэтому «строить свой институт под область» окупается через бонус, а не штраф.

## 4. Назначение приоритетного узла
1. В дереве клик по узлу → «Назначить институту» → список институтов страны: имя, иконки областей с уровнями, бонус для этого узла («+10 %» или «без бонуса»), занят или свободен.
2. Назначить можно любой институт (#488); без уровня в области бонуса нет, опыт в области растёт (разд. 3).
3. Один институт — один узел. Переназначение занятого слота: прогресс узла сохраняется, **ограничение** — не чаще раза в 12 месяцев на слот (это правило против микроменеджмента, серая кнопка называет причину; не «отсутствие штрафа», а явный лимит).
4. Цель за непройденными предпосылками: узлы её пути во фронте входят в группу и получают деньги первыми (разд. 5); слотов не занимают, бонус института на них не действует.
5. Узел завершён: слот свободен, автопауза «Институт N свободен» не чаще раза в год на страну.
6. Число слотов = число институтов (#485).

## 5. Деньги первым (численно)
Обозначения кода (`KnowledgeSystem`: `ProgressRate`, `ComputeFull`): `S` = ResearchBudget (с эффективной мощностью, разд. 8); `w_r = Priority·J` для узлов фронта; `wsum = Σw_r`; сейчас `alloc_r = S·(w_r/wsum)`, `Δprog = alloc_r/CEff_r`.

**Новое.** Группы цели `G_k` (цель, если во фронте, и её путь во фронте; узел, уже занятый другой группой, остаётся в первой по порядку списка). `W = Σ_k W_k` — суммарный вес всех групп. **Общий множитель**
`κ_eff = max(1; min(κ; (1−ρ)·wsum/W))`, κ = 1,5 (#487), ρ = 0,25 (доля, которую остальные не отдают) [Предп.].
- группа: `alloc_r = κ_eff·S·w_r/wsum`; остальной фронт: `alloc_r = (S − κ_eff·S·W/wsum)·w_r/(wsum − W)`;
- скорость целевого узла: `Δprog = alloc_r·m_inst/CEff_r`; путь цели и прочие: `m = 1`.
- Свойства [Предл.]: (1) `Σ alloc = S`; остаток остальным `≥ min(ρ·S; (1 − W/wsum)·S)`: ρ = 25 % гарантирован, пока `W ≤ (1−ρ)·wsum`; при больших W `κ_eff = 1` и остаток равен обычной доле неприоритетных узлов (K = 8 из 10: **20 %**, не 25 %; критика economy-analyst); (2) `κ_eff ≥ 1`: узел группы никогда не медленнее, чем без приоритета (тест P-8); (3) κ_eff общий, порядок слотов не влияет; (4) **K = 0 → старый код без изменений** (бит-в-бит, проверка по хешам P-1; «κ=1, m=1» через новую формулу НЕ утверждаем: округление Fx6 иначе, критика п. 7, advocate п. 2); (5) остаток: при `wsum = W` (весь фронт — приоритет) `κ_eff = 1` и остатка нет; если фронт пуст, остаётся старое правило ядра (§3.4 спецификации) (критика п. 11, advocate п. 10).
- Пример: S=100, 10 равных узлов. K=3: κ_eff = 1,5; приоритетные по 15, остальные 7 узлов делят 55 → **7,86** (−21 %); целевой узел уровня 3: скорость 15·1,15/10 = **×1,73**. K=6 (USA): κ_eff = 1,25, приоритетные по 12,5, остальные по 6,25 (−37,5 %); прежний вариант без ρ давал 2,5 (−75 %). K=8: κ_eff = 1, рывка нет, остальным остаётся их обычные 20 % (свойство ρ = 25 % здесь не действует; тест P-2 проверяет формулу с min).

## 8. Новые институты (#491, #494, #495)
[Предл.; цифры Предп., economy-analyst; rev 4 по O-059].
- **Кандидаты страны** (данные): исторические, основанные после 1945, с реальным годом (ONERA 1946, НИИ‑88 1946, DARPA 1958; NASA = переименование NACA без нового слота; остальные [Не подтв.], разд. 1.1) и типовые по области (одна область, старт 1–2). Пример ONERA (Σ = 4): +3,2 % мощности, содержание 1,6 %, чистый выигрыш ≈ +1,6 % `S`/год (rev 3: +3,4 % — завышено, содержание было почти нулевым). - **Окно (O-059).** Стройку нельзя **начать** раньше `ref_year − 10` (серая кнопка: «Окно откроется в {год}»). Для типовых кандидатов `ref_year` — ближайший исторический аналог области в данных.
- **Малые страны (O-059).** Сумма уровней одного проекта ≤ 3 (SWE; FRA и GBR по полю `small_country` в данных страны, критерий — доля `budget_index` от USA ≤ 0,1 [Предп.], решает economy-analyst); крупные страны ограничены только деньгами и кадрами. Большой институт малой страны достигается несколькими проектами по очереди, каждый платит содержание.
- **Цена стройки.** Базовая: 1,5 % `Research` в год за уровень Σ, срок `T = 2 + 0,5·Σ` лет (ONERA: 6 %/год, 4 года, итого ≈ 24 % годового бюджета). **Зависимость от года:** множитель `1 + 0,02·y²`, `y` = лет до `ref_year`, `y ∈ [0; 10]` (окно); потолок множителя убран (при окне максимум ×3; если окно изменят, потолок 10, не 3: иначе ранний путь выигрывает, проверка economy-analyst разд. 4); открытие в срок = ×1.
- **Окупаемость:** ONERA в срок ≈ 24 % / 1,6 % ≈ 15 лет после открытия, около 19 лет с начала [расчёт по формулам rev 4]. При раннем начале (y=10 → ×3) ≈ 45 лет: раннее строительство невыгодно. Главный выигрыш института — слот и год открытия узлов, а не деньги; P-7 проверяет это на деле.
- **Платёж.** Проектов можно вести несколько, лимит — деньги. Источник: `Research` (уменьшает `S` **всем** узлам пропорционально, до распределения разд. 5) или резерв (#475, теряет ≈ 10 % в год, `PLAYER_LEVERS_WAVE1.md` §A2); игрок выбирает. Не хватает денег — срок растягивается пропорционально, без штрафа. Нужны свободные кадры (`reserve_workforce`), иначе серая кнопка «нет кадров».
- **Карточка стройки:** институт и исторический год; стоимость в год ($ 1990, #476) и срок; множитель за раннее открытие; источник оплаты; области и уровни при открытии; что даёт («+1 слот, мощность +4 %, содержание 0,6 % в год»); что изменится («остальным направлениям −6 % денег на время стройки»).
