# ADR-0011 — Представление карты

## Решение (предложение)
- Источник истины — векторные полигоны провинций поверх Natural Earth.
- Инструмент-компилятор строит граф провинций: соседство, площадь, центроид; проливы и каналы — отдельный ручной список.
- Провинции имеют стабильные строковые ID.
- Растровые карты для рендера генерируются из полигонов позже.
- Для M0 нужен только граф.

## Открыто
Масштаб (число провинций) — вопрос PHASE F.
