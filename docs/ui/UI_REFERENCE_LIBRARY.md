# UI REFERENCE LIBRARY — библиотека референсов

**Статус:** v0.2 — к предложению `UI_ART_DIRECTION.md` v0.2 (добавлен §4) · **Автор:** ui-art-director · **Дата доступа ко всем ссылкам:** 2026-11-03

В v0.2 колонка «Напр.» в §1–§3 по-прежнему относится к направлениям раунда 1 (I, II, III). Направления раунда 2 (A, B, C) указаны в §4.

Правило: референс — источник принципа, а не образец внешнего вида. Ассеты, раскладки и фирменный стиль чужих игр не копируются (бриф §2.1, ADR-0009). Наблюдения об интерфейсах игр — мои оценки [Предп.], если не указано иное. Колонка «Напр.» — для какого направления референс важнее всего (I атлас, II мнемощит, III карта и стол).

## Краткий вывод
- Самые полезные референсы — неигровые: картография (Bertin, Imhof, атласное раскрашивание), промышленные HMI (ISA-101), чертёжная нотация (штамп, выноска, cutaway), историческая инфографика (Minard, Priestley, Isotype, Du Bois).
- Из игр берём решения задач (потоки, абстракция карты, сигнализация), но не облик. Главный антиреференс — «стандартная» раскладка grand strategy: полоса ресурсов сверху, плашки по краям, одинаковые окна.
