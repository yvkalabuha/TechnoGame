# Gate: парк без замены — адвокат альтернатив (2026-11-19)

Артефакт: `docs/game-design/notes/fleet-without-replacement.md`. Отчёт агента advocate, сохранён Orchestrator (у агента нет записи).

## Краткий вывод
- Основное правило верное: парк держится до замены; замена — 50 машин нового поколения в строю, один к одному.
- Слабое место: старение входит только в последний член ключа места `P`, поэтому слова решения #431 «место падает постепенно» не выполняются, и у игрока нет решения в пустые десятилетия.
- Главная альтернатива: сильно постаревший парк считается в месте на одно поколение ниже. Следом — модернизация.

## Замечания
| Важность | Альтернатива | Позиция | Когда |
|---|---|---|---|
| высокая | Старение понижает поколение в ключе места: поколение считается, только если не меньше 50 единиц выше пола ценности. Игрок видит срок: «через 2 года ваш G3 будет считаться G2». Цена 1–2 дня. Дефект записки: пол ценности 50 %, а условие варианта 1(б) — «ниже 50 %», оно не сработает никогда; нужно условие «на полу» (10 лет сверх срока) | принять | сейчас |
| высокая | Модернизация: заплатить, чтобы вернуть ценность когорты. Единственное решение игрока там, где 91–100 % месяцев пусты. Без предыдущего пункта бессмысленна. Новая механика: gate, экран, правило ИИ; добавляет объём M-play | принять | следом, отдельным gate |
| средняя | Показатель «состояние парка» — как вид в карточке («до понижения поколения N лет»), не как отдельная цифра без последствий | принять как вид | сейчас |
| средняя | Содержание растёт у старых машин — только после замера доли оплаты в прогоне FLEET_KEEP; если вводить, то для когорт старше 25 лет | отложить | после замера |
| низкая | Потери единиц; жёсткий предел 45 лет; замена по идущей серии | не принимать | — |
| низкая | В записке два наклона старения (50 % «на 25-м году» и на 10-м по формуле); новый выпуск того же поколения не выводит перестарков — добавить в меру разбивку по поколениям | исправить | сейчас |
