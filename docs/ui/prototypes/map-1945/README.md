# Карта Европы на 1945-10-01 (отладочный рендер T2)

`europe-1945-10-01.png` строится командой `MapBuilder build --render` из `tools/map` (TASK-0075). Это проверка данных, а не дизайн клиента.

- **Заливка** — цвет `owner` провинции. **Штриховка** — цвет `controller`, если он отличается от `owner` (зоны Германии и Австрии, Польша на востоке Германии, Кёнигсберг, Порккала, Додеканес).
- Совместные политии (`ALLIED_BERLIN`, `ALLIED_VIENNA`) красятся первым членом, второй идёт полосами.
- **Границы**: толстая тёмная линия — смена `owner` или берег; тонкая — граница провинции.
- Данные таблицы владения — черновик разработчика, их проверяет T4 (research-scientist) и critic.
- Секторы Берлина и Вены на рендере не разрезаны (нет PD/CC0 источника линий): оба города одна провинция с совместным `controller`.

Цвета: серый — DEU (под оккупацией), красно-кирпичный — SUN; остальные политии получают цвет по порядку id (`Render.Palette`).
