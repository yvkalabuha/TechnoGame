## 0. Предрегистрация (до прогонов)

### 0.1. Какое решение меняет исход
Какое правило целей институтов ИИ (`CURRENT` — самый весомый узел фронта, `PATH`, `PATH2`, `MIX1`; определения — `ai-institute-goals.md` §2) и какая настройка рынка лицензий (`M0` — как в сборке; `M1` — проходной набор TASK-0179: прыжок поколения ≤ 1, `AiPriceK` 1,2, ИИ покупает только у блока и друзей; `M2` — `M1` + друзья Швеции `SWE–GBR 1945–1990`, `SWE–USA 1960–1990` из `docs/research/notes/sweden-licence-partners.md` как данные песочницы) идут в сборку с рычагами по умолчанию (TASK-0171).

### 0.2. Критерии (на каждую серию против `LEGACY` той же сборки, парные seeds)
1. **Даты (окна C4).** Первая машина любого из пяти акторов поколения G2 / G3 / G4 (`gen_times.csv`, минимум `t_first_unit` по акторам), медиана по seeds; месяц 0 = 1945-09; окна G2 = мес. 16–87, G3 = 100–195, G4 = 256–363 (`lab/analysis/ai_goals_history.py`). Расстояние до окна `d` = 0 внутри окна, иначе до ближайшей границы. Прогон без машины поколения до конца горизонта (2000-12) считается как «никогда» (+∞) при взятии медианы. **Серия проходит**, если для каждого из G2, G3, G4 `d(серия) ≤ d(LEGACY)`.
2. **Структура (§8-d, #554).** Только пункты мест и ключа: места 1960 и 1977 каждого актора совпадают с `LEGACY` не менее чем в 8 из 10 seeds и нигде не отличаются больше чем на 1; медиана `key_G` 1977 каждого актора равна медиане `LEGACY` (те же формулы, что `tm_budget_rules.tolerance_s8`). **Серия проходит**, если нарушений 0. Пункты-даты §8-d (поштучные сдвиги против `LEGACY`) печатаются для сведения и решения не меняют: по #558 мерило дат — окна, а не `LEGACY`.
3. Серия **проходит**, если проходят 1 и 2. Прогоны не `ok` — серия недействительна.

### 0.3. Правило выбора (seeds 1–10)
- Правило целей: среди проходящих — наименьшая сумма `d` по G2+G3+G4; при равенстве — меньше пунктов-дат §8-d. Если не проходит ни одно — рекомендации нет, вопрос владельцу (D1) с числами.
- Рынок: среди проходящих — наименьшая сумма `d`; при равенстве — порядок, заданный заранее: `M2`, затем `M1`, затем `M0` (больше исторических данных о кругах покупателей).
- Пара: выбранное правило + выбранный рынок + резерв, разведка, советник (`LEVERS = ON`, институты κ = 1,5). Пара проходит по тем же критериям 1–2.
- **Отложенные seeds 11–20**: `LEGACY`, выбранная пара, выбранное правило отдельно, выбранный рынок отдельно. Итог — PASS, если пара проходит 1–2 на 11–20; иначе выбор не подтверждён (сообщить, не подбирать заново на 11–20).
