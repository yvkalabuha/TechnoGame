1. [C2, блок] Легенда: «Маршрут к цели» — синяя линия, на карте (tree_legend_sel, оба цвета) маршрут и выноска чёрные. Один знак — два вида. Предложение: нарисовать маршрут цветом из легенды или переделать легенду по реальному штриху.

3. [Приёмка шага 2] Нет кадров SUN (неизвестные узлы F6, фронтир-пунктир F5, корень F4 на карте) и USA с корнем.
