## 3. Разбор
1. **Почему R2 не годится.** Тягу он чинит, но `maint` остаётся долевым. Лёгкий объём рядом всё равно тянет пол забывания вниз: I1 (1 862 сбоя), K3 (258/378), K6 (освоенное сползает на 0,17 уровня). Критик был прав: главная причина F2 — в `maint` (дополнение RR-0006 §1), а не в `drive`.
2. **Почему R0 не годится.** Он разбавляет (I1, I3, K3, K6 −0,40) и не зависит от темпа вообще. Символическая линия в одиночку (`s` = 1) учится и держит фронтир как полная (K2: 100% сбоев). K4 он проходит только потому, что темп ни на что не влияет.
3. **`β` = 0,5 хуже `β` = 1 по всем пунктам.** Корень поднимает `u` малых темпов: символический цех (5% нормы) получает `u` 0,22–0,45. K2a/K2b проваливаются, `maint` рвётся у нуля (I5-непрерывность). Предложение critic «`β` < 1» данными не подтверждается. Из двух его вариантов работает второй: «`v_full` от минимального темпа» (`r_full` < нормы).
4. **Конфликт K2b ↔ K4c в R1 — свойство линейного `u`, а не случайность сетки.** В прогоне время до `g_H` 0,9 ровно ∝ 1/`u` при `u ≥ u_m` (2,50× при `u` = 0,4). Чтобы K4c (`T(5) ≤ 2·T(25)`) выполнялся, нужно `u(5)` ≥ 0,5, то есть `r_full` ≤ 10. Тогда `u(1,25)` ≥ 0,125, а K2b при таком `u` даёт 0,23–0,29: прирост вогнут, норма за 10 лет насыщается. Проба вне сетки [Факт, `--only posthoc`, выбрать нельзя]: `r_full` 10, `u_m` 0,5 — K2 0 сбоев (0,228), K4c 38/189 (ровно 2,0×, округление месяца); `r_full` 8 — K2b 11/189 (0,293), K4c 6/189. Удовлетворить обе части #79 сразу может только выпуклая у нуля форма `u` (порог или `β` > 1). Это новая формула, и по #80 я её не предлагаю без решения владельца.
5. **Что в R1 устойчиво к его параметрам.** I1–I4, K3 и K6 выполняются при всех 12 вариантах (с D-1…D-3). K2a держится при `β` = 1 и `u_m` = 0,5 во всех `r_full`. От `r_full` зависит только компромисс K2b ↔ K4c.
6. **Ограничения.** Стенд одного site без соперника (`catch` = 0), `act` = 1, без слоя изделия. K2–K4 — по 25 парам × окно `α` × 3 `δ_H` (пары повторяются, независимых случаев 25). В K6 при реальной оснастке малые страны теряют линии (D-1) — правило ИИ оснастки для всех ячеек с линиями (аналог A30) — отдельный вопрос.

### 5.1 Определение и сетка (зафиксировано 2026-11-03T12:43:35+00:00, до прогона R1c)
[Предл.] `drive`, `catch`, `maint` — как у R1 (§1.1). Меняется только `u_p`:
```
x_p = min(1, v_p / v_full(p)),   v_full(p) = r_full · labour_p
u_p = x_p · x_p · (3 − 2·x_p)            # smoothstep; Fx6: ((x·x)·(3 − 2·x)), floor на каждом ·
```
Почему smoothstep, а не `x^γ`:
- выпукла у нуля (`u ≈ 3x²`) и плоская у насыщения (`u'(1) = 0`). Получается то, что сказано в #85: символический выпуск ≈ 0, затем быстрый выход на норму. У `x^γ` при `γ > 1` крутизна наибольшая как раз у `x = 1`, поэтому темп чуть ниже `r_full` теряет заметно больше;
- два умножения `Fx6` и вычитание: нет степени и корня, нет таблиц, результат детерминирован и монотонен (`u ∈ [0; 1]`, `u' = 6x(1 − x) ≥ 0`);
- `|u'| ≤ 1,5`: `maint` непрерывен (I5);
- новый параметр формы не нужен: форму задаёт одно число `r_full`, как и у линейного R1.

Сетка (как у R1, `β` нет): `r_full` ∈ {6,25; 8; 10; 12,5} × `u_m` ∈ {0,25; 0,5} — 8 вариантов. Ориентиры (расчёт до прогона) — `u` при темпах 1,25 / 5 / 10: при 6,25 — 0,104 / 0,896 / 1; при 8 — 0,065 / 0,648 / 1; при 10 — 0,043 / 0,500 / 1; при 12,5 — 0,028 / 0,352 / 0,896.
