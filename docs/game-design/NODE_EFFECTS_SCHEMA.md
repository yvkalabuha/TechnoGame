## 4. Поля yaml для mods/core [Предл.]

Новый блок в узле (`nodes.yaml`), необязательный; значения эффектов не дублируются, а ссылаются на данные:

```yaml
effects:
  - {kind: slot_perf, ref: jet_fighter.airframe.af_milled, shows: perf_mult}
  - {kind: alloy_need, ref: jet_fighter.hot_section.hot_sa2_forged}
history_only:            # справка без механики
  - {text_key: node-s8-eng-delta_wing_airframe.fact1}
epic: false
history:
  text_key: node-...-history      # 3-6 предложений, локаль ru/en в data.ftl
  sources:
    - {url: "...", accessed: "2026-11-24", license: PD|CC0|CC-BY, quoted: false}
```

Генератор карточки читает `ref`, берёт число из product_classes, считает разницу с предыдущим рангом слота и формирует строку по §1. Если `ref` не разрешается или группа `any_of`, карточка пишет «общий эффект с узлом X». Проверка в тесте данных: каждый `ref` существует; узел с `kind` без `ref` запрещён. ## 5. История узла

- 3-6 предложений: кто, где, когда, что дало; один факт на предложение; без оценок и без сравнения «лучше чем».
- Каждое утверждение с датой или числом опирается на источник: URL + дата доступа. Минимум один источник на узел, лучше два.
- Цитаты только из PD, CC0, CC BY (ADR-0009); иначе пересказ своими словами. Википедия (CC BY-SA) не цитируется, допустима как ориентир к первичному источнику, не как источник текста. Wikidata CC0.
- Альтернативная история: история описывает реальный прототип; игровую дату открытия она не определяет. Разница годов помечается «в игре возможно иначе».
- Непроверенное: слово «[не подтверждено]» вместо вымысла.

## 6. Пять разобранных узлов

1. **delta_wing_airframe**. Эффекты: `slot_unlock` af_milled (общий с area_ruled), `slot_perf` x1,5 к af_straight (+15 % к стреловидному 1,3: 1,5/1,3), `af_class` 3, `process_unlock` machined_integral_skins (7500 ч), `complexity` +1 тир-очко процесса. Карточка: «Планер цельнофрезерованный: лётные характеристики +15 % к стреловидному; проектирование x1,64 (1,82/1,11); можно взять вместо area_ruled». Справка: Convair F-102 (1953).
2. **turbojet_g2**. `slot_perf` eng_g2 x1,3 (+30 % к G1); `generation` G2 при ранге планера 2+. Справка: без механики никакой.
3. **heat_resistant_alloy** (s5.cmp). `engine_cap`: снимает потолок G1 у горячей секции (hot_nicr_forged `alloy_kg` 290, perf x1,0 против подстановки 0,90, обслуживание x2,5 -> x1). Карточка: «двигатель выше G1, расход сплава 290 кг, обслуживание в 2,5 раза дешевле».
4. **afterburner**. `slot_perf` ab_on x1,15 (+15 %), `process_unlock` afterburner_fabrication (900 ч). Тяга в Н не выводится.
5. **single_crystal blade** (turbine_blade_single_crystal). `slot_perf` hot_sc_sc x1,6 (+10 % к ds_cooled), `alloy_need` 3600 кг (+21 %), процесс single_crystal_casting (5000 ч, тир 5+: действует программа освоения). Пометка `epic: true`.

Расчёт «+15 %» взят делением множителей соседних рангов; формула показа одна на все слоты.
