# HYP-0005 — Open race: the 1945-1975 leadership outcome is neither predetermined nor random

> Пре-регистрация (черновик game-designer для gate 3.1 MS-M1, `development/milestones/MS-M1-economy-provinces-open-race.md`). Всё, что не помечено [Факт], — [Предл.] до gate. Числа в полосах и порогах, помеченные [Предл.], фиксируются на gate и после него не меняются. Основания: DECISIONS_LOG #323, #329, #330, #332, #334, #335, #339–#344; gate `docs/reviews/ms-m1-draft-{critic,advocate,deepseek}.md`; урок HYP-0002 [Факт: `docs/reviews/exp0002-result-critic.md`, `docs/simulation/exp0002-result.md`].

## Гипотеза
На мире с экономикой E1 (E1a, E1b, слой H/M), провинциями и стартом 1945-10-01, возмущённым по seed в пределах неопределённости источников (#329), исход гонки за 360 месяцев **не предрешён и не случаен**: лидер `t1` не определяется лидером `t0`, но и не меняется как попало (мало смен за прогон, разнообразие лидеров ограничено). Это свойство **распределения исходов по seeds**, а не желание, чтобы победил заданный актор; реальные траектории в метрику не входят (RISK-0011). Сценарные события — только по дате и структурным условиям, без RNG (#328, #340–#342).

## Причина появления
HYP-0002 опровергнута: `chg` = 0,052 при ожидании 0,30–0,40; P1 и P3 провалились зависимо (пол «один лидер в ~95% seeds»), мощность считалась при `chg_full` ≈ 0,35 [Факт: exp0002-result]. Здесь всё, что тогда выбиралось после взгляда на данные (метрика лидера, зависимость P1/P2, гистерезис, источник разброса, правило при промахе), фиксируется до прогонов.

## Предполагаемый эффект
Либо `supports`: открытая гонка проверена и модель лидерства принимается как основа M2 (война, торговля). Либо `refutes`: владелец получает данные о том, что именно замыкает гонку (старт, события, ИИ), и решает по #335 / #43.

## Объект гонки
- **Участники `G(t)`:** акторы, существующие в `t` и имеющие ≥ 5 регионов в `t` (регион принадлежит актору, если `owner` ≥ 50% его провинций по населению; совместная полития — её члены с долями по провинциям). Государство, созданное событием (ФРГ, Индия, Индонезия), входит в `G` с первого месяца, когда выполнено условие, и участвует в рангах с этого месяца. Кандидат в лидеры `t1` — любой актор из `G(t1)`. «Великие державы» — 8 акторов с наибольшим промышленным выпуском на `t0`; список печатается в манифесте.
- **Оси (#330):** A — доля мирового промышленного выпуска E1 актора (скользящая сумма за 12 мес.); B — `tech_lead` (#44, лексикографический порядок). Ранги внутри `G(t)`; равные значения оси получают средний ранг (дробный).
- **Позиция** `R(a,t) = rankA + rankB` (меньше — лучше). **Лидер месяца** — минимум `R`. **Ничья:** меньший средний `R` за последние 12 мес.; затем меньший `rankB`; затем меньший id актора.
- **Гистерезис (12 мес.):** «лидер записи» `L(t)`. `L(t0)` — лидер месяца `t0`. Претендент становится лидером записи, только если был лидером месяца ≥ 12 месяцев подряд; дата смены — начало этого окна. Окно, не закрытое к `t1`, смены не создаёт. Отдельно печатается лидер только по `tech_lead` (B), по тому же правилу.
- Горизонт: `t0` = 1945-10, `t1` = `t0` + 360 мес.; +240 мес. — диагностика.

**Связь P1 и P2 (урок критика/адвоката):** при общем `L(t0)` в полных seeds `Neff ≤ 1/(1−chg30)²` (при `chg30` = 0,20 ≤ 1,56 < 1,6). Поэтому P2 считается среди seeds со сменой и не зависит от частоты смены. Печатается проверка: доля seeds с общим `L(t0)` (при #329 лидер на `t0` может различаться).

**Когда P2 не оценивается (< 30 seeds со сменой):** если P1 провален снизу, используется `mob5` по тем же правилам. Если P1 в серой зоне, а смен < 30 — `inconclusive`, пока `n` не достигнет 600.

### S3 (определение)
- Тестовый актор `a*` = актор с 3-м `R` на `t0` в данном seed (ничья — по id). Только он получает один из 4 пресетов бюджета: `industry`, `science`, `balanced`, `knowledge_import` (2.7); остальные — базовый ИИ. Остальные условия — те же seeds, те же потоки RNG (парный дизайн).
- `q_k = P(L(t1) = a*)` по пресету `k` (Wilson); `Δ_{jk}` — парная разность (McNemar-CI).
- **Доминирование:** есть пресет `j`, для которого `q_j − q_k ≥ 0,15` для всех `k ≠ j` и CI всех `Δ_{jk}` > 0. Результат печатается; порога исхода нет. Диагностика «нет дегенеративной стратегии» (RISK-0010).
- Оговорка: если `max q_k < 0,15`, `dom` недостижим по построению (пол) — это печатается как «S3 не информативна», а не «доминирования нет».

## Правило исхода (#332, #334)
Оценки по полному набору seeds серии `full` на последнем шаге плана.
- `supports`: P1 pass, P2 pass (по `Neff_c` или, при < 30 сменах, по `mob5`), P3 pass.
- `refutes`: (P1 fail **и** P2 fail) **или** P3 fail.
- `inconclusive`: остальное (в том числе серая зона у полос, P2 не оценён при `n` = 600).
- `invalid`: нарушена воспроизводимость (L1/L2 на 23001–23060), `data_hash`/метка таблиц отличаются в любом `run.json`, рабочее дерево «грязное» для данных, нарушена пре-регистрация, провал инвариантов K3/K9 на любом seed.
- **Правило S4 (#334):** `full` проходит, `no_events` вне полос ⇒ исход `supports` с записью «supports only with scripts» (закрывает K7 с оговоркой). `full` не проходит, `no_events` проходит ⇒ запись «скрипты ломают гонку»; исход по `full`.
- **Пол (#335):** если в пилоте после единственной коррекции ≥ 90% seeds имеют одного лидера `t1`, серия не запускается, вопрос возвращается владельцу с данными.
- Вывод всегда формулируется с областью: «E1 + три слоя + базовый ИИ + таблица событий версии X + возмущение старта Y», не как опровержение архитектуры в целом (урок EXP-0002, п. 6).

**Мощность и последовательный план (метод):**
1. Размер выборки задаётся ширинами CI, а не мощностью по гипотетическому эффекту (урок HYP-0002: мощность при `chg` ≈ 0,35 оказалась фикцией). Полуширина Wilson при p = 0,30: n = 300 → ≈ 0,052; n = 600 → ≈ 0,037; на границе полосы это достаточно для различения 0,20 vs 0,15 лишь при n = 600 [Факт: арифметика].
2. Два шага (300, 600); уровень CI по Pocock для двух взглядов: номинал 0,0294 (97,1% двусторонний) на обоих шагах [Предл.]. Расширение до 600, только если на шаге 300 CI P1 или P2 пересекает границу полосы pass или fail; иначе серия закрыта на 300.
3. Мощность считает simulation-engineer **симуляцией**: для гипотетических `chg30` ∈ {0,10; 0,20; 0,35; 0,50; 0,60} и `Neff_c` ∈ {1,3; 2,5; 4,5} по ресэмплингу калибровочного распределения (без печати `chg30`) — вероятность выдать `supports/refutes/inconclusive` при n = 300 и 600. Таблица до заморозки манифеста.
4. McNemar для S1/S5 на n = 300: минимально обнаружимая разность `chg30` между сериями при `b + c` из пилота; печатается как предел чувствительности.
5. Вычислительный бюджет — матрица «серия × n × время одного прогона в 1 поток в дневном режиме» (3.2); сверка с бюджетом Lab до заморозки.

**Контрфакт для K8 (S2):** выборка ≥ 30 смен лидера; для каждой — перезапуск того же seed с нейтрализованной названной причиной; смена исчезла в ≥ 70% [Предл.]. Нет ≥ 30 смен — выборка из всех.

**Чувствительность (урок EXP-0002, п. 5):** для `full` на 20001–20300 — сетка 3 значения × 2 калибруемых параметра экономики (амплитуда возмущения старта ×{0,5; 1; 1,5} и один параметр масштаба, назначаемый при калибровке); печатается диапазон `chg30` и флаг `knife_edge`, если исход меняется по сетке.

**Воспроизводимость (урок EXP-0002, п. 7):** до чтения результата проверить `data_hash` и метку таблиц во **всех** `run.json`; прогон на чистом дереве для `mods/` и `lab/manifests/`; список грязных файлов печатается.

## Допустимая калибровка и её пределы
- Только по микроякорям региона: население, пашня, угольная мощность и подобные (CC0/CC BY, ADR-0009). Исторические лидеры, `chg30`, ранги — не якоря (RISK-0011).
- Пилот пола (3.2a): на 22001–22100 после первой рабочей E1a, с событийным ядром. Печатает: распределение `L(t0)`, разброс стартовых `R`, долю seeds с одним лидером `t1`. Это единственный разрешённый взгляд на `chg30`.
- Если доля одного лидера `t1` ≥ 90%: допустима **одна** коррекция старта, только внутри документированного интервала источника (#329); повторный пилот на тех же seeds; если ≥ 90% сохраняется — серия останавливается, решение владельца (#335). Коррекция вне интервала — решение владельца.
- Запрещено после пилота: смена метрики лидера, гистерезиса, полос, состава `G`, ИИ; подбор параметров по `chg30`/`Neff` на 22001–22100. ИИ и таблица событий заморожены до заморозки манифеста 3.3 (хеши в манифесте).
- Любое отступление — в `meta.deviations` **до** чтения результата.

## Альтернативы
1. **Лидер только по `tech_lead`** (#27): отвергнуто владельцем (#330); печатается отдельно.
2. **Одна метрика Neff на все seeds:** отвергнуто, P1/P2 зависимы; заменено `Neff_c` и `mob5`.
3. **Точечная цель `chg` 0,30–0,40 (#24):** заменено полосами (#323); точка — след ошибки HYP-0002.
4. **Годовые точки вместо гистерезиса:** грубее, смену нельзя датировать; выбран гистерезис 12 мес.
5. **События со случайным окном и разбросом:** отвергнуто (#342); разнообразие — из возмущения старта и науки.
6. **Мощность по эффекту:** заменена шириной CI и симуляцией.

## Риски
- **Пол HYP-0002 повторится** (≥ 90% одного лидера): пилот до серии, #335, одна коррекция.
- **Событийная таблица предрешает лидера** (RISK-0011): S4, S5, абляции по 5 группам, события только по структурным условиям.
- **P1/P2/P3 независимы лишь по построению:** провал P3 при низком `chg30` — механический (урок критика EXP-0002, п. 2); учтено в правиле «P3 fail ⇒ refutes» только вместе с печатью `chg30`; [вопрос gate: нужен ли P3 при `chg30` < 0,15].
- **Подглядывание** (RISK-0021): `chg30` скрыт на калибровочных seeds; точный взгляд — пилот.
- **Артефакты метрики:** мерцание сумм рангов — гистерезис; дискретная ось B — средние ранги и ничья.
- **Широкий Neff за счёт малых стран:** S6.
- **Парный дизайн ломается при общих потоках RNG:** требуется потокового разделения; иначе S1/S5 — непарные, CI шире.
- **Объём вычислений (14 серий × 300–600):** оценка до заморозки (3.2).
- **Расходимость моделей:** вывод относится к конкретной модели и версии таблицы событий (см. правило исхода).

## Критерии успеха
`supports` по правилу исхода: P1 ∈ [0,20; 0,50], P2 ∈ [1,6; 4,0], P3 ≤ 0,10; плюс `knife_edge` = нет, воспроизводимость L1/L2 на 23001–23060. Дополнительно (не исход): K8 — контрфакт ≥ 70%; S6 в пределах порога; S3 без доминирования.
