# Поворот #561/#562: сводка и предложение плана

Orchestrator, 2026-11-25. Источники: `docs/game-design/notes/pivot-561-game-design.md` (game-designer), `docs/simulation/notes/pivot-561-model-impact.md` (simulation-engineer), `docs/ui/specs/pivot-561-tech-map.md` (ui-art-director), отчёт critic (в этом файле, §4).

## Краткий вывод
- [Факт] Сегодня бюджет науки делится между всеми доступными узлами; институты только ускоряют цели. #561 меняет это: прогресс есть только у узла, на котором стоит институт.
- [Предл.] Новый режим знаний «по слотам» рядом со старым (старый — для сравнения). Узел: цена (как сейчас), время T_n (новое, растёт с поколением медленнее цены), направление. Деньги идут потоком цена/время; нехватка замедляет все слоты поровну; излишек — в резерв. Фокус: два платных уровня ×1,25 и ×1,5. Очередь: активный узел + 2. Прогресс снятого узла сохраняется. Узлы-ускорители науки: эффект research_speed, бонусы складываются, потолок.
- [Предл.] Цель партии на ближайшую сборку — «воздушная мощь» (индекс парка, паритет/превосходство/господство); «Давление» (принуждение к блоку или уступке) — отдельный gate.
- [Предл.] Проверки: инварианты, прогон живости, широкие полосы темпа ±8–10 лет; окна C4 и §8-d — справка, не ворота.
- [Предп.] Объём: ядро ≈ 28–31 агент-день, карта знаний стадии 0–1 ≈ 8, «Давление» ≈ 12–16. Короткая версия для партии (ядро слотов + ИИ + карточка и полоса институтов) ≈ 2–3 недели агентов.

## 1. Порядок работ [Предл.]
1. Влить TASK-0171 (2026-11-26): все механики остаются; PATH станет основой ИИ для слотов.
2. Lab-пилот (≈ 2 дня): ширина фронта по годам, срок узла T_n, число слотов; выбрать масштаб T_n и стартовые институты.
3. Ядро «по слотам» + очередь + фокус + research_speed (gate: critic, advocate, DeepSeek) — новый пакет изменений, меняющих эталоны.
4. ИИ: выбор узла на свободный слот (PATH + запасные ступени), фокус, стройка институтов.
5. Карта знаний стадии 0–1: карточка выбора, полоса институтов, цепочка до цели, очередь.
6. Индекс воздушной мощи и цель партии; партия владельца.
7. Потом: ведомость и фильтры (стадия 2), «Давление» (gate), расширение дерева (узлы-ускорители, вычислительная техника).

## 4. Риски (critic)
Микроуправление на полном дереве (20–50 выборов в год) — очередь, цепочка до цели и подсказка советника обязательны; малые страны с 0–1 институтом стоят — потолок через содержание и лицензии как замена; к 1990-м выбор кончается на 99 узлах — нужно расширение дерева; военное превосходство без войны и дипломатии — только индекс и «Давление»; калибровка обнуляется.
