# TASK-0034 — C3 при ускоренном темпе знания (вход для калибровки T12)

## Цель
Проверить до калибровки T12, сохраняется ли якорь C3 (CV в коридоре 0,3–0,5), если знание ускорить в 2–3 раза. Сейчас темп знания в 2–3 раза медленнее якорей. Этап C4 в T12 двигает `c_n` после того, как C3 уже зафиксирован (порядок §8.2 C1 → C3 → C2 → C4). Без этой проверки сбой C3 увидит только итоговая проверка L.

## Описание
- Стенд C3 из `SmokeT4s` (команда `smoke-t4s`) на HEAD, с `c_n`/k при k ∈ {1; 1,5; 2; 3}.
- Тот же прогон с другим рычагом ускорения: доля НИОКР на узел, при той же эффективной скорости.
- Результат — §7 в `docs/simulation/smoke-t4s.md`: медиана и диапазон CV по ★, сравнение с коридором, вывод о рычаге.
- Рекомендация для манифеста калибровки T12: каким рычагом ускорять знание и нужен ли пересмотр порядка этапов §8.2. Запись в манифест делает владелец спеки после решения Orchestrator.
- Исходное наблюдение: отчёт simulation-engineer 2026-11-13 о сверке TASK-0017, §6 `smoke-t4s.md`. Оценка [Предп.]: медиана CV ≈ 0,49 при ×2 и 0,62 при ×4.
