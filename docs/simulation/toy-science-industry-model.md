# Toy-модель «наука → инженерия → производство» (пилот HYP-0001 / EXP-0001)

> Статус: спецификация для C# Core, ред. 2 (TASK-0003, после gate-ревью EXP-0001 и DECISIONS_LOG #12–#15). Масштаб игрушечный, модель не калибруется по истории (HYP-0001, «Риски»).
> Эталонная реализация: `lab/proto/model.py` (Python, stdlib). Порядок операций в коде прототипа — часть спецификации: C# должен повторить его, тогда `yearly.csv` совпадёт бит-в-бит.
> Связано: HYP-0001, EXP-0001, `exp0001-csv-format.md`, ADR-0002/0003/0004/0006/0008, манифест `lab/manifests/EXP-0001.json`.

## Краткий вывод
- [Предл.] 6 стран (архетипы A1–A6), у каждой 6 запасов в `long` Fx6 (K, A, T, P, R, E), константа N и счётчик B. Воронка: знание K → освоенная техника A → техника станочного парка T → выпуск Y (вместе с капиталом P и ресурсами N). Кадры R, E растут с бюджетом с лагом обучения.
- Месячный тик, 1910-01…1950-12 = 492 тика; метрики раз в год.
- **Правило снимка:** все правые части тика t читают только S_t (состояние на начало месяца t и Kmax_t, Amax_t). Значения t+1 внутри тика не читаются. Порядок подсистем внутри страны поэтому на результат не влияет.
- **Правило приращений:** новый запас = старый raw + ⌊Δx·10^6⌋. Это даёт точную монотонность K и инварианты с допуском ±1 raw.
- Контроли: B — единый уровень τ, калибруется под среднюю траекторию Power A5 модели A (§2.8); C — фиксированный лаг 120 мес. (§2.9).
- Ярлыки узких мест в Core не считаются и в CSV не пишутся: их выводит только анализ (EXP-0001 «Ревью» п.5).
- [Факт] (прототип, `lab/results/`, не коммитится) Прогон матрицы EXP-0001 на прототипе — EXP-0001 «Предварительные результаты прототипа».

## 1. Состояние и входы
| Переменная | Смысл | Тип |
|---|---|---|
| K | запас знаний (открытия) | `long` Fx6 |
| A | освоенная инженерно техника, 0 ≤ A ≤ F | `long` Fx6 |
| T | технический уровень станочного парка (vintage-среднее) | `long` Fx6 |
| P | производственный капитал | `long` Fx6 |
| R, E | учёные, инженеры (тыс. чел.) | `long` Fx6 |
| B | накопленный счётчик прорывов | `int` |
| N | ресурсная база; константа прогона (вход) | `long` Fx6 |

**Архетипы** — таблица HYP-0001 ред. 2 (A4: S l, E m, Pl m, Nl h, ρ l/m). Уровни l = 0,6, m = 1,0, h = 1,6. ι = 0,6 для A1–A5, 0,96 для A6.
**SETUP (тик 0):** для страны i множители mult_k = 0,85 + 0,30·u_k, u_k = RNG(seed, 0, SETUP, i, k), k = 0..3 → S, E, Pl, Nl. Уровни (double): S = lvl_S·mult_0 и т. д. Образование не умножается.
**Производные входы (double, не состояние):** s_R = 0,02·S, s_E = 0,02·E, s_P = 0,12·(0,5 + 0,5·Pl); ρ_R = ρ0·lvl_R(t), ρ_E = ρ0·lvl_E(t), ρ0 = 0,12/год. У A6 lvl(t) = 0,6 + 1,0·min(t, 360)/360 (линейно 1910-01 → 1940-01, далее 1,6), t — индекс месяца.
**Начальное состояние (raw = ⌊x·10^6⌋, в этом порядке):** N = ⌊100·Nl⌋, K0 = ⌊100·S⌋, R0 = ⌊3·S⌋, E0 = ⌊3·E⌋, A0 = min(⌊60·E⌋, K0), T0 = ⌊fx(A0)·(0,5 + 0,25·Pl)⌋, P0 = ⌊100·Pl⌋, B = 0. Здесь fx(raw) = raw / 10^6 (double).
Модель B: K0 ← ⌊c_τ0·fx(K0)⌋, A0 = T0 = K0. Модель C: A0 = T0 = ⌊ψ·fx(K0)⌋.

## 2. Тик t модели A (страна i; все x = fx(raw) из S_t; dt = 1/12)
1. **Выпуск:** u1 = RNG(seed, t, PRODUCTION, i, 0); shock = ν·σ0·(2·u1 − 1);
   Y = z · PowDyadic(1 + T/T_ref, 8γ) · PowDyadic(P, 8β) · PowDyadic(N, 8 − 8β) · (1 + shock) — умножение слева направо; Y_raw = ⌊Y·10^6⌋.
2. **Бюджет (raw):** spR = ⌊s_R·Y_raw⌋, spE = ⌊s_E·Y_raw⌋, I = ⌊s_P·Y_raw⌋, C = Y_raw − spR − spE − I (C ≥ 0).
3. **Наука (Jones):** ΔK = dt·(δ_K·√R·√K + μ·ι·max(0, Kmax − K)).
   u2 = RNG(seed, t, SCIENCE, i, 0). Если ν > 0: p = min(0,5; p0·√R/ν); при u2 < p: ΔK = ΔK + ν·g0·K, B += 1. (При ν = 0 прорывов нет.) Ожидание p·g от ν не зависит, пока p < 0,5.
   K' = K_raw + ⌊ΔK·10^6⌋.
4. **Инженерия:** F_raw = max(K_raw, ⌊ι·Amax⌋) (K_t, не K'); G = fx(max(0, F_raw − A_raw)); cap_e = η·E, cap_g = θ·G;
   `eng_binding` = (cap_e < cap_g); ΔA = dt·(min(cap_e, cap_g) − δ_A·A); A' = min(max(A_raw + ⌊ΔA·10^6⌋, 0), F_raw).
5. **Капитал и парк (vintage):** inv = κ·fx(I); dep = δ_P·dt·P; P1 = P + (inv − dep) (double, без округления);
   P' = P_raw + ⌊(inv − dep)·10^6⌋; T' = T_raw + ⌊inv·(A − T)/P1·10^6⌋. Новый капитал несёт A_t (не A').
   Это алгебраически равно T' = [(1 − δ_P dt)·P·T + κ·I·A]/P1, но в форме приращения.
6. **Кадры:** R' = R_raw + ⌊ρ_R(t)·dt·(fx(spR)/w − R)·10^6⌋; E' = E_raw + ⌊ρ_E(t)·dt·(fx(spE)/w − E)·10^6⌋.
7. **Накопители года:** Y_year += Y_raw; eng_binding_months += eng_binding; shock_sum += shock.
Степени — только `DetMath.PowDyadic` (двоичная сетка {k/8}); √ — `Math.Sqrt`. `Pow/Exp/Log` в состоянии запрещены (ADR-0003).

### 2.8 Контроль B (единый уровень τ)
τ хранится в слоте K; A = T = τ (в CSV K = A = T = τ). Отличия от A: в п.1 T заменяется на τ; в п.3 вместо R — H = R + E, вместо δ_K — δ_τ; п.4 и формула T' в п.5 отсутствуют (eng_binding = 0). R и E обновляются по п.6, бюджет тот же.
**Правило калибровки [Предл.]** (решение #15): для каждого ν отдельно, при β, γ основного прогона, на калибровочных seeds 10001…10050 (не пересекаются с прогоном).
- Цель m_A(y) — средняя по seeds Power_y страны A5 в модели A; m_B(y) — то же в модели B.
- Подбираются c_τ0 ∈ [0,05; 2] (по совпадению m_B(1910) = m_A(1910)) и δ_τ ∈ [0; 0,5] (по m_B(1950) = m_A(1950)): бисекция по 30 шагов, по очереди c_τ0 → δ_τ, 3 раунда. Переполнение (|raw| ≥ 2^53) трактуется как +∞.
- Отчётная мера качества: max и RMS |ln m_B(y)/m_A(y)| по 1910–1950. Значения пишутся в манифест; C# Lab пересчитывает их по правилу и сверяет с манифестом.

### 2.9 Контроль C (фиксированный лаг)
Наука — как п.3 модели A (с R). Инженерии нет: A' = T' = ⌊ψ·fx(K_{t+1−L})⌋, K_s = K0 при s < 0, L = 120 мес., ψ = 0,45 (= T0/K0 архетипа A5 при номинальных уровнях: 0,6·0,75). Здесь, как исключение, T' читает K из истории (K' того же тика при L = 0 — не используется). P, R, E — как в A, E на выпуск не влияет. Лаг L = 120 [Предл.] — медиана лага модели A в прототипе (124 мес., все архетипы, ν = 1, seeds 1–40), округлённая до года.

## 3. Числовая политика (ADR-0003)
- Запасы — `long` Fx6 (масштаб 10^6), assert |raw| < 2^53, тогда `long → double` точен. fx(raw) = raw / 1e6.
- Промежуточные — `double`, только `+ − * /`, `Math.Sqrt`, `Math.Floor`, `Math.Min/Max`. Без FMA, без `float`.
- Округление: `Fx6.FromDouble` = ⌊x·10^6⌋ с проверкой `double.IsFinite`. Новый запас всегда = старый raw + FromDouble(Δx) (кроме clamp A и п.2.9).
- Лестница вех: q_0 = 100·10^6 raw, q_{j+1} = ⌊q_j·5/4⌋ в `long`, j = 0..23.
- Ln для разложения узких мест — только в анализе (Python).

## 4. RNG (ADR-0004)
u = (CounterRng(seed).NextU64(tick, system, entity, n) >> 11)·2⁻⁵³; цепочка mix с солями на поле — `tools/reference/kernel_vectors.py`.
| system | tick | entity | n | значение |
|---|---|---|---|---|
| 0 SETUP | 0 | i | 0, 1, 2, 3 | mult_S, mult_E, mult_Pl, mult_Nl |
| 1 SCIENCE | t | i | 0 | u2 (прорыв) |
| 2 PRODUCTION | t | i | 0 | u1 (шок выпуска) |
u1 и u2 тянутся при любом ν (при ν = 0 не используются). Порядок вызовов на результат не влияет.

## 5. Фазы тика (ADR-0006) и параллельность
- **commands:** пусто. **compute:** `Parallel.For` по чанкам стран; страна читает S_t, пишет только `next[i]` (SoA, двойной буфер) и свои накопители.
- **merge:** обмен буферов (для C — ещё добавление K' в историю K).
- **post (последовательно по индексу):** инварианты §7 (сравнение next с S_t); Kmax_{t+1}, Amax_{t+1}; вехи; в декабре (t mod 12 = 11) — годовая строка (запасы после тика t, накопители года) и сброс накопителей; в конце — StateHash.
- StateHash (EXP-0001 «Ревью» п.7): SHA-256 от `<i32 schema=1><i64 tick=492><i32 n=6>` + колонки K, A, T, P, R, E, N (int64 LE) + B (int32 LE). Прототип пишет его в `runs.csv` (`state_hash`) — эталон для C#.
L2 выполняется: результат для i — чистая функция (S_t, seed, t, i); max по странам не зависит от порядка.

## 6. Метрики (CSV — `exp0001-csv-format.md`)
- Годовая строка: K, A, T, P, R, E, N на конец декабря; Y_year = Σ Y_raw за год; B накопленный; eng_binding_months; shock = shock_sum/12 (double, только анализ).
- **Итоговая мощь:** Power_y = Y_year; ранги по Power с разбором ничьих по индексу страны.
- **Вехи:** m_X(j) для X ∈ {K, A, T} — индекс месяца t, после которого (в post тика t) впервые X ≥ q_j; если X_0 ≥ q_j, m = 0. Не достигнуто — пусто. Анализ считает m = 0 левой цензурой (сюда попадает и пересечение в январе 1910 — консервативно).
- **Узкие места — только анализ** (`exp0001.py`): ln(Power_L/Power_i) раскладывается на c_TECH (делится на SCIENCE/ENGINEERS/MACHINE_PARK по ln K, ln A/K, ln T/A), c_CAPITAL = β·ln(P_L/P_i), c_RESOURCES = (1−β)·ln(N_L/N_i), NOISE = остаток. Core и `yearly.csv` ярлыков не содержат.

## 7. Инварианты (post каждого тика; нарушение = исключение)
1. K', A', T', P', R', E' ≥ 0; все double конечны (FromDouble).
2. K' ≥ K (точно, raw). 0 ≤ A' ≤ F_t, F_t = max(K_t, ⌊ι·Amax_t⌋) (модель A).
3. min(T_t, A_t) − 1 ≤ T' ≤ max(T_t, A_t) + 1 (raw; модель A). Значения — из S_t; ±1 raw покрывает floor приращения.
4. spR + spE + I + C = Y_raw точно; C ≥ 0.
5. |raw| < 2^53 для всех запасов; вехи монотонны по j.
6. L1: два прогона с одним seed — один StateHash и один хеш `yearly.csv`; L2: threads = 1 и N — то же.

## 9. Известные ограничения
- [Предп.] Высокая чувствительность к β и γ — поэтому сетка β×γ входит в EXP-0001 (решение #13).
- [Факт] (прототип) Рост Power за 1910–1950 — около ×30–50: сильная обратная связь Y → I → P и Y → кадры. Для toy-модели допустимо, но абсолютные уровни не интерпретируются.
- [Факт] (прототип) Калибровка B совпадает на концах (1910, 1950), в середине траектории расхождение средней до ~10% (max |ln dev| ≈ 0,10).
- Нет торговли, войн и населения; ресурсы постоянны. Трансфер (альтернатива D) — только ι·Amax.
