## Плечи
Общее: проход 1 A39 — первым и водопадом в каноническом порядке во всех плечах; цель и участие прохода 2 — V5 (спека §3.5 A39 «v0.22»). Обозначения месяца t, актор a: `Π` — участвующие ячейки прохода 2; `need'_i = min(need_i, room_i − invest_i)` после прохода 1 (raw `Fx6`); `P` — `pool_left` после прохода 1; `N = Σ_{i∈Π} need'_i`.

**Если `N ≤ P`, все правила дают `x_i = need'_i`** (план побитно равен `CAN`). Правила различаются только в месяцах исчерпания (`N > P`), и во всех правилах (кроме остатка `PROP`) тратится весь `P` — меняется распределение, не сумма.

| id | Плечо | Правило прохода 2 при `N > P` | Роль | `S` (новых правил) |
|---|---|---|---|---|
| V0 | V0, `CAN` | как сборка TASK-0031 | V-0, K5 | — |
| VINF | VINF | деньги условные, правило не действует | эталон `D` | — |
| `CAN` | V5, водопад: site ↑, кластеры MET, CHEM, MECH, AERO, измерения `precision`, `purity`, `quality_control` | main сейчас (#163) | контроль | 0 |
| `REV` | V5, водопад: site ↑, кластеры **AERO, MECH, CHEM, MET**, измерения канонически | контроль механизма; **не выбирается** | 0 |
| `PROP` | V5: `x_i = ⌊need'_i · P / N⌋` (raw, `Int128`, floor); остаток `P − Σ x_i` (< `|Π|` raw) не раздаётся и уходит в `T_a` как невзятое | кандидат | 2 (деление, правило остатка) |
| `SEV` | V5, водопад в порядке `sev_i` ↓, ничья — канонический порядок `CAN`; `sev_i = max_p (1 − g(M[s,c,d] − r_d(p)))` — максимум по процессам p, дающим участие ячейки | кандидат | 1 (ключ сортировки) |

- **Почему эти.** `PROP` — ни один кластер не последний; `SEV` — деньги сначала туда, где узкое место тяжелее (форма «пропорция по тяжести» без деления и без правила перераспределения потолков: взвешенная пропорция требует итеративного заполнения при `x_i > need'_i` — больше правил при той же идее). `REV` переносит «последнего» с AERO на MET: если `D` у `REV` ≈ `CAN`, а недолив просто переехал, — порядок перераспределяет, а не улучшает. Постоянный приоритет кластера — утверждение о том, какая промышленность важнее; эксперимент его не обосновывает, поэтому `REV` не выбирается (выбор фиксированного приоритета — владельцу, если печать покажет причину).
- **`SEV`, формула (r1).** `sev_i = max_{p} (1 − g(x_p))`, `x_p = M[s,c,d] − r_d(p)`, `g(x)` по контракту §4.2: `0` при `x < −1`, `(1 + x)²` при `−1 ≤ x < 0`, `1` при `x ≥ 0` (raw `Fx6`, произведение — floor). `M` — снимка t: вложения прохода 1 того же месяца `M` до прохода 2 не меняют (A39 — план по снимку), поэтому «`M` после прохода 1» = `M` снимка. Аргумент — `M`, а не `min(H, M)`: у участвующей ячейки `M ≤ H`, они равны. `sev_i ∈ (0; 1]`: `M < r_d` ⇒ `x < 0` ⇒ `g < 1`. Так реализовано в `ToolingPlan.CellTarget` (a32022c).
- Переключатель `POOL_ORDER` и `k_cap` — только Lab (спека §11 POOL_ORDER).

## Метрики
Судятся USA и GBR; SUN, FRA, SWE — печать (как T6e2 r1). `E*` — объединение по V0 и VINF той же конфигурации и seed (О3 EXP-0005). Суммы — по seeds набора, CI — парный bootstrap 2000 повторов по seeds.
- **M-E — исчерпание пула (r1):** доля месяцев (актор), где **до распределения** `N > P` (нужда прохода 1 и 2 больше пула). Не зависит от правила: раннер считает на снимке плеча план `CAN` и отмечает месяц, если у него есть недолив `Unmet > 0` (столбец `exh` в `pool.csv`).
- **M-U — недолив по кластерам:** `U(a, c) = Σ (need'_i − x_i)` по участвующим ячейкам кластера c (из леджера плана; это проход-2 часть `tool_unmet`); доля наибольшего кластера `U_max/ΣU`.
- **`D`, `ΔD`, `R`** — T6e2 r1; P-dec (культура + оснастка ниже культуры) по кластерам.
- **`Q(a, O)` — доля закрытого остатка:** `Q = Σ_s (D(a, s, CAN) − D(a, s, O)) / Σ_s (D(a, s, CAN) − D(a, s, VINF))` — какую часть разрыва `CAN` ↔ VINF закрывает правило O. Определён, только если знаменатель ≥ 0,05·`Σ_s D(a, s, CAN)` (r1; иначе Г3 не выполнено).
- **K2 `π̂`, K4 `b_w`, K5 `R5`** — T6e2 r1, для каждого плеча V5 (годность).
- **Баланс против `CAN`:** медиана по seeds `r_w(O)/r_w(CAN)` по окнам w0–w7 (окна с выпуском USA и GBR > 0 в `CAN`).
- **Печать (не критерии):** `Q`, `U`, M-E у FRA и SUN; FRA — первый месяц серии (якорь #150, мес. 75, полоса 60–110 — диагностика), окна с выпуском (M2); SUN — первый G1; `D_g` (вес `1 − g_d`, P-g EXP-0005) — `SEV` выигрывает по нему по построению, поэтому только печать; `T_a` и неизрасходованный остаток; наибольший остаток `PROP` `P − Σ x_i` (raw, `prop_rem` в `pool.csv`, ожидание < `|Π|`); доля звеньев `TOOLING_POOL_EXHAUSTED` (если п.2 задачи в сборке).

## Критерии (объявлены до прогона)
Правило O ∈ {`PROP`, `SEV`} **годно**, если:
- **П1 — годность V5 сохраняется (main):** K1 (`R ≥ 0,75` у USA и GBR; факторные — как T6e2 r1), K2 (`π̂ ≤ 1`), K4 (медиана `b_w` ∈ [0,67; 1,5]), K5 (`R5 ≥ 0,75`). Основание: замена порядка не должна отнять свойства, за которые V5 принят (#163).
- **П2 — не хуже `CAN` в main:** у USA и GBR (r1) **всегда** `ΣD(O) ≤ 1,01·ΣD(CAN)` точечно; если `Q_main` определён (Г3) — ещё `Q_main ≥ −0,10` точечно и верхняя граница CI `Q_main` ≥ 0. Основание [не из чисел]: 1% — допуск шума при равных суммах денег; −0,10 — правило не отдаёт больше десятой доли уже закрытого остатка.
- **П3 — лучше при малом пуле (стресс):** у каждой судимой в стрессе державы (Г2, Г3) `Q_stress ≥ 0,25` точечно и нижняя граница CI > 0; судимой должна быть хотя бы одна держава. **r1:** у GBR знак `Q` в main и в стрессе один (если `Q_main` GBR определён; `Q = 0` точно — знак любого) — улучшение «малой державы» не должно оборачиваться ухудшением GBR при её настоящем пуле.
- **П4 — без сдвига баланса (main и стресс, r1):** медиана `r_w(O)/r_w(CAN)` ∈ [0,67; 1,5] во всех окнах с выпуском USA и GBR > 0 в `CAN`.
- **П5 — вето FRA (решение Orchestrator, r1; защищает RISK-0018):** в main и в стрессе `ΣD(FRA, O) ≤ 1,05·ΣD(FRA, CAN)`; иначе правило не годно. FRA в выборе не участвует (не входит в `Q` и правило выбора). SUN — только печать. [Опора на EXP-0005 — да: FRA выбран из-за исчерпания пула в 50% месяцев участия; порог 5% — допуск, не из чисел.]
- **Почему 0,25** [не из чисел EXP-0005]: K1 разрешает V5 терять до 1/4 улучшения VINF; новое правило (`S` ≥ 1) оправдано, только если возвращает не меньше такой же доли оставшегося разрыва. Меньший эффект — шум 20 seeds и лишнее правило.
- `REV` считается по тем же критериям, печатается, не выбирается. **Годный `REV` при негодных `PROP` и `SEV` — исход п.3 правила выбора** (`CAN`, refutes); годность `REV` — только печать владельцу (вопрос о фиксированном приоритете кластера — его решение, не этого EXP).

## Правило выбора (объявлено до прогона, подстройки после нет)
1. Из годных (П1–П5) — наибольшее среднее `Q_stress` по судимым державам (точечные значения).
2. Разница точечных средних `Q_stress` ≤ 0,05 → меньший `S` (`SEV` 1 < `PROP` 2).
3. Годных нет при выполненных предусловиях → остаётся `CAN`, `outcome` = refutes; RISK-0018 остаётся открытым с печатью `TOOLING_POOL_EXHAUSTED`; отчёт владельцу.
4. Г2 или Г3 в стрессе не выполнены ни у USA, ни у GBR → `outcome` = inconclusive (стресс не дал случая для сравнения); новый масштаб — только новым EXP.
5. Выбор — владелец после gate (critic + advocate).

- FRA (печать): правила различаются больше всего (EXP-0005: исчерпание 50%; **опора на EXP-0005 — да**); вывести FRA из ловушки культуры правило распределения не может (A43.8: без выпуска культура не растёт) — ожидается сдвиг части «оснастка ниже культуры», не части «культура».

## Ограничения
