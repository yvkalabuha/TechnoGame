# AUDIO_DIRECTION v0.1 — звук и музыка PROJECT SINGULARITY

Статус: [Предл.] первый документ; решения владельца: #296 (звук и музыка), #288 (реестр авторов), ADR-0009 (лицензии). Роль sound-director временно ведёт ui-art-director. Связанные документы: `docs/ui/UI_ART_DIRECTION.md`, `docs/ui/GLOBE_DIRECTION.md`.
Размещение: файл лежит в `docs/ui/` из-за зоны записи агента; целевой путь `docs/audio/AUDIO_DIRECTION.md` (Orchestrator переносит `git mv`).

## Краткий вывод
- [Предл.] Звук продолжает визуальный закон: **звук означает отклонение**. По умолчанию — тишина и тихая «комната» (тон помещения, шум оборудования). Яркий звук есть только у события, которое требует внимания или подтверждает команду.
- [Предл.] Идентичность — «аппаратная государства»: реле, телетайп, ламповый тон (1945) → транзистор, перфолента, ЭВМ → синтезатор, цифровой писк. Эволюция идёт **по году игры** внутри одного семейства тембров (один стиль на всю игру, как #37 для графики): меняется материал звука, не язык.
- [Предл.] Тревоги слышны всегда (канал `alert`, не ослабляется дакингом и паузой). Всё остальное имеет лимиты частоты, вариации и затухание под 4–10 часов сессии.
- [Предл.] Музыка — разреженная, адаптивная: 4 слоя-стема и стинг; на 1 мес/с музыка не ускоряется, а стягивается к ровному слою.
- [Факт] Под ADR-0009 из проверенных источников подходят: Freesound (только фильтр CC0 / CC BY), Kenney (CC0). **Не подходят без новой ADR:** Pixabay и Sonniss (собственные лицензии, не CC), OGA-BY (не CC), CC BY-SA и GPL. См. §6.

## 1. Идентичность звука
**Принцип.** Игрок — не герой, а оператор государственной аппаратной. Звук — это сигналы приборов, а не «эпическая» озвучка. Три правила:
1. **Тишина по умолчанию.** Нет события — звучит только фон (§4) на пороге слышимости. Пауза = фон приглушён, тон «держится».
2. **Звук = отклонение.** Рутина (ход времени, прокрутка, наведение, подтверждение обычных команд) почти беззвучна. Громче и ярче — то, что нарушает норму: тревога, срыв, война, запуск, прорыв.
3. **Причина и следствие звучат одним тембром** (параллель «цвет у причины»): подъём и снятие сигнала — одна пара звуков, вверх и вниз.

**Тембровые семейства.** [Предл.] Параметр `era_tone` ∈ [0..1] от года игры (1945 → 0, 2100 → 1), плавный, без ступенек (эпох как этапов в UI нет, #37). Он двигает материал, а не мелодию:

| Период | Материал UI-звуков | Фон аппаратной | Музыка (тембры) |
|---|---|---|---|
| 1945–1960 | щелчок реле, удар каретки телетайпа, ламповый зуммер (синус + мягкое насыщение), колокольчик | гул трансформатора 50/60 Гц, шорох эфира | струнные пиццикато, фортепиано, вибрафон, низкие духовые; плёночная «пыль» |
| 1960–1980 | транзисторные писки, перфоратор, ферритовые щелчки, шаговые двигатели | вентиляция, ленточные приводы | электропиано, ранние аналоговые синты, щётки |
| 1980–2010 | FM-колокольчики, 8–12-бит тики, клавиатурные щелчки, дисковод | тихий вентилятор | пады, арпеджио, мягкий бас |
| 2010–2100 | чистые синусные «капли», гранулярные хвосты | почти тишина, тонкий «воздух» | гранулярные текстуры, длинные пады, минимум ритма |

Слушатель не слышит «смену эпохи», слышит, что аппаратная стала современнее.

**Чего нет.** Голоса диктора, фанфар на каждый ход, победной музыки на рутину, звуков на каждое движение мыши.

## 2. Карта UI-звуков
Приоритеты: **P0** — всегда слышен (канал `alert`); **P1** — важное, слышно всегда, но подчиняется лимитам; **P2** — подтверждение (глобально выключаемо); **P3** — микро-обратная связь (выключаемо, очень тихо).

| Событие | Характер | Приор. | Примечание |
|---|---|---|---|
| Приказ принят | короткий мягкий «клик-реле» вниз, ≤120 мс | P2 | один звук для всех приказов; тон по классу (экономика / наука / военное), не громкость |
| Приказ отклонён | глухой двойной «стук», тон ниже, без хвоста | P1 | причина в тексте |
| Команда в очереди (pending) | тихий тик при постановке; затем **беззвучно** | P3 | ожидание не «тикает» непрерывно |
| Команда исполнена | мягкий ответный тон вверх | P2 | сворачивается в один звук при ≥3 за 2 с |
| Сигнал поднят | два тона вверх (малая терция), чистый | **P0** | сила зависит от тяжести: внимание < тревога < критично |
| Сигнал снят | та же пара вниз, тише | P1 | слышна пара |
| Сигнал держится | звуком не повторяется; растёт визуальный индикатор; напоминание **один раз** через 60 с реального времени, тише | P0 | запрет непрерывного писка |
| Узел открыт | «колокольчик + щелчок реле», 2–3 ноты, хвост ~600 мс | P1 | редкое, может быть ярче; ключевой прорыв — вариант с гармоникой |
| Линия введена в эксплуатацию | «замыкание контактора + нарастающий гул» 400 мс | P1 | в конце анимации строительства (#263) |
| Идёт строительство | почти тишина; шорох пера только при приближении камеры | P3 | |
| Война: объявление / вход в состояние войны | низкий удар + сухой зуммер 1 с, один раз | **P0** | |
| Война: потеря территории, удар по важному объекту | короткая средняя тревога | **P0** | агрегация по лимиту |
| Война: перемирие / мир (#275) | два тона вниз-вверх, спокойные | P1 | снимает слой «война» в музыке |
| Запуск (RR-0013) | космический: шорох-нарастание 1.2 с + чистый тон вверх; ядерный: низкий тон с биениями, без мелодии | ядерный P0, космический P1 | |
| Смена темпа | «щёлчок переключателя»: день/с — 1, неделя/с — 2, месяц/с — 3 быстрых | P2 | максимум 1 звук в 150 мс при Ctrl+колесо |
| Пауза / снятие паузы | «выдох» (фон −6 дБ за 200 мс) / «вдох» | P2 | пауза не глушит P0 |
| Наведение / выбор / окно | микро-тик ≤40 мс | P3 | тише других на 6–10 дБ |

**Всегда слышны (P0):** сигналы (внимание, тревога, критично), война, ядерный запуск. Канал `alert` не дакается музыкой, не отключается глобальным «выключить эффекты» и не глушится паузой. [Предл.] Тревогу можно уменьшить, не выключить; каждый P0 дублируется визуально (табло).

**Усталость (4–10 часов).**
1. **Окно агрегации.** Не более 1 звука класса на 400 мс; при ≥3 событиях за 2 с играет один собирательный звук ступенью выше.
2. **Бюджет голосов.** Не более 3 одновременных UI-голосов; P0 вытесняет P3 и P2.
3. **Вариация.** У частых звуков 4–6 вариантов, питч ±3%, фильтр ±5%, один вариант подряд не повторяется. Редкие (открытие, запуск) без вариации питча: узнаваемость.
4. **Дакинг.** При P0/P1 музыка −6 дБ на время звука + 400 мс; фон освобождает полосу 1–4 кГц. P2/P3 музыку не дакают.
5. **Скрытая адаптация.** После 90 мин непрерывной игры P3 −3 дБ, P2 −1.5 дБ; сбрасывается в настройках. [Предп.] проверить на тестерах.
6. **Спектр.** Частые звуки: энергия 600 Гц–4 кГц, острые пики 2–4 кГц запрещены; тревоги звонче, но короче 300 мс.
7. **Темп.** На 1 мес/с события идут пачками: действует агрегация (п.1), P0 остаются.

## 3. Адаптивная музыка
**Принцип.** Не саундтрек к каждой минуте, а длинные «дыхания» с паузами: сессия музыки 3–5 мин, тишина 30–90 с, затем другая. Для 4–10 часов материал разрежен и модулен. Ползунок «музыки мало / обычно / много».

**Слои (стемы)**, синхронные, один темп и тональный центр на сессию:

| Слой | Роль | Когда |
|---|---|---|
| L0 «Тон» | длинный пад/дрон, без пульса | всегда внутри сессии |
| L1 «Пульс» | лёгкий ритм: щётки, шаги, арпеджио | мир, активное развитие |
| L2 «Напряжение» | диссонанс, низкие, ритм быстрее | сигналы, санкции, кризис |
| L3 «Война» | низкие ударные, ostinato | состояние войны (#274–#282) |
| S «Прорыв» | стинг 6–10 с | ключевое открытие, запуск спутника |

Состояния: **мир** L0+L1; **напряжение** L0+L2; **война** L0+L2+L3 (L1 выкл.); **прорыв** — стинг поверх, состояние не меняется. Эпоха — через набор инструментов (§1), не через иную структуру.

**Переходы.**
- Квантизация по такту, кроссфейд 2–4 такта; вход в войну быстрее (1 такт), это P0.
- Выход из войны медленнее (8 тактов) и через «напряжение»: перемирие #275 — не мир.
- Гистерезис: состояние держится ≥30 с реального времени до смены.
- Стинг дакает L1 на −4 дБ.

**Высокий темп.** Музыка **не ускоряется** (никакого питч-шифта). На «неделя/с» и «месяц/с» L1 и L2 −6 дБ, гистерезис 60 с, стинги только для ключевых событий. На паузе L1–L3 приглушаются, L0 держится.

**Бриф композитору [Предл.].**
- Сдержанно, аналитично; тревога без мелодрамы. Никакого героического оркестра и хоров холодной войны.
- Одна мотивная ячейка 4–6 нот на всю игру; меняется только оркестровка по периодам (§1).
- Объём: 4 периода × ~6 сессий × стемы L0–L3, 6–8 стингов, не менее 12 мин материала на состояние.
- Стемы строго синхронны, бесшовные петли, хвосты ревербации 2–4 с отдельными файлами.
- Сдача: WAV 48 кГц 24 бит, стемы раздельно. Лицензия: передача прав или эксклюзив; атрибуция по договорённости (в титрах).
- Для прототипа: временная музыка CC0/CC BY с теми же слоями, запись в реестр атрибуции (#288).

## 4. Фоновые «постели»
Источники: CC0/CC BY (§6). Включаются, когда камера стоит >2 с. Уровень −36…−28 LUFS-S, на пороге слышимости.

| Зум | Постель | Заметки |
|---|---|---|
| Космос / орбиты | низкий гул, редкие радиошорохи | без клише «космического ambient»; согласован с запусками |
| Весь глобус | шорох эфира + гул аппаратной (1945: трансформатор, AM-шум) | основной фон |
| Регион | море (волна, ветер), континент (ветер), пустыня | кроссфейд 1.5 с на границе, один слой |
| Город / объект | далёкий завод, порт, станция; не более 2 слоёв | усиливается при стройке (#263) |
| Театр войны (#274–#282) | далёкий низкий гул | **без стрельбы и взрывов** как фона: звук войны — сигнал P0, не шум |

Правила: плейлист из 4–6 кусков по ≥60 с, случайный порядок, fade 3 с. Атрибуция каждого файла в реестре.

## 5. Спецификация синтеза UI-звуков
**Подход [Предл.].** Звуки создаются кодом: (а) оффлайн-генератор `tools/audio/` на C# (детерминированный, с seed), результаты кладутся в клиент как WAV — предпочтительно; (б) рантайм через `AudioStreamGenerator`. Аудио — клиентский слой: свой RNG, не связан с детерминизмом симуляции.

**Формат.** 48 кГц. UI: WAV PCM 16 бит моно (<1 с, без задержки декодирования). Постели и музыка: OGG Vorbis q5–6 стерео. Исходники стемов: WAV 24 бит.

**Блоки.**
- Осцилляторы: sine, triangle, square (PWM 10–50%), saw, FM из двух операторов (ratio 1:1…7:1, индекс 0–6), белый/розовый шум.
- Огибающая ADSR: атака 0–30 мс (клик <2 мс), экспоненциальный спад 30–600 мс, релиз 20–200 мс.
- Фильтры: 2-pole LP/BP/HP, Q 0.7–8, огибающая частоты среза.
- Эффекты: waveshaper 0–30% («лампа»), комната RT60 0.1–0.3 с (микс 5–15%), bit-crush для 1980–2010.
- `era_tone` смешивает «реле + шум-атака» (0) и «чистый синус/FM» (1): насыщение 30% → 0%, шум-атака 40% → 5%.

**Громкость [Предл.]** (BS.1770, short-term для коротких звуков): пик ≤ −3 dBTP. P3 −32…−28 LUFS-S; P2 −26…−22; P1 −22…−18; P0 −20…−16 (короче 300 мс, если частые). Музыка −23 LUFS integrated, стинги −20; постели −36…−28 LUFS-S. Лимитер на мастере −1 dBTP. Тревога на 4–6 дБ громче музыки.

## 7. Заметки по Godot 4 .NET (для systems-architect, [Предл.])
- **Шины:** `Master` → `Music`, `Ambient`, `UI` (P2, P3), `Alert` (P0, P1; не ducked), `Sfx`. Дакинг: Compressor с sidechain на `Music` и `Ambient`, либо твин громкости шины.
- **Лимитер** на `Master`, потолок −1 dB.
- **Вариации:** `AudioStreamRandomizer` (питч, громкость, без повтора подряд); `max_polyphony` на плеере.
- **Интерактивная музыка:** `AudioStreamInteractive` (клипы и таблица переходов, режимы Immediate / NextBeat / NextBar / End) для состояний; `AudioStreamSynchronized` для слоёв-стемов с громкостью на стем. [Предп.] имена и поведение сверить с версией Godot проекта.
- **`AudioDirector`** — клиентский C#-класс: слушает те же события, что и табло; агрегация, лимиты, гистерезис, `era_tone`; чистая логика тестируется без Godot; на симуляцию и сохранения не влияет.
- **Ресурсы:** UI в WAV, музыка и постели в OGG с loop-offset.
- **Тест:** замер LUFS и пика сгенерированных звуков (например, ffmpeg `ebur128`) в CI.
- Озвучки нет, ADR-0018 звука не касается.
