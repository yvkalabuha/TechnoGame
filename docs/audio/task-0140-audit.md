## 3. Системные находки
1. [Факт] Опрос `ObserveHost` сравнивает значения по кадрам, не по событиям: любые «прирост» (known/series) срабатывают на загрузке и смене `Actor` лишь частично (baseline обнуляется только по `_baseActor`) — риск ложного звука при загрузке сохранения [Предп., нужна проверка].
2. [Факт] Окно `order` 0.4 с и общий дакинг превращают пары (ok/done, attention/clear) в «одно из двух» непредсказуемо — это и ощущается «невпопад».
3. [Факт] Два слайдера без работы: «Sfx» (`Settings.cs`, индекс 4, отдельной шины нет, `AudioDirector.cs:69`) и `SoundInBackground` (в `AudioDirector` не используется) — проверить [Предп.].
4. [Факт] Много P1 идёт на шину Alert, которая не глушится дакингом и не опускается ниже 20%. Рутинные успехи (узел, линия, снятие) не должны быть на Alert; по #298 «алерты можно приглушить, не выключить» относится к тревогам.

## 5. Дакинг [Предл.]
Дакинг музыки/фона только от P0 и от breakthrough (-4 дБ вместо -6); от P1-рутины (узел, линия, отказ) — нет. Хвост 0.4 с -> 0.8 с, чтобы музыка не «дышала» на серии.
