# Toy-модель «наука → инженерия → производство» (пилот HYP-0001 / EXP-0001)

> Статус: проект модели для пилота PHASE E. Масштаб игрушечный. Модель не калибруется по истории и абстрактна (HYP-0001, «Риски»).
> Связано: HYP-0001, EXP-0001, ADR-0002/0003/0004/0006/0008.

## Краткий вывод
- [Предл.] У страны 7 запасов (`long` fixed-point) и 1 счётчик. Воронка такая: знание **K** → освоенная техника **A** → техника в станочном парке **T** → выпуск **Y** вместе с капиталом **P** и ресурсами **N**. Кадры **R** (учёные) и **E** (инженеры) растут с бюджетом, но с лагом обучения.
- [Предл.] Тик месячный, 1910-01…1950-12, это 492 тика. Метрики пишутся раз в год. Месяц нужен, чтобы мерить лаг «открытие → серия» (критерий 3) точнее года.
- [Предл.] Все показатели степени двоичные: 1/2, 1/4, 1/8. Степени вычисляются цепочками `Math.Sqrt`: по IEEE 754 sqrt округляется корректно и бит-в-бит воспроизводим. `Math.Pow/Exp/Log` в коде состояния не используются (ADR-0003).
- [Предл.] Контроль B — модель с единым «уровнем технологий» τ, она включается флагом в той же системе. Шум задаётся явным параметром ν: он меняет дисперсию, а среднее остаётся прежним.
- [Предп.] Быстрый прототип на Python (float, 100 seeds, в репозиторий не входит) показал: при параметрах по умолчанию доминанта нет, но A3 и A6 почти не попадают в топ-2, а итоги сильно зависят от β и γ (см. EXP-0001).

## 1. Состояние страны i
| Переменная | Смысл | Тип |
|---|---|---|
| K | запас знаний (открытия) | `long`, масштаб 10^6 |
| A | освоенная инженерно техника (A ≤ фронтир F) | `long`, 10^6 |
| T | технический уровень станочного парка (vintage-среднее) | `long`, 10^6 |
| P | производственный капитал | `long`, 10^6 |
| R, E | учёные, инженеры (тыс. чел.) | `long`, 10^6 |
| B | счётчик прорывов | `int` |
| N | ресурсная база, константа на весь прогон (вход, не состояние) | `long`, 10^6 |
Входы архетипа (не меняются за прогон): доли бюджета s_R, s_E, s_P, открытость ι, темпы обучения ρ_R, ρ_E. У A6 темп обучения растёт по линейному графику.

## 2. Уравнения за месяц (dt = 1/12 года)
Снимок S_t содержит состояние всех стран и глобальные агрегаты Kmax_t, Amax_t, посчитанные в post прошлого тика.
1. **Выпуск:** Y = z · (1 + T/T_ref)^γ · P^β · N^(1−β) · (1 + ν·σ0·(2u₁ − 1)). Шок равномерный, u₁ ∈ [0,1).
   По умолчанию γ = 1, β = 5/8. Тогда P^(5/8) = √P · √√√P и N^(3/8) = √√N · √√√N.
2. **Бюджет (точное сохранение в `long`):** spend_R = ⌊s_R·Y⌋, spend_E = ⌊s_E·Y⌋, I = ⌊s_P·Y⌋, C = Y − spend_R − spend_E − I.
3. **Наука (Jones):** ΔK = dt·[δ_K·R^λ·K^φ + μ·ι·max(0, Kmax − K)] + 𝟙[u₂ < p]·g·K,
   где λ = φ = 1/2, p = min(0,5; p0·√R / ν), g = ν·g0. Ожидаемый прирост от прорывов p·g от ν не зависит, а дисперсия растёт пропорционально ν.
4. **Инженерия:** фронтир F = max(K, ι·Amax), разрыв G = max(0, F − A).
   ΔA = dt·[min(η·E, θ·G) − δ_A·A], затем A ← clamp(A, 0, F). Если η·E < θ·G, месяц помечается флагом `eng_binding` (не хватает инженеров).
5. **Капитал и станочный парк (vintage):** P' = (1 − δ_P·dt)·P + κ·I; T' = [(1 − δ_P·dt)·P·T + κ·I·A] / P'.
   Новый капитал несёт текущий уровень A, поэтому медленно растущий парк держит T ниже A.
6. **Кадры:** R' = R + ρ_R·dt·(spend_R/w − R), E' = E + ρ_E·dt·(spend_E/w − E). Подготовка занимает поколение: 1/ρ ≈ 8 лет.
7. **Контроль B:** один запас τ на месте K. Кадры H = R + E, s_H = s_R + s_E. Δτ считается по п. 3 с H вместо R. В выпуске T заменяется на τ: открытие сразу идёт в производство. A, T, E-воронки нет.
Диффузия (μ и ι·Amax) читает только снимок S_t, поэтому остаётся детерминированной при любом числе потоков.

## 3. Числовая политика (ADR-0003, PROPOSED)
- Запасы хранятся как `long` с масштабом 10^6 (`Fx6`, одна константа в Kernel). Ожидаемые величины до ~10^4 ед., то есть ~10^10 raw, запас до 2^53 огромный. Перевод `long → double` точен; проверка `|raw| < 2^53` (assert).
- Промежуточные значения считаются в `double`, используются только `+ − * /` и `Math.Sqrt`. FMA вручную не вызывается, `MathF`/`float` запрещены. Округление обратно: `(long)Math.Floor(x * 1e6)`, перед ним `double.IsFinite`, иначе исключение.
- Степени берутся из двоичной сетки {1/8 … 1}: `Kernel.DetMath.PowDyadic(x, k/8)` через цепочку sqrt. Для произвольных степеней позже появится `DetMath.Pow` (log2/exp2 полиномом фиксированного порядка). В пилоте он не нужен.
- Лестница порогов q_j = 100·(5/4)^j считается заранее в `long`, повторным умножением ×5/4 без Pow.
- Ln для объяснения отставания (§6) считается только в анализе (Python) и в состояние не входит.

## 4. RNG (ADR-0004)
u = (SplitMix64(seed, tick, system, entity, n) >> 11) · 2⁻⁵³, точный double в [0,1).
system: 0 = SETUP (разброс начальных условий), 1 = SCIENCE (n = 0: прорыв), 2 = PRODUCTION (n = 0: шок). entity — индекс страны. Порядок вызовов на результат не влияет.

## 5. Фазы тика (ADR-0006) и параллельность
Тик ядра — месяц пилота. Когда появится дневной конвейер, система получит частоту Month, а ключ RNG останется индексом месяца.
- **commands:** в пилоте пусто.
- **compute:** `Parallel.For` по чанкам индексов стран (`threads` из CLI). Каждая страна читает S_t и пишет только `next[i]` в двойном буфере SoA и свою строку метрик. Общих записей нет.
- **merge:** обмен буферов. Буферов событий нет, кроме вех (§7), которые пишутся в per-country строки.
- **post (последовательно, по индексу):** Kmax, Amax (max не зависит от порядка); инварианты; годовые метрики в декабре; SHA-256 (BCL) от колонок в порядке индексов (little-endian).
Почему выполняется L2: результат для i — чистая функция от (S_t, seed, t, i). Суммы между странами считаются только в `long`. Тест L2 гоняет ещё и 64 синтетические страны, чтобы чанкинг был нетривиальным.

## 6. Метрики (раз в год на страну) и узкие места
- Запасы K, A, T, P, R, E, N; Y_year = сумма помесячных Y; B (прорывы); `eng_binding_months`.
- **Итоговая мощь** (для ранжирования): Power_y = Y_year, сумма выпуска за календарный год y. Выпуск уже включает технический уровень через (1 + T/T_ref)^γ. Ранг считается по Power_y, итоговый ранг по Power_1950. Ничьи раздаются по индексу страны.
- **Воронка:** открыто (K), освоено (A), в серии (T), а также доли A/K и T/A.
- **Вехи:** для каждого порога q_j фиксируются месяцы m_K, m_A, m_T первого пересечения K, A и T. Лаг «открытие → серия» = m_T − m_K, если m_K ≤ m_T. Если T до конца прогона не дошёл, лаг цензурируется значением 492 − m_K (нижняя оценка). Если m_T < m_K, это «импорт», он в лаг не входит.
- **Узкое место** (страна-год, отставание: Power_i < 0,8·Power_лидера, год ≥ 1915). Разложение ln(Power_L/Power_i):
  c_TECH = γ·ln[(1+T_L/T_ref)/(1+T_i/T_ref)], c_CAPITAL = β·ln(P_L/P_i), c_RESOURCES = (1−β)·ln(N_L/N_i).
  c_TECH делится на SCIENCE / ENGINEERS / MACHINE_PARK пропорционально положительным частям ln(K_L/K_i), ln(e_L/e_i) и ln(m_L/m_i), где e = A/K, m = T/A.
  Ярлыки: `SCIENCE`, `ENGINEERS`, `MACHINE_PARK`, `CAPITAL`, `RESOURCES`. Core пишет `bottleneck1/2` по ранжированию отношений (логарифмы не нужны). Доли считает анализ.
  Отставание «объяснено 1–2 узкими местами», если доля двух главных факторов ≥ 0,7 [Предл.]. В отчёт идёт распределение этой доли, а не только процент прохождения.

## 7. Инварианты (post, каждый тик; нарушение = исключение)
1. K, A, T, P, R, E ≥ 0; все промежуточные double конечны (нет NaN/Inf).
2. K не убывает; 0 ≤ A ≤ F_t; min(T, A) ≤ T' ≤ max(T, A) (vintage-среднее).
3. spend_R + spend_E + I + C == Y, точное равенство в `long`. C ≥ 0, потому что s_R + s_E + s_P ≤ 1.
4. |raw| < 2^53 для всех запасов; вехи монотонны: m_K(j) ≤ m_K(j+1).
5. L1: два прогона с одним seed дают одинаковый хеш. L2: хеш при threads = 1 и threads = N одинаков.

## 9. Известные ограничения
- [Предп.] Чувствительность к β и γ высокая: в прототипе β = 1/2 давало доминанта A4, γ = 1/2 — доминанта A2. Нужен отдельный sweep, это кандидат в EXP-0002.
- Нет торговли, войн и населения; ресурсы постоянны. Канал трансфера (альтернатива D) есть только как ι·Amax.
