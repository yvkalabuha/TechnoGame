# RR-0020 — Scripted ownership events 1945-1975: dates and sources

> Пометки: **[Факт]** — подтверждено источником; **[Предп.]** — предположение; **[Предл.]** — предложение.

## Вопрос исследования

Какие смены `owner` и/или `controller` без войны произошли 1945-10-01 … 1975-10-01, в какие даты, по каким документам (решения #325, #328; пункт 1.6a плана MS-M1)? Каждое событие в игре срабатывает строго в свою дату, без окна.

## Краткий вывод

1. Таблица ниже: **34 строки ядра** (C01–C34: Германия, Берлин, Саар, Корея, Австрия, Триест, Тайвань, совместные администрации) и **128 строк широкого списка** (B01–B134 без 6 пустых/дублей: Азия, Ближний Восток, Африка, Карибы, Океания, Европа). Всего 162 строки, из них 7 `no-effect`, 2 исключены в M2; ~153 рабочих смены. Подсчёт — §2.5.
2. [Факт] День известен для подавляющего большинства событий. Дата зависит от выбора «подпись / вступление в силу / фактическая передача»; для спорных случаев указаны все три, а колонка «Рек.» (предложение) выбирает одну.
3. [Факт] Карта M1 (`provinces.yaml`) — только Европа. Неевропейские события привязаны к описанию территории (`geo: описание`); id провинций есть лишь для Германии, Австрии, Додеканеса, Порккала, Калининграда, Юлийской Марки (частично).
4. Пробелы карты для ядра: нет провинции Саар, нет секторов Берлина, нет Триеста / зоны A/B, нет Истрии (кроме `croatia.primorsko_goranska`, `croatia.zadarska`, `slovenia.ilirska_bistrica`, `italy_firenze.udine`). Нужны новые провинции или разрезы (задача карты).
5. Спорные: де-юре владелец земель восточнее Одера–Нейсе и Калининграда; Тайвань; Кашмир; Сикким; Восточная Эритрея; Коморы (Майотта); Триест до 1975. Они помечены `disputed`.
6. Военные по происхождению передачи помечены `war-related` (решение за game-designer). Исключены как M2: Гайдерабад 1948, Корейская война, Суэц 1956, Бангладеш 1971, Кипр 1974, Вьетнам и Камбоджа 1975, Ангола.
7. Лицензии: тексты договоров — государственные документы (PD по сути), но площадки (UN, CVCE, Avalon, UK OGL) имеют свои условия. В игру копируются только даты и факты (не защищаются авторским правом), не тексты. Подробности — в «Источниках».
8. [Предп.] Источники открывались через поиск; ни одна страница не загружалась целиком через fetch. Строки с `U` в колонке достоверности — даты по общеизвестным справочным данным, не сверенные постранично. Их нужно сверить critic'ом до заморозки (#3.3).

## Анализ

### 0. Соглашения

- Даты ISO. `~` — день не подтверждён. «Рек.» — какую дату брать в игре (предложение).
- Достоверность: **H** — день подтверждён минимум двумя независимыми источниками либо первичным текстом; **M** — месяц/год подтверждены, день по одному источнику или сводным справочникам; **L** — требует проверки.
- Источники указаны ключами из раздела «Источники» (П — первичный, В — вторичный).
- Флаги: `war-related`, `disputed`, `partial`, `no-effect` (событие не меняет owner/controller, дано для полноты — game-designer может отбросить).
- Полиции id: существующие из `polities.yaml` (USA, GBR, FRA, SUN, DEU, AUT, POL, YUG, ITA, GRC, FIN, ALLIED_BERLIN, ALLIED_VIENNA и др.); новые предложены **[Предл.]** курсивом нет, помечены `NEW:`. Для не-европейских ядерных стран использованы коды ISO-3 (CHN, JPN, KOR…), финальные коды фиксирует T4.
- Стартовое состояние 1945-10-01 для не-Европы в `owners.yaml` отсутствует (только Европа): событиям даётся `from`, предполагаемый из документов [Предп.].

#### 2.5 Подсчёт

- Ядро: C01–C34 = **34** строки (из них `no-effect`/опции: C04, C10, C11, C23, C24, C25, C29 = 7; дубль C18/B106).
- Широкий список: B01–B134 минус пустые/дубли (B19, B106, B112, B115, B133, B134) = **128** строк. Из них `war-related`: B09, B10, B16, B17, B21, B22, B29–B34, B39–B41, B56, B93–B95, B113, B114, B117, B45 (≈ 25), исключены как M2: B11, B114.
- Итого 34 + 128 = 162 строки; минус 7 `no-effect` и 2 исключённых (M2) ≈ **153 рабочих смены** для 1.6a. Порядок дат внутри таблиц не хронологический (группировка по региону): загрузчик сортирует сам.
- Известные недочёты черновика: C18 и B106 — дубль (Тенда/Бриг); C32 (Северная Буковина) в Паризском договоре с Финляндией относится к Петсамо, Буковина — другой договор (1945-06-29 с Румынией не оформлялась; в 1947 закреплена Парижским договором с Румынией); строки-метки B19, B112, B115, B133, B134 пустые.

## Риски

- Дата зависит от выбора юридического момента (подпись, вступление в силу, фактическая передача): разброс до лет (Пондишери 1954/1956/1962, Кёнигсберг 1946/1970). Закрывается колонкой «Рек.» и тремя датами.
- Спорные случаи (Тайвань, Кашмир, Сикким, Эритрея, Коморы) — политически чувствительны; игра обязана показывать оба статуса (owner vs controller).
- Лицензии: даты и юридические факты не защищены; копировать нельзя тексты договоров из площадок с ограничениями (см. «Источники»).
- Объём: не все строки сверены постранично (см. краткий вывод п.8).
