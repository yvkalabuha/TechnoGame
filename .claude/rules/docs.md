# Documentation rules

- Documents for the owner (vision, design, ADR, reports, handoffs, tasks) are written in Russian. Identifiers, file names, code and technical terms stay in English.
- Mark claims: **[Факт]** (with source), **[Предп.]** (assumption), **[Предл.]** (proposal). Never present a proposal as an approved decision.
- Sources: URL + access date.
- Registry items (MS, TASK, HYP, EXP, ADR, RR) have YAML frontmatter; create them with `/new`. Only the Orchestrator changes `status:`.
- Old decisions are never deleted: mark them SUPERSEDED / superseded and give the reason and the replacement.
- An ACCEPTED ADR is immutable except its `status:` and `superseded_by:` lines.
- `development/BACKLOG.md` and the active-tasks block in `CURRENT_STATE.md` are generated by `registry.py index`; never edit them by hand.
- Keep documents short. One document per purpose; do not duplicate content, link to it. No empty placeholder sections.
