# MS-M0 — Headless-прототип симуляции и Simulation Lab

## Цель
Проверяемое ядро без графики: несколько государств, упрощённые наука и экономика, Simulation Lab с массовыми запусками и регрессиями. Решение владельца (DECISIONS_LOG #3).

## Критерии завершения (черновик — утверждается вместе со списком задач)
- [ ] Kernel: тик, детерминированный RNG, fixed-point, хеш состояния; тесты L1/L2 в CI.
- [ ] Core: минимальные модели науки и экономики по утверждённым гипотезам.
- [ ] Lab: прогон по манифесту, batch и Monte Carlo, метрики, сравнение с golden-run.
- [ ] Хотя бы одна гипотеза проверена экспериментом с полями воспроизводимости.
- [ ] Бенчмарк тика зафиксирован.

## Задачи
Формируются после PHASE E (пилот) и PHASE F (фундаментальная модель).

## Зависимости
PHASE E, PHASE F; ADR-0003…0008 до ACCEPTED.
