## 4. Разбор
- [Факт] Возврат за месяц = `S − Σ r`, где `r = c_eff·M·s^0,6/T_eff`, `c_eff` делится на `(1 + k_K·Kmix/K_ref)` — у лидеров с большим `K` узлы ещё дешевле. Бюджет растёт с экономикой, цена узла — нет, отсюда 94 % возврата USA в 2005–2030 (база).
- [Факт] Покрытие `u` одно на страну: дорогой новый узел в слоте даёт месяцы недостачи (у USA 16–38 % месяцев после 1990 при кривых A–C) и **замедляет все 7 слотов**, а в месяцы на старых узлах деньги снова возвращаются. Поэтому возврат падает медленнее, чем растёт цена (×16 → 54–60 %, ×256 → 31 %).
- [Предп.] Рычаг, растущий с богатством, — **число слотов**: USA и SUN держат 7 институтов при потолке `Cmax_c(t) = round(4 + 8·√b) + ⌊(год − 1945)/10⌋` = 16 у USA в 1990-х по первой части (SCIENCE_SLOTS §2a; часть `⌊0,25·S/u_inst⌋` не проверена). Правило ИИ «строить институт при устойчивом излишке» (DEBT-0115: «правило стройки при излишке») превратит деньги лидеров в параллельные узлы, не трогая цену для малых. Не замерено: правило в Core, в Lab его нет.
- [Предп.] Риск правила стройки: дерево 1990–2030 исчерпается раньше (в базе USA к 2030 знает 60 из 73 новых узлов при 7 слотах). Поэтому сочетание «стройка + умеренная эра-цена B min» — кандидат для следующего пилота.
