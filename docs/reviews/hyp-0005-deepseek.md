- [high] Events 'by date and structural conditions' contradict MS-M1's explicit exclusion of conditional events: The Hypothesis and the 'Объект гонки' section say scenario events act 'только по дате и структурным условиям' (#328, #340–#342), and S4/S5 depend on this. The approved milestone MS-M1 (#333) states in 'Вне M1 (явно)': 'События по условию и любая реакция событий на состояние мира: в M1 только дата, без окна и разброса (#328)'. The HYP neither quotes a superseding decision nor notes the conflict. The difference is substantive: structural preconditions let the simulated state gate an event, which is the 'scripts predetermine the leader' mechanism (RISK-0011) the design claims to exclude, and it changes what S4/S5 measure.
- [high] The one authorised start correction is selected after seeing the pilot outcome: The floor pilot on 22001–22100 prints the share of seeds with a single t1 leader; if it is ≥90%, one start correction is allowed 'only within the documented interval', with no rule mapping the pilot result to a value. The analyst can therefore choose the point in the interval that avoids the floor and re-pilot on the same 100 seeds — tuning the primary variance source on the outcome, on the very seeds the next bullet forbids tuning chg30/Neff on. This is not hypothetical: EXP-0002 found start sensitivity dominating (critic finding 6: START_PERT chg 0.40, START_SYM 0.78), so this degree of freedom can determine the study's outcome.
- [high] The floor path yields no pre-registered outcome and makes K7 unclosable: Rule #335: if ≥90% of pilot seeds have the same t1 leader after the single correction, 'серия не запускается, вопрос возвращается владельцу'. The outcome enum contains only supports/refutes/inconclusive/invalid, and MS-M1 K7 accepts only a valid supports or refutes. On this path no hypothesis outcome is ever produced, so M1 cannot be closed, and no document says what is recorded. MS-M1 open question 2 asks the owner exactly this; HYP-0005 neither resolves it nor flags the dependency.
- [high] 'Supports only with scripts' is asserted to close K7, but MS-M1 still lists this as an open critical owner question: The S4 rule says this case 'закрывает K7 с оговоркой', citing #334. - [medium] 'Not random' is not operationalised: no baseline distinguishes structure from start sensitivity: The claim is 'ни предрешён, ни случаен'. 'Not predetermined' maps to P1; 'not random' maps only to Neff_c ∈ [1.6; 4.0] and flip ≤ 0.10, i.e., limited diversity, which any draw among 2–4 challengers satisfies. In M1 the only inter-seed randomness is the start perturbation (events are date-only, the AI is deterministic with a fixed day offset), so 'random' and 'sensitive to start noise inside source uncertainty' are indistinguishable by the declared metrics. EXP-0002 already showed that start sensitivity can dominate the outcome, and the K8 counterfactual is explicitly outside the outcome.
- [medium] The `invalid` criteria reference run.json fields that do not exist: The rule makes a run invalid if 'data_hash/метка таблиц отличаются в любом run.json' and requires that 'список грязных файлов печатается'. As written, the criterion cannot be evaluated mechanically, and the reproducibility improvement over deviation #265 depends on a capability that is not built.
