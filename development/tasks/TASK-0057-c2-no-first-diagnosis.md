# TASK-0057 — Разбор C2: известно, но не в серии

## Цель
Найти причину, по которой этап калибровки C2 ломается во всех точках (`d_C2` = 1): ★-PRC tier-4 известен стране, но доля пар без первого выпуска (`no_t_first`) — 0,75–0,94. Предложить исправление (дефект, правило ИИ или постановка C2) для gate.

## Описание
1. Диагностика на настоящем Core по прогонам T12 (`lab/results/t12*`) и малым новым прогонам: для каждой пары (актор, tier-4 процесс) — когда известен, был ли проект изделия с этим процессом в составе, допуск, линия, выпуск; где цепочка обрывается (знание → проект → допуск → серия). Причины по долям.
2. Сверить с определением C2 в спеке (`slice-jet-aviation.md` v0.28 §8.2) — не ошибка ли постановки (например, процесс известен, но ни одно изделие среза его не требует до горизонта).
3. Варианты исправления с последствиями (Core/данные/спека/ИИ, golden, пре-регистрация) и рекомендация.
4. Учесть #236 (C4 исключён из M0): какие этапы калибровки остаются и в каком порядке.
