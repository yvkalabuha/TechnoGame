Дизайн v2 — ревизия #302

Предложение ui-art-director, ждёт выбора владельца. Здесь: три варианта палитры на одном куске клиента, шкала скруглений и состояния, набор иконок времени, главное меню, настройки. Чертёжный шрифт в макете заменён на Jura (OpenGost Type B нет в Google Fonts). Карта и дерево схематичны, не география. Цвета тревоги alarm, warn, command одинаковы во всех вариантах.

1. Три палитры на куске клиента

Что смотреть: красная плашка «ОТКАЗ», янтарная «РАЗРЫВ», синие маршрут и приказ остаются единственными насыщенными пятнами; всё остальное цвет «подкраски» (тинты, полосы разделов, ветви дисциплин). От A к C растёт насыщенность и доля площади под цветом, не число цветовых ролей.

A · «Подкраска» (умеренная)

Цвет только в тонких полосах и линиях. Тинты государств на 30% насыщеннее v0.2; заливок панелей нет. Самое близкое к текущему клиенту.

2. Форма: скругления, фокус, наведение

Скругление применяется к контейнерам и контролам и не применяется к знакам данных (узлы ○ □ ◇, полосы потоков, штриховка, рамка штампа). Образ из чертежа: сопряжение, скругление радиусом R на углу контура. Внутренний радиус = внешний − поле (6 → 4 → 2), так вложенные рамки остаются концентричными.

r0 · 0
r1 · 2 px
r2 · 4 px
r3 · 6 px

r0 — карта, схемы, штамп, полосы, зоны графика · r1 — флажок, ярлык-плашка, клавиша, шкала-«стекло» · r2 — кнопки, поля, сегменты, пункты меню, чипы · r3 — панели, вклейки, диалоги, подсказки. Крайний пример — вложение r3 → r1.

Состояния кнопки

Фокус стал сплошным двойным кольцом (тушь + зазор листа): пунктир 2/2 не рисуется по скруглённому контуру в Godot StyleBox, а кольцо видно на любой подложке, включая насыщенные тинты. Фокус не окрашивается: синий — только приказ.

3. Иконки времени

Сетка 20 du, одна линия 1,5 du без заливки, прямые углы (miter), торцы butt: как чертёж, без скруглений внутри знака (скругляется только контейнер-кнопка). Темп — шкала из трёх засечек растущей высоты (как градуировка линейки): заполнено столько, сколько ступеней включено. Слово темпа остаётся рядом, число — в подсказке.

4. Главное меню и настройки (переключатель палитры)

Главное меню: два состояния

Слева: старт игры, меню поверх живого глобуса (медленно вращается, не интерактивен). Справа: то же меню по Esc внутри игры: поверх приглушённого клиента, добавлены «Продолжить» и «Сохранить». Выбранный пункт — цвет домена только в 3 px кромке и иконке; тревожных красок в меню нет.
