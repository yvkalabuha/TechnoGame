## 3. Компетенция и скорость (ограниченно)

[Предл.] Для приоритетного узла `r` области `d`, закреплённого за институтом `i`: `m_inst(i,r) = 1 + 0,05·(c(i,d) − c_ref(a,d,t)) + e_lead`, где `c_ref` — компетенция **лучшего** института области на траектории ИИ (IP2 6.1; нормировка, чтобы AI-траектория давала `m = 1` и калибровка годов #457/#458 не менялась), `e_lead ∈ [−0,04; +0,04]` (#461; IP2 6.2).
- Пределы: `c − c_ref ∈ [−4; +2]`, поэтому ограничиваем `|0,05·(c−c_ref)| ≤ 0,10`; **общий |m − 1| ≤ 0,14 < 0,15** (#462). Затухание у границы по годам Y = 3 (IP2 6.3) остаётся.
- Узлы вне приоритета: `m = 1` (общий фон страны). Доля IP2 «ступень 6 + профиль 5 + руководитель 4» заменяется на «компетенция 10 + руководитель 4»: ступень и профиль IP2 становятся **компетенцией института** (ступень = рост компетенций, профиль = набор областей). Это изменение IP2; без решения владельца IP2 не правлю (OPEN 3).
- Для узла пути приоритетной цели берётся компетенция назначенного института **по области самого узла** пути (слабая область замедляет путь).
- [Предп.] Значения 5 %/ступень и 0,14 — проектный выбор [Предп.] как и 15 % (#462).

### Как растёт компетенция
[Предл., #192: специализация меняется медленно] (а) **опыт**: за каждый завершённый приоритетный узел области, назначенный институту, накапливается `exp`; порог на ступень +1 растёт выпукло (≈ 8, 15, 25, 40 узлов-равных); (б) **проект «углубить область»** (национальный проект): +1 к компетенции в одной области за ≈ 5 лет, цена как у малого проекта (≈ 3 % бюджета науки в год) [Предп., economy-analyst]; (в) **забывание**: без работы в области 20 лет −1 [Предп.]. Максимум один рост на область за 10 лет; предел 4. Соотношение: компетенция 0–4 за партию 1945–2030 меняется на 0–2 ступени в 1–2 областях — «медленная специализация».

## 4. Назначение приоритетного узла

2. **Правило покрытия.** [Предл.] Можно назначить любой институт, в том числе с компетенцией 0 (скорость −10 %, с пометкой «не профильный»): жёсткий запрет сделал бы слоты бесполезными в расширяющихся областях и вёл бы к ощущению «заперт». Альтернатива: запрет при 0, см. OPEN 1.
3. **Свободный слот.** Один институт — один приоритетный узел. Занятый слот можно **переназначить** (прогресс узла не теряется, штрафа нет — как в A1 п. 3г — но пауза **12 месяцев** до следующей смены этого слота, чтобы не микроуправлять) [Предл.].
4. **Узел вне фронта.** Если выбран узел за непройденными предпосылками, его **путь во фронте** (узлы замыкания, уже доступные к изучению) входит в приоритетную группу и получает деньги первыми (разд. 5). Узлы пути серые «нужно для цели»; слотов не занимают.
5. При завершении узла слот освобождается, автопауза «Институт N свободен» ≤ 1 в игровой год на страну.
6. Сколько слотов: `N_slots = число институтов страны` (#485), потолок по данным.

## 5. Финансирование: деньги первым (численно)

Обозначения по коду (`KnowledgeSystem.ProgressRate`, `ComputeFull`): `S = ResearchBudget(a,t)`; фронт `F`; `w_r = Priority(a,r,t)·J(a,r,t)`; `wsum = Σ_{r∈F} w_r`; `CEff(r)` включает множитель опережения.
Сейчас: `Δprog_r = S·(w_r/wsum)/CEff_r`.

**Новое** (приоритеты по порядку списка игрока `k = 1..K`, `K ≤ N_slots`):
- Группа `G_k` = узлы фронта, входящие в замыкание цели `k` (сама цель, если во фронте; узел, уже занятый более ранней группой, остаётся там). `W_k = Σ_{r∈G_k} w_r`.
- Естественная доля: `nat_k = S·W_k/wsum`. Спрос: `dem_k = κ·nat_k`, **κ = 2** [Предп.; Lab].
- Выделено: `A_k = min(dem_k, S − Σ_{j<k} A_j)`; внутри группы `alloc_r = A_k·w_r/W_k`.
- Остаток: `R = S − Σ A_k`; остальной фронт: `alloc_r = R·w_r/(wsum − Σ W_k)`. Если остальных нет, остаток тратится по правилу ядра (сгорает, §3.4 спецификации).
- Скорость: `Δprog_r = alloc_r·m_inst(i,r)/CEff_r` (`m=1` вне приоритета).

Пример: `S = 100`, 10 узлов фронта с равным весом, 3 приоритетных узла (по одному в группе), κ = 2. `nat = 10`, `A = 20×3 = 60`; остаток 40 на 7 узлов: **5,7 вместо 10** (−43 %). Приоритетные узлы идут вдвое быстрее (при `m=1`); дорогое опережение уменьшает выигрыш через `CEff`.

Свойства [Предл.]: (1) `Σ alloc ≤ S` (инвариант I4); (2) при κ=1 и `m=1` результат совпадает с текущим бит-в-бит; (3) при отсутствии приоритетов — бит-в-бит как сейчас (ИИ-мир не меняется); (4) приоритет **не** берёт деньги сверх `S`, поэтому «другим направлениям» достаётся то, что осталось: это (#484) и есть «перераспределение», без отдельного штрафа; (5) при дефиците денег (`S` мало) приоритетные узлы первыми «выбирают» деньги по порядку списка. Реализация в ядре: один проход по фронту + K групп, O(|F|·K) в месяц — копейки.

## 9. Риски, проверки Lab, интерфейсы
**Риски.** (1) Доминирующая стратегия «κ на самую быструю область»; смягчение: κ=2, цена опережения до 10×, шаг 5 %. (2) Нечитаемость при 6 слотах USA: одна карточка = один узел, порядок = очередь.
