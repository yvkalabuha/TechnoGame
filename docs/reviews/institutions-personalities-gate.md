# Gate черновика INSTITUTIONS_PERSONALITIES (#459, #460), 2026-11-24

Критик, защитник, DeepSeek (third). Полные ответы — в сессии Orchestrator.

## Высокие (общие у критика и защитника)
1. Коридор ±15 % взят из RR-0012/RR-0011 D15, где он ограничивает срок и риск проекта КБ, а не скорость знаний, и D15 открыт. Решение #206 ограничивает влияние руководителя сроком и администрированием — `m_leader` на скорости знаний его расширяет (D1 владельцу).
2. «Траектория» для `m_dev` не определена: ИИ-страны тоже решают за институты; база — политика ИИ по умолчанию, одна механика для ИИ и игрока; стартовые ступени нормировать к 1.
3. Профиль `spec` дублирует `Priority`/`w_n` и `SetEffortFocus` (RR-0012 D17): делать профиль как вес приоритета по дисциплинам (сумма сохраняется), не как множитель скорости.
4. Насыщение: один `spec` занимает весь потолок — ступень и руководитель становятся невидимыми; доли потолка по источникам или мягкое насыщение.
5. Потолок по ступени на деньги (`tier` ceiling) — второй нелинейный канал вне ±15 %; убрать из среза или доказать, что на историческом пути не действует; КБ не финансировать из доли знаний.

## Средние
- ±15 % на скорость ≠ ±15 % на итог (снежный ком через `K_d`/`c_eff`): потолок задавать в годах ключевых узлов; в UI «≈ N лет впереди».
- Ширина коридора по странам без источников и против цели «догоняние» (#422): одинаковый потолок, разница из данных.
- Подставной множитель — в Lab-адаптере (inputs), не в Core (#459: кода нет); проверка по дисциплинам (передано simulation-engineer).
- Срез v0: профиль + `tier_up` + вымышленные руководители; реальные люди — следующим слоем (#218, #219).
- DeepSeek: противоречия частоты `tier_up`, эффекта `funding_priority`, `branched` против нейтральности, UI показывает скрытый множитель лидера, критерии Lab без порогов, `spec` пресет или вектор, судьба избытка денег сверх потолка, организация в пуле личностей.
