# Gate RR-0017 / RR-0019 — critic (2026-11-18)

Common: both are written for a monthly tick (ADR-0019 makes it daily, #344/#345); both lack rules for regions where owner ≠ controller (ADR-0020, #349/#350); v1 scope is unrealistic for one developer in M2. No direct conflict with #321/#322.

## RR-0017 (intelligence)
- **high, §2, §3 T6.** Monthly `intel.expose` roll keyed by month. Fix: intelligence cadence in days (roll on day 1, RNG key `(seed, tick=day, intel.expose, (o,t))`); AI decisions (turn/expose, `dir`, budget) in the weekly slot (#344).
- **high, §2 2c, §4 A-INT-evt.** A scandal (#256) is a random event, but ADR-0019 and #342 only have `ScenarioEventSystem` without RNG. Fix: a separate stochastic event system (own stream P05, own writer `support`, merge order), described in an ADR before M2; #342 applies to scripted events only.
- **medium.** Depends on a non-existent "PRC/France milestone" and on RR-0015 (now RR-0021: `Regime`, `Alignment`, `support`, `legitimacy`). Fix: `aff = 0` until RR-0021 lands; check the model works on `fund` alone.
- **medium, §2 `Net[o,t]`, `ci_eff`.** No rules for inactive and joint polities (ADR-0020): targets DEU/KOR without government, occupation zones, actors appearing or vanishing by events. Fix: a target is only an active actor; rules when the target dies, splits (FRG/GDR) or is absorbed; `GDP_t` = output of regions it controls (#349).
- **medium, risks, #260.** v1 has 4 outputs, turned networks, source cross-checks and AI rules — too much. Fix (owner, changes #260): M2 observation, counter-intelligence, network growth, scandal; M3 `steal`; later `dis`/`turned`.
- **medium, §1 T5.** Key calibration ("theft gives 1–2 years", ≥ 70 %) has no computed source; Holloway, COCOM, Double-Cross, Walker "not re-checked". Fix: research-scientist verifies; T5 is a HYP, not an acceptance criterion.
- **low.** `eff = N·maturity` in the summary vs `conf` in §2 while `eff` is still used in `steal` cap, `p_expose`, turning; open question 2 closed by #261; duplicate P05 row; rounding of `c = round(φ·s)` undefined.

## RR-0019 (logistics, communications)
- **high, §2 (`cap` t/month, `spend_max` per month, monthly BPR smoothing).** Contradicts ADR-0019/#345. Fix: annual rates sliced by day; link opening and blockade as events applied in merge D−1 (#347); Dijkstra recomputation in post by network version (memo like ADR-0020).
- **high, §2 cross-country edges, §5.** "Country" border undefined when controller ≠ owner (Berlin, Vienna sectors, zones, east of Oder–Neisse). Fix: a link belongs to and is paid by the controller of its source region; cross-country = different controllers; a controller change triggers Φ recomputation.
- **medium.** Replacing `m_d` with Φ changes E1 and the M1 golden and may invalidate the M1 race outcome (#332/#334). Fix: equivalence test — default network Φ reproduces `m_d = m_1·d` within tolerance; otherwise a model change with HYP re-check.
- **medium.** v1 too big (three modes, Φ, congestion, 6-level `comm` with 4 multipliers, airfields, fleet, build animation). Fix: M2 = rail, road, sea with cap/upkeep/q and Φ; `comm`, airfields, visualisation in M3.
- **medium.** No PD/CC BY data on the 1945 network (ADR-0009); the default "1 port + 1 rail + 1 road" drives start asymmetry (#329). Fix: research-scientist data task before M2; until then per-region-type parameters flagged in START_PERT.
- **medium, network management.** Allocator `size_a·size_b·gap` amplifies strong regions; Lab checks only mode dominance. Fix: Lab metrics — quality gap large vs small nodes over 30 years; does `p_mode` or a corridor change the race outcome at equal `B_inf`.
- **medium, `λ` loss, buffer `β`.** Unclear whether E1/E2 have stocks `β` can tie; otherwise fake mechanic. Fix: bind to an E1 column or drop from v1.
- **low.** Sources: BPR 1964 URL unchecked, +700 % containerisation from a working paper, Jensen 8 %/4 % and Statista secondary, Red Ball Express from Wikipedia. Determinism: `util^4` overflow in Fx6; `e^{−x}` approximation needs a hashed data table. Open questions start at 4.

Before M2: cadences in the daily model; ADR on a stochastic event system; controller rule for networks and links; v1 staging of intelligence (owner, changes #260); fate of `m_d` and Φ equivalence test; 1945 infrastructure data source.
