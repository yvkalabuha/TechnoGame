# Картинки областей (решение #352)

Свои чертежи в стиле `../node-schematics/`: фон `#1E4673`, сетка 20 px `#3A6491`, рамка `#B9CBDA` 0,75, контур `#EEF2F0` 1,5, вторичные `#EEF2F0` 1, осевые и размерные `#B9CBDA` 0,75. SVG 320x120, без текста (локализация не нужна). Левая кромка 4 px — роспись домена области (`#D8CCEE` наука, `#BFE6E5` производство, `#EAD9A3` финансы, `#C3D8EA` силы, `#F0C9E0` разведка, `#CFE6AA` политика, `#EEF2F0` проекты и карта). Сюжет читается в крупных формах: силуэт, не мелкая деталь (проверка — уменьшение до 160x60).
