# HYP-0005 rev 3 — пересчёт мощности после #356–#359

Скрипт: `lab/analysis/hyp0005_power.py` (stdlib, детерминирован, seed ячейки = 50000 + i). ## Краткий вывод
- [Факт: симуляция] План 300→600 с решением по точке на 600 (#359) — почти идеальный порог по истинному `chg30`: при `chg30` ∈ [0,25; 0,45] `supports` ≥ 99%, при 0,10 и 0,60 — 0%. На краях полосы (0,20 и 0,50) — монетка (≈ 50/50), ширина переходной зоны ≈ ±0,03.
- [Факт: симуляция] Ранняя остановка на 300 срабатывает только далеко от полосы: `chg30` = 0,10 → 61%, 0,60 → 34%; внутри [0,15; 0,55] — ≤ 2%.
- [Факт: симуляция] Почти все `refutes` на 600 у краёв полосы — «серая зона» (caveat): точка вне pass, CI не целиком вне fail. В ячейках 0,20 и 0,50 caveat = вся доля `refutes` (≈ 48%).
- [Факт: симуляция] Доля возвратов A→B→A на P1/P3 не влияет (P1 считает `ever`), она влияет только на `chg_end` и оценимость P2. P2 не оценён на 600 только при `chg30` = 0,10 и возвратах 0,4 (13%).
- [Факт: симуляция] Связь P1/P3 после #357: при доле `flip` среди менявшихся 0,3 P3 становится главным условием провала уже при `chg30` ≥ 0,3 (`refutes` 18% при 0,3; 92% при 0,4).
- [Предп.] Полоса [0,20; 0,50] подходит к `ever` без сдвига, **если** #323 задумывался как «хоть одна смена»; если владелец имел в виду конечное состояние (как в HYP-0002), эквивалент по `ever` — [0,20; 0,50] / (1 − доля возвратов). Это Q42, ниже только данные.

## Модель
Единица — seed. Траектория лидеров записи (после гистерезиса 12 мес.): с вероятностью `chg30` есть ≥ 1 смена; среди менявшихся доля `f` имеет > 3 смен (4 + геом.), остальные 1/2/3 смены (0,6/0,25/0,15); доля `r` возвращается к `L(t0)` (≥ 2 смены), остальные кончают у претендента из 7, веса геометрические под заданный `Neff_c`. Общий `L(t0)` у всех seeds. Метрики P1–P3 считаются по траекториям по определениям HYP-0005 rev 3.
Правило: шаг 300 (z = 2,18): `refutes`, если Wilson P1 целиком вне [0,15; 0,55] или нижняя граница P3 > 0,15. Иначе шаг 600 по точке: P1 ∈ [0,20; 0,50], P3 ≤ 0,10, P2 ∈ [1,6; 4,0] при ≥ 30 seeds с конечной сменой. Caveat = `refutes` на 600, где ни одно сработавшее условие не является CI-fail (P2 — bootstrap 400, 97,1%). Повтор (#43): n = 400, по точке.
Не моделировано [Предп.]: потеря смен, начатых в последние 12 мес. (при постоянном риске и `chg30` = 0,5 ≈ 0,012 — сдвиг вниз); корреляция возвратов и `flip`; разные `L(t0)`.

## P1 [0,20; 0,50] и определение `ever` (Q42, данные)
- [Факт: арифметика модели] `chg_end = chg30 · (1 − r)`. Полоса по `ever` [0,20; 0,50] соответствует по конечному состоянию: r = 0 → [0,20; 0,50]; r = 0,2 → [0,16; 0,40]; r = 0,4 → [0,12; 0,30].
- Обратно: если #323 задумана по конечному состоянию, эквивалент по `ever`: r = 0,2 → [0,25; 0,625]; r = 0,4 → [0,33; 0,83]. Доля возвратов до прогонов неизвестна, поэтому эквивалентный сдвиг не фиксируется заранее без предположения о `r`.
- Порог по `ever` не может стать «строже» конечного: при одной и той же модели `ever` ≥ `chg_end`, поэтому старая полоса на `ever` скорее даёт P1 fail сверху, чем снизу; HYP-0002 (`chg_end` 0,052) по `ever` проваливается снизу только если `chg30` < 0,15 (таблица: P1 снизу ≈ 1 при `chg30` ≤ 0,15).
- P3 (≤ 0,10) по-прежнему считается по `ever`-траекториям; при сдвиге P1 вверх (r = 0,4 → верх 0,83) P3 станет обязывающим условием при умеренной доле `flip` (см. чувствительность), т.е. сдвиг P1 без пересмотра P3 почти ничего не расширит.
- Вывод для владельца [Предл.]: выбор — (а) оставить [0,20; 0,50] по `ever` (полоса = «хоть одна смена», как буквально в #323/#357); (б) сдвинуть по фиксированной `r` (нужно предположение); (в) задать P1 на `chg_end`, а `ever` печатать — противоречит #357.

## Что важно для решения
- [Факт: симуляция] Ошибка решения сосредоточена в ±0,03 от краёв полосы; вне её — ≤ 1% неверных исходов. Повтор n = 400 ведёт себя почти так же (на краях ≈ 50%, переход немного шире).
- [Факт: симуляция] Caveat ≈ доля `refutes` в любой ячейке у края; caveat > 0 там, где истинное значение в зоне между pass и fail — так задумано (#359), но владельцу стоит знать: `refutes` с caveat почти всегда означает «истина у края полосы».
- [Предп.] Сетка `Neff_c` 1,3 и 4,5 из rev 3 сама лежит в серой зоне P2 ([1,3; 1,6) и (4,0; 5,0]): `refutes` там — по точке с caveat почти всегда.
