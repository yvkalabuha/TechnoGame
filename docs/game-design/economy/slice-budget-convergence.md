## 1. Что такое «бюджет» и какая цель
- [Факт, `docs/research/data/jet-slice/scenario_1945.md`, R-BUD] `budget_index = gdp_a/gdp_USA × (доля авиации_a / доля авиации_USA)`, доля авиации у всех одинакова (оценка: открытого ряда с лицензией нет). Это индекс военно-авиационных программ, пропорциональный ВВП при равной доле.
- **Выбранная мера цели: доля ВВП страны от USA (Maddison, 2011 $ ППС).** Обоснование [Предл.]: (1) единственный ряд с лицензией CC BY, который я открыл и прочитал; (2) совпадает с определением стартового `budget_index` (R-BUD) — цель и старт одной меры; (3) военная доля (SIPRI) для СССР 1945–1991 не имеет надёжного ряда и меняется в разы между оценками.
  SIPRI https://www.sipri.org/databases/milex в расчёт **не входит** (не открывался; 2022: USA 877, RUS 86, GBR 68, FRA 54 млрд долл. — по памяти, [Предп.]).
- Следствие: `s_a` = относительный ВВП × (допущение равной доли авиации). Для SUN реальный военный бюджет в холодную войну выше, чем по ВВП [Предп.]; для Швеции доля авиации выше средней [Предп.]. Это ошибка меры, а не параметров.

## 3. Правило А (калиброванная сходимость к рубежу USA)
**Обозначения (одно определение).** `B_a(t)` — бюджет на снимке `Current` месяца `t`; рубеж `F(t) ≡ B_USA(t)`, рост рубежа `B_USA(t+1) = B_USA(t)·(1+g_m)`, `g_m = ⌊g/12⌋` (как `BudgetMath.Next`). Максимума нет: лидер — USA по определению (калибровочный якорь).
```
B_a(t+1) = max(1 raw, (B_a(t) + λ_m·(s_a·B_USA(t) − B_a(t))) · (1 + g_m)),   λ_m = ⌊λ_pa/12⌋
```
- Обе величины читаются из `Current`, пишутся в `Next` своей строки: порядок акторов не влияет. USA: `s = 1`, ряд совпадает с нынешним `BudgetMath.Next`.
- Доля `r = B_a/B_USA`: `r_{n+1} = r_n + λ_m(s − r_n)`, неподвижная точка ровно `s`; `r_n = s − (s − r0)(1 − λ_m)^n`. Монотонно, без колебаний; при `s ≤ 1`, `λ_m ≤ 1` бюджет не обгоняет USA.
- Это замкнутая функция месяца (`n`): три числа на страну (`r0` из сценария, `s`, `λ`).
- Реализация (`BudgetMath.NextConverging`): рост рубежа `g_USA` применяется к актору (как `g_m` выше), затем результат зажимается так, чтобы доля не пересекала `s`: цель следующего месяца `s·Next(B_USA, g_USA)`; бюджет не ниже цели, если был не ниже, и не выше, если был ниже (точное сравнение целых `Int128`). `Next` не читается.

## 6. Что увидит игрок
- [Факт, `m-play-horizon-2030.md`] Неиспользованный остаток оснастки 0,67–0,85 до 1977 и 0,94–0,98 после 2000: деньги почти не ограничивают развитие. Место зависит от поколения на вооружении, а не от размера парка.
