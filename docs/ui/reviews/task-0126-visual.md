3. Тики часов декад (A2). В центре видны тики толщиной около 2 px, засечки различимы. Точное измерение по PNG не делал [Предп.: ок]. Прошу в отчёте разработчика числом: толщина в физических px.
4. Титул без HUD на 100 % и 150 %: PASS. Ни верхней полосы, ни рейла, ни времени; панель меню масштабируется (150 %: панель 480 px, текст крупнее), вмещается. Мелочь: на кадре 150 % у верхнего края глобуса обрезана подпись страны (видна только нижняя часть).
5. "№2": без кадра подписи согласие невозможно. По существу: отказ добавлять имя принимаю, если подпись остаётся однозначным номером, а имя доступно в списке фронтира и всплывающей подсказке (имя в подписи на плотных кольцах дало бы наложения, см. п. 2). Условие: подсказка открывается наведением и с клавиатуры (A-пункты).
6. Низкий приоритет. В меню видна внутренняя ссылка "ADR-0013" ("Нужен код сохранений (ADR-0013)"). Игроку это ничего не говорит. Заменить на "Сохранения пока недоступны".
