### B1. `chg` по старому правилу r6 `fielded` на main (critic 4) [Предп.: приближение]
- Точно пересчитать нельзя. Не хватает помесячного ключа `K = (G, T, N, P)` по правилу r6 у каждой великой державы. Дамп D3 даёт только первый месяц каждого поколения по обоим правилам и эпизоды `G_L > G_r6` с `g_l_max`/`g_r6_min`. `actor_year` — годовой, `summary` — след лидера только по `fielded_L`. Точная печать требует колонки «лидер по r6» в `calib-print` и его повторного прогона на main 1…1000 (детерминированное воспроизведение, ≈ 10 мин). **Это новый прогон — пропущен.**
- Приближение из существующих данных. Допущения: `G_L` монотонна; внутри эпизода D3 `G_r6 = g_r6_min`; `T`, `N`, `P` при обоих правилах одинаковы; `lead_field` «=» означает полную ничью лидера с лучшим соперником. Самопроверка: без эпизодов D3 приближение воспроизводит `chg` 0,052 и гистограмму лет точно.
- Результат: **`chg_r6` ≈ 0,305** (305/1000, Wilson [0,277; 0,334]). Все 52 смены по `fielded_L` сохраняются. Новый лидер — GBR в 300 случаях из 305. Первая смена — 1965–1975, пик в 1968 году.
- Механизм: в 62% месяцев 0–359 USA держит лидерство ничьей («=»). Эпизод r6 (закрыта последняя линия процесса, `G_r6` падает 1→0 или 2→0) передаёт лидерство GBR, а ничья затем удерживает нового лидера. USA лидирует внутри эпизода ≥ 24 мес. подряд в 249 seeds.
- Разделение падения 0,37 → 0,052 (ориентировочно): **метрика ≈ 0,25** (0,305 → 0,052 на одной и той же новой динамике). **Остальное ≈ 0,07** (0,37 → ≈ 0,30) — динамика #247, I-OC + A41 и другие seeds вместе, без разделения. Вывод: смены, на которых выбран вариант сборки (#244), почти целиком были сменами-артефактами метрики, которые #246/#247 признали ложными. Вопрос «дефект модели или настоящее опровержение» этим не закрыт: настоящих (по `fielded_L`) смен в новой динамике мало, и это не артефакт метрики.
